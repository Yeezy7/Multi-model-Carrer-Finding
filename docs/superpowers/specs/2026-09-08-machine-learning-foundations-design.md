# 多模态算法工程师机器学习基础笔记设计

## 背景

`NOTES/多模态算法工程师/` 已经覆盖 PyTorch、Transformer、CLIP/SigLIP、优化器、损失函数、正则化、评测、检索和异常检测等内容，但传统机器学习中适合算法笔试与面试的基础考点没有形成独立入口。新增模块用于补齐统计学习、经典模型、泛化分析、评估方法和机器学习排错能力，并与已有多模态笔记建立衔接。

## 目标

- 新增 `NOTES/多模态算法工程师/机器学习基础/` 文件夹。
- 按知识点拆分 Markdown 文件，便于单独阅读和复习。
- 覆盖算法笔试及面试中的高频机器学习考点。
- 每个知识点都包含数学直觉、核心公式、算法流程、易错点和面向多模态岗位的联系。
- 对已有专题只做链接，不重复完整展开。

## 统一写作模板

每篇知识点笔记按以下顺序组织：

1. 一句话定义与适用场景。
2. 数学直觉和核心公式。
3. 算法流程、伪代码或最小示例。
4. 复杂度、优点、局限和选型对比。
5. 在视觉、多模态、检索或异常检测项目中的对应场景。
6. 高频易错点和常见误区。
7. 笔试题、面试题及简洁答题框架。
8. 自测 checklist。

## 内容边界

- 优先覆盖能在笔试中计算、在面试中解释、在项目中排错的知识点。
- 经典模型讲清核心机制与选型，不追求完整实现所有变体。
- 优化器、损失函数、正则化、归一化和对比学习的详细内容沿用现有专题，并通过相对链接关联。
- 不新增与当前目标无关的深度强化学习、GAN 全套或过深的优化理论。
- 不修改已有笔记内容；本次只新增机器学习基础文件夹及其中的 Markdown 文件。

## 验收标准

- 12 个 Markdown 文件全部存在且标题与目录一致。
- 学习地图能够串联全部知识点并指向已有相关笔记。
- 关键公式、指标定义、算法差异和复杂度表述前后一致。
- 笔试与面试题覆盖定义、推导、比较、计算、场景分析和排错六类问题。
- 新增内容不引入未解析的本地链接或明显占位符。
