# 文档加载与文本分割

## 一、文档加载器（Document Loader）

LangChain 提供了多种文档加载器，将不同格式的文件统一转换为 `Document` 对象。每个 Document 对象包含 `page_content`（文本内容）和 `metadata`（元数据，如来源文件名）。

### 1.1 TextLoader（文本加载器）

- **用途：** 加载纯文本文件（.txt）
- **关键参数：** `file_path`（文件路径）、`encoding`（编码格式）
- **返回：** `list[Document]`

### 1.2 CSVLoader（CSV 加载器）

- **用途：** 加载 CSV 格式数据
- **关键参数：**
  - `file_path` —— 文件路径
  - `encoding` —— 编码格式
  - `csv_args` —— CSV 解析参数（分隔符、引号字符、字段名等）
  - `source_column` —— 指定来源列（用于 metadata）
- **加载方式：**
  - `loader.load()` —— 批量加载，一次性返回所有 Document
  - `loader.lazy_load()` —— 懒加载，逐条返回（适合大文件）

### 1.3 JSONLoader（JSON 加载器）

- **用途：** 加载 JSON 格式数据
- **关键参数：**
  - `jq_schema` —— jq 表达式，指定抽取哪些字段
    - `"."` —— 抽取整个 JSON
    - `".name"` —— 抽取所有元素的 name 字段
    - `".[0].name"` —— 抽取第一个元素的 name 字段
  - `text_content` —— 布尔值，告知抽取的内容是否为字符串
  - `json_lines` —— 布尔值，是否为 JSONLines 格式（每行一个 JSON）

### 1.4 PyPDFLoader（PDF 加载器）

- **用途：** 加载 PDF 文件
- **关键参数：**
  - `file_path` —— 文件路径
  - `mode` —— 加载模式
    - `"page"`（默认）—— 每页一个 Document
    - `"single"` —— 整个 PDF 一个 Document
  - `password` —— 加密 PDF 的密码

## 二、文档分割器（Text Splitter）

### 2.1 为什么需要分割

大语言模型的上下文窗口有限，长文档需要切分为小块（chunks）才能送入模型。分割器的作用是将长文档智能切分为多个较小的文档块。

### 2.2 RecursiveCharacterTextSplitter（递归字符分割器）

这是 LangChain 中最常用的文本分割器，按分隔符优先级递归分割。

**核心参数：**

| 参数 | 说明 | 示例值 |
|------|------|--------|
| `chunk_size` | 每个文档块的最大长度（字符数） | 1000 |
| `chunk_overlap` | 相邻文档块之间的重叠字符数 | 100 |
| `separators` | 分隔符列表，按优先级排列 | `["\n\n", "\n", ".", " ", ""]` |
| `length_function` | 计算文本长度的函数 | `len` |

### 2.3 分隔符的优先级

分割器按顺序尝试用分隔符分割：
1. 先尝试 `\n\n`（段落分隔）
2. 再尝试 `\n`（换行）
3. 再尝试 `.`（句号）
4. 最后尝试空字符（按字符分割）

**设计思想：** 尽量在自然断句处分割，保持语义完整性。

### 2.4 chunk_overlap 的作用

重叠区域确保相邻文档块之间有上下文衔接，避免重要信息被切断。

**示例：**
```
chunk_size=100, chunk_overlap=20
块1: [0-100]
块2: [80-180]  （与块1重叠20字符）
块3: [160-260] （与块2重叠20字符）
```

## 三、Document 对象结构

每个 Document 对象包含：
- `page_content` —— 文本内容（str）
- `metadata` —— 元数据字典（dict），通常包含 source（来源文件名）等信息
