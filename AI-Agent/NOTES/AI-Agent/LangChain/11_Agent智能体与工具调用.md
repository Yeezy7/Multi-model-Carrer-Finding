# Agent 智能体与工具调用

## 一、Agent 核心概念

Agent（智能体）是能够自主决定调用哪些工具、何时调用、以及如何处理工具返回结果的 AI 系统。与传统链式调用不同，Agent 具备**自主决策能力**。

**Agent vs Chain 的区别：**

| 特性 | Chain | Agent |
|------|-------|-------|
| 执行流程 | 固定，按顺序执行 | 动态，由模型自主决定 |
| 工具调用 | 无或固定顺序 | 模型根据需要选择调用 |
| 适用场景 | 流程明确的任务 | 需要判断和决策的任务 |

## 二、Agent 创建与使用

### 2.1 创建 Agent

通过 `create_agent` 函数创建，需要提供：
- `model` —— 大语言模型实例
- `tools` —— 可用工具列表
- `system_prompt` —— 系统提示词（可选）
- `middleware` —— 中间件列表（可选）

### 2.2 工具定义

使用 `@tool` 装饰器定义工具函数：

**关键要素：**
- `description` —— 工具功能描述（模型根据描述决定是否调用）
- 函数参数 —— 工具的输入参数
- 返回值 —— 工具的执行结果（字符串）

**工具设计原则：**
- description 要清晰，让模型理解何时该调用
- 参数类型要明确（如 `city: str`）
- 返回值为字符串，便于模型理解

### 2.3 调用 Agent

```python
agent.invoke({
    "messages": [
        {"role": "user", "content": "用户问题"}
    ]
})
```

返回结果包含 `messages` 列表，记录了完整的交互过程：
- HumanMessage —— 用户输入
- AIMessage —— 模型的思考和决策
- ToolMessage —— 工具调用结果

## 三、Agent 流式输出

Agent 的 stream 方法支持流式输出，可以实时观察模型的思考过程。

**stream_mode="values"：** 返回完整的状态快照，包含所有消息。

**流式输出中可观察到：**
- `latest_message.content` —— 模型的思考文本
- `latest_message.tool_calls` —— 模型决定调用的工具列表

## 四、ReAct 框架

### 4.1 核心思想

ReAct（Reasoning + Acting）是一种 Agent 推理框架，要求模型严格按照以下循环执行：

```
思考（Thought）→ 行动（Action）→ 观察（Observation）→ 再思考 → ...
```

### 4.2 ReAct 循环

1. **思考：** 分析当前信息，判断需要获取什么
2. **行动：** 调用一个工具获取信息
3. **观察：** 查看工具返回的结果
4. **再思考：** 基于新信息决定下一步

### 4.3 ReAct 的约束

- 每轮只能思考并调用**一个工具**
- 禁止单次调用多个工具
- 必须输出思考过程
- 直到信息足够才给出最终回答

### 4.4 在 System Prompt 中引导 ReAct

```
你是严格遵循ReAct框架的智能体，必须按照「思考->行动->观察->再思考」的流程解决问题。
且每轮仅能思考并调用1个工具，禁止单次调用多个工具。
并告知我你的思考过程，工具的调用原因，按思考、行动、观察三个结构告知我。
```

## 五、Agent 的消息记录

Agent 执行后返回的消息列表记录了完整的交互过程：

| 消息类型 | 含义 |
|---------|------|
| HumanMessage | 用户的原始输入 |
| AIMessage | 模型的思考和工具调用决策 |
| ToolMessage | 工具执行的结果 |
| AIMessage | 最终的回答 |

**用途：** 可以分析 Agent 的决策过程，调试工具调用逻辑。
