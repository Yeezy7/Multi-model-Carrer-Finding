# 大模型 API 调用基础

## 一、调用流程总览

调用大语言模型的本质是通过 HTTP 请求向模型服务端发送对话数据，并接收模型返回的文本结果。整个流程分为三步：

1. **创建客户端（Client）** —— 初始化 SDK 客户端，配置 API Key 和 Base URL
2. **构建消息列表（Messages）** —— 定义 system、user、assistant 三种角色的消息
3. **发起请求并处理结果** —— 调用 API，从响应中提取模型生成的文本

## 二、客户端配置

使用 OpenAI 兼容模式调用国内大模型（如阿里云通义千问），只需将 `base_url` 指向兼容 OpenAI 接口格式的网关地址。这让开发者可以用同一套 OpenAI SDK 调用不同厂商的模型服务。

**关键配置项：**

| 配置项 | 说明 | 来源 |
|--------|------|------|
| `api_key` | 身份认证密钥 | 从环境变量读取，避免硬编码 |
| `base_url` | API 网关地址 | 阿里云 DashScope 兼容端点 |
| `model` | 模型名称 | 如 qwen3-max、qwen-max |

**为什么用 OpenAI SDK 而不是专用 SDK：**
- OpenAI SDK 是行业事实标准，生态最丰富
- 国内大模型厂商大多提供兼容模式，接口格式一致
- 项目从 OpenAI 迁移到国产模型只需改 base_url

## 三、消息系统（Messages）

LLM 的输入是一个消息列表（messages），每条消息包含 `role`（角色）和 `content`（内容）两个字段。

### 3.1 三种核心角色

| 角色 | 含义 | 优先级 | 作用 |
|------|------|--------|------|
| `system` | 系统指令 | 最高 | 设定 AI 的身份、行为规则、输出格式 |
| `user` | 用户消息 | 中 | 用户的提问或指令 |
| `assistant` | AI 回复 | 低 | 模型的回答，也可用于提供示例 |

**System Prompt 的四大设计方向：**
1. **角色定义** —— "你是一个 Python 编程专家"
2. **行为约束** —— "话不多"、"回答简洁"
3. **格式控制** —— "按 JSON 字符串输出"
4. **边界设定** —— "不清楚的分类为'不清楚类别'"

### 3.2 "记忆"的本质

**关键认知：模型本身不记忆之前的对话。** 每次请求都是独立的。要让模型"记住"历史，必须在每次请求时将完整的对话历史包含在 messages 列表中。

**消息组织原则：**
- system 消息放在最前面，定义全局行为
- user 和 assistant 消息按时间交替排列
- 模型通过读取所有历史消息来"理解"上下文
- 实际应用需注意 token 长度限制，超出时需做截断或摘要

**消息结构示例：**
```
messages = [
    {"role": "system",      "content": "设定AI行为"},
    {"role": "user",        "content": "第一轮提问"},
    {"role": "assistant",   "content": "第一轮回复"},
    {"role": "user",        "content": "第二轮提问（依赖上文）"},
]
```

## 四、非流式输出 vs 流式输出

| 模式 | 请求参数 | 返回方式 | 适用场景 |
|------|----------|----------|----------|
| **非流式** | 默认（不传 stream） | 等待完整生成后一次性返回 | 短文本、即时问答 |
| **流式** | `stream=True` | 逐 token 返回，实时展示 | 长文本、打字机效果 |

**流式输出的处理要点：**
- 响应是一个迭代器，需用 for 循环逐块（chunk）读取
- 每个 chunk 包含 `choices[0].delta.content`，可能为 None
- 使用 `end=""` 控制不换行，`flush=True` 实时刷新缓冲区

## 五、JSON 格式在 LLM 交互中的作用

JSON 是 LLM Agent 开发中最常用的数据交换格式。

**核心操作：**
- `json.dumps(obj)` —— Python 对象 → JSON 字符串（序列化）
- `json.loads(str)` —— JSON 字符串 → Python 对象（反序列化）
- `ensure_ascii=False` —— 输出中文时不转义为 Unicode

**JSON 的三大作用：**
1. 要求 AI 以 JSON 格式输出，结果可直接被程序解析
2. 用 JSON 结构定义 schema，让 AI 理解需要抽取的字段
3. 模型返回的 JSON 字符串经反序列化后变为结构化数据
