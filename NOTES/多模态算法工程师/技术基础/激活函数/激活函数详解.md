## 一、激活函数的作用

神经网络的多层线性变换复合仍然是线性变换（$W_2(W_1 x + b_1) + b_2$ 还是线性的）。**激活函数引入非线性**，是深层网络能拟合任意函数的根源。好的激活函数还应该：

1. 梯度流动好（不消失、不爆炸）；
2. 计算便宜（Transformer 里 FFN 的激活是主要计算之一）；
3. 原点附近行为可控（影响初始化与归一化）。

## 二、经典激活函数

### 2.1 Sigmoid（Logistic）

$$\sigma(x) = \frac{1}{1 + e^{-x}}, \qquad \sigma'(x) = \sigma(x)(1 - \sigma(x))$$

| 优点              | 缺点                            |
| --------------- | ----------------------------- |
| 输出 (0,1)，可解释为概率 | 两端饱和：梯度消失（$\sigma' \le 0.25$） |
| 平滑可导            | 输出非零中心（恒正），梯度单向               |
|                 | 指数计算较贵                        |
|                 |                               |

**现在用法**：只作为**输出层**的二分类概率映射（BCE 内部用），不用于隐层。

### 2.2 Tanh

$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} = 2\sigma(2x) - 1$$

| 优点 | 缺点 |
|------|------|
| 零中心（输出 (-1,1)） | 两端仍饱和，梯度消失 |

### 2.3 ReLU（Rectified Linear Unit）

$$\text{ReLU}(x) = \max(0, x)$$

| 优点                | 缺点                               |
| ----------------- | -------------------------------- |
| 计算极简（一次比较）        | 负半轴梯度恒为 0 → **神经元死亡**（dead ReLU） |
| 正半轴梯度恒 1 → 缓解梯度消失 | 输出非零中心                           |
| 实际收敛快             | 输出无上界 → 激活值膨胀                    |

**Dead ReLU 问题**：某个神经元的输入长期为负 → 梯度恒 0 → 参数永不更新，神经元"死亡"。缓解：小学习率、更好的初始化、LeakyReLU。

### 2.4 LeakyReLU / PReLU / ELU

$$\text{LeakyReLU}(x) = \begin{cases} x & x \ge 0 \\ \alpha x & x < 0 \end{cases}, \quad \alpha = 0.01$$

- LeakyReLU：负半轴给小斜率 α，神经元不会完全死亡；
- PReLU：α 变成可学习参数；
- ELU：负半轴指数平滑，更鲁棒但计算重。

## 三、Transformer 时代：GELU

### 3.1 定义

$$\text{GELU}(x) = x \cdot \Phi(x)$$

其中 $\Phi(x)$ 是标准正态分布的 CDF。近似形式（计算更便宜，广泛使用）：

$$\text{GELU}(x) \approx 0.5x \left(1 + \tanh\left(\sqrt{2/\pi}(x + 0.044715x^3)\right)\right)$$

或更简单的近似：$x \cdot \sigma(1.702x)$。

### 3.2 与 ReLU 的关系

```text
ReLU:  x > 0 保留，x ≤ 0 硬置 0     （硬门控）
GELU:  x > 0 大概率保留，x ≤ 0 部分保留 （软门控，随机丢弃式）
```

GELU 的本质：**对输入乘一个基于自身大小的软掩码**（0~1 之间），比 ReLU 的硬截断更平滑，梯度在 x=0 附近连续。

### 3.3 为什么 Transformer/ViT 用 GELU

1. **平滑性**：梯度处处连续（ReLU 在 0 处不可导），训练更稳；
2. **更好的性能**：BERT/ViT 实验证明 GELU 优于 ReLU；
3. **与 LN 配合**：归一化后输入多在原点附近，GELU 在该区域的非线性更强（不像 ReLU 直接截断）。

> **面试点**：ViT 的 MLP 块 = Linear → GELU → Linear；BERT 的 FFN 也默认 GELU。

## 四、SiLU / Swish

$$\text{SiLU}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}$$

（Swish 是 β 可调的版本：$x \cdot \sigma(\beta x)$，β=1 时就是 SiLU）

| 性质     | 说明                             |
| ------ | ------------------------------ |
| 光滑     | 处处可导、无饱和硬截断                    |
| 非单调    | x<0 时有一个负小谷值（约 -0.28），提供"抑制"能力 |
| 无上界有下界 | 输出 ∈ (-0.28, +∞)               |
|        |                                |

**用法**：ConvNeXt、EfficientNet（Swish）、**SwiGLU 的激活基础**（现代 LLM）。

---

## 五、SwiGLU（现代大模型 FFN 标配）

### 5.1 定义

$$\text{SwiGLU}(x) = \text{SiLU}(x W_1) \otimes (x W_2)$$

- 两个线性变换，一个过 SiLU，一个直接过，逐元素相乘；
- **门控机制（GLU 家族）**：SiLU 分支相当于"门"，控制另一个分支的信息通过量。

### 5.2 GLU 家族

| 变体 | 公式 | 代表模型 |
|------|------|---------|
| GEGLU | GELU(xW₁) ⊗ xW₂ | T5、PaLM |
| SwiGLU | SiLU(xW₁) ⊗ xW₂ | **LLaMA、Mistral、Qwen** |
| ReGLU | ReLU(xW₁) ⊗ xW₂ | — |

### 5.3 为什么 LLM 都用 SwiGLU

1. **效果更好**：论文实验显示 SwiGLU 比标准 FFN（GELU）和 ReLU FFN 在各种规模上都更强；
2. **代价**：参数更多（两个投影矩阵）——LLaMA 通过把中间维度从 4d 降到 8/3·d 补偿，总参数持平。

```text
标准 FFN:    Linear(d→4d) → GELU → Linear(4d→d)
SwiGLU FFN:  Linear(d→8d/3) → SiLU  ┐
             Linear(d→8d/3) ────────┴→ 逐元素乘 → Linear(8d/3→d)
```

### 5.4 激活函数演进路线图

```text
Sigmoid → Tanh → ReLU → LeakyReLU/ELU → GELU → SiLU/Swish → SwiGLU
  (消失梯度)   (同左)   (死亡神经元)   (修复)   (平滑)   (门控)    (门控+更好)
```

## 六、输出层激活：Softmax

$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$

- 输出概率分布（和为 1）→ 分类头、相似度矩阵（CLIP 行 softmax）；
- 温度版：$\text{softmax}(z/\tau)$ → 训练温度（对比学习）+ 解码温度（生成采样）；
- **数值技巧**：减最大值 $e^{z_i - \max z}$ 防溢出；
- 与交叉熵联合使用时不要显式 softmax（框架内部处理）。

## 七、激活函数对比总结

### 7.1 总对比表

| 激活 | 公式 | 梯度消失 | 死亡神经元 | 零中心 | 计算 | 现代用法 |
|------|------|---------|-----------|--------|------|---------|
| Sigmoid | $\frac{1}{1+e^{-x}}$ | 严重 | — | 否 | 贵 | 输出层二分类 |
| Tanh | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | 严重 | — | 是 | 贵 | 少用 |
| ReLU | $\max(0,x)$ | 无 | 有 | 否 | 极简 | 经典 CNN |
| LeakyReLU | $x$ 或 $\alpha x$ | 无 | 缓解 | 否 | 极简 | 检测/GAN |
| GELU | $x\Phi(x)$ | 无 | 无 | 否 | 中 | **Transformer/ViT** |
| SiLU/Swish | $x\sigma(x)$ | 无 | 无 | 否 | 中 | ConvNeXt、GLU 组件 |
| SwiGLU | $SiLU(xW_1)\otimes xW_2$ | 无 | 无 | — | 中 | **LLM FFN 标配** |

### 7.2 各架构选型速查

| 架构 | 隐层激活 | FFN 激活 |
|------|---------|---------|
| ResNet 等 CNN | ReLU | — |
| BERT | GELU | GELU |
| ViT | GELU | GELU |
| GPT-2 | GELU | GELU |
| LLaMA | SiLU | **SwiGLU** |
| Qwen | SiLU | **SwiGLU** |
| Mistral | SiLU | **SwiGLU** |
| ConvNeXt | GELU | — |

## 八、激活函数与训练的关系（面试要点）

### 8.1 为什么 ReLU 时代容易死神经元，GELU 不会？

ReLU 对负输入梯度恒为 0（硬截断），一旦权重被推入负区就"锁死"；GELU 对负输入的梯度虽然小但非零，且是连续函数，权重总能"爬回来"。

### 8.2 激活函数与初始化/归一化的配合

- **Kaiming 初始化**是配合 ReLU 推导的（见参数初始化模块）；
- **Xavier 初始化**配合 Sigmoid/Tanh；
- Transformer 的缩放初始化（$\propto 1/\sqrt{d}$）考虑的是 residual 与激活函数的方差传播。

### 8.3 混合精度下的激活

- GELU/SiLU 在 FP16 下数值稳定（无大指数）；
- Sigmoid 输入过大时 FP16 溢出 → 输出层用 FP32 或加 logits 缩放；
- 注意：有些框架 GELU 的近似公式（tanh 近似）在 FP16 下与精确版有微小差异，一般可忽略。

### 8.4 什么情况下选什么激活

| 场景 | 推荐 |
|------|------|
| 通用深度网络（隐层） | ReLU 或 GELU |
| Transformer/ViT | GELU |
| LLM FFN | SwiGLU |
| 二分类输出 | 无（BCE 内部 sigmoid） |
| 多分类输出 | 无（CE 内部 softmax） |
| 概率/注意力权重 | Softmax（注意力）、Sigmoid（门控） |

## 九、高频面试问答

**Q1：为什么 ReLU 比 Sigmoid 好？**
① 正半轴梯度恒 1，不消失；② 计算是常数时间（比较运算）；③ 稀疏激活（一半输出为 0）有正则化效果。缺点：死亡神经元、非零中心。

**Q2：什么是 Dead ReLU？怎么解决？**
输入长期为负导致梯度恒 0、神经元永不更新。解决：LeakyReLU（小斜率）、更小学习率、合理初始化、GELU（软门控）。

**Q3：GELU 和 ReLU 的区别？为什么 Transformer 用 GELU？**
GELU 是软门控（乘一个 0~1 的连续掩码），ReLU 是硬截断。GELU 平滑、梯度连续、在归一化后的原点附近非线性更好，实验上 Transformer/ViT 效果更优。

**Q4：SwiGLU 是什么？为什么 LLM 都用它？**
SwiGLU = SiLU 门控的 GLU：SiLU(xW₁) ⊗ xW₂。比标准 FFN 效果更好（论文实验各规模均占优），LLaMA/Qwen/Mistral 通过把中间维度从 4d 调到 8d/3 控制参数量。

**Q5：Softmax 的作用和数值注意事项？**
把 logits 变成概率分布（求和为 1），用于分类输出和注意力权重。数值上减最大值（log-sum-exp）防溢出；与交叉熵联用时不显式 softmax。

**Q6：为什么激活函数要非线性和可导？**
非线性是深层网络表达能力的来源（线性复合仍是线性）；可导是梯度下降的前提（分段可导也可，如 ReLU）。

**Q7：Sigmoid 输出非零中心为什么不好？**
全部输出为正 → 下一层输入恒正 → 梯度方向被一层层一致偏置，收敛变慢（zig-zag）。Tanh 零中心是相对 Sigmoid 的改进，但饱和问题依旧。

**Q8：ViT 的 MLP 块结构？**
Linear(d→4d) → GELU → Dropout → Linear(4d→d) → Dropout。GELU 在两个线性层中间提供非线性。

**Q9：注意力里的 softmax 和分类的 softmax 有区别吗？**
数学相同，但注意：注意力 softmax 在**每个位置的行**上做（维度 = 序列长度）；分类 softmax 在类别维度。生成解码时还要除以温度控制多样性。

**Q10：怎么验证激活函数选得对？**
① 初始化后激活值分布检查（不该全是 0 或爆炸）；② 梯度统计（各层梯度量级应一致）；③ 单 batch 过拟合测试；④ 最终指标对比实验（不同激活同配置对比）。
