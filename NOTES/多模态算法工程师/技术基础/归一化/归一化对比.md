# 归一化对比：BN / LN / IN / GN / RMSNorm 五者速查

> 本模块索引见 [归一化技术详解](归一化技术详解.md)

## 一、五者一图总览

归一化家族唯一的区别是：**统计量 μ、σ² 求在哪一维**。以 $x \in \mathbb{R}^{N \times C \times H \times W}$（图像）或 $\mathbb{R}^{N \times L \times D}$（序列）为例：

| 归一化 | 统计维度 | 统计量个数 | 一句话记忆 |
|--------|---------|-----------|-----------|
| **BN** | 跨样本、按通道（N,H,W） | C | 通道内"全体样本"一起归 |
| **LN** | 单样本、全特征（C,H,W 或 L,D） | N（或 N×L） | 每个样本"自己全部"一起归 |
| **IN** | 单样本、单通道（H,W） | N×C | 每个样本每通道"各自独立"归 |
| **GN** | 单样本、组内通道（H,W，通道分组） | N×G | 通道"分组"共享统计量 |
| **RMSNorm** | 单样本、全特征（只有缩放） | N（或 N×L） | LN 去掉均值，只按均方根缩放 |

统一数学模板（五者共用，只是 μ/σ² 的范围不同）：

$$\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}, \qquad y = \gamma \hat{x} + \beta \quad (\text{RMSNorm 无 } \mu \text{，一般也无 } \beta)$$

> **速记口诀**："BN 看 batch，LN 看样本，IN 看单通道，GN 看通道组，RMS 只看量级"。

### 1.1 统计范围矩阵（哪一维参与统计）

对图像张量 [N, C, H, W]，✓ 表示该维度**被聚合**进统计量（求 μ/σ² 时被约掉）：

| 归一化 | N（样本） | C（通道） | H、W（空间） | 每个统计量覆盖的元素数 |
|--------|-----------|-----------|--------------|----------------------|
| BN | ✓ | 分别统计 | ✓ | N×H×W（每通道） |
| LN | 分别统计 | ✓ | ✓ | C×H×W（每样本） |
| IN | 分别统计 | 分别统计 | ✓ | H×W（每样本每通道） |
| GN | 分别统计 | 分组统计 | ✓ | (C/G)×H×W（每样本每组） |
| RMSNorm | 分别统计 | ✓ | ✓ | C×H×W（每样本，只算 x² 均值） |

> "分别统计"意味着该维不作为聚合范围，每个实例单独归一化——这正是"与 batch 无关"的由来。

## 二、统一源码对比（一个接口跑五种归一化）

```python
import torch
import torch.nn as nn

class UnifiedNorm(nn.Module):
    """统一接口：只需切换 mode，即可在五种归一化间对比"""

    def __init__(self, C, mode="LN", G=3, eps=1e-5, spatial=(4, 4)):
        super().__init__()
        if mode == "BN":
            self.norm = nn.BatchNorm2d(C)
        elif mode == "LN":
            self.norm = nn.LayerNorm([C] + list(spatial))
        elif mode == "IN":
            self.norm = nn.InstanceNorm2d(C)
        elif mode == "GN":
            self.norm = nn.GroupNorm(G, C)
        elif mode == "RMS":
            self.norm = nn.RMSNorm([C] + list(spatial))

    def forward(self, x):
        return self.norm(x)

torch.manual_seed(0)
x = torch.randn(2, 6, 4, 4)                     # [N=2, C=6, H=4, W=4]
for mode in ["BN", "LN", "IN", "GN", "RMS"]:
    y = UnifiedNorm(6, mode, G=3)(x)            # 注意：BN 需处于 train 模式
    print(f"{mode}: 输出 mean={y.mean().item():.5f} var={y.var().item():.5f}")
# BN : 输出 mean=0.00000 var=1.00522
# LN : 输出 mean=-0.00000 var=1.00522
# IN : 输出 mean=-0.00000 var=1.00522
# GN : 输出 mean=0.00000 var=1.00522
# RMS: 输出 mean=0.00651 var=1.00519
```

> 对标准正态输入，五种归一化的宏观输出几乎一样（mean≈0、var≈1）——**它们的差异只有偏移输入时才显形**，见下面的区分度实验。

### 2.1 区分度实验：谁保留/移除了什么偏移

给样本 1 整体 +3（样本偏移）、通道 1 整体 +10（通道偏移），看各归一化输出的逐样本均值、逐通道均值：

```python
torch.manual_seed(0)
xd = torch.randn(2, 2, 2, 2)
xd = xd + torch.tensor([[0.0], [3.0]]) + torch.tensor([[[[0.0]], [[10.0]]]])
print("逐样本输入均值:", xd.mean((1, 2, 3)).tolist())    # [6.02, 6.74]（样本1整体+3）
print("逐通道输入均值:", xd.mean((0, 2, 3)).tolist())    # [1.09, 11.67]（通道1整体+10）

for mode in ["BN", "LN", "IN", "GN", "RMS"]:
    y = UnifiedNorm(2, mode, G=1, spatial=(2, 2))(xd)
    ps = y.mean((1, 2, 3))     # 逐样本输出均值
    pc = y.mean((0, 2, 3))     # 逐通道输出均值
    print(f"{mode}: 逐样本输出均值={ps.tolist()} 逐通道输出均值={pc.tolist()}")
# BN : 逐样本输出均值=[-0.2377, 0.2377] 逐通道输出均值=[0.0, -0.0]     ← 移除了通道偏移，保留样本偏移
# LN : 逐样本输出均值=[-0.0, 0.0] 逐通道输出均值=[-0.9563, 0.9563]     ← 移除了样本偏移，保留通道偏移
# IN : 逐样本输出均值=[0.0, 0.0] 逐通道输出均值=[0.0, 0.0]            ← 两类偏移全部移除
# GN : 逐样本输出均值=[-0.0, 0.0] 逐通道输出均值=[-0.9563, 0.9563]     ← 与 LN 相同（此实验 G=1）
# RMS: 逐样本输出均值=[0.7407, 0.7694] 逐通道输出均值=[0.1283, 1.3818] ← 只缩放，任何偏移都不移除
```

**读法（面试大杀器）**：
- BN 统计跨样本 → 通道偏移被平均掉，样本间差异保留；
- LN 统计样本内 → 样本偏移被减掉，通道间差异保留；
- IN 两者都独立 → 两类偏移全移除；
- RMSNorm 不做平移 → 什么都不移除，只统一量级。

### 2.2 统计量个数对比

```python
def n_stats(mode, N, C, G):
    return {"BN": C, "LN": N, "IN": N * C, "GN": N * G, "RMS": N}[mode]

N, C, G = 32, 64, 32      # 典型分类模型：batch=32, 通道=64, 组数=32
for mode in ["BN", "LN", "IN", "GN", "RMS"]:
    print(f"{mode}: {n_stats(mode, N, C, G)} 个统计量")
# BN : 64 个    ← 统计量最少，共享最充分（所以依赖大 batch 才可靠）
# LN : 32 个
# IN : 2048 个  ← 统计量最多，每个统计量最"局部"、噪声最大
# GN : 1024 个
# RMS: 32 个
```

### 2.3 GN 是两个极端的插值（等价性验证）

```python
torch.manual_seed(0)
x = torch.randn(2, 6, 4, 4)
print("GN(1) == LN :", torch.allclose(nn.GroupNorm(1, 6)(x), nn.LayerNorm([6, 4, 4])(x)))   # True
print("GN(C) == IN :", torch.allclose(nn.GroupNorm(6, 6)(x), nn.InstanceNorm2d(6)(x)))       # True
```

### 2.4 训练/推理一致性速测

```python
def train_eval_diff(norm, x):
    norm.train(); a = norm(x)
    norm.eval();  b = norm(x)
    return (a - b).abs().max().item()

torch.manual_seed(0)
x = torch.randn(2, 6, 4, 4)
print("BN :", train_eval_diff(nn.BatchNorm2d(6), x))      # 0.4353（用 running stats，差异显著）
print("LN :", train_eval_diff(nn.LayerNorm([6, 4, 4]), x))  # 0.0
print("IN :", train_eval_diff(nn.InstanceNorm2d(6), x))    # 0.0
print("GN :", train_eval_diff(nn.GroupNorm(2, 6), x))      # 0.0
print("RMS:", train_eval_diff(nn.RMSNorm([6, 4, 4]), x))   # 0.0
```

> 只有 BN 有 running stats，其余四者 train/eval 输出逐位一致——**推理阶段唯一需要特殊处理的只有 BN**。

## 三、五者对比总表

| 维度 | BatchNorm | LayerNorm | InstanceNorm | GroupNorm | RMSNorm |
|------|-----------|-----------|--------------|-----------|---------|
| 统计维度 | 跨样本按通道 | 单样本全特征 | 单样本单通道 | 单样本组内通道 | 单样本全特征 |
| 均值减除 | 有 | 有 | 有 | 有 | **无** |
| 可学习参数 | γ、β | γ、β | γ、β（可选） | γ、β | γ（一般无 β） |
| 依赖 batch | **强** | 无 | 无 | 无 | 无 |
| 小 batch 表现 | **崩** | 好 | 好 | 好 | 好 |
| 大 batch 表现 | 最优 | 好 | 一般 | 接近 BN | 好 |
| 训练/推理一致 | **不一致**（running stats） | 一致 | 一致（默认） | 一致 | 一致 |
| 变长序列 | 受污染 | 免疫 | 免疫 | 免疫 | 免疫 |
| 统计量个数 | C | N | N×C | N×G | N |
| 计算开销 | 中 | 中 | 中 | 中 | **最低** |
| 隐式正则化 | 有（batch 噪声） | 无 | 无 | 无 | 无 |
| 推理部署 | 可折叠进 Conv | 原样 | 原样 | 原样 | 原样 |
| 适用架构 | CNN（分类） | Transformer/NLP/ViT | 风格迁移/生成 | 检测/分割（小 batch） | LLM |
| 代表模型 | ResNet、VGG | BERT、ViT、CLIP 文本塔 | AdaIN、StyleGAN | Mask R-CNN、YOLO | LLaMA、Qwen |

## 四、选型决策树

```text
要归一化的输入是什么？
│
├─ 图像/视频（CNN 特征图 [N,C,H,W]）？
│   ├─ batch 稳定且较大（≥32）？
│   │   ├─ 是 → BatchNorm（收敛快、效果最好，可折叠部署）
│   │   └─ 否（检测/分割/视频，batch 2~16）
│   │       └─ GroupNorm（G=32 或 8，小 batch 唯一可靠选择）
│   ├─ 是生成/风格任务？
│   │   └─ InstanceNorm / AdaIN（剥离亮度对比度，注入风格统计）
│   └─ 需要与 Transformer 混合（如 ViT）？
│       └─ LayerNorm（Pre-LN）
│
├─ 序列/文本（Transformer，[N,L,D]）？
│   ├─ 经典 Transformer/BERT/ViT 微调 → LayerNorm
│   └─ LLM 预训练（LLaMA/Qwen/Mistral）→ RMSNorm（省算力 + 更稳）
│
└─ 不确定/通用小模型 → LayerNorm（与 batch 无关、训练推理一致，最省心）
```

**迁移指南（BN → 其他）**：
- 分类模型从大 batch 切到小 batch：`BatchNorm2d` → `GroupNorm(32, C)`，其余不动；
- CNN 特征送进 Transformer：把 BN 全部换成 LayerNorm（如 ViT 早期设计）；
- 直接改跑 LLM：一律 RMSNorm。

## 五、多模态场景速查

| 多模态组件 | 归一化选择 | 理由 |
|-----------|-----------|------|
| ViT 视觉塔 | LayerNorm（Pre-LN） | 与 batch 无关、训练推理一致 |
| CLIP/SigLIP 文本塔 | LayerNorm | Transformer 标配 |
| LLaVA 的 LLM 底座 | RMSNorm | LLaMA/Qwen 结构 |
| 双塔输出特征 | **L2 归一化**（非层归一化！） | 相似度度量需要模长统一 |
| 检测头（如 GLIP 的视觉头） | GroupNorm | 小 batch 训练 |
| 生成模型（如扩散的图像分支） | GroupNorm / AdaIN 风格调制 | 通道级统计 + 风格控制 |

> **易混点**："特征 L2 归一化"（除以 ‖x‖₂，用于余弦相似度）与"层归一化"（减均值除方差，用于训练稳定）目标、公式、位置都不同，面试别混（详见总览篇第七节）。

### 5.1 常见模型归一化一栏速查

| 模型 | 归一化 | 备注 |
|------|--------|------|
| ResNet / VGG / DenseNet | BatchNorm | 大 batch 分类基准 |
| EfficientNet | BatchNorm | 同上（SyncBN 用于分布式） |
| BERT / GPT-2 / ViT | LayerNorm | Pre-LN 结构 |
| CLIP / SigLIP / BLIP | LayerNorm + 输出 L2 | 双塔输出做特征归一化 |
| LLaMA 1/2/3 / Qwen / Mistral / Gemma | **RMSNorm** | 预训练大模型标配 |
| Mask R-CNN / Faster R-CNN / YOLO | GroupNorm（或 FrozenBN） | 小 batch 检测 |
| AdaIN / StyleGAN 系 | InstanceNorm / 调制解调 | 风格迁移生成 |
| Stable Diffusion | GroupNorm（+时间嵌入） | UNet 骨干 |

## 六、面试速答（五连问）

**Q1：BN/LN/IN/GN 的区别？一句话各是什么？**
统一回答模板：五种归一化的公式都是 $(\hat{x} = (x-\mu)/\sqrt{\sigma^2+\epsilon})$，区别只在 μ/σ² 的统计范围——BN 跨样本按通道（batch 相关），LN 单样本全特征（batch 无关），IN 单样本单通道，GN 单样本组内通道，RMSNorm 是 LN 去掉均值的简化版。

**Q2：小 batch 时怎么办？**
BN 统计噪声与 batch 成反比，batch<16 换 GN（CNN 任务）或 LN（Transformer 任务）；跨卡训练可用 SyncBN 等效扩大 batch。

**Q3：为什么 Transformer 用 LN/RMSNorm 不用 BN？**
① BN 依赖 batch（生成/长序列场景 batch 小或为 1）；② 变长序列 padding 污染 BN 统计；③ BN 训练/推理统计量来源不一致，LN/RMS 一致；④ LN 的逐位置归一化与 attention 表示空间更匹配。

**Q4：LLaMA 为什么用 RMSNorm？**
省算力（少一次均值归约，约快 30%）、训练更稳、实现简单（只有 γ）；论文表明去掉均值中心化不伤效果。

**Q5：五个归一化 train/eval 行为谁不同？**
只有 BN 不同：训练用 batch 统计量 + 更新 running stats，推理用 running stats；LN/IN（默认）/GN/RMSNorm 无 running stats，两阶段完全一致。

**Q6：把现成的 BN 模型换成 GN 需要改什么？**
几乎只改一行：`nn.BatchNorm2d(C)` → `nn.GroupNorm(32, C)`，γ、β 结构相同、前后接口不变。注意：BN 换掉后 batch 可以任意调小，但换回 BN 时需确认 batch 足够大；另外预训练 BN 模型直接换 GN 需要重新训练（统计量来源不同）。
