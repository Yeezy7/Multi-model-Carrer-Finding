## 一、为什么需要归一化

### 1.1 深层网络训练的困难

深层网络训练难，根源在于**内部协变量偏移（Internal Covariate Shift）**：每一层的输入分布会随着前面层的参数更新而不断变化，导致：

1. 网络需要不断适应变化的数据分布，收敛慢；
2. 饱和区域激活函数（Tanh/Sigmoid）的梯度会消失；
3. 学习率难以调大（大 lr 放大分布漂移）。

**归一化的核心思想**：把每一层的激活值重新缩放/平移到一个稳定分布（均值 0、方差 1），让深层网络训练稳定、收敛快、能用更大学习率。

### 1.2 归一化通用的数学形式

几乎所有归一化都遵循同一模板（以特征值 $x_i$ 为例）：

$$\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}}, \qquad y_i = \gamma \hat{x}_i + \beta$$

- $\mu, \sigma$：统计量（按不同维度计算，见下表）；
- $\epsilon$：防止除零的小常数（如 1e-5）；
- $\gamma, \beta$：可学习的缩放/平移参数（保证归一化不损失表达能力——网络可以"撤销"归一化）。

> **各归一化的区别只在"对哪一维求统计量"**。这是理解全家族的一把钥匙。

### 1.3 一张图理解四个维度

把神经网络的激活值看成一个四维张量：`[N, C, H, W]`（样本、通道、高、宽）或 `[N, L, D]`（样本、序列长度、特征维度）：

| 归一化          | 统计量求在哪               | 核心思想                |
| ------------ | -------------------- | ------------------- |
| BatchNorm    | N、H、W 维度（跨样本、按通道）    | 一个 batch 内，每个通道所有像素 |
| LayerNorm    | C、H、W 或 L、D（单个样本内全部） | 每个样本内部全部特征          |
| InstanceNorm | H、W（单样本单通道）          | 每个样本每个通道独立          |
| GroupNorm    | 按通道分组后的 H、W          | 通道分组的折中方案           |
| RMSNorm      | 单个样本内全部（只有缩放）        | LayerNorm 去均值，只要缩放  |

## 二、LayerNorm（层归一化）—— Transformer 标配

### 2.1 定义与公式

对单个样本的所有特征维度做归一化（不依赖 batch 内其他样本）：

$$\mu = \frac{1}{D}\sum_{i=1}^{D} x_i, \qquad \sigma^2 = \frac{1}{D}\sum_{i=1}^{D}(x_i - \mu)^2$$

$$\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}}, \qquad y_i = \gamma \hat{x}_i + \beta$$

其中 $D$ 是该样本的特征维数（Transformer 中即 d_model）。

### 2.2 为什么 Transformer 用 LayerNorm 而不是 BatchNorm（必考）

1. **与 batch size 无关**：LN 只依赖单个样本自身，batch=1（单条推理）、变长序列都能正常计算；
2. **变长输入友好**：NLP 中序列长度不一，BN 在 padding 位置的统计会被污染；
3. **训练/推理行为一致**：BN 训练用 batch 统计量、推理用累计统计量，两阶段行为不一致；LN 完全相同；
4. **缓解梯度问题**：残差 + LN 让梯度路径稳定（深层 Transformer 可训）；
5. **对比学习友好**：CLIP/SigLIP 等模型在 batch 大小受限时依然稳定。

### 2.3 LN 在 Transformer 中的位置

- **嵌入层之后**：输入进入第一个 block 前（LLaMA/Qwen 的做法是 token embedding 后直接过 LN，通常叫 `pre_norm` 或 embedding LN）；
- **每个 Attention/FFN 之前**（Pre-LN）；
- **LLM 最后的输出前**：final LN（`model.norm`），把 logits 归一化到稳定范围；
- **对比学习双塔的投影头**：CLIP 的 text tower 输出前也有 LN。

```text
Transformer Block（Pre-LN 结构）:
x → LN → MultiHeadAttention → 残差+ → LN → FFN → 残差+ → x'
```

### 2.4 LN 的梯度性质（面试加分）

LN 输出对输入的雅可比矩阵的行向量具有各向同性缩放性质：梯度回传时 $\frac{\partial \hat{x}}{\partial x}$ 的特征值只差一个标量倍数。简单说，**LN 让梯度在反传时不会出现方向上的扭曲**，这是它稳定深网络的重要原因。

## 三、RMSNorm（均方根归一化）—— 现代大模型标配

### 3.1 动机

论文（Zhang & Sennrich, 2019）观察到：**LN 中的均值减除（centering）对效果贡献很小**，核心收益来自缩放（scaling）。于是砍掉均值计算，只保留均方根：

### 3.2 定义与公式

$$\hat{x}_i = \frac{x_i}{\sqrt{\text{RMS}(x)}} = \frac{x_i}{\sqrt{\frac{1}{D}\sum_{j=1}^{D} x_j^2 + \epsilon}}, \qquad y_i = \gamma \hat{x}_i$$

- 没有 $\mu$ 项、没有 $\beta$（或保留 $\beta$ 亦可，主流实现一般只有 $\gamma$）；
- 少了均值计算 → 计算更快（省一次约减和一次减法）。

### 3.3 与 LayerNorm 的对比

| 维度 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 均值减除 | 有 | 无 |
| 缩放 | 标准差 | 均方根 |
| 可学习参数 | γ、β | γ（一般） |
| 计算量 | 较高（两趟归约） | 低约 30% |
| 训练稳定性 | 基准 | 相当甚至更好 |
| 使用模型 | BERT、ViT、原版 Transformer | **LLaMA、Qwen、Mistral、Gemma** |

### 3.4 为什么 LLaMA 系都用 RMSNorm

1. **省算力**：训练和推理都要省，RMSNorm 无均值计算；
2. **更稳定**：实验显示去掉中心化反而提升了大模型的训练稳定性与效果；
3. **简洁**：只有 γ 一个可学习参数，实现简单。

```python
# RMSNorm 实现（LLaMA 风格）
class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))
        self.eps = eps

    def forward(self, x):
        # x: [..., dim]
        rms = x.pow(2).mean(-1, keepdim=True) + self.eps
        return x * torch.rsqrt(rms) * self.weight
```

> **面试记忆点**：LayerNorm 是"均值+方差都归"，RMSNorm 是"只归方差（均方根）"。Transformer 时代 BERT 用 LN，大模型时代 LLaMA/Qwen 用 RMSNorm。

## 四、BatchNorm（批归一化）—— CNN 标配

### 4.1 定义与公式

按**通道**在 batch 内统计（对 [N, H, W] 求均值方差），每个通道一组 γ、β：

$$\mu_c = \frac{1}{N \cdot H \cdot W}\sum_{n,h,w} x_{n,c,h,w}, \qquad \sigma_c^2 = \frac{1}{N \cdot H \cdot W}\sum_{n,h,w}(x_{n,c,h,w} - \mu_c)^2$$

训练时用**当前 batch** 的统计量；推理时用训练中累计的**移动平均**统计量（running_mean/running_var）。

### 4.2 优缺点

| 优点 | 缺点 |
|------|------|
| CNN 上收敛快、可用大 lr | 依赖 batch size：batch 小统计不准，效果崩 |
| 有轻微正则化作用（batch 内噪声） | 训练/推理行为不一致（统计量来源不同） |
| 与卷积结构契合（通道统计） | NLP/Transformer 场景基本不可用 |
| 支持分布内训练 | 分布外（OOD）数据推理退化 |

### 4.3 BN vs LN 对比表（面试高频）

| 维度 | BatchNorm | LayerNorm |
|------|-----------|-----------|
| 归一化维度 | 跨样本、按通道 | 单样本、全特征 |
| 依赖 batch | 强依赖 | 不依赖 |
| 训练/推理一致性 | 不一致（running stats） | 一致 |
| 适用架构 | CNN | Transformer/NLP/ViT |
| 小 batch 表现 | 差 | 好 |
| 变长输入 | 受影响 | 不受影响 |
| 典型用法 | ResNet 等 CNN | BERT、ViT、LLM |

## 五、InstanceNorm 与 GroupNorm

### 5.1 InstanceNorm（实例归一化）

对**单个样本、单个通道**统计（[H, W]）：

$$\mu_{n,c} = \frac{1}{HW}\sum_{h,w} x_{n,c,h,w}$$

**应用**：风格迁移（AdaIN）、图像生成。归一化消除"对比度/亮度"信息，保留纹理与结构——风格迁移正需要剥离"亮度"这种风格属性。

### 5.2 GroupNorm（分组归一化）

把通道分成 G 组，对**单个样本、每组通道**统计（[H, W] 且通道分组内）：

$$\mu_{n,g} = \frac{1}{C_g \cdot H \cdot W}\sum_{c \in g} x_{n,c,h,w}$$

- G=1：退化为 LayerNorm（单样本全通道）；
- G=C：退化为 InstanceNorm（单样本单通道）；
- 中间值（G=32 或 8）：**检测/分割任务的小 batch 场景标配**（Mask R-CNN 等）。

### 5.3 归一化四兄弟速记

| 归一化 | 统计范围 | 一句话 |
|--------|---------|--------|
| BN | 跨样本同通道 | 通道内全体样本 |
| LN | 单样本全通道 | 样本内全体特征 |
| IN | 单样本单通道 | 每个样本每通道独立 |
| GN | 单样本分通道组 | 通道分组的折中 |

## 六、Pre-LN vs Post-LN（残差位置选择）

### 6.1 两种结构

```text
Post-LN（原版 Transformer）: 子层 → 残差 → LN
Pre-LN（现代大模型）:       LN → 子层 → 残差
```

### 6.2 对比

| 维度 | Post-LN | Pre-LN |
|------|---------|--------|
| 训练稳定性 | 差（深网络需 careful warmup） | 好（残差路径无 LN） |
| 梯度 | 经过 LN 的梯度有缩放风险 | 残差捷径梯度恒为 1 |
| 学习率 | 大 lr 易崩 | 可以用更大 lr |
| 表示能力 | 理论更强 | 略有损失（补偿：深模型） |
| 使用 | 原版 Transformer | GPT/LLaMA/Qwen/ViT 主流 |

> 变体：**Sandwich-LN**（残差两侧都加 LN）稳定性最好但成本高；**DeepNorm** 用特定初始化 + 缩放配合 Post-LN 训练更深模型（见参数初始化模块）。

## 七、归一化在"多模态模型"中的使用位置汇总

| 组件 | 用的归一化 | 位置 |
|------|-----------|------|
| ViT 视觉塔 | Pre-LN（原版 ViT） | 每个 block 前 |
| CLIP/SigLIP 文本塔 | LN | 每层 + 输出前 |
| LLaMA/Qwen LLM | **RMSNorm** | embedding 后 + 每层前 + 输出前 |
| 对比学习 logits 缩放 | 特征 L2 归一化（不是 LN！） | 双塔输出后 |
| 投影层（MLP projector） | 通常无或 LN | LLaVA 的 MLP 里 GELU 无 norm |
| Q-Former | LN | Transformer 内 |

> **区分两个"归一化"**（面试易混）：
> 1. **特征归一化（L2 Normalize）**：把 embedding 归一化到单位球面，用于相似度计算（CLIP/SigLIP 双塔）；
> 2. **层归一化（LayerNorm/RMSNorm）**：稳定深层训练。
> 两者目标不同、位置不同、公式不同，不要混为一谈。

## 八、归一化的常见问题与排查

### 8.1 BN 在小 batch 下崩掉怎么办？

1. 换 GN（检测/分割标配）；
2. 用 SyncBN（跨卡同步统计，batch 等效变大）；
3. 换 LN（NLP/Transformer 场景直接换）。

### 8.2 LN/RMSNorm 的 eps 怎么设？

- LN 通常 1e-5；
- RMSNorm 通常 1e-5 ~ 1e-6（LLaMA 用 1e-6）；
- BF16 训练下 eps 太小会导致除零/不稳定，可调大到 1e-6~1e-5；
- eps 过大（如 1e-2）会扭曲归一化，一般不用。

### 8.3 混合精度下归一化的问题

- BN 在 FP16 下数值不稳定（统计量精度损失），大模型预训练几乎不用 BN；
- LN/RMSNorm 的归约（mean/rsqrt）在 FP16 下可能溢出，实现上常用 FP32 计算归一化统计量、输出转回输入精度（HuggingFace/LLaMA 实现都这么做）。

### 8.4 归一化参数训练中不更新？

- BN 的 running stats 不是梯度更新，是移动平均；`momentum` 默认 0.1；
- LN/RMSNorm 的 γ、β 是普通参数，会随优化器更新；`model.eval()` 不影响 LN 行为（不像 BN）。

## 九、高频面试问答

**Q1：BN 和 LN 的本质区别？**
归一化维度不同：BN 跨样本按通道统计（batch 相关），LN 单样本全特征统计（batch 无关）。由此带来 BN 依赖大 batch、训练推理不一致、不适合变长序列；LN 无这些限制，成为 Transformer 标配。

**Q2：为什么 Transformer 不用 BN？**
① 变长序列 + padding 破坏 batch 统计；② 小 batch（生成模型 batch 常较小）统计不稳；③ 训练/推理统计量不一致；④ 逐 token 预测任务中 LN 的"样本内归一化"与 attention 的表示空间更匹配。

**Q3：RMSNorm 和 LayerNorm 的区别？为什么 LLaMA 用 RMSNorm？**
RMSNorm 去掉均值中心化，只按均方根缩放，省一次归约（快约 30%），效果相当或更好；LLaMA/Qwen/Mistral 为了算力与稳定性采用 RMSNorm。

**Q4：归一化在推理时有什么讲究？**
LN/RMSNorm 训练推理一致，无需特殊处理；BN 推理必须用 running stats（PyTorch 自动处理）；双塔模型推理时特征要做 L2 归一化才能正确计算余弦相似度。

**Q5：为什么归一化后面要加 γ、β（可学习参数）？**
保证归一化不损失表达能力：如果网络认为原始尺度/偏移更好，可以直接学出 γ=σ、β=μ 撤销归一化。γ、β 让"归一化"成为一种可被网络自适应调节的变换而非硬约束。

**Q6：Post-LN 和 Pre-LN 哪个更好？**
Pre-LN 训练稳定（残差捷径干净、无 LN 阻挡梯度）、可用大 lr、深模型友好，是现代模型（GPT/LLaMA/Qwen/ViT）的主流；Post-LN 原版结构、理论表达能力更强但深模型训练困难。

**Q7：LN 的 γ 初始化为 1、β 初始化为 0 吗？为什么？**
是。γ=1、β=0 让归一化层初始时退化为"纯归一化"（输出接近标准正态），不干扰预训练初期的特征尺度；错误初始化（如 γ=0）会导致信号直接消失。

**Q8：BatchNorm 为什么能正则化？**
BN 用当前 batch 的统计量，而 batch 是随机采样的，统计量本身带噪声，相当于给激活值注入随机扰动，有轻微正则化效果（论文观察，非主要目的）。

**Q9：多模态双塔为什么要对特征做 L2 归一化而不是 LN？**
双塔的目标是度量相似度（余弦），LN 会改变特征方向（减均值），破坏相似度的几何意义；L2 归一化保持方向不变、只统一模长，让内积 = 余弦相似度。

**Q10：weight normalization、spectral norm 是归一化吗？**
是归一化家族的另类成员：WeightNorm 归一化权重向量本身（w = g·v/||v||），SpectralNorm 用最大奇异值约束权重谱范数（GAN 常用）。与激活归一化不同，它们归一化的是**参数**而非激活值。
