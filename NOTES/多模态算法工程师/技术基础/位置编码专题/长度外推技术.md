# 长度外推技术：PI / NTK / YaRN / LongRoPE

> 本模块索引见 [位置编码专题详解](位置编码专题详解.md)

## 一、定义与公式

RoPE 训练长度 $L_{train}$ 之外相位组合 OOD（PPL 尖峰），长度外推技术解决"如何把训练 4K 的模型用到 128K"。设目标长度 $L_{new} = s \cdot L_{train}$（$s$ 为扩展倍率），四类主流方法如下。

### 1.1 位置插值 PI（Position Interpolation）

**思想**：不把位置推到区间外，而是把**坐标压缩**进训练区间——"用更慢的指针走更长的路"。

$$f'(x, m) = f\!\left(x, \frac{m}{s}\right) \quad \Longleftrightarrow \quad \theta_i' = \frac{\theta_i}{s}$$

- 所有频率统一除以 $s$（波长统一放大 $s$ 倍）；
- $m = s \cdot L_{train}$ 处旋转角 $= \frac{s L_{train} \theta_i}{s} = L_{train}\theta_i$ → 角度值域**完全不越界**；
- Meta 用此方法把 LLaMA 扩到 32768（5B token 微调）。

### 1.2 NTK-Aware 缩放（高频不缩放、低频缩放）

**思想**（神经正切核视角 + 信号处理直觉）：高频维度负责**局部近邻**分辨率，低频维度负责**全局长程**。外推只需把低频波长拉长（把长距离信息压缩回训练分布），高频保持原样以保住局部精度：

$$\theta_i' = \theta_i \cdot s^{-2i/(d-2)}$$

- $i=0$（最高频）：指数为 0 → **完全不缩放**；
- $i = d/2-1$（最低频）：指数 $\approx -1$ → 频率缩小约 $s$ 倍（波长放大 $s$ 倍）。

**等价实现**：只改 base 一个超参。因为：

$$(base')^{-2i/d} = base^{-2i/d} \cdot s^{-2i/(d-2)} \implies base' = base \cdot s^{d/(d-2)}$$

社区（Meta 外）主流做法：`base = 10000 * s^(d/(d-2))`，无需改任何代码。

### 1.3 YaRN（Yet another RoPE extensioN）

**① NTK-by-parts（分波长段处理）**：按波长 $\lambda_i = 2\pi/\theta_i$ 与训练长度的关系把维度分三段：

| 波长条件 | 含义 | 处理 |
|---------|------|------|
| $\lambda_i \ll L_{train}$ | 纯高频，只编码局部 | **不缩放**（保持原频率） |
| $\lambda_i \gg L_{train}$ | 纯低频，只编码长程 | **按 PI 缩放**（$\theta_i/s$） |
| 中间带 | 模糊区 | 平滑过渡（插值系数 $\gamma \in [0,1]$） |

**② 注意力温度校正**：插值改变了 attention logits 的统计分布（相位压缩后 $\langle q,k\rangle$ 幅度变小），YaRN 引入温度 $t$ 缩放 logits：

$$\text{score}' = \frac{\text{score}}{t}, \qquad t \approx \text{函数}(s)$$

补偿分布偏移（论文由能量守恒推导闭式解，直觉量级 $\approx 1/\sqrt{s}$ 附近）。Mistral 7B 官方用 YaRN 扩到 128K。

### 1.4 LongRoPE（非均匀插值）

- **思想**：每个维度对长程扩展的"承受力"不同（低频维缩放损失小、高频维缩放损失大）。LongRoPE **逐维搜索最优缩放系数**，把信息损失集中到影响小的高频维度 → **256K 无微调损失**；
- **机制**：搜索 + 验证自动确定各维系数（无需人工曲线）；
- **两阶段**：先扩 256K，再"微调 + 二次扩展"到 2M（Grok-1 采用）。

## 二、核心原理与直觉

### 2.1 外推 vs 插值（关键区分）

| | 外推 | 插值 |
|---|------|------|
| 行为 | 直接用训练长度外的位置/相位 | 把位置坐标**压缩**回训练区间 |
| RoPE 后果 | 相位 OOD → PPL 尖峰 | 相位值域不越界 → 平滑 |
| 例子 | LLaMA 4K 直接跑 8K | PI/NTK/YaRN/LongRoPE |

**一句话**：所有插值方法解决的都是同一个问题——"让新长度的旋转角落在训练期见过的范围内"。

### 2.2 为什么 PI 简单但有损

PI 对所有维度统一除以 $s$：相邻位置的相位差从 $\theta_i$ 缩到 $\theta_i/s$ → **近邻区分度下降 $s$ 倍**（高频分辨率损失）。类比：钟表指针转速全变慢，秒针也变成"半秒一格"，相邻时刻看不清。

### 2.3 为什么 NTK 更好

| 频率段 | 职责 | PI 的行为 | NTK 的行为 |
|--------|------|-----------|-----------|
| 高频（$i$ 小） | 局部近邻精度 | 缩放（损失精度） | **不缩放**（保住精度） |
| 低频（$i$ 大） | 长程全局 | 缩放 | 缩放约 $s$ 倍（承担扩展） |

NTK 把"扩展代价"集中到低频段——低频相位本来就转得慢，缩放损失小；高频是"信息密度"最高的维度，保留原样。**"高频保精度、低频担扩展"是理解整个长度外推技术的核心框架**。

### 2.4 为什么 YaRN 要校正温度

插值/缩放改变了 $q \cdot k$ 的统计幅度：旋转角被压缩后，各维度相位差的分布整体收窄 → logits 的均值/方差移动 → softmax 分布变"平"。温度 $t$ 把 logits 重新拉回原尺度，恢复注意力锐度。这个细节是 YaRN 相比纯 NTK 效果好一截的原因。

## 三、源码实现

### 3.1 手写实现：PI / NTK / YaRN 频率缩放

```python
import torch
import math

def rope_theta(d, base=10000.0):
    """RoPE 原始频率 [d/2]"""
    return base ** (-torch.arange(0, d, 2).float() / d)

def scale_pi(theta, s):
    """PI：所有频率除以 s"""
    return theta / s

def scale_ntk(theta, s, d):
    """NTK-Aware：theta_i * s^{-2i/(d-2)}
       等价实现：base 换成 base * s^{d/(d-2)}（注释见下）"""
    i = torch.arange(theta.numel())
    return theta * (s ** (-2 * i / (d - 2)))

def scale_ntk_base(d, s, base=10000.0):
    """NTK 的 base 等价写法：base' = base * s^{d/(d-2)}，直接换 base 即可"""
    return base * (s ** (d / (d - 2)))

def scale_yarn(theta, d, s, l_train, ramp_ratio=0.1, alpha=1.0, beta=0.1):
    """YaRN（NTK-by-parts + 平滑过渡）:
       - 波长远小于 L_train（纯高频）: 不缩放
       - 波长远大于 L_train（纯低频）: 按 PI 缩放（/s）
       - 中间: 插值系数 gamma 平滑过渡
       返回 (缩放后的频率, 温度 t)"""
    L = l_train
    lambdas = 2 * math.pi / theta                 # 各维度波长 [d/2]
    # 分界: 高频侧阈值 L * ramp_ratio，低频侧阈值 L
    lo = L * ramp_ratio
    gamma = torch.clamp((lambdas - lo) / (L - lo), min=0.0, max=1.0)
    # 混合: 不缩放（1.0）与 PI 缩放（1/s）之间按 gamma 插值
    theta_scaled = theta * (gamma / s + (1 - gamma) * 1.0)
    # 温度校正（简化形式，完整闭式解见论文）
    t = 1.0 / (alpha * (1.0 / s) + beta)
    return theta_scaled, t

# 对比三种缩放：d=128, 目标 8 倍
d, s = 128, 8.0
theta = rope_theta(d)
pi_t = scale_pi(theta, s)
ntk_t = scale_ntk(theta, s, d)
yarn_t, t = scale_yarn(theta, d, s, l_train=4096)

print(f"theta[0]  (最高频): {theta[0].item():.4f}")
print(f"  PI : {pi_t[0].item():.4f}（/8，精度损失）")
print(f"  NTK: {ntk_t[0].item():.4f}（不缩放）")
print(f"theta[-1] (最低频): {theta[-1].item():.6f}")
print(f"  PI : {pi_t[-1].item():.6f}")
print(f"  NTK: {ntk_t[-1].item():.6f}（≈/8，承担扩展）")
print(f"YaRN 温度 t = {t:.3f}")
print(f"NTK 等价 base = {scale_ntk_base(d, s):.0f}（原 10000）")
```

### 3.2 完整推理流程（缩放 + 旋转 + 验证外推）

```python
def build_rotary(max_len, d, s=1.0, method="ntk", l_train=4096):
    """按缩放方法生成频率并预计算旋转角表（cos/sin）"""
    theta = rope_theta(d)
    if s > 1.0:
        if method == "pi":
            theta = scale_pi(theta, s)
        elif method == "ntk":
            theta = scale_ntk(theta, s, d)
        elif method == "yarn":
            theta, _ = scale_yarn(theta, d, s, l_train)
    m = torch.arange(max_len, dtype=torch.float32)
    angles = torch.outer(m, theta)                # [L, d/2]
    return torch.cos(angles), torch.sin(angles)   # 与 HF 官方接口一致

def rotate_with_cos_sin(q, cos, sin):
    """HF 风格旋转（rotate_half 布局）"""
    x1, x2 = q[..., : q.shape[-1] // 2], q[..., q.shape[-1] // 2 :]
    return q * cos + torch.cat((-x2, x1), dim=-1) * sin

# 数值验证：NTK 缩放下，目标位置 s*L_train 的旋转角 ≈ 训练时 L_train 的旋转角（低频段）
d, l_train, s = 128, 64, 4.0
theta = rope_theta(d)
theta_ntk = scale_ntk(theta, s, d)
angles_new = (l_train * s) * theta_ntk    # 新长度末端
angles_old = l_train * theta              # 训练长度末端
print(torch.allclose(angles_new[-1], angles_old[-1], atol=1e-3))  # True（低频≈不越界）
```

### 3.3 与官方实现对比验证

参考实现：transformers `DynamicNTKScalingRotaryEmbedding`（LLaMA 系）与 `LlamaYaRNScalingRotaryEmbedding`。核心就是"缩放后的 $\theta$ 替换原始 $\theta$，其余完全复用 RoPE 逻辑"。内嵌官方等价写法验证：

```python
def dynamic_ntk_theta_official(d, s, base=10000.0):
    """transformers DynamicNTKScalingRotaryEmbedding 的频率公式：
       theta = (base * s^(d/(d-2)))^(-2i/d)"""
    theta = base * (s ** (d / (d - 2)))
    return theta ** (-torch.arange(0, d, 2).float() / d)

def yarn_theta_official(d, s, l_train, base=10000.0, beta_fast=32, beta_slow=1):
    """transformers YaRN 官方频率：同样先算原始 theta，再做逐维插值
       （beta_fast/beta_slow 控制高低频阈值，此处给简化等价形式）"""
    theta = base ** (-torch.arange(0, d, 2).float() / d)
    lambdas = 2 * math.pi / theta
    # 官方: gamma = (lambdas 对数位置) 线性插值（本质同 3.1 的 clamp 混合）
    lo, hi = l_train * (beta_slow / beta_fast), l_train
    gamma = torch.clamp((lambdas - lo) / (hi - lo), 0.0, 1.0)
    return theta * (gamma / s + (1 - gamma))

# 等价性验证
d, s = 128, 8.0
torch.manual_seed(0)
a = scale_ntk(theta, s, d)                 # 手写（式 1）
b = dynamic_ntk_theta_official(d, s)       # 官方 base 写法
print(torch.allclose(a, b, atol=1e-6))     # True（式 1 与 base 写法完全等价）

# 应用示例：把缩放后的频率喂给 3.2 的旋转逻辑，得到可直接推理的 cos/sin
cos, sin = build_rotary(8192, d=128, s=8.0, method="yarn", l_train=1024)
print(cos.shape)                           # torch.Size([8192, 64])
```

## 四、性质分析

### 4.1 对比总表

| 方法 | 缩放方式 | 参数/超参 | 微调需求 | 核心思想 | 代表 |
|------|---------|-----------|---------|---------|------|
| PI | 全维度 $\theta_i/s$ | $s$ | 少量 | 坐标线性压缩进训练区间 | Meta LLaMA 长上下文 |
| NTK-Aware | $\theta_i s^{-2i/(d-2)}$ | $s$（或 base） | 少量 | 高频保留、低频缩放 | 社区主流（OASST 等） |
| YaRN | 分波长段 PI/NTK 混合 | $s$、临界波长、温度 $t$ | 少量 | NTK-by-parts + logits 温度校正 | Mistral 7B 128K |
| LongRoPE | 逐维独立缩放 | 每维一个系数 | 少量/两阶段 | 非均匀插值 + 搜索最优 | LongRoPE、Grok-1 2M |

### 4.2 各方法行为对比

| 观察点 | PI | NTK | YaRN | LongRoPE |
|--------|----|-----|------|----------|
| 高频（局部精度） | 损失 $s$ 倍 | 保留 | 保留（短波长段不缩放） | 多缩放（承担损失） |
| 低频（长程） | 缩放 | 缩放 $s$ 倍 | 按 PI 缩放 | 少缩放 |
| 无微调直接用 | 差 | 中 | 中 | **好**（256K 无微调损失） |
| 最大扩展 | 32K 级 | 64K 级 | 128K 级（Mistral） | 2M 级（Grok-1） |

### 4.3 组合使用规则（面试加分）

- 插值类技术**不需要重训**，但"少量长文本微调"能显著提升长程效果（Meta 用 5B token）；
- 可以叠加：LongRoPE 本质 = "逐维最优 NTK 系数 + 搜索"，YaRN = "NTK-by-parts + 温度"；
- 与 M-RoPE 兼容：Qwen2-VL 的文本段外推同样走 PI/NTK 路线（视觉段坐标天然小）。

## 五、优缺点

| 方法 | 优点 | 缺点 |
|------|------|------|
| PI | 实现最简单；角度值域严格不越界 | 高频分辨率损失 $s$ 倍；短文本性能下降 |
| NTK-Aware | 只改 base 一个超参；保局部精度 | 无温度校正，logits 分布偏移未补偿 |
| YaRN | 分波长段精细处理 + 温度校正，效果最好 | 超参多（临界波长、温度函数需调） |
| LongRoPE | 逐维最优，扩展倍数最大（256K/2M） | 需要搜索流程（离线计算各维系数） |

## 六、与同类对比

| 方案 | 位置机制 | 扩展方式 | 外推能力 | 代表 |
|------|---------|---------|---------|------|
| RoPE 原样 | 旋转 | 无 | 差（相位 OOD） | LLaMA 早期 |
| RoPE + PI | 旋转 | 坐标压缩 | 好（需微调） | LLaMA 长上下文 |
| RoPE + NTK | 旋转 | 分级缩放 | 好 | 社区主流 |
| RoPE + YaRN | 旋转 | 分段 + 温度 | 很好（128K） | Mistral |
| RoPE + LongRoPE | 旋转 | 逐维非均匀 | 极好（2M） | Grok-1 |
| ALiBi | 线性偏置 | **无需任何技术** | 好（0-成本） | BLOOM |
| 可学习表 | 查表 | 插值表 | 差 | 旧版模型 |

**关键结论**：
1. **ALiBi 是唯一"原生外推"**：距离值域全覆盖，不需要插值；RoPE 系全部需要插值技术；
2. **插值 vs 重训**：插值"立即生效 + 少量微调"，重训"从头学位置分布"——现代路线几乎全是插值；
3. 选择逻辑：实现优先 → PI；效果优先 → YaRN；极致长上下文 → LongRoPE。

## 七、高频面试问答

**Q1：外推和插值的区别？**
外推=直接使用训练长度外的位置（RoPE 相位 OOD → 崩溃）；插值=把位置坐标压缩回训练区间（PI/NTK/YaRN/LongRoPE 都是"内插"）。插值不引入新分布，所以可行。

**Q2：PI 和 NTK 的区别？**
PI 所有维度统一 $\theta_i/s$（简单但损失高频分辨率）；NTK 分级：高频（$i$ 小）不缩放、低频（$i$ 大）缩放约 $s$ 倍，等价于把 base 改为 $10000 \cdot s^{d/(d-2)}$——保局部精度、让低频承担扩展。

**Q3：NTK 的 base 等价写法推导？**
$(base \cdot s^{d/(d-2)})^{-2i/d} = base^{-2i/d} \cdot s^{-2i/(d-2)}$，恰好等于 NTK 缩放公式 $\theta_i s^{-2i/(d-2)}$。所以实现上只需换 base 一个超参。

**Q4：YaRN 相比 NTK 改进在哪？**
① NTK-by-parts：按波长与 $L_{train}$ 关系分三段（纯高频不缩放、纯低频按 PI、中间平滑过渡）；② 温度校正：插值后 logits 统计分布偏移，引入温度 $t$ 缩放补偿。Mistral 7B 用 YaRN 到 128K。

**Q5：为什么高频不能缩放、低频可以？**
高频（$i$ 小）波长短，负责分辨近邻位置——缩放后近邻相位差缩小，局部精度丢失；低频波长长，本来"转得慢"，缩放造成的相位变化相对小，承担长程扩展的信息损失最小。

**Q6：为什么插值后需要微调？**
插值改变了注意力分布的统计特性（logits 幅度、softmax 锐度），少量长文本微调（Meta 用 5B token）让模型重新适配新分布。LongRoPE 通过逐维系数搜索 + 温度校正做到了"无微调 256K"。

**Q7：LongRoPE 为什么比 PI 好？**
PI 对每个维度用同一系数，但各维"承受力"不同；LongRoPE 逐维搜索最优系数，把信息损失集中到影响小的高频维度、低频尽量少缩放，整体损失最小 → 256K 无微调、两阶段到 2M（Grok-1）。

**Q8：ALiBi 模型需要这些技术吗？**
不需要。ALiBi 距离值域训练期全覆盖，直接延长惩罚直线即可外推（BLOOM 2048→4096）。这些技术只针对 RoPE 的相位 OOD 问题。
