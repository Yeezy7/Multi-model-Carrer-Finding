## 一、为什么需要位置编码

### 1.1 Attention 的置换等变性（根源）

自注意力核心计算是内积 + softmax + 加权求和：

$$\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right)V$$

对任意置换 $\pi$，注意力满足**置换等变性（Permutation Equivariance）**：

$$\text{Attn}(\pi \cdot X) = \pi \cdot \text{Attn}(X)$$

即：把输入序列打乱，输出只是被"同样地打乱"，而非产生新信息。这意味着：

1. 对**任意顺序**的输入，注意力计算的"结果值"完全一样——它看不到谁在前、谁在后；
2. 两个不同句子 "A 在 B 前" 与 "B 在 A 前" 在无位置信息时输出相同（对集合而言）；
3. 语言中大量语义依赖顺序（"我爱猫" vs "猫爱我"），图像中 patch 的顺序也携带空间结构。

**结论**：Transformer 必须额外注入"顺序/位置"信息，否则退化为词袋模型（bag of words）。这是位置编码存在的根本原因。

### 1.2 三大方案：绝对 / 相对 / 无位置

| 方案 | 注入方式 | 典型代表 | 核心思想 |
|------|---------|---------|---------|
| **绝对位置编码** | 在输入 embedding 上加位置向量 $e_i = x_i + p_i$ | Transformer 原版（正弦）、BERT、ViT | 每个位置 $i$ 一个固定表示，先验是"位置本身就是特征" |
| **相对位置编码** | 在 attention 计算中注入位置差 $i-j$ | Transformer-XL、T5、ALiBi、RoPE | 先验是"距离 $i-j$ 比绝对下标更有用" |
| **无位置编码** | 什么都不加 | NoPE（研究性） | 靠因果掩码 + token 内容隐式学位置 |

### 1.3 描述位置编码的四个维度（记忆框架）

| 维度 | 问题 | 选项 |
|------|------|------|
| **注入点** | 位置加在哪里？ | 输入 embedding（加性）/ attention logits（偏置）/ q、k 变换（乘性） |
| **参数性** | 位置是固定的还是学出来的？ | 函数式固定（正弦）/ 可学习（查表）/ 可学习但函数约束（T5 桶） |
| **相对性** | 用的是绝对下标还是距离？ | 绝对 $i$ / 相对 $i-j$ / 坐标 $(t,h,w)$ |
| **外推性** | 超训练长度还能用吗？ | 差（查表崩溃）/ 中（有限）/ 好（函数式或距离值域不变） |

> **一句话总览**：绝对编码解决"有无位置"问题，相对编码解决"如何外推 + 平移不变"问题，RoPE 把相对编码融进旋转矩阵以兼容"乘性位置 + 线性注意力"，M-RoPE 再把它推广到三维时间-空间。

## 二、绝对位置编码（重点）

### 2.1 正弦/余弦编码（Transformer 原版，Vaswani 2017）

#### 公式

对位置 $pos$、维度下标 $i$（$0 \le i < d/2$），位置向量第 $2i$ 和第 $2i+1$ 维定义为：

$$PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right), \qquad PE(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

记 $\omega_i = 10000^{-2i/d}$（角频率），则 $PE(pos, 2i) = \sin(pos \cdot \omega_i)$。

**结构**：$d$ 维位置向量由 $d/2$ 个"不同频率的 sin/cos 对"拼成：

$$PE(pos) = [\sin(pos\,\omega_0), \cos(pos\,\omega_0), \sin(pos\,\omega_1), \cos(pos\,\omega_1), \dots]$$

**作用方式**（加性）：$e_{pos} = x_{pos} + PE(pos)$，即词嵌入与位置向量逐元素相加后进入 Transformer。

#### 为什么频率取几何级数（面试必考）

$\omega_i = 10000^{-2i/d}$ 意味着波长从 $2\pi$（$i=0$，最快）指数增长到 $2\pi \cdot 10000 \approx 62832$（$i=d/2-1$，最慢）：

$$\lambda_i = \frac{2\pi}{\omega_i} = 2\pi \cdot 10000^{2i/d}$$

用**时钟类比**最直观：同一根轴上装了 $d/2$ 根指针，转速各差 10000 倍——

| 维度 | 指针类比 | 作用 |
|------|---------|------|
| 高频（$i$ 小，周期短） | 秒针 | 分辨**相邻**位置（局部精度） |
| 中频（$i$ 中） | 分针 | 分辨**较近**位置 |
| 低频（$i$ 大，周期长） | 时针 | 分辨**全局**/远距位置 |

为什么这样设计，两条理由：

1. **多尺度覆盖**：语言中近邻关系（词法/句法，距离 1-3）与远距关系（指代/长程依赖，距离几十上百）都需要区分。单一频率无法兼顾：高频很快"绕圈"产生位置混淆（$sin(pos\omega)$ 与 $sin((pos+2\pi/\omega)\omega)$ 相同），低频则无法区分近邻位置（$sin(pos\omega)$ 与 $sin((pos+1)\omega)$ 几乎相等）。几何级数让每个尺度都有若干维度专门负责。
2. **位置指纹均匀化**：每个位置在 $d$ 维空间形成一个"相位指纹"。几何级数保证任意两个位置的编码向量在 Hamming/欧氏意义下不会大面积重合，模型能"按需取用"不同分辨率的维度。

#### 为什么能表达相对位置（三角恒等式推导，面试必考）

**引理**：对任意偏移 $k$，$PE(pos+k)$ 是 $PE(pos)$ 的**线性函数**（系数只依赖 $k$）。

推导：$\sin(a+b) = \sin a \cos b + \cos a \sin b$，代入 $a = pos \cdot \omega_i$、$b = k \cdot \omega_i$：

$$\begin{aligned}
PE(pos+k, 2i) &= \sin((pos+k)\omega_i) \\
&= \underbrace{\cos(k\omega_i)}_{\text{只与 } k \text{ 有关}} \cdot \sin(pos\,\omega_i) + \underbrace{\sin(k\omega_i)}_{\text{只与 } k \text{ 有关}} \cdot \cos(pos\,\omega_i) \\
&= \cos(k\omega_i)\, PE(pos, 2i) + \sin(k\omega_i)\, PE(pos, 2i+1)
\end{aligned}$$

对每个 $i$ 成立，所以存在一个**只由 $k$ 决定的对角/块旋转矩阵** $T_k$：

$$PE(pos+k) = T_k \, PE(pos)$$

**含义**：模型要建模"相对位置 $k$"，只需学一组线性变换 $\{T_k\}$；由于权重在全部位置上共享，一个线性层同时实现了所有位置的相对位移——绝对编码"免费"获得了表达相对位置的能力。

**更强的结论（绝对编码在 attention 中的相对性）**：若 $q,k$ 都带绝对正弦编码，展开内积可得：

$$\begin{aligned}
(x_i + PE_i)^\top (x_j + PE_j)
&= x_i^\top x_j + x_i^\top PE_j + PE_i^\top x_j + PE_i^\top PE_j
\end{aligned}$$

最后一项用积化和差公式 $\sin a\sin b + \cos a\cos b = \cos(a-b)$：

$$PE_i^\top PE_j = \sum_{i'=0}^{d/2-1} \cos((i-j)\,\omega_{i'})$$

**只依赖 $i-j$**。即：即便论文声称是"绝对编码"，它在 attention 内积中天然携带相对距离项。这也是"绝对编码在外推测试上并没有彻底崩溃"的部分原因。

### 2.2 可学习位置编码（BERT / ViT）

做法：直接定义一个可学习参数矩阵 $P \in \mathbb{R}^{L_{\max} \times d}$，位置 $i$ 的向量就是第 $i$ 行，随训练一起更新：

$$e_i = x_i + P[i, :]$$

| 模型 | 表大小 | 说明 |
|------|--------|------|
| BERT | $512 \times 768$ | 输入最长 512 token |
| GPT-2 | $1024 \times 768$ | |
| ViT | $197 \times 768$ | 196 个 patch + 1 个 CLS |
| CLIP 双塔 | $197 \times 768$ | 与 ViT 相同 |

**特点**：

1. 表达能力不受公式约束，完全由数据决定——BERT 原论文报告其效果**略优于**正弦编码；
2. 查表操作 $O(1)$，实现简单；
3. **外推性差**：训练长度 $L_{\max}$ 之外的位置**没有对应向量**（不存在"计算"方法），属于彻底 OOD，直接崩溃；
4. 若要换更大分辨率/更长上下文，只能**插值**（双线性插值整张表）或继续训练（位置表被"撑大"）。

### 2.3 正弦 vs 可学习：对比表

| 维度 | 正弦编码 | 可学习编码 |
|------|---------|-----------|
| 参数 | **0**（函数式，固定） | $L_{\max} \times d$ |
| 超长度是否有定义 | 有（任意 $pos$ 可计算） | **无**（越界即 OOD） |
| 实际外推效果 | 有限（短程可用，200+ 衰减） | 差（直接崩溃） |
| 表达能力 | 受频率结构约束 | 自由 |
| 相对位置表达能力 | 有（三角恒等式，见 2.1） | 有（数据中学出来） |
| 实现 | 预计算一张表即可（仍是查表） | 初始化 + 训练 |
| 典型模型 | Transformer 原版 | BERT、GPT-2、ViT、CLIP |
| 训练效率 | 略快（省梯度更新） | 略慢（多一个矩阵） |

> **面试记忆点**：正弦编码的"外推优势"仅是**定义域**优势（任意长度都有值），不是**效果**优势——两个都不擅长真正外推，这是后来相对位置编码登场的原因。

## 三、相对位置编码（重点）

### 3.1 为什么需要相对位置

1. **语言先验是"距离"而非"下标"**：指代消解、句法依存、"A 修饰 B" 等核心关系只依赖相对距离 $i-j$；同一个词出现在第 100 位还是第 500 位，其"语法角色"一样。
2. **平移不变性**：句子的意义不因整体平移而改变。绝对编码需要模型额外学习"位置的不变性"，浪费参数。
3. **长度外推（关键）**：绝对编码中，位置组合 $(内容, i)$ 在训练时只见过 $i < L_{train}$ 的部分；而相对编码中，**距离 $i-j$ 的值域 $[0, L_{train})$ 在训练中已被全部覆盖**。外推只是把"已见过的距离"用在更长序列上，天然外推友好。

### 3.2 Shaw 相对位置编码（原始形式，也是 T5 bias 的基础）

**思想**：不再把位置信息加入输入 embedding，而是把它作为**偏置**直接加进 attention 分数。

$$\text{score}(i, j) = q_i^\top (k_j + b_{j-i}) \quad \text{或} \quad \text{score}(i, j) = q_i^\top k_j + b_{j-i}$$

其中 $b_{j-i} \in \mathbb{R}^d$（或标量）是**可学习**的相对位置向量，只依赖 $j-i$。

**截断窗口**：距离范围裁剪到 $[-K, K]$，超出部分统一取边界值：

$$b_{j-i} \rightarrow b_{\text{clip}(j-i, -K, K)}$$

好处：① 参数有限（$O(2K \cdot d)$）；② 超出 $K$ 的远距离"一视同仁"，让模型专注于近程局部关系。

**局限**：训练长度内的距离被截断后信息有损；长距离关系（超过 $K$）完全无法区分。

### 3.3 Transformer-XL 的相对位置编码（四项拆解思想）

Transformer-XL 把绝对位置编码展开，逐项替换为相对量——这是面试中"推导相对位置编码"的经典题。

**第一步：展开**。绝对编码下 $Q_i = (E_i + U_i)W_q$，$K_j = (E_j + U_j)W_k$（$E$ 为词嵌入，$U$ 为绝对位置），内积展开为四项：

$$A_{ij} = \underbrace{E_i W_q W_k^\top E_j^\top}_{\text{① 内容-内容}} + \underbrace{E_i W_q W_k^\top U_j^\top}_{\text{② 内容-绝对位置}} + \underbrace{U_i W_q W_k^\top E_j^\top}_{\text{③ 绝对位置-内容}} + \underbrace{U_i W_q W_k^\top U_j^\top}_{\text{④ 绝对位置-绝对位置}}$$

**第二步：逐项替换**：

- ① 保持不变（词之间的语义匹配）；
- ② 把绝对位置 $U_j$ 换成**相对位置** $R_{i-j}$（正弦编码，固定、不参与训练），并给位置单独配一个 Key 投影 $W_{k,R}$；
- ③ 把 $U_i$ 换成**与内容无关的可学习标量向量** $u$（含义："query 端无条件偏向某些位置"）；
- ④ 换成另一个可学习标量向量 $v$（含义："全局位置-位置偏置"）。

得到四项式：

$$A_{ij} = E_i W_q W_k^\top E_j^\top + E_i W_q W_{k,R}^\top R_{i-j}^\top + u^\top W_k^\top E_j^\top + v^\top W_{k,R}^\top R_{i-j}^\top$$

**核心思想**（背下来）：
1. **位置只出现在 Key 侧**（query 侧的位置退化为全局偏置 $u,v$）——因为 query 的绝对位置没有"相对"意义，只有 key 的相对距离有用；
2. 相对位置 $R_{i-j}$ 用**固定正弦函数**生成，超训练长度也可计算 → 支持 Transformer-XL 的**状态复用（segment 间跨越）与长度外推**；
3. 四项各自承担可解释的角色：内容匹配 / 内容对位置的注意力 / 内容偏置 / 位置偏置。

### 3.4 ALiBi（Attention with Linear Biases）—— 零参数外推王者

#### 定义

ALiBi **完全不做位置 embedding**，只在 attention 分数上加一个线性的距离惩罚：

$$\text{score}(i, j) = q_i^\top k_j \; - \; m \cdot |i - j|$$

- $m$ 是**每头不同的固定斜率**（不训练，零参数）；
- 常用设定：第 $h$ 个头的斜率 $m_h = 2^{-8h/H}$（$h = 1..H$，MPT/BLOOM 实现），或 $m_h = 2^{-h}$（$h = 0..H-1$）；总之是一个**几何序列**，头部之间斜率成倍递减；
- 因果注意力中 $i \ge j$，故等价于 $-m \cdot (i-j)$，直接加到 logits 上：$\text{logits} = qk^\top/\sqrt{d} - m(i-j)$。

#### 为什么零参数还能外推（面试必考）

1. **距离值域训练期全覆盖**：$|i-j| \in [0, L_{train})$，所有距离的惩罚值在训练中都见过；外推只是把同一根惩罚直线延长到更大距离，**没有引入任何新的输入分布**（对比：RoPE 外推是未见过的旋转角度组合；可学习表外推是未定义的索引）；
2. **近因偏置（Recency Bias）符合语言先验**：大多数注意力应该聚焦最近词——线性惩罚让远端 token 的分数随距离线性衰减，与语言模型的实际注意力模式一致；
3. **强制"内容优先、位置衰减"的结构**：ALiBi 等于告诉模型"位置信息只以距离函数形式存在"，避免了模型去记忆绝对位置 → 训练分布里没有位置长尾，也就没有外推崩溃的根源。

**代表模型**：BLOOM（2048→4096 直接外推）、GPT-NeoX（2K/4K）、MPT。**代价**：注意力受距离惩罚，长文本上"远距信息读取"能力比 RoPE 弱一些。

#### 与 T5 relative bias 的联系

两者都把偏置加在 logits 上（$\text{score} = qk^\top + b_{i-j}$）；区别在于 ALiBi 的 $b_{i-j} = -m|i-j|$ 是**固定的线性函数**（零参数），T5 的 $b$ 是**可学习的查表**。

### 3.5 T5 的可学习相对位置偏置（Relative Bias Buckets）

**做法**：相对距离 $j-i$ 先映射到"桶"（bucket），每个桶对应一个可学习标量偏置，加到 logits：

$$\text{score}(i, j) = q_i^\top k_j + b_{\text{bucket}(j-i)}, \qquad b \in \mathbb{R}^{\text{num\_buckets}}$$

**桶的分桶策略**（T5 默认 `num_buckets=32, max_distance=128`）：**近处线性、远处对数**：

```python
def relative_position_bucket(distance, num_buckets=32, max_distance=128):
    # distance = j - i
    if distance <= 0:
        return 0                                  # 负距离（或左侧）共用一个桶
    max_exact = num_buckets // 2                  # 16
    if distance < max_exact:                      # 近处：每距离一个桶（线性）
        return distance + 1
    # 远处：对数分桶，每 2 倍距离一个桶
    bucket = max_exact + 1 + int(math.log(distance / max_exact)
                / math.log(max_distance / max_exact)
                * (num_buckets - max_exact - 1))
    return min(bucket, num_buckets - 1)
```

**为什么这么设计**：

| 距离范围 | 分桶 | 理由 |
|---------|------|------|
| 近（$< 16$） | 每 1 个距离一个桶 | 近程语法关系敏感，需要细粒度区分 |
| 远（$\ge 16$） | 每约 2 倍距离一个桶 | 远距关系粗糙，对数分桶省参数 |
| 超 max_distance | 全部落入最后一个桶 | 远距"一视同仁"，参数封闭、可外推 |

**优点**：参数从 $O(L^2)$（每对距离一个标量）降到 $O(\text{buckets})$；对数桶天然把"训练中从未组合过的远距离"映射到已学习的桶上，具备一定外推性（T5 由此 512→数千无碍）。

## 四、RoPE：旋转位置编码（重点中的重点）

RoPE（Rotary Position Embedding，Su et al. 2021）把位置编码设计为对 **Q、K 向量的旋转**，使注意力分数天然只依赖相对位置，且不引入任何位置参数。LLaMA、Qwen、GLM、GPT-NeoX 之后的几乎全部开源大模型都在用。

### 4.1 旋转矩阵的几何含义

把 $d$ 维向量按相邻两维配对：$(x_0, x_1), (x_2, x_3), \dots$，每一对看作二维平面上的一个点。位置 $m$ 对向量 $x$ 的作用是**把每一对按对应角度旋转**：

$$f_q(x, m) = R_m x, \qquad R_m = \text{diag}\big(R(\theta_0 m), R(\theta_1 m), \dots, R(\theta_{d/2-1} m)\big)$$

其中二维旋转矩阵为：

$$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$

对第 $i$ 对维度显式写出：

$$\begin{pmatrix} x_{2i}' \\ x_{2i+1}' \end{pmatrix} = \begin{pmatrix} \cos(m\theta_i) & -\sin(m\theta_i) \\ \sin(m\theta_i) & \cos(m\theta_i) \end{pmatrix} \begin{pmatrix} x_{2i} \\ x_{2i+1} \end{pmatrix}$$

**几何直觉**：位置 $m$ 越靠后，向量转过的角度越大。注意这里与加性编码的差别——RoPE 是**乘性变换**（旋转），且只作用在 $q$ 和 $k$ 上，$v$ 与输入 embedding **不加任何位置**。

### 4.2 复数表示：旋转 = 复数乘法

二维旋转与复数乘法同构：把 $(x_{2i}, x_{2i+1})$ 写成复数 $z_i = x_{2i} + \mathrm{i}\,x_{2i+1}$，则"旋转 $\theta_i m$ 弧度"等价于乘以单位复数 $e^{\mathrm{i}m\theta_i}$：

$$f(z_i, m) = z_i \cdot e^{\mathrm{i}m\theta_i}$$

沿所有维度拼接，就是整个向量的复频域旋转。这个视角让"为什么内积只依赖相对位置"的推导变得极其简洁。

### 4.3 核心推导：旋转后内积只依赖相对位置（面试必考）

**二维/复数形式推导**。设 $q$ 在位置 $m$、$k$ 在位置 $n$，$q_k = q_{2i} + \mathrm{i}q_{2i+1}$：

$$f_q(q, m) = q\,e^{\mathrm{i}m\theta_i}, \qquad f_k(k, n) = k\,e^{\mathrm{i}n\theta_i}$$

实数内积 = 复乘积的实部：

$$\langle f_q(q,m), f_k(k,n) \rangle = \text{Re}\Big( q\,e^{\mathrm{i}m\theta_i} \cdot \overline{k\,e^{\mathrm{i}n\theta_i}} \Big) = \text{Re}\Big( q\,\overline{k} \, e^{\mathrm{i}(m-n)\theta_i} \Big)$$

**旋转后的内积只通过 $e^{\mathrm{i}(m-n)\theta_i}$ 依赖 $m-n$**。

**矩阵形式推导**。$R_m$ 是正交矩阵（$R_m^\top = R_{-m} = R_m^{-1}$），且同频旋转可合并（$R_a R_b = R_{a+b}$）：

$$\langle R_m q, R_n k \rangle = q^\top R_m^\top R_n k = q^\top R_{-m} R_n k = q^\top R_{n-m} k$$

同样只依赖 $n-m$。**含义**：

1. attention 分数由"内容匹配 $q^\top k$"经相对距离 $n-m$ 的旋转调制得到——位置信息 100% 是相对距离的函数；
2. 旋转保持范数：$\|R_m x\| = \|x\|$，数值稳定，且与 RMSNorm 天然兼容；
3. 距离越远，角度差越大，$q$ 与 $k$ 的相位错位越大 → 长距离匹配天然衰减（与 ALiBi 的"近因偏置"异曲同工，但机制是乘性的余弦调制而非减性的线性惩罚）。

### 4.4 具体实现：频率与维度的对应

**基频**（与正弦编码同一套路）：$d$ 为 head_dim，配对维度下标 $i = 0, 1, \dots, d/2-1$：

$$\theta_i = 10000^{-2i/d}, \qquad \lambda_i = \frac{2\pi}{\theta_i} = 2\pi \cdot 10000^{2i/d}$$

- $i=0$：$\theta=1$，波长 $2\pi$（最高频，秒针）；
- $i = d/2-1$：$\theta \approx 10000^{-1}$，波长 $\approx 62832$（最低频，时针）。

**位置 $m$ 的旋转角** = $m \cdot \theta_i$（每个维度对用自己独立的 $\theta_i$）。实现时预计算角度表：

```python
def precompute_rope_freqs(head_dim, max_len, base=10000.0):
    # 频率: [head_dim/2]，几何级数
    theta = base ** (-torch.arange(0, head_dim, 2).float() / head_dim)
    m = torch.arange(max_len)
    freqs = torch.outer(m, theta)          # 角度表 [L, head_dim/2]
    return freqs

def apply_rope(x, freqs):
    # x: [B, L, H, D]（q 或 k），freqs: [L, D/2]
    x = x.reshape(*x.shape[:-1], -1, 2)    # 配对 [..., D/2, 2]
    x_c = torch.view_as_complex(x)         # 转复数
    freqs_c = torch.polar(torch.ones_like(freqs), freqs)   # e^{i*m*theta}
    x_rot = torch.view_as_real(x_c * freqs_c.unsqueeze(0).unsqueeze(2)).flatten(-2)
    return x_rot
```

实现要点（面试细节）：

| 要点 | 说明 |
|------|------|
| 旋转对象 | **只有 q 和 k**，v 不旋转，输入 embedding 不加位置 |
| 配对方式 | 相邻两维 $(2i, 2i+1)$ 为一对；实现上常用"错位对偶"技巧（维度对旋转后相邻交换）以提升访存效率 |
| 频率维度 | 每个配对 $i$ 用独立 $\theta_i$，从 $10000^0=1$ 到 $10000^{-(d-2)/d}$ 几何递减 |
| 因果注意 | 位置从 0 开始计；跨模块拼接时（如多图）位置索引可平移/重置 |
| 与加性编码 | 互不冲突，可叠加（如 GPT-NeoX 在 RoPE 之外也可加可学习绝对位置） |

### 4.5 外推问题：为什么训练长度是硬约束

RoPE 的旋转角 $\phi = m\theta_i$ 与位置 $m$ 线性增长。训练长度 $L$ 内模型见过的角度集是 $[0, L\theta_i)$；一旦 $m > L$：

1. **未见角度组合**：所有 $d/2$ 个维度的相位 $(m\theta_0, \dots, m\theta_{d/2-1})$ 是一个从未出现的 $d/2$ 维向量——属于严格 OOD 输入；
2. **注意力分布漂移**：高频维（$i$ 小）角度早已转过很多圈，$q,k$ 的相位错位模式与训练分布完全不同 → PPL 在 $L$ 处突然尖峰（典型表现：4K 训练的 LLaMA 直接跑 8K 上下文，PPL 暴涨、输出退化）；
3. **没有"距离值域覆盖"保护**：与 ALiBi 不同，RoPE 的位置信息是**乘性相位**，不存在"训练中见过所有值"的维度。

因此 RoPE 必须配合**长度扩展技术**（下一节）或继续训练才能超过训练长度。

## 五、RoPE 的长度外推技术（必考方向）

设训练长度 $L_{train}$，目标长度 $L_{new} = s \cdot L_{train}$（$s$ 为扩展倍率）。四类主流方法：

### 5.1 位置插值 PI（Position Interpolation）

**思想**：不把位置推到区间外，而是把**坐标压缩**进训练区间——"用更慢的指针走更长的路"。

$$f'(x, m) = f\!\left(x, \frac{m}{s}\right) \quad \Longleftrightarrow \quad \theta_i' = \frac{\theta_i}{s}$$

所有频率统一除以 $s$（波长统一放大 $s$ 倍）。$m = s \cdot L_{train}$ 处恰好旋转角度等于训练时的 $L_{train}$ 处 → **角度值域完全不越界**。

| 优点 | 缺点 |
|------|------|
| 立即生效，无需从头训练 | 高频分辨率损失：压缩后相邻位置的相位差缩小 $s$ 倍，长距离内"近邻区分度"下降 |
| 只需少量微调（Meta 用 5B token 数据） | 直接使用不微调时效果仍差 |
| 短文本性能损失可控 | 后续外推仍受限于新长度 |

**代表**：Meta LLaMA 长上下文工作、CodeLlama（RoPE scaling）。

### 5.2 NTK-Aware 缩放（高频不缩放、低频缩放）

**思想**（来自神经正切核视角 + 信号处理直觉）：高频维度负责**局部近邻**分辨率，低频维度负责**全局长程**。外推只需要把**低频**的波长拉长（把长距离信息"压缩"回训练分布），**高频**保持原样以保住局部精度：

$$\theta_i' = \theta_i \cdot s^{-2i/(d-2)}$$

- $i=0$（最高频）：指数为 0 → **完全不缩放**；
- $i = d/2-1$（最低频）：指数 $\approx -1$ → 频率缩小约 $s$ 倍（波长放大 $s$ 倍）。

**等价描述**：把 base 放大为 $base' = base \cdot s^{d/(d-2)}$（因为 $(base')^{-2i/d} = base^{-2i/d} \cdot s^{-2i/(d-2)}$），实现上只需改一个超参。

**与 PI 的区别**（面试高频）：PI 对所有维度统一缩放（$s^{-1}$），NTK 按维度分级缩放（$s^{-2i/(d-2)}$）——高频保留分辨率、低频承担扩展。

### 5.3 YaRN（NTK-by-parts + 温度校正）

YaRN（Yet another RoPE extensioN，2023）改进两点：

**① NTK-by-parts（分波长段处理）**：按波长 $\lambda_i = 2\pi/\theta_i$ 与训练长度的关系，把维度分三段：

| 波长条件 | 含义 | 处理 |
|---------|------|------|
| $\lambda_i \ll L_{train}$ | 纯高频，只编码局部 | **不缩放**（保持原频率） |
| $\lambda_i \gg L_{train}$ | 纯低频，只编码长程 | **按 PI 缩放**（$\theta_i/s$） |
| 中间带 | 模糊区 | 平滑过渡（插值系数 $\gamma \in [0,1]$） |

**② 注意力温度校正**：插值改变了 attention logits 的平均幅度（位置相位被压缩后，$\langle q,k\rangle$ 的统计分布移动），YaRN 引入一个**温度 $t$** 对 logits 做缩放（$\text{logits}/t$，相当于 softmax 温度），补偿分布偏移；$t$ 是 $s$ 的函数（直觉量级 $\approx 1/\sqrt{s}$），具体闭式解在论文中由能量守恒推导。

**结果**：Mistral 7B 官方用 YaRN 扩到 128K；效果普遍优于纯 PI 与纯 NTK。

### 5.4 LongRoPE（非均匀插值）

**思想**：PI 用统一缩放系数，但**每个维度对长程扩展的"承受力"不同**（低频维缩放损失小、高频维缩放损失大）。LongRoPE 在**每个维度上独立搜索最优缩放系数**：

- 把插值引入的信息损失集中到**影响小的高频维度**（高频维多缩放、低频维少缩放），从而整体损失最小化 → **256K 无微调损失**；
- 用**搜索 + 验证**自动确定各维系数（无需人工设计曲线）；
- **两阶段扩展**：先扩到 256K，再"微调 + 二次扩展"到 2M（Grok-1 采用）。

### 5.5 外推技术对比总结

| 方法 | 缩放方式 | 参数/超参 | 微调需求 | 核心思想 | 代表 |
|------|---------|-----------|---------|---------|------|
| PI | 全维度 $\theta_i/s$ | $s$ | 少量 | 坐标线性压缩进训练区间 | LLaMA 长上下文 |
| NTK-Aware | 维度相关 $\theta_i s^{-2i/(d-2)}$ | $s$（或 base） | 少量 | 高频保留、低频压缩 | 社区主流（OASST 等） |
| YaRN | 分波长段 PI/NTK 组合 | $s$、临界波长、温度 $t$ | 少量 | NTK-by-parts + logits 温度校正 | Mistral 7B 128K |
| LongRoPE | 逐维独立缩放 | 每维一个系数 | 少量/两阶段 | 非均匀插值 + 搜索最优 | LongRoPE、Grok-1 2M |

> **面试记忆点**：外推 = 超范围直接用（RoPE 会崩）；插值 = 把位置坐标压缩回训练范围（PI/NTK/YaRN/LongRoPE 都是"内插"）。它们解决的都是同一个问题：RoPE 的相位在训练长度外是 OOD。

## 六、2D/3D 位置编码（多模态视角，重点）

### 6.1 ViT 的 1D 位置编码 vs 2D 分解

**ViT 原版（1D）**：图像切成 $H \times W$ 个 patch 后按行优先展成一维序列，使用**可学习 1D 位置表**（$P \in \mathbb{R}^{(HW+1) \times d}$，加 CLS）。

**2D 分解**：位置用坐标 $(r, c)$ 表示，位置向量 = **行向量 + 列向量**：

$$PE(r, c) = P_{\text{row}}[r] + P_{\text{col}}[c], \qquad P_{\text{row}} \in \mathbb{R}^{H \times d}, \; P_{\text{col}} \in \mathbb{R}^{W \times d}$$

| 维度 | 1D 表 | 2D 分解 |
|------|-------|---------|
| 参数量 | $HW \cdot d$ | $(H+W) \cdot d$（大幅减少） |
| 任意分辨率 | 需插值或重训 | **取前 $R$ 行、前 $C$ 列即可组合**，无需插值 |
| 结构先验 | 无（顺序即结构） | 显式行/列语义，利于平移不变性 |
| 表达能力 | 理论更强（参数多） | 够用且泛化更好 |

**为什么 2D 分解在动态分辨率下更好**：1D 表把 $(r, c)$ 编码成单一序号，序号与分辨率绑定；2D 分解把两个坐标轴**解耦**，任何 $H' \times W'$ 的图像都只需取行表前 $H'$ 行 + 列表前 $W'$ 列——**零插值、零重训**。这也是为何多模态模型的视觉塔普遍倾向 2D 化（或直接上 M-RoPE）。

### 6.2 Swin Transformer 的相对位置偏置

Swin 用**窗口内**自注意力（窗口 $M \times M$），位置信息用**可学习的二维相对位置偏置表**：

$$\text{score}(i, j) = \frac{q_i^\top k_j}{\sqrt{d}} + B[\Delta h + (M-1), \; \Delta w + (M-1)], \qquad \Delta h = h_i - h_j,\; \Delta w = w_i - w_j$$

- 偏置表 $B \in \mathbb{R}^{(2M-1) \times (2M-1)}$（$M=7$ 时仅 $13 \times 13 = 169$ 个参数）；
- 相对偏移**平移不变**：窗口内任意位置的配对共享同一偏置；
- 索引加 $(M-1)$ 把负偏移平移到非负下标。

**SwinV2 改进**（面试加分）：用**对数间距的连续相对位置偏置**（log-spaced CPB），以 8×8 窗口训练的偏置网络可迁移到任意窗口大小（跨分辨率推理）。

### 6.3 M-RoPE：Qwen2-VL 的 3D 旋转位置编码（多模态必考）

**问题**：视频/多图输入中，token 的位置天然是**三维**的——第几帧 $t$、帧内第几行 $h$、第几列 $w$。若只用 2D 空间位置：

1. 不同帧、同一位置的 patch 无法区分（时间混淆）→ 注意力会把跨帧内容当同一画面；
2. 帧间运动（时序关系）无法建模。

**方案**：把 RoPE 推广到 3D——每个 token 的位置索引从标量 $m$ 变成三元组 $(m_t, m_h, m_w)$：

| 维度 | 含义 | 示例（视频第 3 帧第 5 行第 7 列） |
|------|------|-----------------------------|
| 时间 $m_t$ | 帧序号（或片段索引） | $m_t = 3$ |
| 高度 $m_h$ | 帧内 patch 行号 | $m_h = 5$ |
| 宽度 $m_w$ | 帧内 patch 列号 | $m_w = 7$ |

**mrope_section 的概念**：head_dim 的一半（RoPE 作用的配对维度数）被**分成三段**，每段分配给一个轴。Qwen2-VL（head_dim=128）配置为：

$$\text{mrope\_section} = [16, 24, 24], \qquad 16 + 24 + 24 = 64 = \frac{d}{2}$$

即：时间轴用频率下标 $i = 0..15$（16 个配对维度）、高度轴用 $i = 16..39$、宽度轴用 $i = 40..63$。每个轴各自按 $\theta_i = 10000^{-2i/d}$ 生成频率，再乘上自己的坐标得到旋转角：

$$\phi(\text{token}) = \big[\, m_t \cdot \theta_{0..15}, \;\; m_h \cdot \theta_{16..39}, \;\; m_w \cdot \theta_{40..63} \,\big]$$

**实现要点**：

1. 同一频率向量 $\theta$ 不变，只是**不同下标区间分配给不同轴**；
2. 纯文本 token 通常取 $(0,0,0)$ 或当前时间索引，与图像/视频 token 对齐；
3. 视频 token 量 = $T \times H \times W$ 个 patch，各自带完整三元组；
4. 动态分辨率、任意帧数下，只需**按真实坐标设置索引**，天然支持任意尺寸组合，完全不需要位置表插值。

**为什么时间轴有效**：同一空间位置、不同帧的 patch，其时间索引不同 → 旋转角度不同 → attention 能区分"跨帧同位置"与"同帧近邻"；帧间长程运动由时间维的低频（16 个维度中的低频段）承载。

**后继者**：Qwen3-VL 沿用 M-RoPE；多模态 VLM 全系（MiniCPM-V、InternVL 的视觉塔）也在采用类似"坐标式 RoPE"。

## 七、动态分辨率下的位置编码处理

多模态输入分辨率/帧数不固定，位置编码的处理策略有四条路线：

| 方案 | 做法 | 优点 | 缺点 | 代表 |
|------|------|------|------|------|
| **插值** | 位置表双线性插值到目标尺寸 | 实现简单、兼容既有模型 | 插值破坏相邻位置关系；需微调 | CLIP 分辨率提升、ViT 高分辨率迁移 |
| **分块（Tiling）** | 大图切多块，各块复用同一位置表 | 复用训练好的位置分布 | 块间位置关系信息弱 | LLaVA-1.5 anyres 网格分块 |
| **2D 分解** | 行列独立表，按实际行列取索引 | 零插值、天然组合任意 $H' \times W'$ | 行列耦合信息缺失（可忽略） | 2D-ViT 系列 |
| **真实坐标（M-RoPE）** | 位置 = 实际坐标 $(t,h,w)$ 的旋转编码 | 任意分辨率/帧数零插值、最通用 | 需模型原生支持 | Qwen2-VL / Qwen3-VL |

> **面试结论**：能插值就不重训（插值）+ 能分解就不插值（2D 分解）+ 能旋转就不查表（M-RoPE）。动态分辨率的最优解是"位置编码不依赖具体分辨率"——这正是 M-RoPE 的设计哲学。

## 八、无位置编码探索：NoPE

### 8.1 研究事实

- **NoPE（No Positional Encoding，2024）**：完全去掉位置编码训练 Transformer。
  - **因果注意力**下：NoPE 等价于在每个 token 上隐式学到**类似 ALiBi 的线性偏置**（各层、各头的偏移量由网络自适应学出）——位置信息通过 softmax 的归一化常数和因果掩码结构泄露；
  - **双向注意力 + 首位 CLS token**：CLS 可以充当"位置锚点"，模型从中提取位置线索。
- **TDC（What Position Do Large Language Models Learn?，2024）**：无显式 PE 的因果 LM 在下游任务上性能接近带 PE 模型，甚至展现出**超训练长度的外推**——因为它不再依赖位置表/频率，而是从 **token 内容**本身推断位置（如单词 "first/second/..."）。

### 8.2 结论与启示

| 观点 | 说明 |
|------|------|
| 显式位置编码是否必需？ | **不是**。因果掩码 + 内容已含位置线索，模型可以隐式学习 |
| 为什么主流模型仍用？ | 显式 PE 收敛更快、更稳定、表达更可控（工程上省事） |
| 与多模态的关联 | 图像/视频的"位置"更多是**空间坐标语义**而非序列下标，NoPE 在视觉上更依赖内容特征（如物体本身的位置线索），但显式坐标编码仍是主流 |

> 面试态度：承认 NoPE 的研究结论，但强调工程上 RoPE/M-RoPE 仍是绝对主流——NoPE 是"可能的机制"，不是"推荐的做法"。

## 十、高频面试问答

**Q1：为什么 Transformer 需要位置编码？**
Self-Attention 是置换等变的：$\text{Attn}(\pi X) = \pi\,\text{Attn}(X)$，不注入顺序信息时模型对序列打乱无感。语言/图像的顺序与空间结构是核心语义，必须显式编码位置。

**Q2：正弦位置编码为什么用不同频率（几何级数 10000^{2i/d}）？**
类比钟表：高频维度（秒针）分辨近邻位置，低频维度（时针）分辨全局/远距位置。几何级数让波长从 $2\pi$ 指数增长到 $2\pi \cdot 10000$，每个尺度都有专门维度负责，位置编码形成"多分辨率相位指纹"，避免单一频率导致的近邻混淆或远距不可分。

**Q3：正弦编码怎么"表达"相对位置？**
三角恒等式：$\sin((pos+k)\omega) = \cos(k\omega)\sin(pos\omega) + \sin(k\omega)\cos(pos\omega)$，所以 $PE(pos+k) = T_k \cdot PE(pos)$，$T_k$ 是只依赖 $k$ 的线性矩阵。模型学一个线性层即可实现所有位置的相对位移；且 $PE_i^\top PE_j = \sum \cos((i-j)\omega)$ 只依赖 $i-j$，绝对编码在 attention 内积中天然带相对项。

**Q4：正弦 vs 可学习位置编码，怎么选？**
正弦：零参数、任意长度有定义，但实际外推效果弱；可学习：参数 $L_{max} \times d$、表达自由、BERT 上效果略优，但越界直接 OOD。两者外推性都不好，现代大模型已全面转向相对编码（RoPE/ALiBi）。

**Q5：绝对位置编码和相对位置编码的本质区别？**
绝对编码把"位置"当作与内容并列的特征（加在 embedding 上），位置信息是"下标"函数；相对编码把"距离 $i-j$"注入 attention 计算（logits 偏置或 q/k 变换），先验是"距离比下标有用"。相对编码距离值域训练期全覆盖 → 天然外推友好；绝对编码训练期外是全新组合 → 外推崩。

**Q6：ALiBi 零参数为什么还能外推？**
① 距离惩罚 $-m|i-j|$ 的值域 $[0, L_{train})$ 训练期全覆盖，外推只是延长同一条直线，无新分布；② 近因偏置符合语言先验；③ 零参数意味着模型从不"记忆位置"，不存在位置 OOD。对比 RoPE 外推是未见过的相位组合。

**Q7：RoPE 的原理，一句话 + 推导？**
把 q/k 每对相邻维度按位置 $m$ 旋转 $m\theta_i$（复数即乘以 $e^{im\theta_i}$），利用旋转矩阵的正交性与可合性：$\langle R_m q, R_n k\rangle = q^\top R_m^\top R_n k = q^\top R_{n-m} k$，内积只依赖相对距离 $n-m$；复数推导同理：$\text{Re}(q\bar{k}e^{i(m-n)\theta_i})$。零参数、范数保持、相对位置严格成立。

**Q8：位置插值（PI）和 NTK 缩放的区别？**
PI 所有维度统一把频率除以 $s$（坐标压缩进训练区间），简单但损失高频分辨率；NTK 按维度分级：高频（$i$ 小）不缩放、低频（$i$ 大）缩放约 $s$ 倍，等价于把 base 放大为 $base \cdot s^{d/(d-2)}$，保留局部精度、让低频承担长程扩展。

**Q9：YaRN 相比 NTK 改进在哪？**
两点：① NTK-by-parts——按波长与训练长度的关系把维度分三段：纯高频不缩放、纯低频按 PI 缩放、中间平滑过渡；② 注意力温度校正——插值后 logits 幅度分布偏移，引入温度 $t$（约 $1/\sqrt{s}$ 量级）缩放 logits 补偿。Mistral 7B 用 YaRN 扩到 128K。

**Q10：2D 位置编码怎么做？为什么比 1D 好？**
位置拆成 $(r,c)$，编码 = 可学习行向量 + 列向量 $PE(r,c) = P_{row}[r] + P_{col}[c]$。参数从 $HW \cdot d$ 降到 $(H+W)d$；任意分辨率只需取前 $R$ 行前 $C$ 列，零插值组合；显式携带行列结构先验。适合动态分辨率多模态场景。

**Q11：M-RoPE 是什么？**
Qwen2-VL 的 3D RoPE：token 位置从标量变成三元组（帧索引 $t$、行 $h$、列 $w$），head_dim 的一半按 mrope_section=[16,24,24] 分成三段频率区间，分别用各自坐标乘以本段频率旋转。让视频/多图在 attention 中可区分"跨帧同位置"与"同帧近邻"，天然支持任意分辨率与帧数，无需位置表插值。

**Q12：模型训练长度外，RoPE 怎么办？**
不能直接用（相位 OOD，PPL 尖峰）。三选一：位置插值 PI（坐标压缩）、NTK-Aware（高频不变低频缩放）、YaRN（NTK-by-parts + 温度）或 LongRoPE（逐维非均匀插值），配合少量长文本微调即可扩展上下文。

## 十一、常见误区

- [ ] **误区 1："正弦编码天然支持任意长度外推"** —— 它只是"定义域"无界（任意 $pos$ 可算），效果上外推到 200+ token 就开始退化；真正外推友好的是相对编码（ALiBi/RoPE+插值）。
- [ ] **误区 2："RoPE 是把位置加到 embedding 上"** —— RoPE 是**乘性旋转**，只作用于 q/k 的每对相邻维度，v 和输入 embedding 都不动；加性注入的是正弦/可学习编码。
- [ ] **误区 3："ALiBi 的斜率是学出来的"** —— 斜率 $m_h$ 是固定的几何序列（零参数）；可学习的是 T5 的相对位置桶表。
- [ ] **误区 4："位置插值 = 位置外推"** —— 方向相反：外推是直接用训练长度外的位置（RoPE 会崩）；插值是**内插**，把坐标压缩回训练区间。
- [ ] **误区 5："NTK 缩放只是换了个 base"** —— 等价表述没错，但本质是"按维度分级缩放（高频不动、低频缩放）"，理解机制才能答好"为什么它比 PI 好"。
