# 可学习位置编码（Learned Positional Embedding）

> 本模块索引见 [位置编码专题详解](位置编码专题详解.md)

## 一、定义与公式

可学习位置编码直接把位置定义为一个**可训练的参数矩阵**，每个位置一行，随训练一起更新。它是 BERT、GPT-2、ViT、CLIP 等模型的标准位置编码方案。

### 1.1 基本公式

$$P \in \mathbb{R}^{L_{max} \times d}, \qquad e_i = x_i + P[i, :]$$

- $L_{max}$：训练时支持的最大序列长度；
- $d$：隐藏维度；
- $e_i$：第 $i$ 个 token 进入 Transformer 前的输入（词嵌入 + 位置向量）。

前向时只需**查表**（取第 $i$ 行），反向时 $P$ 按普通参数更新。

### 1.2 典型配置

| 模型 | 表大小 | 说明 |
|------|--------|------|
| BERT | $512 \times 768$ | 输入最长 512 token |
| GPT-2 | $1024 \times 768$ | |
| ViT-B/16 | $197 \times 768$ | 196 个 patch + 1 个 CLS |
| CLIP 双塔 | $197 \times 768$ | 与 ViT 相同 |
| GPT-3 | $2048 \times 12288$ | 更长的表、更大的 d |

### 1.3 训练中的角色

$P$ 参与梯度更新，但**没有结构约束**——每个位置向量独立演化，完全由数据决定。BERT 原论文报告其效果**略优于**正弦编码（"learned positional embeddings are used, and we found that the learned positional embeddings perform slightly better than the sinusoidal version"）。

## 二、核心原理与直觉

### 2.1 为什么"查表"就够用

- 语言中位置信息量有限：本质上是"第 $i$ 个位置的特征"，$L_{max} \times d$ 个参数足以编码（对比词表 $V \times d$ 的量级，位置表小得多）；
- 每个位置向量独立优化，不受频率公式约束，理论上表达能力 ≥ 正弦编码；
- 实现 $O(1)$ 查表，无数值问题，训练稳定。

### 2.2 外推问题（本质缺陷）

**越界即 OOD**：$pos > L_{max}$ 时**不存在对应向量**（无法"计算"出位置 512 的向量），只能：

1. **截断**：把超长输入截到 $L_{max}$（信息丢失）；
2. **插值**（Position Interpolation 的雏形）：把整张表**双线性插值**到更大尺寸 $L' \times d$——相邻位置向量被"平均混合"；
3. **重训/继续训练**：初始化更大的表，让位置 512+ 从头学（代价大）。

对比：正弦编码任意 $pos$ 都有公式可算（定义域无界），而可学习表**连定义都没有**——这是两者外推性的根本差异。

### 2.3 ViT 的位置编码插值（多模态高频考点）

ViT 训练时位置表是 $197 \times d$（1 CLS + 196 patch）。迁移到更高分辨率（如 224→384 输入）时，patch 数变成 196×3.2≈576 个，**位置表必须插值**：

```python
def interpolate_pos_embed(pos_embed, new_h, new_w, cls_token=True):
    """ViT 位置表插值：把 [1, N, d] 的 patch 部分 reshape 成 2D 网格再双线性插值
       （CLIP/ViT 分辨率迁移的标准做法）"""
    from torch.nn.functional import interpolate
    d = pos_embed.shape[-1]
    if cls_token:
        cls_tok = pos_embed[:, :1]            # CLS 位置保持不动
        patch_embed = pos_embed[:, 1:]        # 只插值 patch 部分
    else:
        cls_tok, patch_embed = None, pos_embed
    h = w = int(patch_embed.shape[1] ** 0.5)
    patch_embed = patch_embed.reshape(1, h, w, d).permute(0, 3, 1, 2)  # [1,d,h,w]
    patch_embed = interpolate(patch_embed, size=(new_h, new_w),
                              mode="bicubic", align_corners=False)
    patch_embed = patch_embed.permute(0, 2, 3, 1).reshape(1, new_h * new_w, d)
    return torch.cat([cls_tok, patch_embed], dim=1) if cls_token else patch_embed
```

**插值的问题**：
1. **破坏相邻关系**：新位置向量是旧向量的加权平均，patch 间"相位差"被稀释，位置区分度下降；
2. **CLS 位置语义漂移**：CLS 在 1D 序中位置 0，插值后其"位置意义"改变；
3. 通常需要**少量高分辨率微调**才能恢复效果。

## 三、源码实现

### 3.1 纯 PyTorch 手写实现

```python
import torch
import torch.nn as nn

class LearnedPositionalEmbedding(nn.Module):
    """手写可学习位置编码：BERT / ViT 同款查表实现"""

    def __init__(self, max_len, d_model):
        super().__init__()
        # 可学习参数表 [max_len, d]，正态初始化（与词嵌入同尺度）
        self.weight = nn.Parameter(torch.randn(max_len, d_model) * 0.02)

    def forward(self, x):
        # x: [B, L, d]，取前 L 行位置向量
        return x + self.weight[: x.size(1)]

# 测试
pe = LearnedPositionalEmbedding(max_len=512, d_model=768)   # BERT 配置
x = torch.randn(2, 32, 768)
y = pe(x)
print(y.shape)                     # torch.Size([2, 32, 768])
print(pe.weight.shape)             # torch.Size([512, 768])
print(pe.weight.grad is None)      # True（尚未反向，参数表可训练）

# 越界行为：长度 > max_len 时直接报错（这就是"外推崩溃"的代码级原因）
try:
    pe(torch.randn(1, 600, 768))
except Exception as e:
    print(f"越界报错: {type(e).__name__}")   # 越界报错: RuntimeError
    # （参数切片越界 → RuntimeError；nn.Embedding 查表越界 → IndexError）
```

### 3.2 与官方实现对比验证

参考实现：transformers 库 `BertEmbeddings` 中通过 `nn.Embedding(max_position_embeddings, hidden_size)` 实现位置表；`GPT2Model` 同理。二者等价于"查表 + 加和"。这里内嵌官方等价写法对比：

```python
class BertEmbeddings(nn.Module):
    """transformers BertEmbeddings 的核心写法（内嵌对照版）：
       token 嵌入 + 位置嵌入（nn.Embedding 查表）逐元素相加，可选 token_type"""

    def __init__(self, vocab_size, hidden_size, max_position_embeddings, pad_token_id=0):
        super().__init__()
        self.word_embeddings = nn.Embedding(vocab_size, hidden_size, padding_idx=pad_token_id)
        self.position_embeddings = nn.Embedding(max_position_embeddings, hidden_size)

    def forward(self, input_ids):
        # 位置索引 = 0..L-1，每个 token 查一行位置向量
        position_ids = torch.arange(input_ids.size(1), device=input_ids.device).unsqueeze(0)
        return self.word_embeddings(input_ids) + self.position_embeddings(position_ids)

# 对比验证：手写版（forward 接收已嵌入的 x）与官方版（接收 id）输出一致
torch.manual_seed(0)
vocab, d, Lmax = 1000, 64, 128
ids = torch.randint(0, vocab, (2, 16))

bert = BertEmbeddings(vocab, d, Lmax)
# 用手写版复现：先取词嵌入 + 位置表前 16 行
x = bert.word_embeddings(ids)
manual = LearnedPositionalEmbedding(Lmax, d)
manual.weight.data.copy_(bert.position_embeddings.weight.data)
out_manual = manual(x)
out_official = bert(ids)
print(torch.allclose(out_manual, out_official, atol=1e-6))   # True
```

### 3.3 ViT 位置编码插值示例（完整可运行）

```python
import torch
import torch.nn.functional as F

class ViTLearnedPos(nn.Module):
    """ViT 风格：CLS + 196 patch 的可学习位置表"""

    def __init__(self, num_patches=196, d_model=768):
        super().__init__()
        self.cls_pe = nn.Parameter(torch.zeros(1, 1, d_model))
        self.patch_pe = nn.Parameter(torch.zeros(1, num_patches, d_model))

    def interpolate(self, new_h, new_w):
        """把 patch 位置表插值到 new_h x new_w 个 patch（分辨率迁移）"""
        patch = self.patch_pe
        h = w = int(patch.shape[1] ** 0.5)                # 训练时 14x14
        patch = patch.reshape(1, h, w, -1).permute(0, 3, 1, 2)
        patch = F.interpolate(patch, size=(new_h, new_w), mode="bicubic",
                              align_corners=False)        # 双三次插值
        patch = patch.permute(0, 2, 3, 1).reshape(1, new_h * new_w, -1)
        return torch.cat([self.cls_pe, patch], dim=1)     # [1, 1+h*w, d]

v = ViTLearnedPos()
pe_224 = v.interpolate(14, 14)     # 原分辨率
pe_384 = v.interpolate(24, 24)     # 384x384 → 24x24 patch
print(pe_224.shape)                # torch.Size([1, 197, 768])
print(pe_384.shape)                # torch.Size([1, 577, 768])
print((pe_384[0, 0] == v.cls_pe[0, 0]).all().item())   # True（CLS 不动）
```

## 四、性质分析

### 4.1 外推性：差（本质性）

| 对比项 | 正弦编码 | 可学习编码 |
|--------|---------|-----------|
| 超长位置 | 有公式可算 | **无定义（索引越界）** |
| 超长效果 | 弱（相位 OOD） | 崩溃（IndexError） |
| 补救 | 直接用（效果差）或插值 | 只能插值 / 重训 |

**补救路径**（按成本排序）：
1. **表插值**（`F.interpolate` 双线性）：立即生效但损失高频细节，需微调；
2. **继续训练**：用更大表从随机初始化重训位置 512+（LLM 早期的做法）；
3. **替换为相对编码**（RoPE/ALiBi）：一劳永逸，现代大模型的路线。

### 4.2 相对位置表达

- **理论**：无显式结构，相对位置完全靠数据隐式学出；
- **事实**：BERT 学出的位置表在**相邻位置**间确实呈平滑变化、**远距离位置**间相似度低（可视化显示对角线结构），说明模型自发学到了某种"距离编码"，但没有保证。

### 4.3 参数

- 参数 $L_{max} \times d$：BERT 为 $512 \times 768 \approx 0.4M$（占 BERT-base 110M 的 0.35%）；
- 位置表**独立于输入**：反向时只有被用到的行更新（但权重共享训练中仍会平滑）；
- 初始化：正态分布（std 0.02，BERT）或零初始化（ViT），对训练影响小。

## 五、优缺点

| 优点 | 缺点 |
|------|------|
| 表达自由，无公式约束（BERT 上略优于正弦） | 外推性差：越界无定义，直接崩溃 |
| 实现简单（查表 O(1)） | 分辨率/长度迁移必须插值或重训 |
| 训练稳定，收敛快 | 插值破坏相邻位置关系，需微调 |
| 与词嵌入同一套机制，工程上统一 | 无法表达显式相对距离结构（靠数据隐式学） |

## 六、与同类对比

| 维度 | 可学习编码 | 正弦编码 | 2D 分解（行列） |
|------|-----------|---------|----------------|
| 参数 | $L_{max} \times d$ | 0 | $(H+W) \times d$ |
| 任意分辨率 | 需插值/重训 | 有定义、效果弱 | **零插值**（取前 R 行前 C 列） |
| 结构先验 | 无 | 频率结构 | 显式行/列语义 |
| 典型模型 | BERT、GPT-2、ViT、CLIP | Transformer 原版 | 2D-ViT 系列 |

**2D 分解（重点对比）**：$PE(r, c) = P_{row}[r] + P_{col}[c]$，参数从 $HW \cdot d$ 降到 $(H+W) \cdot d$，且任何 $H' \times W'$ 只需取行表前 $H'$ 行 + 列表前 $W'$ 列——**零插值、零重训**。这是多模态视觉塔（动态分辨率）弃用 1D 可学习表转向 2D/M-RoPE 的原因。

## 七、高频面试问答

**Q1：可学习位置编码为什么外推性差？**
因为它是查表：位置 $> L_{max}$ 时**连向量都不存在**（索引越界），属于"定义上就 OOD"。对比正弦编码至少能算出一个值。

**Q2：序列超长时怎么办？**
三条路：① 表插值（双线性/双三次，ViT 分辨率迁移的标准做法，需微调）；② 重训更大的表（成本高）；③ 换成 RoPE/ALiBi 等相对编码（现代方案）。

**Q3：ViT 分辨率提升为什么要插值位置编码？**
patch 数随分辨率平方增长（224→384 时 196→576），新 patch 没有位置向量；把训练好的 $14 \times 14$ 网格插值到 $24 \times 24$，CLS 位置单独保留。插值后需少量高分辨率微调。

**Q4：可学习编码和正弦编码哪个好？**
BERT 实测可学习略优（表达自由）；正弦零参数、任意长度有定义。但两者外推都弱，现代大模型用 RoPE 取代两者。

**Q5：可学习位置表学到了什么结构？**
通常相邻位置向量平滑变化、距离越远相似度越低（近似学到"距离"信息），但无数学保证——结构完全由数据决定，这与正弦编码的显式几何级数结构不同。

**Q6：位置表能和 2D 位置分解结合吗？**
可以：ViT 变体用 $P_{row}[r] + P_{col}[c]$ 两个可学习小表。好处是参数 $(H+W)d$ 且任意分辨率零插值——动态分辨率多模态场景的标准选择。

**Q7：为什么 BERT 之后的大模型基本不用可学习位置编码了？**
长上下文需求（4K→128K+）下，可学习表"定义域有限 + 插值失真"两个硬伤无法回避；RoPE 零参数、严格相对位置、配合插值技术可扩到 100K+。
