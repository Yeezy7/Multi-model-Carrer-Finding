# 正弦位置编码（Sinusoidal Positional Encoding）

> 本模块索引见 [位置编码专题详解](位置编码专题详解.md)

## 一、定义与公式

正弦位置编码出自 Transformer 原始论文（Vaswani et al., 2017），是**绝对位置编码**的经典方案：为每个位置 $pos$ 生成一个 $d$ 维向量，加到词嵌入上。

### 1.1 基本公式

对位置 $pos$、维度下标 $i$（$0 \le i < d/2$），第 $2i$ 和第 $2i+1$ 维定义为：

$$PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right), \qquad PE(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

记角频率 $\omega_i = 10000^{-2i/d}$，则：

$$PE(pos, 2i) = \sin(pos \cdot \omega_i), \qquad PE(pos, 2i+1) = \cos(pos \cdot \omega_i)$$

**作用方式**（加性注入）：$e_{pos} = x_{pos} + PE(pos)$，词嵌入与位置向量逐元素相加后进入 Transformer。

### 1.2 为什么频率是几何级数（推导）

$\omega_i = 10000^{-2i/d}$ 意味着角频率随 $i$ 按**几何级数衰减**。对应波长：

$$\lambda_i = \frac{2\pi}{\omega_i} = 2\pi \cdot 10000^{2i/d}$$

- $i = 0$：$\omega_0 = 1$，波长 $2\pi$（最快，高频）；
- $i = d/2 - 1$：$\omega_{d/2-1} = 10000^{-(d-2)/d} \approx 1/10000$，波长约 $62832$（最慢，低频）。

若用**单一频率** $\omega$ 编码位置会出两个问题：

1. **高频（大 $\omega$）**：$\sin(pos\,\omega)$ 很快"绕圈"，当 $pos$ 变化 $\frac{2\pi}{\omega}$ 时相位完全重复 → 长距离位置混淆（$PE(pos) = PE(pos + 2\pi/\omega)$）；
2. **低频（小 $\omega$）**：相邻位置 $pos$ 与 $pos+1$ 的相位差 $\omega$ 极小，$\sin(pos\,\omega) \approx \sin((pos+1)\,\omega)$ → 近邻位置无法区分。

几何级数在 $d/2$ 个维度上均匀铺开"从秒针到时针"的所有转速（相邻频率比值固定为 $10000^{-2/d}$），每个尺度都有专门维度负责，这是正弦编码能同时分辨近邻与远距的根本原因。

> **记忆点**：几何级数的两个作用——① 多尺度覆盖（近邻/远距都有人管）；② 每个位置在 $d$ 维空间形成独特的"相位指纹"，任意两个位置编码不重叠。

## 二、核心原理与直觉

### 2.1 时钟类比（面试必答）

同一根轴上装了 $d/2$ 根指针，转速各差 10000 倍：

| 维度 | 指针类比 | 周期 | 作用 |
|------|---------|------|------|
| 高频（$i$ 小，$\omega$ 大） | 秒针 | 短 | 分辨**相邻**位置（局部精度） |
| 中频（$i$ 中） | 分针 | 中 | 分辨**较近**位置 |
| 低频（$i$ 大，$\omega$ 小） | 时针 | 长 | 分辨**全局**/远距位置 |

语言中近邻关系（词法/句法，距离 1-3）与远距关系（指代/长程依赖，距离几十上百）都需要区分，单一频率无法兼顾，几何级数让每个尺度都有维度负责。

### 2.2 PE(pos+k) 是 PE(pos) 的线性函数（关键推导）

**引理**：对任意偏移 $k$，$PE(pos+k)$ 可由 $PE(pos)$ 经一个**只依赖 $k$** 的线性变换得到。

利用三角恒等式 $\sin(a+b) = \sin a \cos b + \cos a \sin b$，代入 $a = pos \cdot \omega_i$、$b = k \cdot \omega_i$：

$$\begin{aligned}
PE(pos+k, 2i) &= \sin((pos+k)\,\omega_i) \\
&= \underbrace{\cos(k\omega_i)}_{\text{只与 }k\text{ 有关}} \cdot \sin(pos\,\omega_i) + \underbrace{\sin(k\omega_i)}_{\text{只与 }k\text{ 有关}} \cdot \cos(pos\,\omega_i) \\
&= \cos(k\omega_i)\,PE(pos, 2i) + \sin(k\omega_i)\,PE(pos, 2i+1)
\end{aligned}$$

对每个配对维度 $i$ 都成立，于是存在块对角矩阵 $T_k = \text{diag}(R(k\omega_0), R(k\omega_1), \dots)$（$R(\theta)$ 为二维旋转矩阵），使得：

$$PE(pos+k) = T_k \cdot PE(pos)$$

**含义**：模型要建模"相对位置 $k$"，只需学一组线性变换；由于权重全位置共享，一个线性层同时实现所有相对位移——**绝对编码"免费"获得表达相对位置的能力**。注意 $T_k$ 恰好是旋转矩阵，这正是 RoPE 直接把旋转作为位置编码的思想源头。

### 2.3 内积展开：attention 中天然携带相对项

若 $q$、$k$ 都带绝对正弦编码，展开内积：

$$(x_i + PE_i)^\top (x_j + PE_j) = x_i^\top x_j + x_i^\top PE_j + PE_i^\top x_j + PE_i^\top PE_j$$

用积化和差 $\sin a \sin b + \cos a \cos b = \cos(a - b)$，最后一项：

$$PE_i^\top PE_j = \sum_{i'=0}^{d/2-1} \cos((i-j)\,\omega_{i'})$$

**只依赖 $i-j$**。即：绝对正弦编码在 attention 内积中天然携带相对距离项，这是它外推效果"有限但没彻底崩溃"的原因。

## 三、源码实现

### 3.1 纯 PyTorch 手写实现

```python
import math
import torch
import torch.nn as nn

class SinusoidalPositionalEncoding(nn.Module):
    """手写正弦位置编码：d_model 维，支持任意长度（max_len 只决定预计算大小）"""

    def __init__(self, d_model, max_len=512, base=10000.0):
        super().__init__()
        # 1. 频率表: [d_model/2]，几何级数（偶数维的角频率）
        #    i = 0, 2, 4, ...（与论文保持一致：对偶数维下标取指数）
        i = torch.arange(0, d_model, 2, dtype=torch.float32)
        theta = base ** (-i / d_model)          # [d/2]

        # 2. 位置向量: [max_len, 1]
        pos = torch.arange(max_len, dtype=torch.float32).unsqueeze(1)

        # 3. 角度表: [max_len, d/2]，每行 = pos * 各频率
        angles = pos * theta.unsqueeze(0)

        # 4. 拼接 sin/cos（交错排列成 [max_len, d]）
        pe = torch.zeros(max_len, d_model)
        pe[:, 0::2] = torch.sin(angles)         # 偶数维 → sin
        pe[:, 1::2] = torch.cos(angles)         # 奇数维 → cos
        self.register_buffer("pe", pe.unsqueeze(0))   # [1, max_len, d]

    def forward(self, x):
        # x: [B, L, d]；取前 L 行加到输入上
        return x + self.pe[:, : x.size(1)]

# 测试
pe = SinusoidalPositionalEncoding(d_model=8, max_len=6)
x = torch.zeros(2, 6, 8)
print(pe(x)[0, 0])   # 位置 0 的编码: [0, 1, 0, 1, 0, 1, 0, 1]（sin0=0, cos0=1）
print(pe(x)[0, 1])   # 位置 1 的编码
```

### 3.2 与官方实现对比验证

参考实现：PyTorch 官方文档 Tutorial（"Language Modeling with nn.TransformerEncoder"）中的 `PositionalEncoding` 类；transformers 库各模型（如 `BertEmbeddings` 之外的 GPT 系列）也内置相同写法。核心区别仅在**维度配对顺序**（逐维交错 vs 对半拼接），数学上等价。这里内嵌官方写法直接对比：

```python
class PositionalEncoding_Official(nn.Module):
    """PyTorch 官方 Tutorial 写法（https://pytorch.org/tutorials/beginner/transformer_tutorial.html）"""

    def __init__(self, d_model, dropout=0.1, max_len=5000):
        super().__init__()
        self.dropout = nn.Dropout(p=dropout)
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len).unsqueeze(1).float()
        div_term = torch.exp(torch.arange(0, d_model, 2).float()
                             * (-math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(position * div_term)   # 偶数维 → sin
        pe[:, 1::2] = torch.cos(position * div_term)   # 奇数维 → cos
        pe = pe.unsqueeze(0)
        self.register_buffer("pe", pe)

    def forward(self, x):
        return self.dropout(x + self.pe[:, : x.size(1)])

# 对比验证：两种写法输出应完全一致（除 dropout）
torch.manual_seed(0)
mine = SinusoidalPositionalEncoding(d_model=16, max_len=8)
official = PositionalEncoding_Official(d_model=16, dropout=0.0, max_len=8)
x = torch.randn(3, 8, 16)
diff = (mine(x) - official(x)).abs().max().item()
print(f"最大差异: {diff:.2e}")   # 最大差异: 0.00e+00（数学等价）
```

> 说明：两种实现都用 `pe[:, 0::2] = sin, pe[:, 1::2] = cos`，因此逐元素完全一致。若改用"前一半 sin 后一半 cos"的拼接写法（某些实现），只需调整维度顺序，数学上仍是同一编码。

### 3.3 可视化：不同频率的相位

```python
# 无 matplotlib 依赖：打印位置-维度相位图（#=sin 正值, .=sin 负值）
d_model, max_len = 16, 64

# #.##############   ← 位置 2（cos(2)≈-0.42 为负）

```

## 四、性质分析

### 4.1 外推性

- **定义域**：任意 $pos$ 都能计算（纯函数），不存在"越界 OOD"；
- **效果**：论文报告模型可推断比训练长度更长的序列（"longer than the ones encountered during training"），但实测 200+ token 后效果明显衰减。原因是低频维度波长约 62832，训练长度内**低频相位组合从未见过**，外推时属于新分布；
- **结论**：正弦编码的"外推优势"是**定义域优势**（有值可用），不是**效果优势**——真正的外推需要相对位置编码。

### 4.2 相对位置表达

由 2.2 推导，$PE(pos+k) = T_k PE(pos)$，相对信息通过线性层可被提取；由 2.3 推导，attention 内积中 $PE_i^\top PE_j = \sum \cos((i-j)\omega)$ 只依赖距离。因此正弦编码是"**绝对编码、隐式相对**"。

### 4.3 参数与实现

| 性质 | 值 |
|------|-----|
| 参数 | **0**（固定函数，不参与训练） |
| 预计算 | 一张 $[L_{max}, d]$ 表，前向 $O(1)$ 查表 |
| 数值 | 无溢出问题（sin/cos 有界），FP16 安全 |
| 与其他编码 | 可与可学习编码叠加（叠加后等价于学一个偏置项） |

## 五、优缺点

| 优点 | 缺点 |
|------|------|
| 零参数，无需训练 | 表达能力受频率结构约束（可学习编码理论上更强） |
| 任意长度有定义（可"算"出外推值） | 实际外推效果弱（200+ 衰减） |
| 隐式携带相对位置（三角恒等式） | 与 RoPE 相比，相对信息需模型"再学一遍"线性变换 |
| 确定性强、可复现、易调试 | 语言先验"距离比下标重要"未被显式利用 |
| 实现简单，任何长度可即时生成 | BERT 实测效果略逊于可学习编码 |

## 六、与同类对比

| 维度 | 正弦编码 | 可学习编码 | RoPE |
|------|---------|-----------|------|
| 位置类型 | 绝对 | 绝对 | 相对 |
| 注入方式 | embedding 相加 | embedding 相加 | q/k 乘性旋转 |
| 参数 | 0 | $L_{max} \times d$ | 0 |
| 相对位置 | 隐式（线性变换 $T_k$） | 隐式（数据学出） | **严格**（内积只依赖 $m-n$） |
| 超长度 | 有定义、效果弱 | 无定义、崩溃 | 相位 OOD、崩溃（需插值） |
| 典型模型 | Transformer 原版 | BERT、ViT、GPT-2 | LLaMA、Qwen、Mistral |

**关键对比结论**：
1. 正弦 vs 可学习：正弦"零参数 + 可外推定义"，可学习"表达自由 + BERT 上效果略优"；两者都是加性绝对编码，外推都不好；
2. 正弦 vs RoPE：RoPE 把正弦的 $T_k$（旋转）从"隐式、需学习"变成"显式、直接施加在 q/k 上"，且只依赖相对距离——这是大模型全面转向 RoPE 的原因。

## 七、高频面试问答

**Q1：为什么频率取几何级数 $10000^{-2i/d}$ 而不是单一频率？**
单一高频会因周期性产生长距位置混淆（$PE(pos) = PE(pos + 2\pi/\omega)$），单一低频无法区分近邻。几何级数让波长从 $2\pi$ 指数增长到 $62832$，每个尺度（秒针到时针）都有专门维度负责。

**Q2：为什么是 sin/cos 成对出现，而不是只用 sin？**
因为要支持线性表示相对位置：$PE(pos+k) = T_k PE(pos)$ 需要 $(\sin, \cos)$ 配对才能用旋转矩阵 $T_k = \text{diag}(R(k\omega_i))$ 表达（$\sin(pos+k) = \cos(k)\sin(pos) + \sin(k)\cos(pos)$）。单用 sin 无法写成线性组合。

**Q3：正弦编码如何表达相对位置？**
$PE(pos+k) = T_k \cdot PE(pos)$，$T_k$ 是只依赖 $k$ 的块旋转矩阵；且 attention 内积中 $PE_i^\top PE_j = \sum_{i'} \cos((i-j)\omega_{i'})$ 只依赖 $i-j$。所以绝对编码在 attention 中天然带相对项。

**Q4：正弦编码能外推吗？**
定义域上能（任意 pos 可计算），效果上弱——低频相位组合在训练长度外是全新分布，实测 200+ token 衰减。真正外推友好的是相对编码（ALiBi / RoPE+插值）。

**Q5：正弦 vs 可学习位置编码，谁更好？**
BERT 原论文报告可学习略优（表达自由）；但正弦零参数、确定性强、任意长度有定义。两者都是加性绝对编码，现代大模型都不用它们做长上下文，而是 RoPE。

**Q6：为什么 RoPE 常被说成"正弦编码的旋转化推广"？**
因为 2.2 推导中 $T_k$ 恰好是旋转矩阵——RoPE 直接把"位置 = 旋转"从隐式变成显式，施加在 q/k 上。两者共享同一频率设计（$\theta_i = 10000^{-2i/d}$）。

**Q7：实现上 `0::2 = sin, 1::2 = cos` 和"前一半 sin 后一半 cos"有区别吗？**
数学等价（都是同一编码的维度重排），但实现需与预训练模型一致，否则维度错位。transformers 中 GPT 系列用逐维交错，部分实现用对半拼接。
