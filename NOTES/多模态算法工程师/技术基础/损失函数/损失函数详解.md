## 一、损失函数总览

损失函数（Loss Function）衡量模型预测与真实标签的差距，是训练优化的唯一信号。选错损失 = 训练方向错误。

```text
常见损失家族：
├── 分类损失：CrossEntropy、BCE、Focal Loss、Hinge Loss
├── 回归损失：MSE、MAE、Smooth L1
├── 度量学习：Triplet、Contrastive、InfoNCE、Sigmoid Loss
├── 生成损失：CrossEntropy（LM）、KL、重建损失
├── 分布损失：KL 散度、JS、Wasserstein
└── 排序损失：Ranking Loss、ListNet、Pairwise
```

### 使用场景速查表

| 任务 | 首选损失 | 备选 |
|------|---------|------|
| 多分类 | CrossEntropyLoss | Label Smoothing 版 CE |
| 二分类/多标签 | BCEWithLogitsLoss | Focal Loss |
| 图文对齐（双塔） | InfoNCE / **SigLIP Sigmoid Loss** | Triplet |
| 图文匹配（单塔） | BCE（ITM） | Hinge |
| 图像描述/生成 | CrossEntropy（因果 LM） | 加 CIDEr 优化（强化学习） |
| 回归 | MSE | Smooth L1、MAE |
| 蒸馏 | KL 散度 | MSE（logits 直接回归） |

## 二、分类损失

### 2.1 CrossEntropyLoss（交叉熵）—— 多分类标配

**公式**（K 个类别，模型输出 logits $z$，真实类别 $y$）：

$$\mathcal{L} = -\log \frac{e^{z_y}}{\sum_{k=1}^{K} e^{z_k}} = -z_y + \log\sum_{k=1}^{K} e^{z_k}$$

**要点**：
- 输入必须是**原始 logits**（框架内部先做 softmax，数值更稳定）；
- 等价于 `NLLLoss(LogSoftmax(z), y)`；
- 梯度形式优美：$\frac{\partial \mathcal{L}}{\partial z_k} = p_k - \mathbb{1}[k=y]$（softmax 概率减 one-hot）。

**Softmax + 交叉熵联合梯度推导（面试必考）**：

设 $p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$，$\mathcal{L} = -\log p_y$，则：

$$\frac{\partial \mathcal{L}}{\partial z_k} = \begin{cases} p_k - 1 & k = y \\ p_k & k \neq y \end{cases}$$

这个形式与 InfoNCE 完全同构（见 04_对比学习）。

**Label Smoothing（标签平滑）**：

$$\mathcal{L} = -(1 - \varepsilon)\log p_y - \frac{\varepsilon}{K}\sum_{k=1}^{K}\log p_k$$

- 把 one-hot 标签软化：$y_{smooth} = (1-\varepsilon) \cdot \text{onehot} + \varepsilon/K$；
- 防止模型过度自信、提升泛化（Transformer 训练常用 ε=0.1）。

### 2.2 BCEWithLogitsLoss（二分类交叉熵）

**公式**（标签 $y \in \{0,1\}$）：

$$\mathcal{L} = -[y \log \sigma(z) + (1-y)\log(1 - \sigma(z))]$$

**±1 标签等价形式**（SigLIP 用，更紧凑稳定）：

$$\mathcal{L} = -\log \sigma(y' \cdot z), \quad y' \in \{-1, +1\}$$

**多标签场景**：每个类别独立算 BCE 再求平均。

### 2.3 Focal Loss（焦点损失）—— 类别不平衡

**公式**：

$$\mathcal{L} = -\alpha (1 - p_t)^{\gamma} \log p_t$$

- $p_t$：该样本的预测概率（正确类别的概率）；
- $\gamma$（常取 2）：**难易样本调制因子**——简单样本的 $(1-p_t)^\gamma \to 0$，损失被压低；困难样本（$p_t$ 小）损失保留；
- $\alpha$：正负样本权重。

**动机**：检测/异常检测中正负样本极度不平衡（背景框占 99%+），普通 BCE 被大量简单负样本淹没。Focal Loss 让模型聚焦难样本。

### 2.4 Hinge Loss（SVM 风格）

$$\mathcal{L} = \max(0, 1 - y \cdot z)$$

边界外正确样本无损失（稀疏），适合"需要较大间隔"的任务。

## 三、回归损失

| 损失 | 公式 | 特点 | 适用 |
|------|------|------|------|
| MSE | $\frac{1}{n}\sum (y-\hat{y})^2$ | 大误差惩罚重、敏感异常值 | 数值稳定任务 |
| MAE | $\frac{1}{n}\sum \|y-\hat{y}\|$ | 对异常值鲁棒、梯度恒定 | 噪声大的回归 |
| Smooth L1 | 小误差用 MSE、大误差用 MAE | 两者折中 | 目标检测框回归（Faster R-CNN） |

$$\text{SmoothL1}(x) = \begin{cases} 0.5 x^2 & \|x\| < 1 \\ \|x\| - 0.5 & \text{otherwise} \end{cases}$$

## 四、度量学习与对比损失（多模态核心）

### 4.1 Triplet Loss（三元组损失）

$$\mathcal{L} = \max(0, \|f(a) - f(p)\|_2^2 - \|f(a) - f(n)\|_2^2 + m)$$

- $a$：锚点；$p$：正样本；$n$：负样本；$m$：间隔；
- 目标：正样本距离 + 间隔 < 负样本距离；
- 只对"违反约束"的三元组产生梯度（稀疏）；
- 缺点：三元组采样困难（全是简单样本 → 无梯度）。

### 4.2 Contrastive Loss（经典对比）

$$\mathcal{L} = y \cdot d^2 + (1-y) \cdot \max(0, m - d)^2$$

其中 $d = \|f(a)-f(b)\|_2$。同类拉近、异类推开（距离大于 m 则不再推）。

### 4.3 InfoNCE（N 选 1 分类）

$$\mathcal{L}_i = -\log \frac{\exp(s_{ii}/\tau)}{\sum_{j=1}^{N}\exp(s_{ij}/\tau)}$$

- 等价于：对相似度矩阵行做 softmax，标签为对角线索引的交叉熵；
- 负样本来自 batch 内（N-1 个）；
- 温度 τ 控制对比强度；
- 详见 04_对比学习与CLIP.md。

### 4.4 Sigmoid Loss（SigLIP，逐对独立）

$$\mathcal{L} = -\frac{1}{N^2}\sum_{i,j} \log \sigma(Y_{ij} \cdot (t \cdot S_{ij} + b))$$

- 每对独立二分类，无全局归一化；
- batch 依赖弱、分布式通信少；
- 支持正负样本加权；
- 数值上必须用 `F.logsigmoid`（详见 05_SigLIP图文对齐.md）。

### 4.5 对比损失全家对比表

| 损失 | 正样本数 | 负样本来源 | 归一化 | batch 依赖 | 权重控制 |
|------|---------|-----------|--------|-----------|---------|
| Triplet | 1 | 手动采样 1 个 | 无 | 弱 | 间隔 m |
| Contrastive | 1 | 成对构造 | 无 | 弱 | 间隔 m |
| InfoNCE | 1 | batch 内 N-1 | softmax | 强 | 温度 τ |
| SigLIP Sigmoid | N | batch 内 N²-N | 无 | 弱 | α/β 权重 |

## 五、生成损失（语言建模）

### 5.1 语言建模交叉熵（Causal LM）

$$\mathcal{L} = -\frac{1}{T}\sum_{t=1}^{T} \log p_\theta(x_t | x_{<t})$$

- 逐 token 交叉熵，只对"回答部分"计算（label mask 掉 prompt，见 12_多模态指令微调）；
- 生成任务（caption、VQA 答案、对话）的标准目标。

### 5.2 为什么生成任务用交叉熵而不用 BLEU 直接优化？

1. BLEU/CIDEr 不可微（基于 n-gram 精确匹配的离散指标）；
2. 交叉熵提供逐 token 的平滑梯度；
3. 训练与推理的分布差异（exposure bias）是另一层面的问题；
4. 更高阶做法：用 CIDEr 作为奖励做强化学习（SCST、Reinforce），或直接做 RLHF/DPO。

## 六、分布损失

### 6.1 KL 散度（KL Divergence）

$$D_{KL}(P \| Q) = \sum_i P(i) \log \frac{P(i)}{Q(i)} = \sum_i P(i)\log P(i) - \sum_i P(i)\log Q(i)$$

- 衡量分布 P 相对于 Q 的信息损失；
- **非对称**：$D_{KL}(P\|Q) \neq D_{KL}(Q\|P)$；
- 拆成两项后与交叉熵只差一个常数（$H(P)$），因此**蒸馏里最小化 KL 等价于最小化交叉熵**；
- 优化器里加 KL 惩罚（如 RL 的 KL 约束、扩散模型的 KL 项）。

**知识蒸馏中的温度化 KL**（Hinton 蒸馏）：

$$\mathcal{L}_{KD} = T^2 \cdot D_{KL}\left(\text{softmax}(z_T / T) \| \text{softmax}(z_S / T)\right)$$

- T 为温度：软化学生要模仿的教师分布（保留类间关系）；
- $T^2$ 为梯度补偿因子（详见知识蒸馏模块）。

### 6.2 JS 散度与 Wasserstein 距离

| 散度 | 特点 | 用途 |
|------|------|------|
| JS | 对称化 KL，分布不重叠时梯度消失 | 早期 GAN |
| Wasserstein | 即使分布不重叠也有连续梯度 | WGAN、最优传输 |

## 七、多模态模型中的损失组合

### 7.1 各模型的损失拼盘

| 模型 | 损失组合 | 说明 |
|------|---------|------|
| CLIP | 对称 InfoNCE（2 项） | 图像→文本 + 文本→图像 |
| SigLIP | Sigmoid Loss（1 项，N² 对） | 逐对二分类 |
| BLIP | ITC + ITM + LM（3 项加权） | 对比 + 匹配 + 生成 |
| BLIP-2 阶段一 | ITC + ITG + ITM | Q-Former 表征学习 |
| LLaVA | LM 交叉熵 | 只生成损失，图像是输入条件 |
| InstructBLIP | LM（SFT） | 指令微调 |
| DPO | 偏好损失 | 见下 |

### 7.2 多任务损失怎么组合？

$$\mathcal{L} = \lambda_1 \mathcal{L}_1 + \lambda_2 \mathcal{L}_2 + \lambda_3 \mathcal{L}_3$$

- 权重手动调（BLIP 的做法）；
- 更高级：不确定性加权（基于 homoscedastic uncertainty 自动调权）、GradNorm。

### 7.3 DPO 损失（偏好对齐，直觉版）

$$\mathcal{L}_{DPO} = -\log \sigma\left(\beta \left[\log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right]\right)$$

- 训练目标：让被偏好的回答（$y_w$）概率相对参考模型上升，被拒绝的（$y_l$）下降；
- 无需显式训练奖励模型（相比 RLHF）；
- 与 SigLIP 的 sigmoid 形式异曲同工——都是"对 log-ratio 做二分类"。

## 八、损失函数调试指南

### 8.1 常见问题与排查

| 现象 | 可能原因 | 排查 |
|------|---------|------|
| Loss 一直是 NaN | lr 过大 / 数据含 NaN / log(0) | 检查输入、加 epsilon、降 lr |
| Loss 不降 | 梯度消失 / 标签错误 / 损失写错 | 单 batch 过拟合测试 |
| Loss 正常但指标差 | 损失与指标不一致（如分类用 MSE） | 检查损失目标与任务是否匹配 |
| Loss 震荡 | lr 大 / batch 小 / 损失权重失衡 | 降 lr、调权重 |
| 训练结束 loss 不为 0 | 数据不可分（软标签） | 正常现象，看指标而非 loss |

### 8.2 检验损失是否写对

1. **单样本过拟合**：1 个样本训几十步，loss 应能降到接近理论最小值；
2. **随机预测 sanity**：随机权重下 loss ≈ 理论期望（如 10 类 CE ≈ log(10)）；
3. **梯度检查**：数值梯度 vs 解析梯度一致（老调试法，现在靠单样本过拟合更实用）。

### 8.3 多模态任务的"损失盲区"

- 只看 loss 下降不代表对齐成功：对比损失收敛但相似度绝对值漂移 → 看 Recall@K；
- 生成 loss 下降不代表描述质量高 → 看 CIDEr + 人工案例；
- **业务指标（准确率/召回/延迟）才是最终验收标准，loss 是训练信号**。

## 九、高频面试问答

**Q1：CrossEntropyLoss 为什么输入 logits 而不是概率？**
数值稳定性：框架内部用 log-softmax 的恒等变换 $z_y - \log\sum e^{z}$（log-sum-exp 技巧）避免 exp 溢出和 log(0)；且梯度直接是 $p - \text{onehot}$，不需要经过 log 的反向传播。

**Q2：InfoNCE 和交叉熵什么关系？**
完全等价：InfoNCE 就是"对相似度矩阵行做带温度 softmax 的交叉熵，标签为对角线索引"。理解这个等价关系是理解 CLIP 的关键。

**Q3：为什么 SigLIP 用 sigmoid 而不是 softmax？**
逐对独立的二分类不需要全局归一化：batch 依赖弱、通信少、可加权、数值稳定（log-sigmoid）。softmax 的"全局竞争"只在 batch 内负样本足够多时才有意义。

**Q4：Focal Loss 为什么能处理类别不平衡？**
$(1-p_t)^\gamma$ 调制：简单样本（$p_t \to 1$）权重趋近 0，难样本（$p_t$ 小）权重接近 1，让模型把注意力放在困难样本上，避免被海量简单负样本淹没。

**Q5：MSE 和 MAE 怎么选？**
MSE 对大误差敏感（平方），异常值会主导梯度；MAE 对异常值鲁棒但梯度恒定（接近最优点时不会变小，可能振荡）；Smooth L1 是折中。回归任务有离群点选 MAE/SmoothL1，否则选 MSE。

**Q6：KL 散度为什么非对称？为什么蒸馏还能用？**
$D_{KL}(P\|Q)$ 衡量"用 Q 编码 P"的额外信息量，P 和 Q 交换角色结果不同。蒸馏中教师 P 固定，最小化 KL 等价于最小化交叉熵（熵项常数），目标明确，非对称不影响使用。

**Q7：多任务损失权重怎么调？**
① 手动网格搜索（简单）；② 不确定性加权：$\mathcal{L} = \sum \frac{1}{2\sigma_i^2}\mathcal{L}_i + \log\sigma_i$；③ GradNorm 动态调整。多模态预训练（BLIP）常用固定加权。

**Q8：标签平滑为什么有用？**
one-hot 标签让 softmax 概率必须冲到 1，参数会被推向极端 → 过拟合 + 校准差。平滑后概率上限 $(1-\varepsilon)+\varepsilon/K < 1$，模型更保守、泛化更好。

**Q9：DPO 的损失形式为什么是 sigmoid 的？**
DPO 把偏好建模为"参考模型下的概率比"，用 Bradley-Terry 模型转成二分类偏好概率，最后得到的就是对 log-ratio 的 logistic 损失——和 SigLIP 对 logits 做 sigmoid 二分类在数学结构上完全一致。

**Q10：图文检索为什么用对比损失而不是分类损失？**
检索的目标是"相似度排序"，需要连续度量空间；分类损失只保证类别可分，不保证同类样本距离近。对比损失直接优化"正近负远"的距离结构，学到的 embedding 天然适合 Top-K 检索。
