# 温度蒸馏（Hinton Knowledge Distillation）

> 本模块索引见 [知识蒸馏详解](知识蒸馏详解.md)

## 一、定义与公式

### 1.1 定义

温度蒸馏（Temperature-based Knowledge Distillation）由 Hinton、Vinyals & Dean 于 2015 年在论文《Distilling the Knowledge in a Neural Network》中提出，是知识蒸馏最经典、最基础、面试必考的形态。核心设定：

- 一个已训练好的**大教师网络**（Teacher）输出 logits $z^T$（softmax 之前的原始分数）；
- 引入**温度 T** 把 logits 软化成一个"信息量更足"的概率分布 $p^{(T)}$，称为**软目标（soft target）**；
- **小学生网络**（Student）用**同一个温度**输出自己的软分布 $q^{(T)}$，用 KL 散度对齐教师的软目标；
- 同时保留与真实标签的交叉熵监督，保证学生不偏离 ground truth。

一句话：**温度蒸馏 = 硬标签监督（保证答对）+ 温度软化后的软目标匹配（学会教师的类间知识）**。

### 1.2 软目标公式

设模型对类别 $i$ 的 logit 为 $z_i$，温度为 $T$ 的软目标定义为：

$$p_i^{(T)} = \frac{\exp(z_i / T)}{\sum_{j} \exp(z_j / T)} = \mathrm{softmax}\!\left(\frac{z}{T}\right)_i$$

| T 取值 | 分布形态 | 含义 |
|--------|---------|------|
| $T \to 0^+$ | 趋近 one-hot（argmax 等价） | 信息只剩"是哪类" |
| $T = 1$ | 普通 softmax | 常规推理/训练分布 |
| $T = 2 \sim 10$ | 明显摊平 | 暴露类间相似度（训练常用） |
| $T \to \infty$ | 均匀分布 $1/N$ | 信息完全抹平，不可用 |

注意：**软目标用的公式与普通 softmax 完全相同，只是把 $z$ 换成 $z/T$**——温度只改变分布的"锐利程度"，不改变 argmax 结果（除法是正变换，类别排序不变，这是软目标不丢失正确答案的原因）。

### 1.3 学生总损失

$$\mathcal{L} = \alpha \, \mathcal{L}_{hard} + \beta \, T^2 \, \mathcal{L}_{soft}$$

两项分别定义为：

$$\mathcal{L}_{hard} = \mathrm{CE}\!\left(y,\ \mathrm{softmax}(z^S)\right) = -\sum_i y_i \log q_i^{(1)}$$

$$\mathcal{L}_{soft} = \mathrm{KL}\!\left(p^{(T)} \,\|\, q^{(T)}\right) = \sum_i p_i^{(T)} \log \frac{p_i^{(T)}}{q_i^{(T)}}$$

| 项 | 温度 | 语义 | 典型取值 |
|----|------|------|---------|
| $\mathcal{L}_{hard}$ | $T = 1$ | 学生与真实标签的交叉熵，底线监督 | $\alpha = 1$（固定） |
| $\mathcal{L}_{soft}$ | 同 $T$（师生一致） | 学生与教师软目标的 KL，传输类间知识 | $\beta$ 经 $T^2$ 补偿后约 1 |
| $T^2$ | — | 梯度补偿因子（推导见 1.5） | 不乘 $T^2$ 时改用大 $\beta$ 手调 |

> **面试必记细节**：学生算软损失的温度必须与教师一致（都用 $T$），算硬损失时温度固定为 $T=1$。

### 1.4 硬损失与软损失各负责什么

- **$\mathcal{L}_{hard}$ 负责"答对"**：one-hot 标签是唯一正确的监督信号，保证学生最终预测偏向 ground truth，去掉它学生会"只学教师的错误尾巴"；
- **$\mathcal{L}_{soft}$ 负责"像教师"**：软目标携带类间相似度，让学生学到"猫和狗近、猫和车远"这类硬标签里没有的结构知识；
- 两者互补：硬标签是"下限"（正确性），软标签是"上限"（逼近教师的泛化能力）。

### 1.5 T² 梯度补偿因子的完整推导（面试加分项）

**第一步：软损失对学生 logits 的精确梯度。**

KL 展开后第一项与学生的参数无关：

$$\mathcal{L}_{soft} = \sum_i p_i \log p_i - \sum_i p_i \log q_i \quad\Longrightarrow\quad \frac{\partial \mathcal{L}_{soft}}{\partial z_j^S} = -\sum_i p_i \, \frac{\partial \log q_i}{\partial z_j^S}$$

其中（对 softmax 的 log 形式求导，$q$ 已含温度 $T$）：

$$\log q_i = \frac{z_i^S}{T} - \log\sum_k e^{z_k^S/T} \quad\Longrightarrow\quad \frac{\partial \log q_i}{\partial z_j^S} = \frac{\delta_{ij} - q_j}{T}$$

代入并整理（$\sum_i p_i = 1$）：

$$\frac{\partial \mathcal{L}_{soft}}{\partial z_j^S} = -\sum_i p_i \cdot \frac{\delta_{ij} - q_j}{T} = \frac{q_j - p_j}{T}$$

**第二步：大 T 线性近似，得到 $1/T^2$ 标度。**

当 $T$ 远大于 logits 量级时，$\exp(z/T) \approx 1 + z/T$，softmax 退化为线性归一化：

$$p_j \approx \frac{1 + z_j^T/T}{\sum_k \left(1 + z_k^T/T\right)} \approx \frac{1 + z_j^T/T}{N}, \qquad q_j \approx \frac{1 + z_j^S/T}{N}$$

代入第一步的精确梯度：

$$\frac{\partial \mathcal{L}_{soft}}{\partial z_j^S} \approx \frac{1}{T} \cdot \frac{\left(1 + z_j^T/T\right) - \left(1 + z_j^S/T\right)}{N} = \frac{z_j^T - z_j^S}{N \cdot T^2}$$

**结论**：

1. 大 $T$ 下软损失梯度**与 $1/T^2$ 成正比**——温度每翻倍，梯度缩小约 4 倍；
2. 若不补偿，调大 $T$ 会让学生的学习信号指数级减弱，蒸馏失效；
3. 因此在损失前乘 $T^2$（$\beta T^2 \mathcal{L}_{soft}$），使梯度量级与温度解耦，只与"师生 logits 差异"成正比；
4. 补偿后梯度 $\propto (z_j^T - z_j^S)$，即**大 T 下温度蒸馏 ≈ 在 logits 空间做均方误差匹配（logit matching）**——这解释了为什么直接回归 logits 的做法（MSE on logits）与温度蒸馏本质相通。

## 二、核心原理

### 2.1 为什么温度有效：软化分布暴露类间关系

教师模型在 $T=1$ 时通常极度自信，软目标接近 one-hot。以四分类为例：

```text
T=1  : 猫 0.980  狗 0.015  车 0.003  飞机 0.002
T=4  : 猫 0.520  狗 0.180  车 0.110  飞机 0.090
T=8  : 猫 0.350  狗 0.240  车 0.180  飞机 0.150
```

- $T=1$ 时"狗 0.015 vs 车 0.003"的**比值关系被压缩淹没**——两者在小数点后第二三位，梯度里几乎不可见，学生学不到类间相似度；
- 升温后分布摊开，"猫 0.52、狗 0.18、车 0.11"让学生清晰看到：**猫与狗比猫与车更相似**（狗的概率显著大于车），这正是软标签的核心价值——**暗知识（dark knowledge）**；
- 同时软分布更平滑，梯度的方差更小，学生训练更稳定。

**类比**：教师像一位裁判，硬标签只给名次（第 1 名），软标签给出完整得分（98、91、70）——后者显然信息更丰富。

### 2.2 为什么不能直接匹配 T=1 的概率或原始 logits

| 做法 | 问题 |
|------|------|
| 直接匹配 $T=1$ 的概率 | 分布近 one-hot，类间比值信息丢失，等价于"带噪声的硬标签" |
| 直接回归原始 logits | logits 的量级/方差无界（教师可能输出 ±30），MSE 被极端值主导，训练不稳；且 logits 的绝对尺度无物理意义 |
| 温度软化后匹配 | 分布有界且摊平，类间关系完整保留，梯度量级可控——温度蒸馏是两者的折中 |

### 2.3 师生同温原则

- 软损失里师生的 softmax 必须用**同一个 $T$**：教师用 $T$ 软化是为了暴露知识，学生用同温度软化才能"在同一标度下对比"；
- 如果用不同温度，两个分布的形状标度不匹配，KL 会被"学生太尖/太平"这类无关因素主导；
- 硬损失永远用 $T=1$（标准 softmax + CE）。

### 2.4 训练与推理的温度不同

| 阶段 | 温度 | 原因 |
|------|------|------|
| 训练（蒸馏时） | $T \approx 2 \sim 10$（论文试过 4、8、20） | 软化分布暴露类间关系 |
| 推理（部署后） | 恒为 $T=1$ | 学生直接输出标准概率 |

**温度只影响训练，推理必须回到 $T=1$**——学生学到的是"软化过的类间关系 + 正确的类别排序"，推理时用它自己的原生 logits 即可。

### 2.5 整体训练流程（两阶段）

```text
阶段 1：用大算力训练教师（与蒸馏无关，训好后冻结，可复用给多个学生）
阶段 2：冻结教师 → 前向出软目标 p^(T) → 学生同温出 q^(T) → 计算
        L = L_hard + β·T²·KL(p^(T) ‖ q^(T)) → 反向更新学生
```

## 三、源码实现

### 3.1 温度软化工具函数

```python
import torch
import torch.nn.functional as F

torch.manual_seed(0)   # 固定随机种子，保证输出可复现

def soften(logits, temperature):
    """温度软化 softmax：p_i = exp(z_i/T) / Σ_j exp(z_j/T)"""
    return (logits / temperature).softmax(dim=-1)

def soft_kl(student_logits, teacher_logits, temperature):
    """学生软预测与教师软目标的 KL 散度（batch 均值）"""
    p = soften(teacher_logits, temperature)                 # 教师软目标
    q_log = F.log_softmax(student_logits / temperature, -1)  # 学生软预测（取 log，数值稳定）
    return F.kl_div(q_log, p, reduction="batchmean")

# 示例
z_s = torch.randn(4, 10)   # 学生 logits
z_t = torch.randn(4, 10)   # 教师 logits
print(soften(z_t, T := 4.0).sum(-1))   # 每行和为 1：tensor([1.0000, 1.0000, 1.0000, 1.0000])
print(soft_kl(z_s, z_t, 4.0))          # 标量损失：tensor(0.0576)
```

### 3.2 完整可运行示例：教师训练 + 温度蒸馏 + 对照实验

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader, TensorDataset

torch.manual_seed(0)

# ---------- 1. 合成数据：500 个样本、32 维、8 类（tanh 非线性标签） ----------
# 数据稀少 + 任务非线性 → 学生自训难以学好，正是蒸馏发挥作用的场景
N, D, C = 500, 32, 8
X = torch.randn(N, D)
W1 = torch.randn(D, 64)
y = ((torch.tanh(X @ W1) @ torch.randn(64, C)) * 0.8).argmax(dim=-1)
loader = DataLoader(TensorDataset(X, y), batch_size=64, shuffle=True)

# ---------- 2. 模型：教师两层 256 宽，学生单层 8 宽（容量差距明显） ----------
class Teacher(nn.Module):
    def __init__(self, d=D, c=C):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(d, 256), nn.ReLU(),
                                 nn.Linear(256, 256), nn.ReLU(),
                                 nn.Linear(256, c))
    def forward(self, x):
        return self.net(x)

class Student(nn.Module):
    def __init__(self, d=D, c=C):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(d, 8), nn.ReLU(), nn.Linear(8, c))
    def forward(self, x):
        return self.net(x)

def soften(logits, temperature):
    return (logits / temperature).softmax(dim=-1)

def accuracy(model, x, y):
    with torch.no_grad():
        return (model(x).argmax(-1) == y).float().mean().item()

# ---------- 3. 阶段一：只训练教师（60 epochs，大数据容量拟合 500 样本） ----------
teacher = Teacher()
opt_t = torch.optim.Adam(teacher.parameters(), lr=1e-3)
for _ in range(60):
    for xb, yb in loader:
        opt_t.zero_grad()
        F.cross_entropy(teacher(xb), yb).backward()
        opt_t.step()
print(f"教师精度: {accuracy(teacher, X, y):.3f}")   # 教师精度: 1.000

# ---------- 4. 阶段二：冻结教师，温度蒸馏训练学生 ----------
T, BETA = 4.0, 0.03      # 温度 4；软损失权重 0.03（补偿 T² 后量级适中）
student = Student()
opt_s = torch.optim.Adam(student.parameters(), lr=1e-3)

for _ in range(60):
    for xb, yb in loader:
        z_s = student(xb)                            # 学生 logits
        with torch.no_grad():                        # 教师完全冻结
            p_t = soften(teacher(xb), T)             # 软目标
        l_hard = F.cross_entropy(z_s, yb)            # T=1 硬损失
        l_soft = F.kl_div(F.log_softmax(z_s / T, -1),
                          p_t, reduction="batchmean")
        loss = l_hard + BETA * (T ** 2) * l_soft     # T² 梯度补偿
        opt_s.zero_grad()
        loss.backward()
        opt_s.step()
print(f"蒸馏学生精度: {accuracy(student, X, y):.3f}")  # 蒸馏学生精度: 0.564

# ---------- 5. 对照：同结构学生，只用硬标签训练 ----------
baseline = Student()
opt_b = torch.optim.Adam(baseline.parameters(), lr=1e-3)
for _ in range(60):
    for xb, yb in loader:
        opt_b.zero_grad()
        F.cross_entropy(baseline(xb), yb).backward()
        opt_b.step()
print(f"无蒸馏学生精度: {accuracy(baseline, X, y):.3f}")  # 无蒸馏学生精度: 0.522
```

> 结果解读：学生同容量同数据，仅多了教师软目标监督，精度 0.522 → 0.564（+4.2 个点）。数据越少、学生越小，蒸馏增益越明显；数据充足且任务简单时增益会变小（这本身是蒸馏的一个特性，面试常被追问）。

### 3.3 推理阶段（与普通模型完全一致）

### 3.4 手写 KL（对照 PyTorch 实现）

```python
def kl_manual(p, q):
    """p、q 均为概率分布（不需要 log），返回逐样本 KL(p‖q)"""
    eps = 1e-12
    return (p * (p + eps).log() - p * (q + eps).log()).sum(-1)

p = torch.tensor([[0.7, 0.2, 0.1], [0.4, 0.4, 0.2]])
q = torch.tensor([[0.6, 0.3, 0.1], [0.5, 0.3, 0.2]])
print(kl_manual(p, q))   # tensor([0.0200, 0.0184])

# 与 F.kl_div 对比（注意：F.kl_div 输入是 log 概率）
print(F.kl_div(q.log(), p, reduction="none").sum(-1))  # tensor([0.0200, 0.0184])
```

## 四、深入分析

### 4.1 温度对梯度方差的影响

- 温度本质上是一个**平滑化/锐化算子**：升温压平分布 → 类间概率差变小 → 梯度的绝对值变小但**分布更均匀**，每个类别都有非零的学习信号；
- 低温时梯度集中在 top-1 附近，其他类别的梯度近似为 0——等于退化成硬标签；
- 因此温度蒸馏的一个隐性收益是**梯度正则化**：软目标让每个样本的梯度携带"全类别信息"，等价于为训练加了一种自适应平滑，训练更稳、收敛更平滑。

### 4.2 温度怎么选（经验法则）

1. 从 $T=4$ 起试，在 $2 \sim 10$ 区间按学生验证集精度网格调；
2. **教师越自信**（训练集精度极高、分布极尖），可用更高温度抵消"过度自信"——Hinton 论文 MNIST 实验用 $T=20$；
3. **学生越小**用越低温度（如 $T=4$）：太高的温度下软目标过于平均，小模型难以从中提炼信号；
4. $T$ 过高（如 100）：分布趋近均匀，几乎不含信息，且 $T^2$ 放大噪声，训练变慢；
5. $T$ 过低（接近 1）：软目标近似硬标签，蒸馏退化为普通训练，类间信息丢失。

### 4.3 容量差距（capacity gap）

教师过强（参数为学生 10 倍以上）时，软目标"过于聪明"——类间关系复杂、概率尖细，小学生学不动，甚至比自训更差：

- 缓解 1：提高温度，把分布摊得更平，降低知识复杂度；
- 缓解 2：用**中等规模教师**过渡（教师 → 中间模型 → 学生，两跳蒸馏）；
- 缓解 3：加特征蒸馏（见"特征蒸馏"子篇）为学生提供中间层学习信号；
- 缓解 4：软化 + 限制蒸馏损失权重 $\beta$，让学生先学会"粗结构"再学"细分布"。

### 4.4 教师集成蒸馏

多个教师的平均软目标比单一教师更稳（模型集成 → 蒸馏）：

$$p^{(T)} = \frac{1}{M}\sum_{m=1}^{M} \mathrm{softmax}(z_m^{(T)} / T)$$

学生只面对一个平均后的软目标，训练成本不增加，知识质量更高——这也是工程上"训练成本在教师侧、学生侧不变"的典型用法。

### 4.5 为什么用 KL 而不是直接最小化 CE（soft）或 MSE

- **KL 的非对称性**：KL 在"教师高概率、学生低概率"处惩罚更重（$p_i \log(p_i/q_i)$ 在 $p_i$ 大、$q_i$ 小时剧烈增大），逼学生"把教师确定的事也确定下来"；用 CE（soft）只求 $-\sum p_i \log q_i$，惩罚更温和；
- **数学上等价于匹配**：soft 版本实际上与 KL 只差一个常数项（$\sum p_i \log p_i$ 与学生参数无关），所以实践中 CE(soft) 与 KL 训练效果等价，KL 只是有"距离"的直观解释；
- **不用 MSE**：概率空间的 MSE 对"近 one-hot 分布"几乎无梯度（饱和），且不匹配概率分布的几何（MSE 用于特征空间更合适，见特征蒸馏子篇）。

## 五、优缺点

| 优点 | 缺点 |
|------|------|
| 实现极简：只需两次前向 + 一个 KL，任何带 softmax 的模型都能用 | 只对齐输出，丢失中间层"推理过程"信息 |
| 任务无关：分类、回归、多标签、多模态都能套 | 需要先训练好教师（两阶段成本） |
| 类间知识迁移，学生精度显著高于同容量自训 | 温度 $T$、权重 $\beta$ 需要调参，且无统一理论指导 |
| 教师可复用：一个教师服务多个学生 | 师生结构差异大时（异构），logits 空间对齐效果有限 |
| 对数据量要求低：软标签自带平滑监督 | 教师过强时有容量差距问题（教学失效） |
| 数值稳定：log-softmax + KL 天然稳定 | 教师推理的开销：离线阶段需要跑一遍全部数据 |

## 六、与同类对比

### 6.1 与特征蒸馏 / 关系蒸馏对比

| 维度 | 温度蒸馏（logits） | 特征蒸馏（FitNets） | 关系蒸馏（RKD） |
|------|-------------------|--------------------|-----------------|
| 对齐对象 | 最终输出 logits/概率 | 中间层特征 | 样本间距离/角度 |
| 信息层次 | 结论（"答案的分布"） | 推理过程（"怎么想"） | 样本间结构（"谁和谁像"） |
| 温度依赖 | 依赖 $T$ 软化 | 不依赖温度 | 不依赖温度 |
| 实现难度 | 低 | 中（层选择 + 维度/空间对齐） | 中高（$O(B^2)$~$O(B^3)$ 样本组合） |
| 异构师生兼容性 | 需同类别空间 | 需投影层 $W_r$ 对齐 | 最兼容（只比关系） |
| 代表工作 | Hinton KD (2015) | FitNets (2015) | RKD (2019) |
| 常用场景 | 分类、轻量化基线 | 视觉、表示学习 | 度量学习、少样本 |

### 6.2 与"直接训练小模型"对比

| 维度 | 小模型自训 | 温度蒸馏 |
|------|-----------|---------|
| 监督信号 | one-hot 硬标签 | 硬标签 + 教师软目标 |
| 信息量 | 每样本仅"答案" | 答案 + 类间相似度 + 不确定度 |
| 梯度 | 仅 top-1 有信号，其余为 0 | 全类别有非零信号，更平滑 |
| 数据效率 | 需要更多数据补信息 | 同数据下精度更高 |
| 成本 | 无额外成本 | 教师前向 + 训练两阶段 |

## 七、高频面试问答

**Q1：软目标比硬标签信息量大在哪里？**
硬标签只有"是哪类"一个比特级信息；软目标携带类间相似度（猫/狗近、猫/车远）、样本难度（置信度）和暗知识（小概率类别的关联），且软分布让每个类别都有非零梯度，训练更平滑。一句话：硬标签告诉你"是什么"，软标签告诉你"和什么像、像多少"。

**Q2：温度 T 的作用？T 越大越好吗？**
T 控制 softmax 的软硬程度：T 大 → 分布摊平暴露类间关系；T 小 → 接近 one-hot。不是越大越好：T→∞ 分布均匀、信息抹平且 T² 放大噪声；T 太低则退化为硬标签。训练常用 2~10（自信教师可到 20），推理必须 T=1。

**Q3：损失里的 T² 从哪来？**
精确梯度推导得 $\partial L_{soft}/\partial z_j^S = (q_j - p_j)/T$；大 T 下 $\exp(z/T)\approx 1+z/T$，softmax 近似线性，代入得梯度 $\propto (z_j^T - z_j^S)/(NT^2)$。即梯度随 $1/T^2$ 衰减，乘 $T^2$ 补偿使梯度量级与温度解耦；补偿后大 T 蒸馏等价于 logits 的 MSE 匹配。

**Q4：硬损失和软损失的温度为什么不同？**
硬损失用 T=1：与标准 CE 一致，保证学生预测"正确类别"；软损失师生同用 T：把两个分布放到同一"标度"下比较，温度只负责暴露类间知识。混用温度会导致标度不匹配，KL 被无关因素主导。

**Q5：为什么不直接回归教师的 logits（MSE on logits）？**
logits 无界、量级无物理意义，MSE 被极端值主导且训练不稳；但大 T 蒸馏在数学上近似 logits 的 MSE——所以"温度蒸馏"可看作 logits 匹配的**有界、稳定、带温度标度的软版本**。实践中直接回归 logits 常用在特征蒸馏里（配合归一化）。

**Q6：KL 与 soft-CE 有什么区别？蒸馏用哪个好？**
KL = soft-CE + 常数（$\sum p_i \log p_i$ 与学生参数无关），优化等价。KL 的语义是"分布距离"，方便解释与调参；实现上两者都需数值稳定写法（log-softmax 输入）。

**Q7：教师太强学生学不好怎么办？**
容量差距问题。缓解：提高温度摊平知识、用中等教师两跳蒸馏、加特征蒸馏、降低 $\beta$ 权重、学生先预训练再蒸馏。

**Q8：温度蒸馏在大模型上为什么不好用？**
① 词表 100k+，全词表 softmax/KL 开销爆炸；② 双模型（几十 B + 几 B）前向训练显存翻倍；③ 长序列逐 token 对齐误差累积；④ 师生 tokenizer 不一致时 logits 空间不对齐。大模型场景改用序列级蒸馏（教师生成文本 → SFT 学生）。
