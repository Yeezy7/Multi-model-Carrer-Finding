# 特征蒸馏（Feature-based Distillation）

> 本模块索引见 [知识蒸馏详解](知识蒸馏详解.md)

## 一、定义与公式

### 1.1 定义

特征蒸馏（Feature-based Distillation）指**不（只）对齐师生模型的最终输出，而是对齐两者中间层提取的特征表示**。代表工作是 FitNets（Romero et al., 2015，全名 "FitNets: Hints for Thin Deep Nets"）。

核心直觉：logits 是"压缩后的结论"，而中间层特征图是"推理过程"——只学结论会丢掉大量信息，直接对齐特征等于让学生继承教师的**思维方式**，而不只是答案。

$$f_T(x) \in \mathbb{R}^{d_T}, \qquad f_S(x) \in \mathbb{R}^{d_S}$$

其中 $f_T$ 是教师第 $k$ 层的特征（hint），$f_S$ 是学生某一层的特征。通常两者**维度不同**（$d_T \neq d_S$），需要引入匹配层（projector）对齐。

### 1.2 匹配层（Projector）设计

学生特征过一层可学习的线性映射（FitNets 原文用的是全连接层 $W_r$，CNN 场景常用 1×1 卷积）：

$$g(x) = W_r \, f_S(x) + b_r \in \mathbb{R}^{d_T}$$

| 师生差异 | 匹配层设计 |
|---------|-----------|
| 维度不同（$d_S \neq d_T$） | 线性层/1×1 卷积投影到教师维度 |
| 空间尺寸不同（特征图 $H\times W$ 不同） | 插值 / 池化到同一尺寸 |
| token 数不同（ViT patch 不同） | 全局池化（CLS/均值）后对齐，或插值 token 网格 |
| 数值量级差异大 | 先做 L2 归一化 / LayerNorm 再算距离 |

> 匹配层只在训练时存在，推理时丢弃——它属于"蒸馏脚手架"，不进入学生部署结构。

### 1.3 损失公式

FitNets 的 hint 损失是学生投影特征与教师特征的 L2 回归：

$$\mathcal{L}_{hint} = \left\| W_r \, f_S(x) - f_T(x) \right\|_2^2$$

实践中几乎都会搭配归一化（否则大数值特征主导损失、小数值特征学不到）：

$$\mathcal{L}_{hint} = \left\| \frac{W_r f_S(x)}{\|W_r f_S(x)\|_2} - \frac{f_T(x)}{\|f_T(x)\|_2} \right\|_2^2 \quad \text{（L2 归一化版本）}$$

特征蒸馏通常与 logits 蒸馏、硬标签 CE 联合使用，统一损失：

$$\mathcal{L} = \alpha \, \mathcal{L}_{hard} + \beta \, T^2 \, \mathcal{L}_{soft} + \gamma \, \mathcal{L}_{hint}$$

### 1.4 完整推导：为什么 L2 而非 KL

特征空间的元素是**欧氏向量**，没有"概率"语义（可负、无界、不相加为 1），KL/CE 要求输入是概率分布，直接套用会出错；而 L2 距离直接度量向量差异，与表示空间的几何一致。若希望特征对齐对"方向"敏感、对"尺度"不敏感，则用余弦相似度或 L2 归一化后的 L2（等价于余弦）。

## 二、核心原理

### 2.1 为什么特征比 logits 信息更丰富

1. **logits 是压缩后的结论**：经过若干层非线性变换，信息被"折叠"成类别分数，非目标类的信息大量丢失；
2. **特征是完整的中间表示**：保留空间结构（目标在哪、边缘在哪）、层级语义（低层纹理 → 高层语义），这些正是下游任务（检测、分割、检索）需要的；
3. **表示继承优于答案模仿**：让学生把"中间表示"对齐到教师，等于强制学生的特征空间向教师的成熟空间靠拢——学生学到的是一套**可迁移的表征**，而不只是"怎么输出"；
4. **信号密度高**：一个 $d$ 维特征向量对齐相当于给每个维度都提供监督梯度，而 logits 蒸馏只给学生 $C$（类别数）个信号。

### 2.2 匹配哪一层（Hint Layer 选择）

- FitNets 原则：选择**教师较深、学生较深**的一对"对应层"（通常按深度比例对应，如教师第 2 个 block ↔ 学生第 1 个 block）；
- 经验：**靠近输出的高层特征收益最大**（语义最成熟、与任务最相关），但要留出"学生自己的学习空间"——全层逐层对齐会过度约束，压制学生自主结构；
- 工程上常用"对齐倒数第 1~2 个 block"或"只对齐 CLS 表征（单 token）"两种配置。

### 2.3 特征对齐的三个工程要点

1. **归一化必须做**：特征量级跨模型差异巨大（教师可能量级 10、学生量级 0.1），不归一化时 L2 损失几乎只由大者决定；
2. **投影层要小**：匹配层用线性层即可，过强的 projector 会"代偿"掉对齐压力（学生自己不变，投影自己去拟合教师）；
3. **warmup 权重**：训练初期学生特征未成型，$\gamma$ 直接拉满会干扰分类头，前 10% 步数把 $\gamma$ 从 0 线性升到目标值。

### 2.4 与 logits 蒸馏的互补关系

| 视角 | logits 蒸馏 | 特征蒸馏 |
|------|------------|---------|
| 对齐"什么" | 结论（输出分布） | 过程（中间表示） |
| 梯度到达哪些层 | 直接到达所有层（通过反向传播） | 只直接约束匹配层所在的位置 |
| 学生自由度 | 内部结构自由，只看输出 | 中间表示被约束，结构偏向教师 |
| 典型组合 | 单独用或打底 | 与 logits 蒸馏叠加（$\gamma$ 调小） |

> 两者不是二选一：**logits 蒸馏给"方向"，特征蒸馏给"形状"**，叠加使用是标准做法。

## 三、源码实现

### 3.1 提取中间层特征的标准写法（Hook 方式）

```python
import torch
import torch.nn as nn

features = {}
def make_hook(name):
    def hook(module, inp, out):
        features[name] = out
    return hook

model = nn.Sequential(
    nn.Linear(32, 128), nn.ReLU(),   # 想对齐这一层的输出
    nn.Linear(128, 64), nn.ReLU(),
    nn.Linear(64, 8),
)
model[0].register_forward_hook(make_hook("fc1"))

x = torch.randn(4, 32)
_ = model(x)
print(features["fc1"].shape)   # torch.Size([4, 128])  ← 中间特征
```

### 3.2 完整可运行示例：FitNets 风格特征蒸馏

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader, TensorDataset

torch.manual_seed(0)

# ---------- 1. 合成数据：2000 样本、32 维、8 类（tanh 非线性，数据有限） ----------
# 数据有限 + 任务非线性 → 小学生的特征"长不好"，正是特征蒸馏的用武之地
N, D, C = 2000, 32, 8
X = torch.randn(N, D)
W1 = torch.randn(D, 64)
y = ((torch.tanh(X @ W1) @ torch.randn(64, C)) * 0.8).argmax(dim=-1)
loader = DataLoader(TensorDataset(X, y), batch_size=64, shuffle=True)

# ---------- 2. 模型：forward 同时返回中间特征与 logits ----------
class Teacher(nn.Module):          # 宽网络：隐层 128 维
    def __init__(self, d=D, c=C, h=128):
        super().__init__()
        self.fc1 = nn.Linear(d, h)
        self.fc2 = nn.Linear(h, h)
        self.head = nn.Linear(h, c)
    def forward(self, x):
        f = F.relu(self.fc2(F.relu(self.fc1(x))))   # 中间特征 128 维
        return f, self.head(f)                       # (特征, logits)

class Student(nn.Module):          # 窄网络：隐层 8 维，特征天然更"贫瘠"
    def __init__(self, d=D, c=C, h=8):
        super().__init__()
        self.fc1 = nn.Linear(d, h)
        self.head = nn.Linear(h, c)
    def forward(self, x):
        f = F.relu(self.fc1(x))                      # 中间特征 8 维
        return f, self.head(f)

def accuracy(model, x, y):
    with torch.no_grad():
        return (model(x)[1].argmax(-1) == y).float().mean().item()

# ---------- 3. 训练教师 ----------
teacher = Teacher()
opt_t = torch.optim.Adam(teacher.parameters(), lr=1e-3)
for _ in range(60):
    for xb, yb in loader:
        opt_t.zero_grad()
        F.cross_entropy(teacher(xb)[1], yb).backward()
        opt_t.step()
print(f"教师精度: {accuracy(teacher, X, y):.3f}")   # 教师精度: 1.000

# ---------- 4. 特征蒸馏训练学生 ----------
student = Student()
projector = nn.Linear(8, 128)      # 匹配层：8 维学生特征 → 128 维教师特征空间
T, BETA, GAMMA = 4.0, 0.03, 2.0
opt_s = torch.optim.Adam(list(student.parameters()) + list(projector.parameters()),
                         lr=1e-3, weight_decay=1e-2)   # wd 防投影层在小数据上过拟合

def l2_norm(f):
    return F.normalize(f, dim=-1)  # L2 归一化，消除量级差异对损失的干扰

for _ in range(60):
    for xb, yb in loader:
        f_t, z_t = teacher(xb)
        with torch.no_grad():                      # 教师冻结
            f_t = f_t.detach()
            p_t = (z_t / T).softmax(-1)
        f_s, z_s = student(xb)

        l_hard = F.cross_entropy(z_s, yb)          # ① 硬标签 CE
        l_soft = F.kl_div(F.log_softmax(z_s / T, -1), p_t, reduction="batchmean")
        l_hint = F.mse_loss(l2_norm(projector(f_s)), l2_norm(f_t))  # ② 特征对齐

        loss = l_hard + BETA * (T ** 2) * l_soft + GAMMA * l_hint
        opt_s.zero_grad()
        loss.backward()
        opt_s.step()
print(f"特征蒸馏学生精度: {accuracy(student, X, y):.3f}")  # 特征蒸馏学生精度: 0.600

# ---------- 5. 对照：同结构学生，仅硬标签 ----------
base = Student()
opt_b = torch.optim.Adam(base.parameters(), lr=1e-3, weight_decay=1e-2)
for _ in range(60):
    for xb, yb in loader:
        opt_b.zero_grad()
        F.cross_entropy(base(xb)[1], yb).backward()
        opt_b.step()
print(f"无蒸馏学生精度: {accuracy(base, X, y):.3f}")  # 无蒸馏学生精度: 0.580
```

> 结果解读：同容量学生（隐层 8 维）仅增加特征对齐监督，精度 0.580 → 0.600。**注意**：小数据上投影层容易过拟合，务必加 weight decay；特征蒸馏的收益在视觉任务（CNN 特征图、检测/分割）上比 toy 任务大得多。

### 3.3 只用特征蒸馏（无 logits 软损失）的简化版

```python
# 只保留 hint 损失的训练步（适用于师生输出空间不可比的场景）
for xb, yb in loader:
    f_t, _ = teacher(xb)
    f_s, z_s = student(xb)
    l_hint = F.mse_loss(l2_norm(projector(f_s)), l2_norm(f_t.detach()))
    l_task = F.cross_entropy(z_s, yb)          # 任务损失不可省，否则学生无任务方向
    loss = l_task + GAMMA * l_hint
```

> 注意：纯特征蒸馏很少单独用，因为特征对齐只约束表示、不约束任务输出，必须搭配任务损失（或 logits 蒸馏）才有意义。

### 3.4 投影层可视化检验

```python
# 检查投影后的特征是否真的接近教师特征
with torch.no_grad():
    f_s, _ = student(X[:64])
    aligned = l2_norm(projector(f_s))
    target = l2_norm(teacher(X[:64])[0])
    print(f"对齐后平均余弦相似度: {(aligned * target).sum(-1).mean().item():.3f}")
# 对齐后平均余弦相似度: 0.919  （训练越久越接近 1，说明学生特征真的"学"到了教师表示）
```

## 四、深入分析

### 4.1 特征蒸馏为什么能提升小模型容量

小网络（窄/浅）的表示空间"容量"不足，自己训练时只能形成粗糙特征；特征蒸馏**用教师特征作为软目标**，等于把教师"算好的中间答案"当监督——学生每个隐层神经元都有明确的"要长成什么样"的参考，从而在相同参数量下获得远超自训的表示质量。FitNets 论文正是用这一思路证明了"深而窄"的学生网络能逼近"宽而浅"教师网络的精度。

### 4.2 匹配层的梯度归属（一个面试细节）

$\mathcal{L}_{hint}$ 的梯度会同时流向 projector 和学生网络：

$$\frac{\partial \mathcal{L}_{hint}}{\partial f_S} = 2\left(W_r f_S - f_T\right) W_r$$

- 如果 projector 太强（多层 MLP），它可以**只靠自己把特征映射到教师空间**，学生本体不动——对齐"假成功"；
- 所以投影层必须"弱"（单层线性），并检查学生的特征本身是否在变（打印 4.1 的对齐相似度 + 学生特征范数变化）。

### 4.3 特征蒸馏的失败模式

| 失败模式 | 表现 | 原因 | 对策 |
|---------|------|------|------|
| 量级主导 | 损失很小但精度不涨 | 未归一化，大量级项主导 | L2 归一化 / LN 后再对齐 |
| 投影代偿 | 特征对齐很好但学生没学到 | projector 过强 | 用单层线性 projector |
| 层位不匹配 | 训练不稳、精度下降 | 对齐了"不该对齐"的层（过浅/过深） | 只对齐高层，留学习空间 |
| 权重过大 | 分类头被压制 | $\gamma$ 太大、无 warmup | $\gamma$ 0.1~1 + 前 10% 步 warmup |
| 空间不对齐 | 特征对不上 | 师生分辨率/token 数不同 | 池化/插值/CLS 对齐（见总览 6.5.4） |

### 4.4 与注意力图蒸馏的关系

特征蒸馏家族还包括 AT（Attention Transfer，Zagoruyko & Komodakis 2017）：把"特征图沿通道求均值/求和的注意力图"作为对齐对象：

$$\mathcal{L}_{AT} = \left\| \frac{A^S}{\|A^S\|_2} - \frac{A^T}{\|A^T\|_2} \right\|_2^2, \qquad A = \sum_{c} |f_c|^p$$

优势：注意力图是单通道 2D 图，天然规避维度/空间对齐问题（与 token 数无关），在多模态（ViT 师生 patch 不同）场景更实用。

## 五、优缺点

| 优点 | 缺点 |
|------|------|
| 信息更丰富：对齐"推理过程"而非"结论" | 实现复杂：层选择、维度/空间对齐、归一化、投影层都要设计 |
| 中间表示可迁移，对下游任务（检测/检索）增益大 | 对师生结构差异敏感：异构网络对齐困难 |
| 特征维度多，监督信号密度远高于 logits | 过强约束会压制学生的自主结构（需留学习空间） |
| 可与 logits 蒸馏/关系蒸馏叠加 | 需额外保存教师中间特征（显存/存储开销） |
| 不依赖温度参数，少一个超参 | 投影层可能代偿，需防"假对齐" |

## 六、与同类对比

### 6.1 特征蒸馏 vs logits 蒸馏（重点）

| 维度 | logits 蒸馏（温度蒸馏） | 特征蒸馏（FitNets） |
|------|------------------------|---------------------|
| 对齐对象 | 输出概率/分数 | 中间层特征向量 |
| 信息内容 | 类间关系（结论） | 表示结构（过程） |
| 信息量 | $C$ 维（类别数） | $d$ 维（特征维度，通常远大于 $C$） |
| 梯度覆盖 | 经输出层流向全网络 | 直接作用于匹配层附近，需透传 |
| 实现成本 | 低（两个 forward + KL） | 中（hook/改造 forward + 投影层） |
| 对异构师生 | 需同类别空间即可 | 需要维度/空间/尺度对齐 |
| 数值需求 | log-softmax 防溢出 | 归一化防量级主导 |
| 代表工作 | Hinton KD (2015) | FitNets (2015) |
| 单独使用效果 | 通常已够用（分类任务） | 通常需叠加任务损失 |

### 6.2 特征蒸馏 vs 关系蒸馏

关系蒸馏（RKD）对齐"样本间距离/角度"，特征蒸馏对齐"单样本特征"。差异：特征蒸馏绑定了具体特征空间（依赖投影对齐），关系蒸馏只依赖样本对结构（对维度/尺度天然鲁棒，$O(B^2)$ 计算）。检测/分割等多模态场景常用"特征 + 关系"组合。

## 七、高频面试问答

**Q1：为什么特征比 logits 信息更丰富？**
logits 是经过全网络折叠后的"结论"，只保留类别信息；特征保留空间结构、层级语义等完整中间表示，是"推理过程"。且特征维度远大于类别数，每个维度都是监督信号，梯度密度高，学到的表示可迁移。

**Q2：师生特征维度不一样怎么办？**
加匹配层（投影）：学生特征过单层线性层/1×1 卷积映射到教师维度；空间尺寸不同则先插值或池化；token 数不同则用全局池化/CLS 对齐（见总览 6.5.4 的 token 对齐方案）。

**Q3：特征蒸馏为什么要归一化？**
不同模型的中间特征量级差异巨大（10 vs 0.1），L2 损失会被大量级一方主导，小量级一方的信息学不到。L2 归一化（或 LayerNorm）后再算距离，使损失只度量"方向/形状"差异。

**Q4：投影层为什么不做得复杂一点？**
投影层是"代偿风险源"：它越强越能独自完成特征空间变换，学生本体不学习，出现"对齐假成功"。单层线性投影 + 检查学生特征本身的变化（余弦相似度/特征范数）是标准做法。

**Q5：特征蒸馏选择哪一层的特征对齐？**
通常选教师较深、学生较深的"对应层"（按深度比例），靠近输出的高层特征收益最大；但要给学生留出自主结构空间——逐层全对齐会过度约束，反而降低学生灵活性。

**Q6：特征蒸馏能单独用吗？**
不建议。特征对齐只约束表示不约束任务输出，必须搭配任务损失（硬标签 CE）或 logits 蒸馏才有任务方向。标准组合是 $\alpha L_{hard} + \beta T^2 L_{soft} + \gamma L_{hint}$，其中 $\gamma$ 常用 warmup 调度。

**Q7：特征蒸馏和 logits 蒸馏怎么配合使用？**
logits 蒸馏管"输出正确性"，特征蒸馏管"表示质量"：先各自单独调试超参，再叠加；$\beta$ 与 $\gamma$ 按梯度量级对齐（打印三项损失，让梯度贡献在 $10^{-1}\sim1$ 量级），特征损失配 warmup。

**Q8：多模态里师生 token 数不同，特征蒸馏怎么做？**
方案按优先级：① 全局特征（CLS/均值池化）对齐（与 token 数无关，最稳）；② token 网格插值对齐；③ 注意力图对齐（AT，与 token 数无关）；④ 干脆输出级蒸馏。详见总览"模态对齐问题"一节。
