# 自蒸馏与在线蒸馏（Self & Online Distillation）

> 本模块索引见 [知识蒸馏详解](知识蒸馏详解.md)

## 一、定义与公式

### 1.1 三类范式的定位

经典 Hinton 温度蒸馏是**离线蒸馏（Offline KD）**：先训练大教师，再冻结教师训练学生（两阶段）。当"没有大教师可用"或"不想付两阶段成本"时，衍生出两种范式：

| 范式 | 教师来源 | 教师是否更新 | 代表工作 |
|------|---------|-------------|---------|
| 离线蒸馏 | 预先训练好的大模型 | 否（冻结） | Hinton KD |
| **在线蒸馏** | 与学生同规模、同训的同伴网络 | 是（双方都更新） | Deep Mutual Learning (DML) |
| **自蒸馏** | 学生自己的历史版本 / EMA | 是（EMA 平滑更新） | DINO、SigLIP 2、Born-Again Networks |

一句话记忆：**离线 = 站在巨人肩膀上；在线 = 互相学习；自蒸馏 = 镜像中的自己。**

### 1.2 在线蒸馏（Online KD）：师生同训

没有预训练教师，让两个（或多个）**同规模网络**同时训练、互相把对方当教师。以 DML（Deep Mutual Learning，Zhang et al. 2018）为例，网络 A 与 B 的联合损失：

$$\mathcal{L} = \mathcal{L}_{task}(x, y) + \lambda \Big[ \mathrm{KL}(p_A \| p_B) + \mathrm{KL}(p_B \| p_A) \Big]$$

- 双方既是教师也是学生，蒸馏损失**对称**；
- 温度 $T$ 仍可引入（软化双方的软目标），但常直接用 $T=1$ 或较小温度；
- 双方都从硬标签 + 对方的软标签学习：相当于两个模型"互相当对方的正则化器"。

### 1.3 自蒸馏（Self-distillation）：自己教自己

学生的"教师"来自它自己的历史状态，最常见三种形式：

**① 参数复制（Born-Again Networks, BAN）**：训练 $n$ 代，第 $k$ 代用第 $k-1$ 代训好的模型当教师：

$$\mathcal{L}_k = \alpha \, \mathcal{L}_{hard} + \beta \, \mathrm{KL}\!\left(p_{k-1}^{(T)} \| p_k^{(T)}\right)$$

**② EMA 教师（DINO 范式）**：训练过程中维护教师 = 学生参数的指数移动平均：

$$\theta_T \leftarrow m \cdot \theta_T + (1-m) \cdot \theta_S, \qquad m \in [0.99, 0.999]$$

教师只前向、不反传；因为教师参数"滞后"于学生，天然更稳定、携带更强的历史先验。

**③ 深度/宽度自蒸馏**：学生与教师结构相同但更深/更宽，浅层部分对齐深层部分的特征。

### 1.4 DINO 的自蒸馏目标（视觉自监督经典）

DINO（Caron et al., 2021，用于 ViT 自监督）把自蒸馏用在了无标签场景：教师和学生看同一张图的两个不同裁剪视角 $x_1, x_2$，**学生去预测教师对另一个视角的输出**：

$$\mathcal{L}_{DINO} = -\sum_i p_t(x_1) \log p_s(x_2) - \sum_i p_t(x_2) \log p_s(x_1)$$

配合三个工程组件：教师输出做**中心化（centering）**与**锐化（sharpening，用低温 softmax）**防止塌缩；教师用 EMA 更新。**训练即蒸馏，零额外教师成本**——这是自监督预训练的核心机制之一。

### 1.5 大模型场景：MiniLLM 与反向 KL

自蒸馏/在线蒸馏的思想在大模型（LLM）时代演化为**以学生自己生成序列为锚点的分布对齐**。MiniLLM（Gu et al., 2023）的核心：让学生按自己的分布采样前缀（on-policy），用**反向 KL** 对齐学生与教师的完整序列分布：

$$\mathcal{L} = \sum_{t} D_{KL}\!\left(p_S(\cdot \mid x, y_{<t}) \,\|\, p_T(\cdot \mid x, y_{<t})\right)$$

正 KL vs 反 KL 的本质差异：

$$D_{KL}(p_T \| p_S) = \mathbb{E}_{x \sim p_T}\log\frac{p_T}{p_S} \quad(\text{零避免/mode covering})$$

$$D_{KL}(p_S \| p_T) = \mathbb{E}_{x \sim p_S}\log\frac{p_S}{p_T} \quad(\text{零强制/mode seeking})$$

- 正 KL：按教师分布采样，要求学生在教师有概率的所有地方都有概率 → 学生被迫覆盖长尾，输出过平滑、废话多；
- 反 KL：按学生自己分布采样，只惩罚"学生给高概率而教师不给"的地方 → 学生只覆盖教师高概率模式，分布尖锐、更自信、幻觉更少；
- MiniLLM 用反 KL 的深层理由：**学生采样即推理行为（on-policy），缓解暴露偏差**，且学生不必拟合教师的长尾噪声。

## 二、核心原理

### 2.1 在线蒸馏为什么有效：互为正则

- 两个网络结构不同、初始化不同，它们的错误模式不完全相关——对方的软目标相当于一个**动态的正则器**，抑制各自过拟合到训练集噪声；
- 软标签（尤其温度软化后）比 one-hot 平滑，把"相似类别"知识在双方间传导，两个网络互相帮对方看清类间结构；
- 实证结果：DML 中两个模型精度都高于各自单独训练，且收敛更快（软目标梯度方向更稳）。

### 2.2 自蒸馏为什么有效：EMA 教师的时间平滑

- 学生的参数在训练中剧烈震荡，而 EMA 教师 $\theta_T$ 是历史的平滑平均，**信号更稳、噪声更小**；
- 教师"滞后"于学生 → 教师看到的是"学生较旧但更成熟"的知识形态，天然比当前学生多一层先验；
- 自蒸馏不引入任何外部模型：**算力成本约等于普通训练**（教师前向只多一次，可共享计算图优化），所以是"穷人的蒸馏"，特别适合预算受限的自监督/多模态预训练。

### 2.3 防塌缩：DINO 的 centering + sharpening

无标签自蒸馏最大的坑是**表示塌缩**（所有样本输出同一个常数分布，损失降到 0 但无意义）。DINO 用两个对抗组件解决：

- **centering（中心化）**：教师输出减去 EMA 均值 $c$，防止某个类被"无脑抬高"；
- **sharpening（锐化）**：教师用低温 $T_t$（如 0.04）softmax，逼教师输出"尖锐"的分布，防止教师分布过平导致学生无信号可学。

两者方向相反、缺一不可：只 center 会塌缩到均匀分布，只 sharpen 会塌缩到 one-hot。

### 2.4 在线 vs 自蒸馏的适用边界

| 场景 | 首选 |
|------|------|
| 有可复用的预训练大教师 | 离线蒸馏 |
| 无教师、预算有限、自监督 | 自蒸馏（EMA） |
| 多模型部署（双塔/双流） | 在线蒸馏（DML），顺带得到两个模型 |
| 学生容量小、教师太大 | 自蒸馏（规避容量差距） |
| 大模型压缩 | 反向 KL 序列级（MiniLLM/GKD 路线） |

## 三、源码实现

### 3.1 完整可运行示例：EMA 自蒸馏（分类任务）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader, TensorDataset

torch.manual_seed(1)

# ---------- 1. 合成数据：500 样本、32 维、8 类（tanh 非线性，数据稀少） ----------
N, D, C = 500, 32, 8
X = torch.randn(N, D)
W1 = torch.randn(D, 64)
y = ((torch.tanh(X @ W1) @ torch.randn(64, C)) * 0.8).argmax(dim=-1)
loader = DataLoader(TensorDataset(X, y), batch_size=64, shuffle=True)

# ---------- 2. 学生与 EMA 教师：同一网络结构，参数互相独立 ----------
class Net(nn.Module):
    def __init__(self, d=D, c=C, h=8):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(d, h), nn.ReLU(), nn.Linear(h, c))
    def forward(self, x):
        return self.net(x)

student = Net()
teacher = Net()
teacher.load_state_dict(student.state_dict())   # 教师初始 = 学生初始
teacher.eval()                                  # 教师永远只做前向、不反传

MOM, T = 0.99, 3.0          # EMA 动量、蒸馏温度

@torch.no_grad()
def ema_update(teacher, student, mom):
    """教师参数向学生参数滑动：θ_t ← m·θ_t + (1-m)·θ_s"""
    for p_t, p_s in zip(teacher.parameters(), student.parameters()):
        p_t.mul_(mom).add_(p_s, alpha=1 - mom)

def accuracy(model, x, y):
    with torch.no_grad():
        return (model(x).argmax(-1) == y).float().mean().item()

# ---------- 3. 自蒸馏训练：学生更新 → 教师 EMA 跟进 ----------
opt = torch.optim.Adam(student.parameters(), lr=1e-3)
for epoch in range(60):
    for xb, yb in loader:
        z_s = student(xb)
        with torch.no_grad():                    # EMA 教师冻结
            p_t = (teacher(xb) / T).softmax(-1)  # 教师软目标
        l_hard = F.cross_entropy(z_s, yb)
        l_soft = F.kl_div(F.log_softmax(z_s / T, -1), p_t, reduction="batchmean")
        loss = l_hard + (T ** 2) * l_soft        # 硬 + 软（含 T² 补偿）
        opt.zero_grad()
        loss.backward()
        opt.step()
        ema_update(teacher, student, MOM)        # 学生动一步，教师跟一步

print(f"学生精度: {accuracy(student, X, y):.3f}")    # 学生精度: 0.592
print(f"EMA教师精度: {accuracy(teacher, X, y):.3f}") # EMA教师精度: 0.562

# 对照：无蒸馏直接训练
base = Net()
opt_b = torch.optim.Adam(base.parameters(), lr=1e-3)
for _ in range(60):
    for xb, yb in loader:
        opt_b.zero_grad()
        F.cross_entropy(base(xb), yb).backward()
        opt_b.step()
print(f"无蒸馏精度: {accuracy(base, X, y):.3f}")     # 无蒸馏精度: 0.548
```

> 结果解读：学生和它的 EMA 教师（0.592 / 0.562）都超过了无蒸馏基线（0.548）——EMA 教师的历史平滑给学生提供了比 one-hot 更稳的学习信号，且**没有增加任何外部教师成本**。EMA 教师可作为推理备选模型（DINO/SigLIP 2 正是用 EMA 教师做推理）。自蒸馏的收益在小数据/难任务上更明显，数据充足且任务简单时与基线差距会收窄。

### 3.2 DINO 风格特征自蒸馏（两视角对比学习版）

```python
# 简化版：同一 batch 两个随机扰动视角，学生预测 EMA 教师对另一视角的特征分布
class DinoLoss(nn.Module):
    def __init__(self, dim, temperature_t=0.04, temperature_s=0.1):
        super().__init__()
        self.head_s = nn.Linear(dim, 256)        # 学生投影头
        self.head_t = nn.Linear(dim, 256)        # 教师投影头
        self.t_t, self.t_s = temperature_t, temperature_s
        self.center = torch.zeros(256)           # centering 向量

    def forward(self, f_s1, f_s2, f_t1, f_t2):
        p_t1 = (self.head_t(f_t1) / self.t_t - self.center).softmax(-1)
        p_t2 = (self.head_t(f_t2) / self.t_t - self.center).softmax(-1)
        q_s1 = F.log_softmax(self.head_s(f_s1) / self.t_s, -1)
        q_s2 = F.log_softmax(self.head_s(f_s2) / self.t_s, -1)
        loss = -(p_t1 * q_s2 + p_t2 * q_s1).sum(-1).mean()   # 交叉预测
        with torch.no_grad():
            self.center = 0.9 * self.center + 0.1 * (p_t1 + p_t2).mean(0)
        return loss

loss_fn = DinoLoss(64)
f_s1, f_s2 = torch.randn(8, 64), torch.randn(8, 64)
f_t1, f_t2 = torch.randn(8, 64), torch.randn(8, 64)
print(loss_fn(f_s1, f_s2, f_t1, f_t2))   # tensor(34.3085, grad_fn=<NegBackward0>)（数值随随机初始化浮动）
```

### 3.3 在线蒸馏（DML）：双网络互教

```python
# DML 最小实现：两个同规模网络，对称 KL 互教（自包含数据，可独立运行）
torch.manual_seed(1)
X = torch.randn(500, 32)
W1 = torch.randn(32, 64)
y = ((torch.tanh(X @ W1) @ torch.randn(64, 8)) * 0.8).argmax(dim=-1)
loader = DataLoader(TensorDataset(X, y), batch_size=64, shuffle=True)

net_a, net_b = Net(), Net()
opt = torch.optim.Adam(list(net_a.parameters()) + list(net_b.parameters()), lr=1e-3)

T = 3.0
for _ in range(60):
    for xb, yb in loader:
        z_a, z_b = net_a(xb), net_b(xb)
        p_a = (z_a / T).softmax(-1).detach()          # 互相把对方当教师
        p_b = (z_b / T).softmax(-1).detach()
        l_a = F.cross_entropy(z_a, yb) + (T ** 2) * F.kl_div(F.log_softmax(z_a / T, -1), p_b, reduction="batchmean")
        l_b = F.cross_entropy(z_b, yb) + (T ** 2) * F.kl_div(F.log_softmax(z_b / T, -1), p_a, reduction="batchmean")
        loss = l_a + l_b                              # 双方梯度都走，等价于对称 KL
        opt.zero_grad()
        loss.backward()
        opt.step()

# 单模型基线（同结构、同数据、同时长）
base = Net()
opt_b = torch.optim.Adam(base.parameters(), lr=1e-3)
for _ in range(60):
    for xb, yb in loader:
        opt_b.zero_grad()
        F.cross_entropy(base(xb), yb).backward()
        opt_b.step()

print(f"net_a: {accuracy(net_a, X, y):.3f}, net_b: {accuracy(net_b, X, y):.3f}")
# net_a: 0.584, net_b: 0.576
print(f"单模型基线: {accuracy(base, X, y):.3f}")
# 单模型基线: 0.548  （互教双方都超过单模型自训，这就是"训练时集成"的收益）
```

### 3.4 MiniLLM 反向 KL 的最小计算示例

```python
# 反向 KL 的 PyTorch 表达：采样来自学生，惩罚用教师打分
def reverse_kl(q_logprobs, p_logprobs):
    """D_KL(q‖p) = Σ q·(log q - log p)，q 是学生分布"""
    return (q_logprobs.exp() * (q_logprobs - p_logprobs)).sum(-1).mean()

q = F.log_softmax(torch.randn(4, 50), -1)   # 学生分布（on-policy 采样）
p = F.log_softmax(torch.randn(4, 50), -1)   # 教师分布
print(reverse_kl(q, p))                     # tensor(0.8273)（数值随随机初始化浮动）
```

## 四、深入分析

### 4.1 EMA 动量怎么选

- $m$ 越大，教师变化越慢、越稳定，但跟随学生太慢会"教旧知识"；$m$ 越小，教师越接近学生，自蒸馏退化为普通训练；
- 经验：训练早期用较小 $m$（如 0.9~0.99）让教师快速跟进，后期升到 0.999+；DINO 对 teacher 动量的设计是 $m = 1 - \frac{1}{2}\cos(\pi \cdot \frac{k}{K})$ 的余弦退火（0.996 → 1.0）。

### 4.2 在线蒸馏为什么精度能超过单模型

两个网络的错误模式不同（结构/初始化差异）→ 对方的软目标提供"教师视角"的额外监督 → 相当于隐式集成：DML 的训练过程等价于让每个网络同时最小化自己的损失 + 与同伴的一致性，最后的"平均效应"让每个模型都吸收了对方的泛化信号。注意这**不是真正的集成**（推理时只用单个模型），而是"训练时集成、推理时单模"。

### 4.3 自蒸馏 vs 在线蒸馏的算力对比

| 范式 | 前向次数 | 反传次数 | 额外开销 |
|------|---------|---------|---------|
| 离线蒸馏 | 学生 1 + 教师 1 | 1（学生） | 教师预训练 + 推理一遍数据 |
| 在线蒸馏 | 2（双方） | 2（双方） | 训练算力翻倍 |
| 自蒸馏（EMA） | 学生 1 + 教师 1 | 1（学生） | 仅教师前向（可近似忽略） |

自蒸馏在算力上最省，这是它在 DINO、SigLIP 2、MoCo 等自监督工作中成为标配的根本原因。

### 4.4 自蒸馏在大模型上的形态：从 EMA 到 on-policy 序列蒸馏

大模型时代 EMA 自蒸馏（参数量级大、EMA 代价高）演化为两个方向：

- **GKD（Generalized KD）**：用学生自己生成的序列（on-policy）配教师打分，本质是"自蒸馏 + 反向 KL"——学生从自己的输出里学，教师只打分；
- **自监督蒸馏**（如 Qwen 系列的 self-play / RLEF 思路）：用模型自己的偏好数据做对齐，不依赖外部教师——把"自蒸馏"的思想延伸到了 RL 阶段。

## 五、优缺点

### 5.1 在线蒸馏

| 优点 | 缺点 |
|------|------|
| 不需要预训练大教师 | 无"大教师天花板"，上限受同规模模型限制 |
| 师生同训，无两阶段 | 训练算力翻倍（双模型反传） |
| 双方互益，可同时得到两个模型 | 需要同步机制（梯度/顺序），多机部署复杂 |
| 软目标互相正则，收敛更稳 | 调参维度多（温度、权重 $\lambda$、网络异构度） |

### 5.2 自蒸馏

| 优点 | 缺点 |
|------|------|
| 零外部教师成本，算力近似普通训练 | 没有外部知识增益，上限受自身容量限制 |
| EMA 教师信号稳定、训练平滑 | 无标签场景必须防表示塌缩（centering/sharpening 调参敏感） |
| 天然规避容量差距问题 | 增益在数据充足/任务简单时不明显 |
| 训练即蒸馏，天然适合自监督/多模态 | EMA 动量、温度需要精心调度 |

## 六、与同类对比

### 6.1 三种蒸馏范式全景对比

| 维度 | 离线蒸馏 | 在线蒸馏 | 自蒸馏 |
|------|---------|---------|--------|
| 教师来源 | 预训练大模型 | 同规模同伴 | 自身历史/EMA |
| 教师更新 | 否 | 是 | 是（EMA） |
| 训练阶段 | 两阶段 | 单阶段 | 单阶段 |
| 教师算力成本 | 高（训练+推理） | 高（翻倍） | 低（仅一次前向） |
| 知识上限 | 高（大教师） | 中（同规模） | 低（自身） |
| 稳定性 | 最稳 | 中（同步依赖） | 稳（EMA 平滑） |
| 典型代表 | Hinton KD | DML | BAN / DINO / SigLIP 2 |
| 大模型形态 | 离线 SeqKD | 在线 SeqKD | GKD / on-policy |

### 6.2 自蒸馏 vs 普通训练（同结构同数据）

| 维度 | 普通训练 | 自蒸馏 |
|------|---------|--------|
| 监督 | 硬标签 | 硬标签 + EMA 教师软目标 |
| 梯度来源 | 当前参数一步 | 当前参数 + 历史平滑的知识 |
| 过拟合倾向 | 高（小数据明显） | 低（软目标天然平滑正则） |
| 训练曲线 | 震荡 | 更平滑、更稳 |
| 增益来源 | — | 时间平滑 + 历史先验 |

## 七、高频面试问答

**Q1：离线、在线、自蒸馏的本质区别？**
教师来源与是否更新：离线用固定预训练大模型（两阶段）；在线用同规模同伴互教同训（双方更新）；自蒸馏的教师是学生自己的 EMA/历史版本。记忆：站在巨人肩膀 / 互相学习 / 镜像中的自己。

**Q2：EMA 教师为什么有效？动量怎么选？**
EMA 教师是学生参数的历史平滑平均，信号稳定、噪声小，且"滞后"带来额外先验。动量 $m$ 大→教师稳但滞后；小→接近学生本身，退化为普通训练。常用 0.99~0.999，DINO 用余弦退火（0.996→1.0）。

**Q3：DINO 为什么需要 centering 和 sharpening？**
防止无标签自蒸馏的表示塌缩：只 center 不 sharpen → 分布塌缩到均匀；只 sharpen 不 center → 塌缩到 one-hot。两者方向相反、缺一不可，保证教师输出既有信息又不会退化为常数。

**Q4：在线蒸馏为什么能超过单模型？**
互教等于双方互为动态正则器：软目标比硬标签平滑，传导类间结构；双方错误模式不相关，互相抵消过拟合。训练时隐式集成、推理时单模，所以精度可超各自单独训练。

**Q5：自蒸馏和普通训练的区别？有什么收益？**
多一个"自己的历史教师"：EMA 教师提供时间平滑的知识信号，训练更稳、更抗过拟合；收益在小数据/难任务上明显，且零额外教师成本——适合预算受限的自监督预训练（DINO、SigLIP 2）。

**Q6：为什么大模型时代用反向 KL 而不是正向 KL？**
正 KL 按教师分布采样、mode covering，学生被迫覆盖教师长尾（含幻觉文本），输出过平滑；反 KL 按学生自己分布采样（on-policy）、mode seeking，只惩罚"学生高概率教师低概率"处，输出尖锐、幻觉少，且采样行为与推理一致，缓解暴露偏差。

**Q7：MiniLLM/GKD 与 Hinton 蒸馏有什么关系？**
本质仍是"学生对齐教师"，但对齐对象从 logits 升级为**完整序列分布**（因词表过大、双模型前向过贵、tokenizer 可能不一致）；并用 on-policy（学生自己采样）替代 off-policy（教师采样），这正是自蒸馏思想在大模型上的延续。

**Q8：自蒸馏和在线蒸馏可以结合吗？**
可以。多教师互相学习 + 各自的 EMA 版本（如 DML + EMA 稳定化），甚至在线师生同训时教师侧用 EMA 平滑——实践中"EMA 教师 + 在线互教"是稳定性的常见组合。
