## 一、为什么初始化重要

### 1.1 不初始化 / 全零初始化的后果

如果不做任何初始化（或全部初始化为同一个常数），会发生两件事：

1. **前向输出为零**：全零初始化时，第一层输出 $y = Wx = 0$，所有层输出恒为 0；
2. **梯度为零**：反向传播时 $\frac{\partial L}{\partial W} = \frac{\partial L}{\partial y} x^T$，由于 $\frac{\partial L}{\partial y}$ 层层回传全部为 0，**所有参数梯度为 0，网络完全无法训练**。

全零初始化还带来一个更隐蔽的问题——**对称性破坏（symmetry breaking）失败**：

- 若一个层内所有神经元参数完全相同（如全零、全常数），则该层所有神经元的输出完全相同，反向梯度也完全相同；
- 这些神经元在训练中**始终同进同退**，永远不会分化成不同的特征检测器；
- 相当于该层"实际宽度 = 1"，网络容量被白白浪费。

> **核心结论**：初始化的第一要务是**破坏对称性**——让同一层内不同神经元的参数随机且互不相同，从而在前向/反向中产生差异化的梯度信号。

### 1.2 初始化对训练速度与最终效果的影响

| 影响维度 | 说明 |
|---------|------|
| 能否收敛 | 初始化过小 → 信号指数衰减，梯度消失；过大 → 信号指数爆炸，loss 变 NaN |
| 收敛速度 | 好的初始化让各层梯度量级均衡，前几轮迭代就能稳定下降（省去/缩短 warmup） |
| 最终效果 | 差的初始化可能把模型推入糟糕的局部最优/鞍点，训练很久也无法逃出 |
| 学习率上限 | 初始化尺度与可用的最大学习率强耦合：尺度越大，可用 lr 越小 |
| 数值稳定性 | FP16/BF16 混合精度下，过大初始化直接导致溢出（inf/NaN） |

### 1.3 为什么归一化不能替代初始化

LayerNorm/RMSNorm 只负责"缩放激活值"，但：

1. LN 消除的是**激活值**的尺度问题，无法补偿**权重矩阵本身**产生的信号损失（如 ReLU 后均值偏移）；
2. LN 之前的残差分支（attention/FFN 输出）如果初始化过大，LN 输入爆炸 → LN 梯度 $\frac{\partial LN(x)}{\partial x} = O(\sqrt{d}/\|x\|)$ 反而变小（见归一化笔记）；
3. 初始化不当造成的**梯度消失**发生在 LN 反向之前，LN 无法救回。

**一句话**：初始化解决"信号如何在网络中传播"，归一化解决"信号在层间如何保持稳定分布"，两者互补、不可互相替代。

## 二、方差传播分析（一切初始化理论的数学基础）

### 2.1 单层线性网络：y = Wx

考虑一个神经元 $y = \sum_{i=1}^{n} w_i x_i$（$n$ 为输入维度，即 fan_in）。假设：

- $w_i$ 与 $x_i$ 相互独立；
- $E[w_i] = E[x_i] = 0$（均值归零，通过把激活函数中心化实现）；
- 各 $(w_i, x_i)$ 对之间独立同分布。

则：

$$Var(y) = Var\left(\sum_{i=1}^{n} w_i x_i\right) = \sum_{i=1}^{n} Var(w_i x_i) = n \cdot Var(w) \cdot Var(x)$$

其中利用均值为零的性质：

$$Var(wx) = E[(wx)^2] - (E[wx])^2 = E[w^2]E[x^2] - (E[w]E[x])^2 = Var(w)Var(x)$$

### 2.2 均匀分布 [-a, a] 的方差

设 $w \sim U[-a, a]$，密度函数 $f(w) = \frac{1}{2a}$，则：

$$Var(w) = E[w^2] = \int_{-a}^{a} \frac{w^2}{2a} dw = \frac{1}{2a} \cdot \frac{2a^3}{3} = \frac{a^2}{3}$$

> **记忆点**：均匀分布 $U[b_1, b_2]$ 方差通式是 $\frac{(b_2 - b_1)^2}{12}$，代入 $[-a, a]$ 即得 $\frac{(2a)^2}{12} = \frac{a^2}{3}$。**给定目标方差 $\sigma^2$，均匀分布的边界就是 $a = \sqrt{3\sigma^2}$**——这是"方差 ↔ 均匀分布区间"互相换算的钥匙。

### 2.3 多层传播：指数爆炸 / 消失

对 $L$ 层网络（无激活、各层独立）反复套用 2.1：

$$Var(x_L) = Var(x_0) \cdot \prod_{l=1}^{L} n_l Var(w_l)$$

设每层方差放大因子 $\beta = n \cdot Var(w)$：

| $\beta$ 取值 | 结果 |
|------------|------|
| $\beta = 1$ | 方差严格守恒，深层信号稳定（理想情况） |
| $\beta > 1$ | 方差以 $\beta^L$ 指数爆炸 → 激活溢出、梯度爆炸 |
| $\beta < 1$ | 方差以 $\beta^L$ 指数衰减 → 深层激活趋近 0、梯度消失 |

### 2.4 反向传播对称性

线性层反向：$\frac{\partial L}{\partial x} = W^T \frac{\partial L}{\partial y}$，对梯度做同样的方差分析（$W^T$ 每行有 $n_{out}$ 个元素）：

$$Var\left(\frac{\partial L}{\partial x}\right) = n_{out} \cdot Var(w) \cdot Var\left(\frac{\partial L}{\partial y}\right)$$

**前向用 fan_in、反向用 fan_out**——这就是 Xavier 同时考虑 $n_{in}$ 与 $n_{out}$ 的原因。好的初始化需要让**前向与反向两套方差都守恒**。

### 2.5 数值验证小实验

```python
import torch

def layer_var_scan(n_in, n_out, n_layers, std, n_trials=1000):
    """随机初始化 n_layers 层线性网络，统计输出方差随深度的变化"""
    vars_list = []
    for _ in range(n_trials):
        x = torch.randn(n_in)
        for l in range(n_layers):
            w = torch.randn(n_in, n_out) * std
            x = x @ w
            vars_list.append((l, x.var().item()))
    return vars_list  # 观察方差是否随深度保持 ~1

# std = 1/sqrt(n_in)  → 方差守恒
# std = 1/n_in       → 方差指数衰减（消失）
# std = 1            → 方差指数爆炸（NaN）
```

## 三、Xavier（Glorot）初始化

### 3.1 动机

Glorot & Bengio (2010) 提出：网络可训练的前提是**信号在前向与反向传播中方差都守恒**。由第二节：

- 前向守恒：$n_{in} \cdot Var(w) = 1 \Rightarrow Var(w) = \frac{1}{n_{in}}$
- 反向守恒：$n_{out} \cdot Var(w) = 1 \Rightarrow Var(w) = \frac{1}{n_{out}}$

取两者折中（避免仅按 $n_{in}$ 初始化导致反向传播数值不稳）：

$$Var(w) = \frac{2}{n_{in} + n_{out}}$$

### 3.2 两种分布形式

**均匀分布版本**（最常用）：

$$w \sim U\left[-\sqrt{\frac{6}{n_{in} + n_{out}}}, \; \sqrt{\frac{6}{n_{in} + n_{out}}}\right]$$

推导：$Var(w) = \frac{a^2}{3} = \frac{2}{n_{in}+n_{out}} \Rightarrow a = \sqrt{\frac{6}{n_{in}+n_{out}}}$。

**高斯分布版本**：

$$w \sim \mathcal{N}\left(0, \frac{2}{n_{in} + n_{out}}\right)$$

```python
# PyTorch 实现
torch.nn.init.xavier_uniform_(w)   # U(-a, a), a = sqrt(6/(fan_in+fan_out))
torch.nn.init.xavier_normal_(w)    # N(0, 2/(fan_in+fan_out))
```

### 3.3 为什么配合 Sigmoid / Tanh

- Sigmoid/Tanh 在 **0 附近近似线性**（$\sigma(x) \approx 0.5 + 0.25x$），Xavier 推导的前提是"激活函数在初始化尺度内保持线性"，这样信号不被非线性扭曲；
- Tanh 是关于原点**对称**的：输入均值为 0 时输出均值也为 0，与"$E[x]=0$"的假设吻合；
- 因此 Xavier 把激活前的信号方差控制在 1 附近，正好落在 tanh/sigmoid 的线性区，避免进入**饱和区**（饱和区导数趋近 0 → 梯度消失）。

### 3.4 局限

1. **假设激活是线性的**：对 ReLU 这类"半线性"激活，负半轴输出恒 0，方差传播不再守恒（见第四章）；
2. **假设输入均值为 0**：ReLU 输出均值 > 0，会引入均值漂移；
3. **忽略非线性引入的方差损失**：即使 tanh，饱和区域也会截断方差；
4. 因此 Xavier 在 CNN+ReLU 时代被 Kaiming 取代，但在**无 ReLU 的场景**（如部分 Transformer 线性投影、按 $\beta$ gain 的 DeepNorm）仍在大量使用。

## 四、Kaiming（He）初始化

### 4.1 动机：ReLU 网络为什么需要它

ReLU 输出 $z = \max(0, x)$：**负半轴直接输出 0**，相当于把信号方差"砍掉一半"。若继续用 Xavier，每过一层方差就衰减一半，深层网络信号指数消失。He et al. (2015) 针对 ReLU 重新推导了方差守恒条件。

### 4.2 方差减半推导（前向）

设前一层输出 $x_{l-1} \sim \mathcal{N}(0, \sigma^2)$（均值 0、方差 $\sigma^2$），过 ReLU 后 $z = \text{ReLU}(x_{l-1})$：

$$E[z^2] = \int_0^{\infty} \frac{x^2}{\sigma\sqrt{2\pi}} e^{-x^2/2\sigma^2} dx = \frac{\sigma^2}{2}$$

即 **ReLU 把方差减半**：$Var(z) = E[z^2] = Var(x_{l-1})/2$（正半轴密度翻倍，期望平方恰为原方差一半）。

于是第 $l$ 层 $y = W z$ 的方差：

$$Var(y) = n_{in} \cdot Var(w) \cdot E[z^2] = n_{in} \cdot Var(w) \cdot \frac{\sigma^2}{2}$$

令 $Var(y) = \sigma^2$（方差守恒），解得：

$$Var(w) = \frac{2}{n_{in}}$$

**关键点**：相比 Xavier 的 $\frac{1}{n_{in}}$，Kaiming 多了一个因子 **2**——这就是对 ReLU 方差减半的**补偿**。

### 4.3 反向推导

ReLU 的导数在负半轴为 0，梯度反传时**以 1/2 概率被置零**，梯度方差同样减半。按对称性可得 $Var(w) = \frac{2}{n_{out}}$。He 论文建议优先保证前向（fan_in），PyTorch 默认 `fan_in`（对 Linear）；也可取两者折中。

### 4.4 两种分布形式

**高斯版本**（论文原版）：

$$w \sim \mathcal{N}\left(0, \sqrt{\frac{2}{n}}\right)$$

**均匀分布版本**（PyTorch 默认）：

$$w \sim U\left[-\sqrt{\frac{6}{n}}, \; \sqrt{\frac{6}{n}}\right]$$

推导：$a^2/3 = 2/n \Rightarrow a = \sqrt{6/n}$（$n$ 为 fan_in）。

```python
torch.nn.init.kaiming_uniform_(w, a=math.sqrt(5))  # PyTorch Linear 默认（a 对应 LeakyReLU 斜率）
torch.nn.init.kaiming_normal_(w, mode='fan_in')     # 论文原版风格
```

### 4.5 Xavier vs Kaiming 对比

| 维度 | Xavier | Kaiming |
|------|--------|---------|
| 论文 | Glorot 2010 | He 2015 |
| 适用激活 | Sigmoid / Tanh（线性区） | ReLU / LeakyReLU 族 |
| 方差目标 | $Var(w) = \frac{2}{n_{in}+n_{out}}$ | $Var(w) = \frac{2}{n_{in}}$（额外 ×2 补偿） |
| 均匀版边界 | $\sqrt{6/(n_{in}+n_{out})}$ | $\sqrt{6/n_{in}}$ |
| 核心思想 | 前后向方差双守恒 | 补偿 ReLU 的方差减半 |
| 在 ReLU 网络 | 每层方差 ×1/2，深层消失 | 方差守恒，深层稳定 |

## 五、各种初始化公式总表

| 初始化 | 分布 / 公式 | 使用场景 |
|--------|------------|---------|
| Uniform 0.07 | $w \sim U[-0.07, 0.07]$ | 早期 BERT 风格实现（如 BERT-pytorch）的 embedding 层；与 $1/\sqrt{200} \approx 0.0707$ 同量级 |
| Truncated Normal | 截断正态：从 $\mathcal{N}(0, \sigma^2)$ 采样，裁掉 $\pm 2\sigma$ 外样本并重新归一化（官方 BERT 用 $\sigma = 0.02$） | Google BERT（TF 版）全部权重 |
| Xavier Uniform | $U[-\sqrt{6/(n_{in}+n_{out})}, \sqrt{6/(n_{in}+n_{out})}]$ | Sigmoid/Tanh 网络、Transformer 线性投影（DeepNorm 以 gain=β 使用其正态版） |
| Kaiming Uniform | $U[-\sqrt{6/n_{in}}, \sqrt{6/n_{in}}]$ | CNN + ReLU、LLaVA 等模型 MLP projector 常用 |
| Kaiming Normal | $\mathcal{N}(0, \sqrt{2/n_{in}})$ | ResNet 卷积、HF 部分线性层 |
| N(0, 0.02) | $\mathcal{N}(0, 0.02^2)$ | **BERT/GPT embedding 与全部权重（HF 默认 initializer_range）** |
| Orthogonal | 对矩阵做 QR 分解取正交部分，再乘增益 | RNN/LSTM/GRU（缓解长期依赖的梯度问题） |
| Zero init | 全 0 | 残差分支（ReZero、Fixup、LoRA 的 B）、bias、部分 gate |

> **三条实用记忆线**：
> 1. **CNN+ReLU 用 Kaiming**，**Sigmoid/Tanh 用 Xavier**；
> 2. **Transformer 全家默认 $\mathcal{N}(0, 0.02)$**（embedding、attention、FFN），残差分支末端再额外缩小；
> 3. **任何"微调/残差"场景的默认安全选择**：从预训练权重出发，新增分支尽量初始化为"对原模型零影响"（零初始化）。

## 六、Transformer 特殊初始化（重点）

### 6.1 预训练模型用 N(0, 0.02) 初始化 embedding 与权重（为什么小）

BERT/GPT 将 embedding 与所有权重初始化为 $\mathcal{N}(0, 0.02)$（HF 的 `initializer_range`，BERT 官方用截断正态 stddev=0.02）。0.02 远小于 Xavier 的 $\sqrt{2/768} \approx 0.051$，为什么？

1. **残差结构要求"初始接近恒等"**：Transformer 是 $x_{l+1} = x_l + F(x_l)$ 的堆叠，初始化应让 $F(x_l)$ 远小于 $x_l$，输出≈输入，深层信号不衰减不爆炸；
2. **避免 Attention 打分饱和**：$QK^T/\sqrt{d_k}$ 过大进入 softmax 饱和区，梯度趋近 0，且初始 attention 分布极度尖锐；
3. **避免 FFN/Logits 溢出**：d_model 很大（768/1024/4096），即使 Xavier 尺度也会让逐点数值偏大，FP16 下容易溢出；
4. **embedding 与输出层无 LN 保护**：embedding 直接进入第一个 block 或直接参与 loss，需要小初始化保证初始 loss 数值稳定；
5. **深层叠加效应**：$L$ 层残差累积方差 $\sim L \cdot \sigma^2$，只有初始就小，深层才不爆炸。

### 6.2 缩放初始化：残差分支 × 1/√L 家族

**问题**：残差结构下第 $l$ 层输出 $x_l = x_0 + \sum_{i<l} F_i(x_i)$。若每个残差分支输出方差为 $\sigma^2$ 且相互独立，$L$ 个分支后 $Var \approx L\sigma^2$——**方差随深度线性增长**。解法是把残差分支整体缩小 $\frac{1}{\sqrt{L}}$：

$$Var(x_L) \approx L \cdot \frac{\sigma^2}{L} = \sigma^2$$

**GPT-2 的 scaled initialization**（论文原话："we scale the weights of residual layers by $\frac{1}{\sqrt{N}}$ where $N$ is the number of residual layers"）：

```python
# HF GPT-2 实现
scale = 1.0 / math.sqrt(2 * n_layer)   # 每个 block 有 attention、FFN 两个残差分支
self.c_proj.weight.data.normal_(mean=0.0, std=initializer_range * scale)
```

**T-Fixup 思想**（Huang et al., ICML 2020）：在分析 Adam 方差 + LN 反传的基础上，提出无需 warmup、甚至无需 LayerNorm 的初始化：

1. **全部 bias 置 0**；
2. embedding 用高斯初始化（方差 $\sim d^{-1/2}$ 量级）；
3. attention 的 value 投影 $v$、输出投影 $w$ 及 FFN 权重矩阵乘以 **$0.67 \cdot N^{-1/4}$**（$N$ 为 Transformer 层数）；
4. 效果：深 Transformer 训练从"需要 warmup + LN"变为"稳定可训"，为后续 DeepNorm 等提供思路。

**Fixup / ReZero**（同族）：

- **Fixup**：每个残差分支的最后一层权重**置 0**，其余用标准初始化——初始时残差分支输出恒为 0，网络退化为恒等映射，再让梯度"首先"激活残差；
- **ReZero**：每个残差分支乘一个可学习标量，初始为 0，同样从恒等映射出发，还允许学习"每层残差的贡献权重"。

> **记忆点**：GPT-2 的 $\frac{1}{\sqrt{N}}$ 是**固定缩放**；Fixup/ReZero 是**零初始化残差**；两者目的相同——让初始化后的网络等于"恒等堆叠"，深度可以无限加。

### 6.3 DeepNorm：Post-LN 深度模型（1000 层）的初始化缩放

**背景**：Post-LN 效果好但深了必崩（模型更新爆炸），Pre-LN 稳定但表达略差。DeepNet（Wang et al., 2022）用**修改的残差公式 + 配套初始化**让 Post-LN 可训到 1000 层。

**数学形式**（核心公式）：

$$x_{l+1} = LN\left(\alpha x_l + G_l(x_l, \theta_l)\right)$$

其中 $G_l$ 为第 $l$ 个子层（attention 或 FFN），$\alpha$ 为残差缩放常数，且子层权重 $\theta_l$ 初始化为比标准 Xavier 更小的 $\beta$ 倍（只缩 **FFN、v_proj、out_proj**，q/k 不缩）。

**α / β 取值表**（只依赖架构深度，N 为 encoder 层数、M 为 decoder 层数）：

| 架构 | α（残差缩放） | β（权重缩放 gain） |
|------|--------------|-------------------|
| Encoder-only（BERT 类） | $(2N)^{1/4}$ | $(8N)^{-1/4}$ |
| Decoder-only（GPT 类） | $(2M)^{1/4}$ | $(8M)^{-1/4}$ |
| Encoder-decoder（encoder 侧） | $0.81(N^4M)^{1/16}$ | $0.87(N^4M)^{-1/16}$ |
| Encoder-decoder（decoder 侧） | $(3M)^{1/4}$ | $(12M)^{-1/4}$ |

```python
# DeepNorm 初始化伪码（以 Xavier 为基础）
def deepnorm_init(w, beta):
    if w in ['ffn', 'v_proj', 'out_proj']:
        nn.init.xavier_normal_(w, gain=beta)
    elif w in ['q_proj', 'k_proj']:
        nn.init.xavier_normal_(w, gain=1)

# 前向：x = LayerNorm(x * alpha + sublayer(x))
```

**为什么能稳定**：论文证明模型更新量可以被常数界定（$\|\Delta F\| \le \sum \frac{\sqrt{v^2+w^2}}{\alpha}\|\theta^* - \theta\|$，vanilla Post-LN 即 $\alpha=1$ 时随深度累积），从而既保留 Post-LN 的表达能力又获得 Pre-LN 的训练稳定性。

### 6.4 Q/K/V 与输出投影的初始化差异

| 参数 | 原版 Transformer | DeepNorm | 直觉 |
|------|-----------------|----------|------|
| q_proj / k_proj | Xavier | Xavier（gain=1，不缩放） | QK 打分有 $\frac{1}{\sqrt{d_k}}$ 缩放，softmax 归一化后**不改变输出量级上界**（DeepNet Lemma 4.1） |
| v_proj | Xavier | ×β 缩小 | V 直接决定 attention 输出幅度 |
| out_proj（残差分支末端） | Xavier | ×β 缩小 | 它的输出要加回残差，必须小 |
| FFN 两层 | Xavier | ×β 缩小 | 与 attention 相同逻辑 |

**通用原则**：**残差分支的末端投影（out_proj、FFN 第二层）永远需要额外缩小**（×1/√N 或 ×β），因为它们的输出直接进入残差求和；而 Q/K 这种"只影响加权方式、不影响幅度"的参数可以保持标准初始化。

## 七、位置编码初始化

### 7.1 可学习位置编码的初始化

- HuggingFace 默认：位置编码作为 `nn.Embedding`，与 token embedding、segment embedding 一起用 `initializer_range = 0.02` 的高斯初始化；
- 即 `pos_emb ~ N(0, 0.02²)`，与 6.1 节同一套尺度；
- 对比：固定式 sinusoid 编码（原版 Transformer）无需初始化；RoPE/ALiBi 等相对位置编码没有可学习向量，也不涉及初始化。

### 7.2 为什么位置编码初始值不宜过大

1. **直接相加**：位置编码与 token embedding **逐元素相加**（$x = e + p$）。若 $p$ 过大，token 语义被淹没，初始表示几乎只剩位置信息；
2. **进入 attention 打分**：过大 $p$ 使 $QK^T/\sqrt{d_k}$ 偏大 → softmax 饱和，初始 attention 分布尖锐且无意义；
3. **深层累积**：位置信息经 $L$ 层残差累加，初始过大 → 深层数值爆炸；
4. **可学习空间的浪费**：训练中位置编码更新量小，初始值偏离目标太远则难以纠正（尤其短序列上，长位置编码几乎学不动）；
5. **数值稳定性**：FP16 训练下过大的 embedding 直接引发溢出。

## 八、LoRA 初始化（微调场景重点）

### 8.1 LoRA 的结构与公式

```text
h = Wx + (α/r) · B·A·x
     └── base 权重（冻结）   └── LoRA 分支（可训练）
```

- $A \in \mathbb{R}^{r \times d}$：把输入从 $d$ 维投影到低秩 $r$；
- $B \in \mathbb{R}^{d \times r}$：把低秩表示投影回 $d$ 维；
- $\alpha$ 为常数、$r$ 为秩，$\alpha/r$ 是整体缩放。

### 8.2 A 用高斯初始化、B 用零初始化

- **A**：随机初始化（LoRA 论文用随机高斯；HF 的 PEFT 实现实际用 `kaiming_uniform(a=√5)` 风格，部分实现用 $\mathcal{N}(0, 0.02)$）；
- **B**：**全零初始化**。

**为什么 B 必须为零**（面试必答）：

1. **初始时 BA = 0**：LoRA 分支输出 $B A x = 0$，前向结果与冻结的 base 模型完全一致——微调从"原模型预测"出发，**不破坏预训练模型的初始行为**；
2. 若 A、B 都随机，初始 $BA \ne 0$，相当于给 base 模型叠加了随机噪声，训练起点偏离预训练分布，且需要额外步数"先纠正回来"；
3. **梯度不对称是设计好的**：$\frac{\partial L}{\partial B} = \frac{\partial L}{\partial h}(Ax)^T \ne 0$（A 随机），而 $\frac{\partial L}{\partial A} = B^T\frac{\partial L}{\partial h}x^T = 0$（B 为零）——所以**第一步只有 B 更新**；B 一旦非零，A 立即获得梯度，两者随后同步训练。这一"先动 B、后动 A"的动态并不影响收敛；
4. 反过来"B 随机、A 为零"同样满足 BA=0，理论上对称可行，但论文约定 + 主流实现统一为 **A 随机、B 为零**。

### 8.3 scale = α/r 的由来

$BA$ 的每个元素是 $r$ 个 rank-1 外积项的求和，**其量级随 $r$ 增长**（约 $\sqrt{r}$ 量级）。若不做处理，切换秩 $r$ 会直接改变 LoRA 分支的更新幅度，等效于改变了学习率。因此：

$$\text{scale} = \frac{\alpha}{r}$$

1. **解耦秩与更新幅度**：除以 $r$ 后，不同 $r$ 下初始更新量级一致，$r$ 只负责"表达空间大小"，不再干扰优化尺度；
2. **α 相当于 LoRA 的学习率**：调 α 即整体缩放分支更新，与 base 学习率解耦；常见取 $\alpha = r$（此时 scale=1）作为基线，再按任务调 α；
3. 若不用 $\alpha/r$，则"把 r 翻倍"会隐式放大更新，产生难排查的训练不稳定。

| 问题 | 结论 |
|------|------|
| A 初始化 | 随机（高斯或 kaiming），保证 $B$ 第一步有非零梯度 |
| B 初始化 | 全零，保证初始 $BA=0$，微调从原模型出发 |
| scale | $\alpha/r$，让更新幅度与秩解耦，α 承担"LoRA 学习率"角色 |
| 秩变大 | 表达能力 ↑，但矩阵乘法成本 ↑，更新量级不变 |

## 九、数值验证方法（初始化后如何自查）

### 9.1 激活统计检查（前向）

初始化后跑一次前向，用 hook 打印各层输出的 mean / std，**期望均值 ≈ 0、方差 ≈ 1**（或与归一化约定一致）：

```python
import torch

def check_activations(model, sample_input, target_module_types=(torch.nn.Linear,)):
    stats = {}
    handles = []
    def hook(module, inp, out):
        if isinstance(module, target_module_types):
            stats[module] = (out.mean().item(), out.std().item())
    for m in model.modules():
        handles.append(m.register_forward_hook(hook))
    model(sample_input)
    for h in handles: h.remove()
    for name, (mean, std) in stats.items():
        print(f"{name}: mean={mean:.3f}, std={std:.3f}")  # 期望 mean≈0, std≈1

# 判定：
#   std 逐层指数衰减 → 初始化太小（或用错方法，如 ReLU 配 Xavier）
#   std 逐层指数爆炸 → 初始化太大 → 必然 NaN
#   std 在第 1 层就巨大 → embedding/首层权重问题
```

### 9.2 梯度量级检查（反向）

一次 `loss.backward()` 后，统计每层参数梯度范数。**好的初始化下，各层梯度范数应处于同一量级**（深度 100 的模型，首层与末层梯度不应差 10⁶ 倍）：

```python
for name, p in model.named_parameters():
    if p.grad is not None:
        g = p.grad.norm().item()
        print(f"{name}: grad_norm={g:.2e}")  # 若按深度指数递增/递减 → 初始化问题
```

### 9.3 单样本前向 NaN 检查

```python
with torch.no_grad():
    out = model(sample_input)
    assert torch.isfinite(out).all(), "输出包含 NaN/Inf"
    loss = loss_fn(out, sample_target)
    assert torch.isfinite(loss), "loss 为 NaN/Inf"
```

- **FP16/BF16 下必查**：混合精度下初始化偏大最容易静默溢出；
- **多模态模型分塔查**：text tower 与 vision tower 分别检查（ViT patch embedding 与文本 embedding 尺度可能不同，需各自验证）。

### 9.4 深度方差扫描

用固定随机输入，比较"初始化后第 1 层输出方差"与"最后一层输出方差"：

- 比值 ≈ 1：方差守恒 ✓；
- 比值 ≪ 1：信号消失 → 需要更大初始化或换初始化方法；
- 比值 ≫ 1：信号爆炸 → 需要更小初始化或残差缩放。

### 9.5 多 seed 稳定性

同一初始化方案跑多个随机种子，统计首轮 loss 的均值/方差。**若不同 seed 的 loss 差异巨大，说明初始化尺度处于临界不稳定区**（如方差稍大就爆炸），需要整体缩小。

## 十、随机种子与可复现性

### 10.1 为什么要固定种子

1. **实验可比**：算法改进（如换了初始化方法）的 0.1% 效果差异，若被随机性淹没则无法判断；
2. **调试**：同样的代码跑出不同结果时无法定位 bug 是代码问题还是随机问题；
3. **论文/上线要求**：复现实验是工程交付的基本要求。

### 10.2 全链路确定性（不只是 torch seed）

```python
import random, numpy as np, torch

def set_seed(seed=42):
    random.seed(seed)                          # Python 内置随机
    np.random.seed(seed)                       # NumPy
    torch.manual_seed(seed)                    # CPU + GPU（统一入口）
    torch.cuda.manual_seed_all(seed)           # 所有 GPU
    torch.backends.cudnn.deterministic = True  # cuDNN 确定性算法
    torch.backends.cudnn.benchmark = False     # 关闭自动选算法（会引入不确定性）
```

**DataLoader 的 worker 也要种**：

```python
def worker_init_fn(worker_id):
    seed = 42 + worker_id
    random.seed(seed); np.random.seed(seed); torch.manual_seed(seed)

DataLoader(ds, num_workers=4, worker_init_fn=worker_init_fn)
```

| 随机性来源 | 固定方式 |
|-----------|---------|
| Python random | `random.seed()` |
| NumPy | `np.random.seed()` |
| PyTorch CPU/GPU | `torch.manual_seed()` / `torch.cuda.manual_seed_all()` |
| cuDNN 卷积/注意力算法 | `deterministic=True` + `benchmark=False` |
| DataLoader 多进程 | `worker_init_fn` |
| Python 哈希随机化 | 环境变量 `PYTHONHASHSEED` |
| 分布式 / AMP / 自定义算子 | 无法完全保证（需逐项验证） |

### 10.3 注意事项

1. **固定 seed 是必要非充分条件**：GPU 上的原子操作（reduce、scatter）、cuDNN 的确定性依赖具体算子，某些情况下固定 seed 仍不可复现；
2. **分布式训练**：多卡通信顺序、梯度 all-reduce 累积顺序都可能引入不确定性；
3. **预训练/大规模训练**：通常不追求逐 bit 复现，而是**多 seed 统计结论**（取均值±方差），单 seed 结果不可信。

## 十一、高频面试问答

**Q1：为什么不能全零初始化？**
全零初始化导致前向输出全 0、反向梯度全 0，网络完全无法训练；即使常数（非零）初始化，同层神经元参数相同 → 前向输出相同、梯度相同 → 对称性无法破坏，所有神经元退化为一个，层宽形同虚设。必须用随机初始化打破对称性。

**Q2：Xavier 和 Kaiming 的区别？**
核心区别在方差目标：Xavier 设 $Var(w) = 2/(n_{in}+n_{out})$，假设激活在线性区、输入均值为 0；Kaiming 针对 ReLU——ReLU 将方差减半（$E[\text{ReLU}(x)^2] = Var(x)/2$），且反向梯度以 1/2 概率置零，因此需要额外 ×2 补偿，即 $Var(w) = 2/n_{in}$。ReLU 网络用 Xavier 每层方差衰减一半，深层梯度消失。

**Q3：为什么 Transformer 初始化要这么小（N(0,0.02)）？**
① 残差结构要求初始输出≈恒等映射，残差分支必须小；② 避免 QK^T 进入 softmax 饱和区；③ 避免 FP16 数值溢出；④ embedding 无 LN 保护且直接参与 loss；⑤ 深层残差方差按层数累积，初始小才能撑住深模型。

**Q4：LoRA 为什么 B 初始化为零？**
保证初始 $BA = 0$，LoRA 分支输出为 0，微调严格从原模型预测出发、不破坏 base 行为。梯度上 $\partial L/\partial B = g \cdot (Ax)^T \ne 0$（A 随机）而 $\partial L/\partial A = 0$（B=0），B 先更新、随后 A 获得梯度，训练动态正常。若 A、B 都随机，初始叠加噪声偏离预训练分布。

**Q5：初始化怎么影响梯度消失 / 爆炸？**
单层 $Var(y) = n \cdot Var(w) \cdot Var(x)$，L 层累积 $Var(x_L) = Var(x_0)\prod n_l Var(w_l)$。$n \cdot Var(w) > 1$ 时方差指数爆炸（梯度爆炸、loss 变 NaN）；< 1 时指数消失（激活趋 0、梯度消失）。好初始化让每层 $n \cdot Var(w) \approx 1$，前后向方差都守恒。

**Q6：为什么说 Xavier 对 ReLU 网络不合适？**
Xavier 假设激活在线性区且输入均值为 0。ReLU 负半轴输出恒 0，输入方差每层减半，还引入正均值偏移，两层假设都违反。用 Xavier 初始化 ReLU 网络，深层方差按 $2^{-L}$ 指数衰减，深层训练不动。这也是 Kaiming 论文的实验动机。

**Q7：GPT-2 的 1/√N 残差缩放有什么用？**
每个残差分支输出方差 σ²，N 个分支叠加后方差 ≈ Nσ²（N = 残差分支数，HF 实现里每个 block 两个分支所以是 1/√(2L)）。把每个残差分支权重乘 1/√N，总方差恢复为 σ²，深层残差结构不再随深度放大信号。

**Q8：DeepNorm 为什么能训练 1000 层？**
把残差改为 $x_{l+1} = LN(\alpha x_l + G_l(x_l))$：α 放大残差路径、β 缩小子层权重（FFN/v_proj/out_proj 用 gain=β 的 Xavier），推导出模型更新量 $\|\Delta F\|$ 有与深度无关的常数上界。既有 Post-LN 的表达能力（不因残差旁路 LN 削弱表征），又有接近 Pre-LN 的训练稳定性。

**Q9：位置编码初始化需要注意什么？**
可学习位置编码与 token embedding 逐元素相加，初始值不能大：大了会淹没 token 语义、使 attention 打分饱和、深层累积后数值爆炸。主流做法是与 embedding 同尺度（HF 默认 N(0,0.02)）；固定 sinusoid 或 RoPE 不涉及初始化。

**Q10：初始化后如何快速验证好坏？**
① 前向一次，hook 打印各层激活 mean/std，应均值≈0、方差≈1，且不随深度指数变化；② backward 后检查各层梯度范数是否同量级；③ 单样本前向检查 NaN/Inf（FP16 必查）；④ 多 seed 首步 loss 方差应小。

## 十二、常见误区

1. **"初始化只是收敛快慢的问题"**：错误的初始化可能导致永远不收敛，或收敛到很差的局部最优；初始化尺度还与可用学习率强耦合。
2. **把 Xavier 直接用于 ReLU / Transformer**：ReLU 需要 Kaiming 的 ×2 补偿；Transformer 更是要用小得多的 N(0,0.02) + 残差缩放，Xavier 尺度在 d 很大时仍然偏大。
3. **"参数越小越安全"**：初始化过小同样致命——方差 $n \cdot Var(w) \ll 1$ 时信号指数消失，深层梯度消失，训练停滞（且表现为"loss 完全不动"，容易被误判为学习率问题）。
4. **固定了 torch seed 就以为可复现**：还需固定 numpy/random、DataLoader worker、cuDNN deterministic；GPU 上部分算子（原子累加、多卡通信）即使全固定也不保证逐 bit 一致。
5. **忽略残差分支的"恒等起点"**：在 Transformer/ResNet 中把所有层都按标准初始化（不缩残差末端），深层方差按层数累积导致训练崩；残差结构必须配合零初始化或 1/√N 缩放。
6. **微调时随机初始化新增模块**：在多模态微调（如把 LoRA 加进 CLIP）里，新增分支若随机初始化会给 base 模型叠加噪声；正确做法是让新增分支初始输出为 0（LoRA B=0、残差分支零初始化）。
