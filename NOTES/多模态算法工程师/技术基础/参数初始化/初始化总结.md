# 初始化总结：公式总表、选型决策树与验证方法

> 本模块索引见 [参数初始化详解](参数初始化详解.md)

## 一、定义与公式：各种初始化总表

| 初始化 | 分布 / 公式 | 关键记忆点 | 使用场景 |
|--------|------------|-----------|---------|
| Xavier Uniform | $U\left[-\sqrt{\frac{6}{n_{in}+n_{out}}}, \sqrt{\frac{6}{n_{in}+n_{out}}}\right]$ | 前后向双守恒，目标方差 $\frac{2}{n_{in}+n_{out}}$ | Sigmoid/Tanh 网络、DeepNorm 基础 |
| Xavier Normal | $\mathcal{N}\left(0, \sqrt{\frac{2}{n_{in}+n_{out}}}\right)$ | 高斯版，gain 可补偿激活压缩 | Tanh 网络、DeepNorm 的 gain=β |
| Kaiming Uniform | $U\left[-\sqrt{\frac{6}{n_{in}}}, \sqrt{\frac{6}{n_{in}}}\right]$ | ReLU 方差减半 → ×2 补偿 | CNN+ReLU、MLP projector |
| Kaiming Normal | $\mathcal{N}\left(0, \sqrt{\frac{2}{(1+a^2)n_{in}}}\right)$ | a 为 LeakyReLU 斜率 | 论文原版、ResNet 卷积 |
| N(0, 0.02) | $\mathcal{N}(0, 0.02^2)$ | 经验小尺度 + LN 兜底 | **Transformer 全家**（HF 默认） |
| GPT-2 Scaled | $\mathcal{N}(0, (\frac{0.02}{\sqrt{2L}})^2)$ 于残差分支 | 方差线性累积 → 1/√N | GPT-2/3 系、LLaMA 变体 |
| DeepNorm | $x_{l+1}=LN(\alpha x_l + G_l)$，FFN/v/out ×β | α/β 有解析公式 | Post-LN 超深模型（1000 层） |
| Truncated Normal | 截断正态（±2σ 外重采样） | BERT TF 版标准 | Google BERT |
| Uniform 0.07 | $U[-0.07, 0.07]$ | $1/\sqrt{200} \approx 0.0707$ | 早期 BERT 复现的 embedding |
| Orthogonal | 正交矩阵（QR 分解）× 增益 | 保范数 | RNN/LSTM/GRU |
| Zero init | 全 0 | 初始零影响 | 残差分支、LoRA B、bias |
| LoRA A | 随机高斯（σ≈0.02）或 kaiming | B=0 → 初始 ΔW=0 | 微调场景 |

**三条实用记忆线**：
1. **CNN+ReLU 用 Kaiming，Sigmoid/Tanh 用 Xavier**；
2. **Transformer 全家默认 N(0, 0.02)**（embedding、attention、FFN），残差分支末端再额外缩小；
3. **任何"微调/残差"场景的默认安全选择**：从预训练权重出发，新增分支尽量初始化为"对原模型零影响"（零初始化）。

## 二、数学原理：选型决策树

### 2.1 决策树（面试画图神器）

```text
问题：给一个新模型选初始化，怎么选？

第 1 层判断：模型结构
├── 纯 MLP / CNN（无归一化、无残差）？
│   ├── 激活是 ReLU 族 → Kaiming（a 按 LeakyReLU 斜率）
│   └── 激活是 Sigmoid/Tanh → Xavier（必要时配 gain）
│
├── 带 LayerNorm/BatchNorm 的深网络？
│   └── 有归一化兜底 → 用 Kaiming/Xavier 合理尺度即可，不必苛求
│
├── Transformer / 残差堆叠结构？
│   ├── 经验工程派 → N(0, 0.02) + 残差分支 1/√N（GPT-2 风格）
│   ├── 需要理论保障 / 超深（>100 层）→ DeepNorm（α/β 解析取值）
│   └── 无 LN 的深 Transformer → T-Fixup（0.67·N^{-1/4} + bias=0）
│
└── RNN 家族 → Orthogonal（配 Xavier/Tanh）

第 2 层判断：训练场景
├── 从头训练 → 按上述结构选，初始化后必做验证（见第四节）
└── 微调预训练模型 → 冻结主路 + 新增分支零初始化（LoRA B=0、Fixup）
    └── 分支权重尺度 → α/r 或可学习标量控制，与秩解耦

第 3 层判断：精度模式
├── FP32 → 常规尺度即可
└── FP16/BF16 → 整体缩小一档 + 必查 NaN（见 4.3）
```

### 2.2 决策依据一句话

| 场景 | 一句话理由 |
|------|-----------|
| ReLU | 激活砍半方差，必须 ×2 补偿（Kaiming） |
| Tanh/Sigmoid | 激活在线性区，前后向双守恒（Xavier） |
| Transformer | 残差 + LN 兜底，保守小尺度 + 恒等起点（N(0,0.02)） |
| 超深 Transformer | 残差累积方差与模型更新量都要理论有界（DeepNorm/T-Fixup） |
| RNN | 长程依赖靠正交保持范数（Orthogonal） |
| 微调 | 新增分支初始零输出，不破坏预训练（LoRA B=0 等） |

### 2.3 所有方案的统一数学视角

几乎所有初始化都在解同一个方程（不同假设下的方差守恒）：

$$n \cdot Var(w) \cdot \underbrace{E[\text{激活}^2]}_{激活方差的损失} = 1 \quad \Longrightarrow \quad Var(w) = \frac{1}{n \cdot E[\text{激活}^2]}$$

| 方法 | 对 $E[\text{激活}^2]$ 的假设 |
|------|---------------------------|
| Xavier | 激活线性无损：$E[\text{激活}^2] = 1$ |
| Kaiming | ReLU 减半：$E[\text{激活}^2] = 1/2$ |
| N(0,0.02) | 放弃守恒假设，靠 LN + 残差恒等起点 |
| DeepNorm | 守恒 + 残差更新有界（α/β 双参数） |

## 三、源码实现：一键初始化工具 + 全零危害演示

### 3.1 全零初始化的危害（可运行演示）

```python
import torch
import torch.nn as nn

torch.manual_seed(0)

# 演示 1：全零初始化 → 前向全零、梯度全零
net = nn.Sequential(nn.Linear(8, 16), nn.ReLU(), nn.Linear(16, 1))
for p in net.parameters():
    nn.init.zeros_(p)                     # 全零初始化
x = torch.randn(4, 8)
out = net(x)
print(f"全零网络输出: {out.flatten()[:4].tolist()}")       # 全零网络输出: [0.0, 0.0, 0.0, 0.0]
out.pow(2).mean().backward()
print(f"全零网络梯度非零的参数数: {sum(1 for p in net.parameters() if p.grad is not None and p.grad.abs().sum() > 0)}")
# 全零网络梯度非零的参数数: 0   <- 完全无法训练

# 演示 2：常数初始化 → 对称性无法破坏
net2 = nn.Sequential(nn.Linear(8, 16), nn.ReLU(), nn.Linear(16, 1))
for p in net2.parameters():
    nn.init.constant_(p, 0.5)             # 同一层所有神经元完全相同的常数
x2 = torch.randn(4, 8)
h = net2[0](x2)
identical = bool(((h - h[:, :1]).abs() < 1e-6).all().item())
print(f"常数初始化: 16 个神经元输出完全相同? {identical}")
# 常数初始化: 16 个神经元输出完全相同? True  <- 16 个神经元退化成 1 个（层宽形同虚设）
```

**结论**：全零 → 前向输出 0、梯度全 0，网络完全不学；常数（非零）→ 同层神经元输出相同、梯度相同，**对称性无法破坏**，层宽度退化为 1。必须用随机初始化打破对称。

### 3.2 初始化工厂（按决策树一键选择）

```python
import math
import torch
import torch.nn as nn

def init_module(m, scheme='auto', nonlinearity='relu', n_layer=12, gain=1.0):
    """按决策树给 nn.Module 选择初始化"""
    for name, p in m.named_parameters():
        if p.dim() < 2:                    # bias、标量统一置零
            nn.init.zeros_(p)
            continue
        if scheme == 'auto':               # 自动模式：按结构与激活判断
            scheme = 'kaiming' if nonlinearity == 'relu' else 'xavier'
        if scheme == 'xavier':
            nn.init.xavier_uniform_(p, gain=gain)
        elif scheme == 'kaiming':
            a = 0.0 if nonlinearity == 'relu' else math.sqrt(5)
            nn.init.kaiming_uniform_(p, a=a)
        elif scheme == 'gpt2':
            scale = 1.0 / math.sqrt(2 * n_layer)
            nn.init.normal_(p, mean=0.0, std=0.02 * scale)   # 残差分支用
        elif scheme == 'bert':
            nn.init.normal_(p, mean=0.0, std=0.02)
        elif scheme == 'zero':
            nn.init.zeros_(p)
    return m

# 用法示例：MLP+ReLU → kaiming
torch.manual_seed(0)                          # 固定种子，保证注释里的输出可复现
mlp = nn.Sequential(nn.Linear(64, 64), nn.ReLU(), nn.Linear(64, 64))
init_module(mlp, scheme='auto', nonlinearity='relu')
print(f"MLP 权重 std: {mlp[0].weight.std().item():.4f}")      # MLP 权重 std: 0.1779（理论 0.1768 = sqrt(6/64)/sqrt(3)）

# Transformer 残差分支 → gpt2 风格
proj = nn.Linear(768, 768)
init_module(proj, scheme='gpt2', n_layer=24)
print(f"GPT2 残差分支 std: {proj.weight.std().item():.4f}")   # GPT2 残差分支 std: 0.0029
```

### 3.3 初始化后必做的四项检查

```python
def check_init(model, sample_input, loss_fn=None):
    """初始化后自查：激活统计 / NaN 检查 / 梯度量级 / 深度方差比"""
    stats = {}
    handles = [m.register_forward_hook(
        lambda m, i, o: stats.__setitem__(m, (o.mean().item(), o.std().item()))
    ) for m in model.modules() if isinstance(m, nn.Linear)]

    # ① 单样本前向：NaN 检查 + 激活统计
    with torch.no_grad():
        out = model(sample_input)
        assert torch.isfinite(out).all(), "输出包含 NaN/Inf → 初始化太大"
    print("① NaN 检查通过；激活 mean/std 逐层打印：")
    for m, (mean, std) in stats.items():
        print(f"   {m}: mean={mean:.3f}, std={std:.3f}")
    for h in handles: h.remove()

    # ② 梯度量级：一次 backward 后各层梯度范数
    loss_fn = loss_fn or (lambda o: o.pow(2).mean())
    loss_fn(model(sample_input)).backward()
    grads = [p.grad.norm().item() for p in model.parameters()
             if p.grad is not None and p.dim() >= 2]
    print(f"② 各层梯度范数: {[f'{g:.2e}' for g in grads]}（应同量级）")
    return stats, grads

torch.manual_seed(0)
mlp = nn.Sequential(nn.Linear(32, 64), nn.ReLU(), nn.Linear(64, 32))
init_module(mlp, scheme='auto')
check_init(mlp, torch.randn(8, 32))
# ① NaN 检查通过；激活 mean/std 逐层打印：
#    Linear(32,64): mean≈0.00, std≈1.47  <- Kaiming 下激活前 E[y²]=2，std≈√2 是正确行为
#    Linear(64,32): mean≈0.17, std≈1.59  <- 均值非零来自 ReLU 正均值漂移（预激活），同样正常
# ② 各层梯度范数: ['1.92e+00', '2.69e+00']（应同量级）
```

> **判定标准细化**：hook 打在 Linear 输出上是**激活前**（pre-activation）。Kaiming 下 $E[y^2]=2$，故 std≈1.41 正确；若打 ReLU **后**，应看到 std≈0.83（见 [Kaiming](Kaiming.md) §2.5）。逐层打印时观察**是否随深度稳定**比绝对数值更重要。

**四项检查的判定标准**：

| 检查 | 期望 | 不满足说明什么 |
|------|------|---------------|
| 前向 NaN | 无 inf/NaN | 初始化过大（FP16 必查） |
| 激活 mean/std | mean≈0，std≈1（或与理论一致如 0.83） | std 逐层衰减 → 偏小/用错方法 |
| 梯度量级 | 各层同量级（差 <10²） | 深度差 10⁶ 倍 → 梯度消失/爆炸 |
| 深度方差比 | 末层/首层 var ≈ 1 | ≪1 消失、≫1 爆炸 |

## 四、深入分析：初始化方法论全景

### 4.1 初始化理论的三个层次

| 层次 | 代表 | 手段 | 局限 |
|------|------|------|------|
| 方差守恒 | Xavier、Kaiming | 控制 $n \cdot Var(w)$ | 只保证单层矩，无残差/深网络失效 |
| 恒等起点 | GPT-2 scaled、Fixup、ReZero | 残差分支缩小/置零 | 需要残差结构 + LN |
| 更新量有界 | DeepNorm、T-Fixup | α/β 或 N^{-1/4} 缩放 | 参数多、实现复杂 |

演进主线：**从"信号尺度守恒"到"模型更新量有界"**——现代超深模型真正怕的不是前向爆炸，而是**梯度更新在残差上累积导致的震荡**。

### 4.2 初始化与归一化、学习率的关系

- **初始化 ↔ 归一化**：LN/BN 负责激活尺度，初始化负责"初始方向与数值安全"；有归一化则初始化容错高，无归一化则初始化几乎决定成败；
- **初始化 ↔ 学习率**：权重尺度 σ 与可用最大学习率强耦合（σ 越大 lr 上限越小）；Adam 对尺度不敏感（归一化梯度），SGD 高度敏感；
- **初始化 ↔ warmup**：T-Fixup 证明"缩放残差分支"后可以免 warmup；不缩残差的深模型需要 warmup 兜底。

### 4.3 FP16/BF16 场景的额外约束

1. 混合精度下过大的 logits/embedding 静默溢出为 inf——**初始化必须为 FP16 留足裕量**；
2. N(0,0.02) 量级在 FP16 下安全；Xavier 在 d 很大时接近 FP16 极限（>65504 溢出）;
3. 训练中每步检查 loss 是否 finite，第一步就 NaN 优先怀疑初始化尺度（见 [Transformer初始化](Transformer初始化.md) Q8）。

### 4.4 多模态模型的特殊注意点

1. **分塔验证**：text tower 与 vision tower 分别检查激活/梯度统计（ViT patch embedding 与文本 embedding 尺度可能不同）；
2. **跨模态新层**：新增的对齐头/投影层（如 CLIP 的 text/vision projector）若随机初始化会破坏两端预训练表示 → 用零初始化或小尺度（N(0,0.02)）+ 残差接入；
3. **微调叠加**：多模态 PEFT（LoRA on CLIP/LLaVA）遵循"主路冻结 + 分支零起点"原则（见 [LoRA初始化](LoRA初始化.md)）。

## 五、优缺点与适用

**各方法一句话评价**：

| 方法 | 优点 | 缺点 |
|------|------|------|
| Xavier | 理论完整、实现简单 | ReLU/深网失效 |
| Kaiming | ReLU 网络标准答案 | 只适合 ReLU 族 + 无残差深网 |
| N(0,0.02) | 工程稳健、生态统一 | 经验值、超深无保障 |
| GPT-2 scaled | 残差方差理论自洽 | 依赖 LN |
| DeepNorm | 可证稳定、1000 层 | 复杂度高、α/β 需查表 |
| T-Fixup | 免 warmup 免 LN | 实现繁琐（逐层乘常数） |
| Orthogonal | RNN 保范数 | 矩阵大时 QR 计算贵 |
| Zero init | 微调/残差安全垫 | 不能用于主干（对称性） |

## 六、与同类对比：一句话总结

| 维度 | Xavier vs Kaiming | N(0,0.02) vs 推导系 |
|------|-------------------|--------------------|
| 本质区别 | 激活假设不同（线性 vs 减半） | 经验 vs 理论 |
| 使用场景 | 激活函数驱动 | 结构驱动（残差+LN） |
| 深网络表现 | 各自在 50~100 层内守恒 | 超深靠 DeepNorm/T-Fixup |
| 微调场景 | 都不直接适用 | 都让位给"零起点分支"方案 |

## 七、高频面试问答

**Q1：给你一个新模型，怎么选初始化？**
按决策树：① 看结构（有无归一化/残差）：无 → 按激活选 Xavier/Kaiming；有 LN 的 Transformer → N(0,0.02)+残差 1/√N，超深用 DeepNorm/T-Fixup；② 看场景：从头训练 vs 微调（微调用零起点分支）；③ 看精度：FP16 缩小一档。最后做四项验证（见 3.3）。

**Q2：初始化、归一化、学习率三者关系？**
归一化管激活尺度，初始化管初始方向与数值安全，二者互补不可替代；初始化尺度决定可用 lr 上限（σ 大 → lr 小），Adam 对尺度不敏感、SGD 敏感；初始化好可以省 warmup（T-Fixup 证明）。

**Q3：为什么"参数越小越安全"是错的？**
初始化过小 → $n \cdot Var(w) \ll 1$ → 信号指数消失 → 深层梯度消失，表现为"loss 完全不动"，容易被误判为学习率问题。好的初始化是让 $n \cdot Var(w) \approx 1$（或按残差结构缩小），不是越小越好。

**Q4：初始化后如何快速验证好坏？**
四件套：① 单样本前向查 NaN/Inf；② hook 打印各层激活 mean/std（应稳定不衰减）；③ backward 后各层梯度范数同量级；④ 深度方差比（末层/首层 ≈1）。FP16 必查 ①，多模态分塔各查一遍。

**Q5：Xavier/Kaiming/Transformer 初始化各解决什么问题？**
Xavier：前向+反向方差双守恒（Sigmoid/Tanh）；Kaiming：补偿 ReLU 的方差减半（×2）；Transformer 系：残差结构下方差线性累积 + 更新量有界（1/√N、α/β）。三者是"由浅入深"的演进：单层矩 → 激活补偿 → 结构补偿。

**Q6：微调预训练模型时新增模块应该怎么初始化？**
零起点原则：新增分支初始输出为 0（LoRA B=0、Fixup 残差末层置零、ReZero 标量置 0），保证微调从原模型预测出发；主路冻结；分支幅度由 α/r 或学习率显式控制。

**Q7：深 Transformer 训练第一步就 NaN，怎么排查？**
按概率：① FP16 溢出（logits/embedding 过大）→ 调小 initializer_range；② 残差分支未缩放（1/√N 缺失）→ 方差累积爆炸；③ lr 过大 + 无 warmup；④ 数据 NaN。用 3.3 检查① 先定位是哪一层出的 NaN（hook 逐层查）。

**Q8：各种初始化的公式能现场推导吗？**
可以，全是同一个方程 $n \cdot Var(w) \cdot E[\text{激活}^2] = 1$ 的变体：Xavier 取 $E[\text{激活}^2]=1$、折中 $n_{in}/n_{out}$；Kaiming 取 $=1/2$；均匀版用 $Var = a^2/3$ 换算边界。Transformer 系则跳出守恒框架，改为"恒等起点 + 更新有界"。
