# 数据增强（Data Augmentation）

> 本模块索引见 [正则化与训练技巧详解](正则化与训练技巧详解.md)

## 一、定义与公式

数据增强：在不增加标注成本的前提下，通过**对输入做保持语义的变换**生成更多训练样本，是**成本最低、收益最高**的正则化手段——不增加任何参数与推理开销，只增加训练数据多样性。

从正则化视角看，数据增强等价于**在经验风险上做邻域平滑**：

$$\hat{L}_{\text{aug}} = \frac{1}{n}\sum_{i=1}^{n} \mathbb{E}_{t \sim \mathcal{T}}\left[\ell(f(t(x_i)), y_i)\right]$$

即对每个样本在其变换轨道 $\mathcal{T}(x_i)$ 上求期望损失——强迫模型在 $x_i$ 的**等价类**上输出一致，直接抑制过拟合与对特定噪声的依赖。

### 1.1 核心分类

| 大类 | 子类 | 代表方法 |
|------|------|---------|
| 几何变换 | 翻转/旋转/裁剪/缩放/仿射 | RandomHorizontalFlip、RandomResizedCrop |
| 颜色变换 | 亮度/对比度/饱和度/色相/灰度 | ColorJitter、Grayscale |
| 模糊/噪声 | 高斯模糊、椒盐噪声、擦除 | GaussianBlur、RandomErasing |
| 混合增强 | 样本线性插值 / 区域粘贴 | MixUp、CutMix |
| 自动增强 | 策略搜索或随机采样 | AutoAugment、RandAugment |

### 1.2 数学上的关键公式

**MixUp**：两张图按 $\lambda \sim \text{Beta}(\alpha, \alpha)$ 线性插值，**标签也插值**：

$$\tilde{x} = \lambda x_1 + (1-\lambda) x_2, \qquad \tilde{y} = \lambda y_1 + (1-\lambda) y_2$$

**CutMix**：把 $x_2$ 的矩形块 $B$ 贴到 $x_1$ 上，标签按**面积比例**混合：

$$\tilde{x} = \mathbf{1}_B \cdot x_2 + (1-\mathbf{1}_B) \cdot x_1, \qquad \tilde{y} = \frac{|B|}{|x|} y_j + \left(1 - \frac{|B|}{|x|}\right) y_i$$

其中 $|B|/|x|$ 是被替换区域的面积占比。MixUp 整图线性混合（可能"鬼影"），CutMix 保留局部语义（贴块），ImageNet 上 CutMix 更优。

## 二、核心原理

### 2.1 为什么数据增强有效

1. **利用数据先验**：水平翻转利用"镜像对称"先验、裁剪利用"目标尺度位置不变"先验——把人类已知的不变性免费注入模型；
2. **扩大有效样本量**：每个原始样本的变换轨道大小即增强倍数（如 1 张图可产生几十种合法变体），等价于更多训练数据；
3. **对抗捷径学习（shortcut learning）**：只依赖纹理/背景/颜色的捷径特征被颜色抖动、模糊等破坏，模型被迫学习语义特征；
4. **平滑决策边界**：邻域损失让输出在变换轨道上一致，决策边界更平滑、更鲁棒。

### 2.2 多模态增强的底线（最重要原则）

> **原则：多模态数据增强必须以"不破坏图-文对应关系"为底线。** 图像裁剪不能剪掉文本所指对象；文本改写不能改变图像能表达的内容。破坏对应关系的增强会直接污染对比学习目标（CLIP 类训练）。

典型要求：
- 图文对做随机裁剪时，**文本语义必须保持不变**（不能说"左半边的猫"）；
- 文本模板改写必须与图像内容一致；
- 视频增强（帧采样/时间裁剪）时字幕与画面片段要同步对齐。

### 2.3 分类 vs 对比学习：增强策略完全不同

| 场景 | 增强强度 | 说明 |
|------|---------|------|
| 图像分类 | 强（RandAugment + CutMix） | 标签随变换走，强度可大 |
| 对比学习（CLIP 双塔） | **谨慎** | MixUp/CutMix 破坏图-文对应关系，**不可用**；只用几何/颜色类 |
| 检测/分割 | 需坐标/掩码同步变换 | 裁剪、翻转要同步改标注 |
| 自监督（SimCLR 等） | 双重强增强 | 两个 view 都要增强 |

## 三、源码实现

### 3.1 图像增强全栈示例（torchvision transforms）

```python
import torch
import torchvision.transforms as T
import torchvision.transforms.functional as TF

basic = T.Compose([
    T.RandomResizedCrop(224, scale=(0.08, 1.0), ratio=(3/4, 4/3)),  # 随机裁剪缩放（CLIP 标配）
    T.RandomHorizontalFlip(p=0.5),        # 水平翻转
    T.ColorJitter(brightness=0.4, contrast=0.4, saturation=0.4, hue=0.1),  # 颜色抖动
    T.RandomGrayscale(p=0.1),             # 小概率灰度化
    T.GaussianBlur(kernel_size=3, sigma=(0.1, 2.0)),  # 高斯模糊
    T.ToTensor(),                         # PIL/ndarray → tensor
    T.Normalize(mean=[0.48145, 0.45782, 0.40821],      # ★ CLIP 专用 mean/std
                std=[0.26862, 0.26130, 0.27577]),
])

x = torch.randn(3, 256, 256)              # 模拟图像 tensor
img = TF.to_pil_image(x)                  # tensor → PIL（无需 numpy）
out = basic(img)                          # 增强 + 归一化后输出
print(out.shape, out.dtype)               # torch.Size([3, 224, 224]) torch.float32
```

> **注意**：CLIP 系模型归一化 mean/std 是 `(0.48145, 0.45782, 0.40821)`，**不是 ImageNet 的** `(0.485, 0.456, 0.406)`——混用直接掉点（模块总览 12.3 事故清单）。

### 3.3 MixUp 与 CutMix 手写实现

```python
import torch

def mixup(x, y, alpha=0.2):
    """线性插值混合图像与标签"""
    lam = torch.distributions.Beta(alpha, alpha).sample().item()
    idx = torch.randperm(x.size(0), device=x.device)
    return lam * x + (1 - lam) * x[idx], lam, idx

def cutmix(x, y, alpha=1.0):
    """区域粘贴混合：标签按面积比例混合"""
    lam = torch.distributions.Beta(alpha, alpha).sample().item()
    idx = torch.randperm(x.size(0), device=x.device)
    _, C, H, W = x.shape
    cx, cy = torch.randint(0, W, (1,)).item(), torch.randint(0, H, (1,)).item()
    bw = int(W * (1 - lam) ** 0.5); bh = int(H * (1 - lam) ** 0.5)
    x1, x2 = max(cx - bw // 2, 0), min(cx + bw // 2, W)
    y1, y2 = max(cy - bh // 2, 0), min(cy + bh // 2, H)
    x[:, :, y1:y2, x1:x2] = x[idx][:, :, y1:y2, x1:x2]   # 贴块
    lam_area = 1 - ((x2 - x1) * (y2 - y1)) / (W * H)      # 实际面积比例
    return x, lam_area, idx

x = torch.randn(8, 3, 224, 224)
y = torch.randint(0, 10, (8,))
xm, lam_m, idx_m = mixup(x, y)
xc, lam_c, idx_c = cutmix(x.clone(), y)
print(lam_m, lam_c)              # 如 0.62 / 0.71（Beta 采样值）
# 混合标签：loss = lam * CE(logits, y) + (1-lam) * CE(logits, y[idx])
```

### 3.4 混合标签训练用法（带损失）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

model = nn.Sequential(nn.Flatten(), nn.Linear(3*224*224, 10))
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

def train_step_mix(x, y):
    xm, lam, idx = mixup(x, y)                       # 复用 3.3 的 mixup
    logits = model(xm)
    loss = lam * F.cross_entropy(logits, y) + (1 - lam) * F.cross_entropy(logits, y[idx])
    opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()

print(train_step_mix(torch.randn(8, 3, 224, 224), torch.randint(0, 10, (8,))))
# 输出：如 2.31（混合 CE 损失，逐 epoch 下降）
```

### 3.5 RandAugment 用法（torchvision 内置）

```python
import torch
import torchvision.transforms as T
from torchvision.transforms import RandAugment

aug = T.Compose([
    T.RandomResizedCrop(224),
    T.RandomHorizontalFlip(),
    RandAugment(num_ops=2, magnitude=9),    # N=2 个随机变换，强度 M=9
    T.ConvertImageDtype(torch.float32),     # tensor 输入用 ConvertImageDtype（PIL 输入则用 ToTensor）
])
print(aug(torch.randn(3, 256, 256)).shape)  # torch.Size([3, 224, 224])
```

> **RandAugment 原理**：从 14 种变换池（旋转/剪切/平移/对比度/亮度/颜色/太阳化等）随机采 $N$ 个，每个强度为 $M$。零学习成本，是 AutoAugment（RL 搜索策略表）的低成本替代品。

### 3.6 检测/分割场景：几何变换需同步标注

```python
import torch
import torchvision.transforms.functional as TF

def hflip_image_boxes(image, boxes, do_flip=True):
    """水平翻转图像时，bbox 坐标必须同步变换（do_flip=False 时原样返回）"""
    _, W = image.shape[-2:]
    if do_flip:
        image = TF.hflip(image)
        boxes = boxes.clone()
        boxes[:, 0], boxes[:, 2] = W - 1 - boxes[:, 2], W - 1 - boxes[:, 0]  # x1,x2 镜像
    return image, boxes

img = torch.randn(3, 224, 224)
boxes = torch.tensor([[60.0, 40.0, 180.0, 190.0]])
out_img, out_boxes = hflip_image_boxes(img, boxes, do_flip=True)
print(out_boxes)    # tensor([[ 43.,  40., 163., 190.]])：x1/x2 镜像，框仍对应同一目标
```

### 3.7 文本增强与多模态同步增强示例

```python
import random
import torch
import torchvision.transforms as T

def template_augment(question, caption):
    """模板多样化：VLM 指令数据最有效的"文本增强"（不改变语义）"""
    templates = ["{q}", "请问{q}？", f"根据图片回答：{q}", f"这张图{question}"]
    return random.choice(templates).format(q=question), caption

def sync_augment(image, caption):
    """多模态同步增强：图做几何变换，文本必须保持不变"""
    t = T.RandomResizedCrop(224)
    return t(image), caption   # ✅ 文本不随裁剪变化（"左半边的猫"问题）

# 反例（禁止）：图像裁掉猫，文本却写"图片里有只猫" → 破坏图-文对应
```

## 四、深入分析

### 4.1 对比学习为什么禁用 MixUp/CutMix

CLIP 类对比学习的标签是"图-文对"的**对应关系**：MixUp 把两张图的像素线性混合后，对应文本是"哪张图"的语义不再明确；CutMix 贴块后，文本可能描述主图也可能描述被贴入的块。混合样本**没有合法的图-文正对**，会直接污染对比目标、造成负样本失效。**多模态增强铁律：几何/颜色类可用，混合类禁用。**

### 4.2 各种增强的"副作用"一览

| 增强 | 副作用 | 对策 |
|------|--------|------|
| 水平翻转 | 文本/道路标志/人脸镜像失真 | 对 OCR、人脸任务关闭 |
| 大角度旋转 | 文字、OCR 不可读 | 旋转限 ±15° |
| 颜色抖动 | 颜色敏感任务（色盲测试、医学染色）失真 | 减小幅度 |
| 随机裁剪 | 剪掉关键对象 | 控制 scale 下限（如 0.5） |
| MixUp | 图像"鬼影"、语义模糊 | 分类外场景慎用 |
| 文本噪声注入 | 学坏语言模型本身 | 保持"轻"扰动 |

### 4.3 视频/多模态的增强维度

- **视频图文**：帧采样（随机起止）、抽帧率随机、时间裁剪——字幕/音频要与画面片段**同步**；
- **多分辨率**：LLaVA-AnyRes 把图像切成多块拼接，把"分辨率"当增强维度；
- **字幕重写**：用 LLM 把训练集字幕重写为多种风格/粒度（简短/详细/追问式），是文本侧多样性增强、LLaVA 数据配方的重要一环；
- **难负例挖掘**：挑与正对相似但语义不同的图文对做负样本，是检索训练核心技巧（数据采样层面的"增强"）。

### 4.4 训练/推理一致性事故（高频）

训练用随机裁剪、eval 忘了用对应的 resize+center crop → 分辨率/分布不一致直接掉点；归一化 mean/std 混用（ImageNet vs CLIP）；验证集用了随机增强（指标带噪不可复现）。**铁律：训练随机、eval 确定，预处理与预训练权重严格一致。**

## 五、优缺点

| 优点 | 缺点 |
|------|------|
| 零参数、零推理开销，成本最低收益最高 | 变换过强会引入失真（镜像文字、鬼影） |
| 直接扩大有效数据量，缓解过拟合 | 分类/对比/检测场景规则不同，易用错 |
| 注入先验（对称性、尺度不变性） | 多模态需保证图文对应，约束多 |
| 与所有正则方法正交叠加 | 自动增强（AutoAugment）需搜索成本 |

## 六、与同类对比

| 方法 | 原理 | 标签处理 | 适用 | 与数据增强关系 |
|------|------|---------|------|---------------|
| 基础变换（翻转/裁剪/抖动） | 保持语义的确定性先验变换 | 不变 | 通用 | 基线 |
| MixUp | 整图线性插值 | 插值混合 | 分类 | 混合增强 |
| CutMix | 区域粘贴 | 面积混合 | 分类/检测 | 混合增强（保留局部结构） |
| RandAugment | 随机采 N 个变换 | 不变 | 分类/自监督 | 自动增强廉价版 |
| AutoAugment | RL 搜索策略表 | 不变 | 分类 | 自动增强（策略绑定数据集） |
| 回译/模板改写 | 文本侧语义保持改写 | 不变 | 文本/VLM 数据 | 文本增强 |
| Dropout | 隐藏特征随机遮挡 | 不变 | 通用 | "特征空间增强"，与输入增强互补 |

## 七、高频面试问答

**Q1：数据增强为什么是正则化？**
等价于在样本的变换轨道上对损失取期望（邻域平滑）：模型被迫在等价类上输出一致，抑制对噪声与捷径特征的过拟合；且零参数零推理开销，是所有正则里性价比最高的。

**Q2：MixUp 和 CutMix 的区别？**
MixUp 整图线性插值（$\lambda$ 个像素级混合、标签也插值），图像可能"鬼影"、语义模糊；CutMix 贴矩形块、标签按面积比例混合，保留局部结构，ImageNet 上更优且更适合细粒度/检测。

**Q3：对比学习（CLIP）为什么不能用 MixUp/CutMix？**
混合后样本没有合法的"图-文正对"：文本对应哪张图语义不明确，会直接污染对比学习目标。多模态增强只能用几何/颜色类且必须保证图文对应不破坏。

**Q4：CLIP 微调用什么增强？eval 用什么？**
训练：RandomResizedCrop + RandomHorizontalFlip + ColorJitter（轻量）；eval：Resize + CenterCrop 的确定性管线；归一化必须用 CLIP 的 mean/std 而非 ImageNet 的。

**Q5：RandAugment 和 AutoAugment 的区别？**
RandAugment 从变换池随机采 N 个、强度 M 统一，无学习成本；AutoAugment 用 RL 搜索"每类每个变换的概率/幅度表"，效果好但策略与数据集绑定、成本高。

**Q6：多模态数据增强的底线是什么？**
不破坏图-文对应关系：裁剪不能剪掉文本所指对象、文本改写不能超出图像内容、视频增强要音画字同步。破坏对应关系会污染对比学习与 VLM 指令数据。

**Q7：文本增强怎么做？要注意什么？**
回译（质量最高、成本高）、同义词替换（注意多义词）、噪声注入（适合 ASR/OCR 鲁棒性）、模板多样化（VLM 指令数据必做）。要"轻"：LLM 已对噪声有先验，过强扰动会学坏语言模型。
