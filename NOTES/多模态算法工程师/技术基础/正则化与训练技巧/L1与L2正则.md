# L1 与 L2 正则

> 本模块索引见 [正则化与训练技巧详解](正则化与训练技巧详解.md)

## 一、定义与公式

### 1.1 L2 正则（权重衰减）

在损失函数上加上权重平方和：

$$L = L_0 + \frac{\lambda}{2} \|w\|_2^2 = L_0 + \frac{\lambda}{2} \sum_{i} w_i^2$$

- $L_0$ 为原始损失（如 CE），$\lambda$ 为正则强度，$w$ 为权重（**通常不含 bias 与归一化层参数**）；
- 系数 $\frac{1}{2}$ 是为了求导后形式干净。

**梯度**：

$$\frac{\partial L}{\partial w} = \frac{\partial L_0}{\partial w} + \lambda w$$

**SGD 更新**（学习率 $\eta$）：

$$w_{t+1} = w_t - \eta\left(\nabla L_0(w_t) + \lambda w_t\right) = \underbrace{(1 - \eta\lambda)}_{\text{衰减因子}} w_t - \eta \nabla L_0(w_t)$$

**推导**：每个 step 都会把权重按 $(1-\eta\lambda)$ 向零方向"缩"一点——这就是"权重衰减（weight decay）"名字的由来。$\lambda$ 越大衰减越强。

### 1.2 L1 正则（稀疏性）

$$L = L_0 + \lambda \|w\|_1 = L_0 + \lambda \sum_i |w_i|$$

**梯度（次梯度）**：

$$\frac{\partial L}{\partial w_i} = \frac{\partial L_0}{\partial w_i} + \lambda \cdot \text{sign}(w_i), \qquad \text{sign}(w_i) = \begin{cases} +1, & w_i > 0 \\ -1, & w_i < 0 \end{cases}$$

**关键差异**：L1 的惩罚梯度是**常数 $\lambda$**（不随 $|w_i|$ 减小而减弱），即使权重已经很小也会被继续推向 0；L2 的惩罚梯度 $\lambda w_i$ 随权重减小而**线性减弱**，越接近 0 推得越轻，因此 L2 只会收缩、很难精确归零。

### 1.3 贝叶斯视角

- **L2 = 零均值高斯先验** $w \sim \mathcal{N}(0, \sigma^2)$ 的 MAP 估计（取对数后出现 $\|w\|_2^2$ 项）；
- **L1 = 拉普拉斯先验** $\text{Laplace}(0, b)$ 的 MAP 估计（取对数后出现 $\|w\|_1$ 项）。

高斯先验集中在 0 附近但处处非零 → L2 解收缩不稀疏；拉普拉斯先验在 0 处有"尖峰" → L1 解稀疏。

## 二、核心原理

### 2.1 为什么小权重泛化好

1. **函数更平滑**：权重小 → 输出对输入变化的敏感度低 → 决策边界平滑，对输入扰动不敏感；
2. **抑制高次特征**：多项式视角下小权重压低高阶项，函数复杂度下降，避免"曲折拟合噪声"；
3. **解的偏好**：多个等价解中 L2 偏好范数最小者，防止某些维度过大垄断损失。

### 2.2 L1 稀疏解的几何直觉（菱形 vs 圆，必考）

把优化问题改写为**约束形式**（拉格朗日对偶视角）：在 $\|w\|_p \le C$ 的约束下最小化 $L_0$。二维参数平面上，最优解是**损失等高线与约束区域的首次相切点**：

- **L2 约束** $\|w\|_2 \le C$：**圆形**区域，边界处处光滑，等高线相切点落在坐标轴上的概率为 0 → 通常只是缩小权重、**很少精确到 0**；
- **L1 约束** $|w_1| + |w_2| \le C$：**菱形**区域，**角点恰好落在坐标轴上**，等高线很容易碰到角点 → 该维度权重**正好为 0** → 稀疏解。

> 直觉总结：**圆的切点都在坐标轴之外（权重非零），菱形的尖角在坐标轴上（权重为零）。** 维度越高，L1 相切角点的概率优势越大。

### 2.3 L2 正则与 AdamW 的问题（与优化器模块联动，必考）

**问题核心**：L2 正则 + Adam 不等价于权重衰减！Adam 更新 $\theta \leftarrow \theta - \eta \frac{\hat{m}}{\sqrt{\hat{v}}+\epsilon}$ 中各项更新量被**二阶动量归一化**；若把 $\lambda w$ 加进梯度，该项也被 $\sqrt{\hat{v}}$ 归一化 → 大权重处衰减被压小、小权重处被放大，**衰减不均匀、与学习率耦合**，效果显著变差。

**AdamW（decoupled weight decay）** 把衰减从梯度中拿出来，直接作用在参数上：

$$\theta_{t+1} = \theta_t - \eta\lambda\theta_t - \eta \frac{\hat{m}}{\sqrt{\hat{v}}+\epsilon}$$

每个参数按**同一比例** $\eta\lambda$ 衰减，不经过二阶动量归一化。

| 方法 | 做法 | 与 Adam 配合 |
|------|------|-------------|
| L2 正则 | 梯度里加 $\lambda w$ | 衰减被 $\sqrt{\hat{v}}$ 扭曲，效果差 |
| 权重衰减（AdamW） | 更新时直接乘 $(1-\eta\lambda)$ | 衰减均匀，效果好 |

> **记忆点**：AdamW = Adam + 解耦权重衰减。预训练/微调大模型（LLM/VLM）现在全部用 AdamW，几乎不用带 L2 的 Adam。PyTorch 里 `optimizer = AdamW(params, lr=..., weight_decay=0.01)` 即对应 $\lambda$。

## 三、源码实现

### 3.1 手写 L2 正则损失（加在 loss 上）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def l2_reg_loss(model, lam=1e-3):
    """手写 L2 正则项：λ/2 · Σw²（通常不含 bias/LN 参数）"""
    reg = 0.0
    for name, p in model.named_parameters():
        if p.requires_grad and p.dim() > 1:     # 跳过 bias 与归一化层（一维）
            reg += p.pow(2).sum()
    return 0.5 * lam * reg

model = nn.Linear(8, 4)
loss = F.mse_loss(model(torch.randn(4, 8)), torch.randn(4, 4))
total = loss + l2_reg_loss(model, lam=1e-3)
print(total.item())          # 如 1.23（原始 loss + 小正则项）
```

### 3.2 手写 L1 正则损失

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def l1_reg_loss(model, lam=1e-4):
    reg = 0.0
    for name, p in model.named_parameters():
        if p.requires_grad and p.dim() > 1:
            reg += p.abs().sum()
    return lam * reg

model = nn.Linear(8, 4)
loss = F.mse_loss(model(torch.randn(4, 8)), torch.randn(4, 4))
total_l1 = loss + l1_reg_loss(model, lam=1e-4)
print(total_l1.item())       # 如 1.22（原始 loss + 小正则项）
```

### 3.3 手动实现 L2 更新的两种写法（演示 L2 与 weight decay 的差别）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def l2_reg(model, lam):
    """块内局部 L2：λ/2 · Σw²（跳过 bias）"""
    return 0.5 * lam * sum(p.pow(2).sum() for n, p in model.named_parameters() if p.dim() > 1)

torch.manual_seed(0)

# 写法 A：损失里加正则项（严格 L2）
def train_l2():
    torch.manual_seed(0)                  # 每个函数内重置种子，保证数据一致
    m = nn.Linear(8, 4)
    opt = torch.optim.SGD(m.parameters(), lr=0.1)
    for _ in range(5):
        opt.zero_grad()
        out = F.mse_loss(m(torch.randn(4, 8)), torch.randn(4, 4)) + l2_reg(m, 0.01)
        out.backward()
        opt.step()
    return m.weight.detach().norm().item()

# 写法 B：优化器 weight_decay 参数（同样跳过 bias，SGD 下与 L2 严格等价）
def train_wd():
    torch.manual_seed(0)                  # 与 train_l2 使用相同数据流
    m = nn.Linear(8, 4)
    weight_params = [p for n, p in m.named_parameters() if p.dim() > 1]
    opt = torch.optim.SGD(weight_params, lr=0.1, weight_decay=0.01)
    for _ in range(5):
        opt.zero_grad()
        F.mse_loss(m(torch.randn(4, 8)), torch.randn(4, 4)).backward()
        opt.step()
    return m.weight.detach().norm().item()

a, b = train_l2(), train_wd()
print(a, b)                         # 两个值几乎一致（如 1.0223 1.0236：数学上严格等价，仅浮点舍入差异）
```

> **SGD 下等价、Adam 下不等价**：SGD 的更新不含二阶动量归一化，L2 与 weight_decay 数学等价；Adam 下必须用 AdamW。

### 3.4 手写 L2 更新的"衰减"视角（验证 1-ηλ 因子）

```python
import torch

torch.manual_seed(0)
w = torch.randn(4)
eta, lam = 0.1, 0.5
grad = torch.randn(4)                 # 模拟 L0 的梯度

for _ in range(5):
    w = (1 - eta * lam) * w - eta * grad   # 先按 (1-ηλ) 衰减，再沿负梯度走

print(w.norm().item())                # 如 0.42（每步都在"缩"）
```

### 3.5 对比官方实现：PyTorch 的 weight_decay 参数

```python
import torch
import torch.nn as nn

# 官方推荐用法（现代训练全部走这条路）
model = nn.Sequential(nn.Linear(8, 8), nn.ReLU(), nn.Linear(8, 4))
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)   # λ=0.01

# 可选组合：只对 2 维以上参数（权重）施加衰减，bias/LN 跳过
decay, no_decay = [], []
for n, p in model.named_parameters():
    (no_decay if n.endswith("bias") or p.dim() == 1 else decay).append(p)
opt = torch.optim.AdamW([
    {"params": decay, "weight_decay": 0.01},
    {"params": no_decay, "weight_decay": 0.0},
], lr=1e-3)
print(len(decay), len(no_decay))    # 如 4 2（decay 组、no_decay 组参数个数）
```

> **工程惯例（必记）**：bias 与 LayerNorm 参数通常**不做 weight decay**（AdamW 官方参数分组就是这么做的）；LLM 微调 weight_decay 常用 0.01~0.1。

## 四、深入分析

### 4.1 为什么 L1 在大模型里几乎没人用

1. **稀疏化收益低**：大模型参数已高度冗余，把权重推成 0 并不能像传统 ML 那样直接"删特征"（需要结构稀疏才有加速收益）；
2. **破坏预训练分布**：L1 的常数梯度 $\pm\lambda$ 会把大量权重**刚性地推向 0**，破坏预训练学到的权重分布，收敛不稳、微调掉点；
3. **优化不稳**：次梯度在 0 附近不光滑，配合 Adam 的归一化行为更差。

**主流共识**：L1 出现在传统 ML（LASSO 特征选择）、稀疏 MoE 路由正则等场景；深度学习训练标配是 **AdamW weight_decay（L2 系）+ Dropout + 数据增强**。面试考理论、工程用 L2。

### 4.2 L1 的次梯度与 proximal 收缩

L1 在 $w_i=0$ 处不可导，用次梯度（集合 $[-1,1]$ 中任取）。实际优化更常用 **proximal 方法**：对 L1 项的精确解是软阈值（soft-threshold）：

$$\text{prox}_{\lambda}(v)_i = \text{sign}(v_i) \max(|v_i| - \lambda, 0)$$

这比次梯度更精确地把小权重"砍"到 0（而非近似接近 0）。PyTorch 不内置，稀疏训练库（如 apollo、momentum 稀疏类库）中可见。

### 4.3 L2 与归一化（BN/LN）的相互作用

归一化层使激活对权重**幅值不变**（缩放权重不改变归一化后的输出），因此 L2 对"权重幅值"的惩罚在归一化层参数上意义有限——这也是工程上**不衰减 LN 参数**的原因。BN/LN 本身的归一化已自带一定正则效果（对输入分布鲁棒），与 L2 互补。

### 4.4 超参 λ 与数据规模的关系

| 场景 | λ 经验值 | 说明 |
|------|---------|------|
| 小数据 + 大模型 | 0.05~0.1 | 正则强，防过拟合 |
| 常规微调（数据中等） | 0.01 | AdamW 默认量级 |
| 大规模预训练 | 0.01~0.1 | 数据多，但训练长仍需防遗忘 |
| LoRA 微调 | 0.0~0.1 | LoRA 本身约束了更新空间（低秩），可减正则 |

## 五、优缺点

| 正则 | 优点 | 缺点 |
|------|------|------|
| L2 | 平滑收缩、解唯一、数值稳定；与 SGD/AdamW 无缝集成；贝叶斯解释清晰 | 不解产生精确稀疏；过大会欠拟合；Adam 下必须用解耦版本 |
| L1 | 精确稀疏（特征选择、压缩）；对 outlier 权重鲁棒；几何直觉清晰 | 0 处不可导（次梯度）；大模型破坏预训练分布；解可能不唯一 |

## 六、与同类对比

| 维度 | L1 | L2 | 其他正则 |
|------|-----|-----|---------|
| 约束形状 | 菱形（$L_1$ 球） | 圆（$L_2$ 球） | —— |
| 解特性 | 稀疏（精确 0） | 平滑收缩（非 0 但小） | —— |
| 惩罚梯度 | 常数 $\lambda$（不衰减） | $\lambda w$（线性衰减） | —— |
| 先验 | 拉普拉斯 | 高斯 | Dropout：无先验，结构随机 |
| 典型用途 | 特征选择、稀疏 MoE | **默认标配（AdamW）** | Dropout 防共适应 |
| 与 Dropout 关系 | 独立可叠加 | 独立可叠加 | 作用在激活 vs 权重，互补 |

**三者关系**：L1/L2 作用在**权重**（确定性惩罚），Dropout 作用在**激活**（随机扰动）；L2 + Dropout + 数据增强是现代 VLM 训练的"三件套"，L1 基本缺席。

## 七、高频面试问答

**Q1：L1 和 L2 的区别？为什么 L1 产生稀疏解？**
L1 惩罚梯度恒为 $\pm\lambda$，不随权重变小而减弱，约束区域是菱形，等高线相切点易落在坐标轴角点 → 权重精确为 0；L2 惩罚梯度 $\lambda w$ 随权重变小而减弱，约束是圆，解只收缩不归零。

**Q2：权重衰减（weight decay）和 L2 正则完全一样吗？**
SGD 下严格等价；Adam 下不等价——L2 的 $\lambda w$ 进梯度后会被二阶动量 $\sqrt{\hat v}$ 归一化，衰减不均匀；AdamW 把衰减解耦出来直接乘在参数上，是现代的标配。

**Q3：为什么 bias 和 BN/LN 参数不做 weight decay？**
bias 平移不影响过拟合的"复杂度"；归一化层参数对权重幅值不敏感（缩放权重不改变归一化输出），惩罚无意义且有害。工程上按 `p.dim()>1` 分组跳过。

**Q4：几何上为什么 L1 是菱形、L2 是圆？解为什么不同？**
$|w_1|+|w_2| \le C$ 在二维是菱形（角点在坐标轴），$\|w\|_2 \le C$ 是圆（边界光滑）；最优解是等高线首次接触边界处：菱形角点（某维为 0）命中概率高 → 稀疏；圆相切点几乎不落在坐标轴上 → 只收缩。

**Q5：L1 在大模型训练里为什么不用？**
稀疏化无加速收益、常数梯度破坏预训练权重分布、次梯度优化不稳。大模型标配 AdamW weight_decay + Dropout + 数据增强。

**Q6：PyTorch 里 L2/weight decay 怎么用？λ 怎么设？**
`AdamW(params, lr, weight_decay=0.01)`；按分组把 bias/LN 的 weight_decay 设 0；微调常用 0.01~0.1，数据越少 λ 越大。

**Q7：L2 正则的贝叶斯解释？**
L2 = 权重加零均值高斯先验的 MAP 估计；L1 = 拉普拉斯先验的 MAP 估计。高斯先验"处处非零" → 收缩；拉普拉斯在 0 处有尖峰 → 稀疏。
