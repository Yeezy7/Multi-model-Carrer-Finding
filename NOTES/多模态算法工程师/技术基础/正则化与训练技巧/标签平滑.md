# 标签平滑（Label Smoothing）

> 本模块索引见 [正则化与训练技巧详解](正则化与训练技巧详解.md)

## 一、定义与公式

标签平滑（Label Smoothing, Szegedy et al., 2016）把 one-hot 硬标签"软化"为软标签：真实类别概率为 $1-\epsilon$，其余 $K-1$ 类均分 $\epsilon$。

设真实类别为 $y$，one-hot 标签 $q(k) = \mathbb{1}[k = y]$，平滑后为：

$$q'(k) = \begin{cases} 1 - \epsilon + \frac{\epsilon}{K}, & k = y \\ \frac{\epsilon}{K}, & k \neq y \end{cases}$$

其中 $K$ 为类别数，$\epsilon$ 为平滑系数（Transformer 论文默认 0.1）。

### 1.1 推导：为什么是 $1-\epsilon + \epsilon/K$ 而不是 $1-\epsilon$

平滑的本质是"对 one-hot 与均匀分布的插值"：

$$q' = (1-\epsilon) \cdot q + \epsilon \cdot u, \qquad u(k) = \frac{1}{K}$$

展开真实类 $k=y$：$(1-\epsilon)\cdot 1 + \epsilon/K = 1-\epsilon+\epsilon/K$；非真实类 $k\neq y$：$(1-\epsilon)\cdot 0 + \epsilon/K = \epsilon/K$。**归一性检查**：$(1-\epsilon+\epsilon/K) + (K-1)\cdot \epsilon/K = 1-\epsilon + \epsilon = 1$，仍是合法概率分布。

### 1.2 平滑后的交叉熵损失

把 $q'$ 代入交叉熵 $L = -\sum_k q'(k)\log p(k)$：

$$L = -\left[(1-\epsilon)\log p(y) + \frac{\epsilon}{K}\sum_{k \neq y}\log p(k)\right]$$

其中 $p(k) = \text{softmax}(z)_k$ 是模型输出概率。**软标签只影响训练损失，推理时照常 argmax，无需任何处理。**

### 1.3 梯度视角：为什么能防止过度自信

对未平滑的 CE 损失 $L = -\log p(y)$，其关于 logit $z_y$ 的梯度为 $p(y) - 1$：只要 $p(y) < 1$，梯度就持续把 $z_y$ 推向 $+\infty$、把其他 logit 推向 $-\infty$——**模型为了"完全对"会无限拉开 logit 差（过度自信）**。

平滑后的梯度（推导关键）：

$$\frac{\partial L}{\partial z_j} = p(j) - q'(j) = p(j) - \begin{cases} 1-\epsilon+\frac{\epsilon}{K}, & j=y \\ \frac{\epsilon}{K}, & j\neq y \end{cases}$$

当 $p(y)$ 逼近目标 $1-\epsilon+\epsilon/K$ 时梯度为 0，logit 差被"封顶"：**真实类 logit 无需无限大，负类 logit 也无需无限小**。这就是"防止过度自信"的数学本质。

> 一句话：one-hot 的梯度永远推着 logit 发散；平滑后的梯度在 $p(y)$ 到达软目标时就归零，logit 幅度受限于 $O(\log\frac{K(1-\epsilon)+\epsilon}{\epsilon})$。

## 二、核心原理

### 2.1 三个作用机制

1. **防过置信（overconfidence）**：软标签给模型"不必全对"的空间，logit 幅值受限，预测分布不走向极端 0/1；
2. **正则化 / 软化决策边界**：等价于给 logits 加"类间均匀"先验，预测分布更平滑，抑制极端输出；
3. **对抗标注噪声**：错误标签在软标签中"可信度"仅为 $\epsilon/K$，模型不会被单条错误标注带偏。

### 2.2 改善校准（Calibration）

未平滑模型常"过分自信"：输出 0.9 的样本实际正确率只有 0.7。标签平滑让 **softmax 输出与真实正确率更接近**（ECE 指标更低、可靠性图更贴合对角线）。这对多模态任务尤其重要：

- **图文检索阈值**：跨模态相似度阈值过滤靠校准良好的置信度；
- **VQA 置信度过滤**：低置信度问题交给外部模型/人工兜底；
- **RLHF 奖励/偏好模型**：偏好概率需要校准，否则 KL 惩罚失真。

### 2.3 与蒸馏的关系（延伸）

知识蒸馏（KD）中 teacher 的软输出本身已是软标签。若同时用 label smoothing 会"双重软化"：teacher 输出被 teacher 自身平滑压低 → student 学到的分布更糊。实践上蒸馏场景要么只用 teacher 软标签、要么把 smoothing 调小。

### 2.4 适用边界

| 场景 | 是否推荐 | 说明 |
|------|---------|------|
| 分类（含多模态分类头） | 推荐 | $\epsilon=0.1$ 起步 |
| Transformer 语言建模 | 推荐 | 论文默认 0.1 |
| 对比学习（CLIP 系） | **不用** | 目标是拉近正对/推远负对，无类别分布，平滑定义不清 |
| 蒸馏场景 | 慎用 | 双重软化 |
| 噪声极大的硬任务 | 谨慎 | $\epsilon>0.3$ 会欠拟合，logits 幅度过小 |

## 三、源码实现

### 3.1 手写实现：平滑标签 + 手动交叉熵

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def smooth_labels(labels, num_classes, eps=0.1):
    """把整数标签转成平滑软标签（向量化）"""
    q = torch.full((labels.shape[0], num_classes), eps / num_classes)
    q[torch.arange(labels.shape[0]), labels] = 1 - eps + eps / num_classes
    return q

labels = torch.tensor([2, 0])
q = smooth_labels(labels, num_classes=5, eps=0.1)
print(q)                      # 每行：真实类 0.92，其余 0.02，和 = 1
print(q.sum(dim=1))           # tensor([1., 1.]) 仍是合法分布
```

### 3.2 手写平滑交叉熵损失（逐样本）

```python
import torch
import torch.nn.functional as F

def label_smoothing_ce(logits, labels, eps=0.1):
    """手写平滑交叉熵：log-softmax + 软标签点乘（软标签内联构造，独立可运行）"""
    K = logits.shape[-1]
    q = torch.full((logits.shape[0], K), eps / K)              # 其余类 ε/K
    q[torch.arange(logits.shape[0]), labels] = 1 - eps + eps / K   # 真实类
    log_probs = F.log_softmax(logits, dim=-1)                  # log p(k)
    return -(q * log_probs).sum(dim=-1).mean()                 # -Σ q'(k) log p(k)

logits = torch.tensor([[2.0, 1.0, 0.5], [0.2, 3.0, 0.1]])
labels = torch.tensor([0, 1])
print(label_smoothing_ce(logits, labels, 0.1))                 # 如 tensor(0.5906)
```

### 3.3 官方接口：F.cross_entropy 一行搞定

```python
import torch
import torch.nn.functional as F

# 官方等价写法：label_smoothing 参数（PyTorch 1.10+）
logits = torch.tensor([[2.0, 1.0, 0.5], [0.2, 3.0, 0.1]])
labels = torch.tensor([0, 1])
loss1 = F.cross_entropy(logits, labels, label_smoothing=0.1)
loss2 = label_smoothing_ce(logits, labels, 0.1)       # 复用 3.2 的函数
print(loss1.item(), loss2.item())       # 两行输出完全一致
```

> **验证**：官方 `label_smoothing` 内部与 3.2 的实现数学等价，只是融合进 kernel 里更快；生产代码直接用官方参数。

### 3.4 训练中用法（含与无平滑的对比）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
model = nn.Sequential(nn.Linear(16, 32), nn.ReLU(), nn.Linear(32, 10))
opt = torch.optim.Adam(model.parameters(), lr=1e-2)

x = torch.randn(64, 16)
y = torch.randint(0, 10, (64,))

logits = model(x)
loss_plain = F.cross_entropy(logits, y)
loss_smooth = F.cross_entropy(logits, y, label_smoothing=0.1)
print(loss_plain.item())      # 硬标签损失（如 2.302）
print(loss_smooth.item())     # 平滑损失更大（多了"其余类均匀"项，如 2.402）

# 平滑版更新一步
opt.zero_grad()
loss_smooth.backward()
opt.step()
print(loss_smooth.item())     # 如 2.395，平稳下降
```

### 3.5 自定义损失类（可与 nn.Module 组合）

```python
import torch
import torch.nn as nn

class LabelSmoothCE(nn.Module):
    def __init__(self, eps=0.1):
        super().__init__()
        self.eps = eps

    def forward(self, logits, labels):
        return label_smoothing_ce(logits, labels, self.eps)   # 复用 3.2 的函数

criterion = LabelSmoothCE(0.1)
model = nn.Sequential(nn.Linear(16, 32), nn.ReLU(), nn.Linear(32, 10))
print(criterion(model(torch.randn(4, 16)), torch.randint(0, 10, (4,))))  # 直接当 loss 用，如 tensor(2.30)
```

## 四、深入分析

### 4.1 平滑的"软上限"：logit 有界性

设模型把 $p(y)$ 推向目标 $1-\epsilon+\epsilon/K$，忽略其余类差异时，真实类 logit 近似有上界：

$$z_y \lesssim \log\frac{K(1-\epsilon)+\epsilon}{\epsilon}$$

$\epsilon=0.1, K=10$ 时上界约 $\log(9.1/0.1)\approx 4.51$；而无平滑时 $z_y$ 理论上无界（实践中常见 logit > 15）。**logit 有界的好处**：① 数值更稳定（FP16 训练不容易爆）；② 输出概率分布保留"尾部概率"，不被极端 one-hot 主导。

### 4.2 与温度缩放（Temperature Scaling）的区别

| 方法 | 作用位置 | 机理 | 训练时使用 |
|------|---------|------|-----------|
| 标签平滑 | 损失函数的**目标标签** | 改目标分布，防过自信 | 是（训练期正则） |
| 温度缩放 | softmax 的**logits**（除以 $T$） | 后处理软化输出分布 | 否（推理期校准） |

两者都让输出"软化"，但一个改目标、一个改 logits；实践中可组合（蒸馏时 smoothing 小 + 温度大）。

### 4.3 平滑与模型蒸馏的关系

蒸馏损失是"student 输出 vs teacher 软标签"的 KL。若 teacher 未经平滑训练，其输出已带校准信息，student 直接学即可；再加 smoothing 相当于在"teacher 分布"和"均匀分布"之间又插一次值，分布更糊、迁移信息受损。**记忆点：smoothing 与 KD 叠加要降强度。**

### 4.4 平滑 + 难样本的交互

硬任务（如 OCR 长尾字符、细粒度物种分类）中，模型本就需要"极端自信"来区分近类。smoothing 统一压低 logit 差会**抹平类间区分度**，表现为 top-1 掉点。这类任务建议 $\epsilon$ 降到 0.05 或按类别频率自适应（focal 化平滑），而非一刀切 0.1。

## 五、优缺点

| 优点 | 缺点 |
|------|------|
| 一行参数实现，零推理开销 | 统一压低 logit 差，可能削弱细粒度区分 |
| 防过置信、改善校准（ECE 下降） | $\epsilon$ 过大（>0.3）导致欠拟合 |
| 对标注噪声鲁棒 | 对"分布外但合法"的样本会掉点（决策边界变保守） |
| 数值稳定（logit 有界，利于 FP16） | 与蒸馏/对比学习不兼容或需降强度 |
| 训练更稳、收敛更平滑 | 定义在类别分布上，无类别任务（回归/对比学习）无法直接用 |

## 六、与同类对比

| 方法 | 机制 | 是否改标签 | 主要收益 | 适用场景 |
|------|------|-----------|---------|---------|
| 标签平滑 | 软标签（对均匀分布插值） | 是 | 校准 + 防过自信 | 分类、LM、VLM 分类头 |
| 知识蒸馏 | teacher 软输出当标签 | 是 | 迁移信息、压缩 | 模型压缩、跨架构迁移 |
| 温度缩放 | 推理期软化 logits | 否 | 校准 | 部署后处理 |
| Dropout | 随机丢激活 | 否 | 泛化（防共适应） | 通用 |
| L2/weight decay | 压权重范数 | 否 | 平滑函数、防过拟合 | 通用 |

**与 Dropout 的互补性**：Dropout 防"特征共适应"，smoothing 防"输出过自信"——一个作用在隐藏层、一个作用在输出目标，可同时使用；多模态 VLM 训练常见组合：FFN dropout 0.1 + 分类头 smoothing 0.1。

## 七、高频面试问答

**Q1：Label Smoothing 的公式？为什么是 $1-\epsilon+\epsilon/K$？**
$q' = (1-\epsilon)\cdot q_{onehot} + \epsilon\cdot u$，展开即真实类 $1-\epsilon+\epsilon/K$、其余 $\epsilon/K$。它是对 one-hot 与均匀分布的插值，保证归一性（和为 1）且可微。

**Q2：为什么能防过拟合/过置信？**
one-hot 下梯度 $p(y)-1$ 永不归零，logit 差无限发散；平滑后梯度在 $p(y)$ 到达软目标 $1-\epsilon+\epsilon/K$ 时归零，logit 有界。同时错误标签可信度被压到 $\epsilon/K$，对标注噪声鲁棒。

**Q3：Transformer 默认平滑系数是多少？**
0.1（Vaswani et al. 论文明确建议）。图像分类 ResNet 系也常用 0.1。

**Q4：平滑对校准（calibration）有什么帮助？**
未平滑模型输出 0.9 的样本实际正确率可能只有 0.7（过自信）；平滑压低极端输出，让 softmax 概率与真实正确率对齐，ECE 下降、可靠性图贴近对角线。对检索阈值、VQA 置信过滤、RLHF 偏好模型重要。

**Q5：CLIP 对比学习为什么不用 label smoothing？**
对比学习目标是拉近正对、推远负对，损失定义在"相似度对"上而非类别分布上，平滑无类别可分配；且平滑会弱化负样本的推离力度。

**Q6：PyTorch 里怎么用？手写和官方等价吗？**
`F.cross_entropy(logits, labels, label_smoothing=0.1)` 一行；手写即 $-\sum q'\log p$。官方实现与该式数学等价（融合进 kernel 更快）。

**Q7：蒸馏场景为什么慎用？**
teacher 软输出本身已是软标签，再加 smoothing 双重软化，student 学到的分布更糊、信息受损。要么只用 teacher 软标签，要么 smoothing 调小并配合温度缩放。
