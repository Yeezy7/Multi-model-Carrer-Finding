# 稀疏与窗口注意力：Sliding Window、Longformer 与 Swin

> 本模块索引见 [注意力机制专题详解](注意力机制专题详解.md)

## 一、定义与公式

### 1.1 核心思想：限制每个 query 可见的 key 集合

稠密 attention 里每个 query 要跟**所有** $n$ 个 key 算分数（$O(n^2)$）。稀疏注意力人为定义每个 query 只能看部分 key（平均 $w$ 个），把复杂度降到 $O(nw)$：

$$O_i = \text{softmax}\left(\frac{q_i^\top K_{\mathcal{S}_i}}{\sqrt{d_k}}\right) V_{\mathcal{S}_i}, \qquad |\mathcal{S}_i| \approx w$$

其中 $\mathcal{S}_i$ 是 query $i$ 允许看到的 key 下标集合，由**固定模式**（pattern）决定。

### 1.2 四种典型模式

| 模式             | $\mathcal{S}_i$ 定义                               | 复杂度     | 代表                         |
| -------------- | ------------------------------------------------ | ------- | -------------------------- |
| Sliding window | $[i-w, i]$（只往前 $w$ 步）                            | $O(nw)$ | **Mistral SWA**、Longformer |
| Strided        | $\{j : j \equiv i \pmod{s}, j \le i\}$（间隔 $s$ 跳） | $O(nw)$ | Sparse Transformer（OpenAI） |
| Global         | 少数 token 看全部，全部 token 也被它们看                      | $O(nw)$ | Longformer、BigBird（[CLS]）  |
| Random         | 每层随机采 $w$ 个位置                                    | $O(nw)$ | BigBird                    |


### 1.3 Sliding Window Attention（SWA，Mistral-7B）

每个 token 只能 attend 到它前面 $W$ 个 token（causal + 窗口）：

$$\text{Attn}_i = \text{softmax}\left(\frac{Q_i K_{[i-W,\, i]}^\top}{\sqrt{d_k}}\right) V_{[i-W,\, i]}$$

**层间滚动（rolling）**：单层只能看 $W$ 步；多层堆叠后信息逐层传播，第 $l$ 层等效感受野 $O(l \cdot W)$。相邻层使用**偏移不同的窗口**（如第 $2k$ 层从 $i-W$ 起，第 $2k+1$ 层从 $i-W+W/2$ 起），让高层窗口能看到低层窗口边缘的 token——信息像传送带一样滚动传播。Mistral-7B：$W=4096$、32 层全 SWA，等效感受野远超 4096。

### 1.4 Longformer：sliding + global

大多数 token 用滑动窗口（局部建模），少数 **global token**（[CLS]、每段开头）保留全序列视野（长距离建模），弥补窗口盲区：

$$\mathcal{S}_i = \begin{cases} [0, n] & i \in \mathcal{G} \text{（global query 看全部）} \\ [i-w, i] \cup \mathcal{G} & \text{（普通 query 看窗口 + 全部 global key）} \end{cases}$$

### 1.5 Swin Transformer：窗口注意力 + 移位

视觉侧的分层窗口注意力：把 $H \times W$ 特征图切成 $\frac{HW}{w^2}$ 个 $w \times w$ 窗口，**只在窗口内做 self-attention**：

$$\text{复杂度} = \frac{HW}{w^2} \cdot O(w^4) = O(HW \cdot w^2) \ll O((HW)^2)$$

窗口间信息交换靠 **shifted window（移位窗口）**：奇数层窗口向右下移 $\lfloor w/2 \rfloor$，使原来处于窗口边界的 patch 在新的窗口里与相邻窗口的 patch 交互；配合 cyclic shift（torch.roll）+ 掩码实现，等价于"窗口平移但计算量不变"。

## 二、核心原理

### 2.1 为什么稀疏模式能省计算

稠密 attention 的 $n^2$ 项里，绝大多数分数对最终输出贡献极小（softmax 会把注意力预算集中到少数 key）。稀疏模式用**先验知识**（局部性：相邻 token 最相关；全局性：少数 token 承载全局信息）直接砍掉低价值边。

### 2.2 局部性与全局性互补

- **局部性**：语言中相邻词依赖最强（句法、短语），视觉中相邻 patch 最相关 → 窗口模式；
- **全局性**：长距离依赖（指代、全局主题）需要全视野 → global token / 大窗口的深层；
- 实践经验：纯窗口有盲区，**sliding + global**（Longformer/BigBird）与**层间滚动**（Mistral）都是对盲区的补救。

### 2.3 为什么大模型最终不用手工稀疏（面试高频）

1. **硬件不友好**：不规则/跳跃的访问模式无法映射到 Tensor Core 的稠密 GEMM，理论提速实现不了；
2. **实现复杂**：每个 pattern 要专门写 kernel，且与 FlashAttention 的分块优化冲突；
3. **质量损失**：启发式固定模式会漏掉窗口外的长程依赖，训练困惑度更高；
4. **FlashAttention 崛起**：dense 的 $O(n^2)$ 显存问题被分块解决后，dense 在可达长度内更优；
5. **更好的方向出现**：线性注意力 / 状态空间模型（Mamba）或 KV 压缩（MLA）。

## 三、源码实现

### 3.1 基础：带掩码的缩放点积注意力

```python
import math
import torch

def sdpa(q, k, v, attn_mask=None):
    """attn_mask: 与分数同形状的 bool 掩码，True 的位置保留，False 的位置置 -inf"""
    d = q.shape[-1]
    scores = (q @ k.transpose(-2, -1)) / math.sqrt(d)   # [..., n_q, n_k]
    if attn_mask is not None:
        scores = scores.masked_fill(~attn_mask, float('-inf'))
    return torch.softmax(scores, dim=-1) @ v
```

### 3.2 Sliding Window：掩码版（直观）与循环版（O(nW)）

```python
def sliding_mask(n, W):
    """causal + 窗口：query i 只保留 key j ∈ [i-W, i]"""
    i = torch.arange(n)
    diff = i[None, :] - i[:, None]                       # j - i
    return (diff <= 0) & (diff >= -W)                    # -W ≤ j-i ≤ 0 ⇔ i-W ≤ j ≤ i

def sliding_window_attention(x, W):
    """掩码实现：正确且直观，但掩码矩阵仍是 n×n（只用于验证/教学）"""
    B, n, d = x.shape
    return sdpa(x, x, x, attn_mask=sliding_mask(n, W).to(x.device))

def sliding_window_loop(x, W):
    """真正 O(nW)：每个 query 只取窗口内的 key，不构造 n×n 掩码"""
    B, n, d = x.shape
    out = torch.empty_like(x)
    for i in range(n):                                   # 串行演示；GPU 上可并行
        lo = max(0, i - W)
        k_i = x[:, lo:i+1]                               # [B, W+1, d]（首行更短）
        scores = (x[:, i:i+1] @ k_i.transpose(-2, -1)) / math.sqrt(d)
        out[:, i:i+1] = torch.softmax(scores, dim=-1) @ k_i
    return out

torch.manual_seed(0)
x = torch.randn(2, 64, 32)
y1 = sliding_window_attention(x, W=8)
y2 = sliding_window_loop(x, W=8)
print(torch.allclose(y1, y2, atol=1e-6))                 # True：两种实现一致
```

### 3.3 Strided 与 Longformer（sliding + global）

```python
def strided_attention(x, stride=16):
    """query i 只看 j ≡ i (mod stride) 且 j ≤ i 的 key"""
    n = x.shape[1]
    i = torch.arange(n)
    mask = ((i[:, None] - i[None, :]) % stride == 0) & (i[None, :] <= i[:, None])
    return sdpa(x, x, x, attn_mask=mask)

def longformer_attention(x, W, global_idx):
    """sliding + global：普通 query 看窗口+全部 global key；global query 看全部"""
    n = x.shape[1]
    i = torch.arange(n)
    window = ((i[:, None] - i[None, :]) >= -W) & (i[None, :] <= i[:, None])  # causal 窗口
    is_global = torch.zeros(n, dtype=torch.bool); is_global[global_idx] = True
    mask = window | is_global[None, :] | (is_global[:, None] & (i[None, :] <= i[:, None]))
    # ↑ 窗口边 + global key 所有人都能看 + global query 看全部（含 causal）
    return sdpa(x, x, x, attn_mask=mask)

x = torch.randn(1, 32, 16)
print(longformer_attention(x, W=4, global_idx=[0]).shape)          # [1, 32, 16]
print(sliding_window_attention(x, W=4).shape)                      # [1, 32, 16]
```

### 3.4 Swin：窗口划分 / 还原 / 移位窗口注意力

```python
def window_partition(x, ws):
    """x: [B, H, W, C] → [B*(H/ws)*(W/ws), ws*ws, C]（每个窗口一行）"""
    B, H, W, C = x.shape
    x = x.view(B, H // ws, ws, W // ws, ws, C)
    x = x.permute(0, 1, 3, 2, 4, 5).contiguous()
    return x.view(-1, ws * ws, C)

def window_reverse(windows, ws, H, W):
    Bn, _, C = windows.shape
    B = Bn // ((H // ws) * (W // ws))
    x = windows.view(B, H // ws, W // ws, ws, ws, C)
    x = x.permute(0, 1, 3, 2, 4, 5).contiguous()
    return x.view(B, H, W, C)

def shift_window_attn_mask(H, W, ws, shift):
    """移位后窗口内的相对位置掩码：同一原始窗口内为 0，跨窗口为 -inf"""
    img_mask = torch.zeros(H, W)
    slices = (slice(0, -ws), slice(-ws, -shift), slice(-shift, None))
    cnt = 0
    for hs in slices:
        for ws_ in slices:
            img_mask[hs, ws_] = cnt; cnt += 1
    mask_windows = window_partition(img_mask.unsqueeze(0).unsqueeze(-1), ws).squeeze(-1)
    attn_mask = mask_windows.unsqueeze(1) - mask_windows.unsqueeze(2)  # [nw, ws², ws²]
    return attn_mask.masked_fill(attn_mask != 0, float('-inf'))

def swin_window_attention(x, ws, shift=0):
    """简化版 Swin 窗口注意力（用特征本身作 Q/K/V，省略投影；重点看窗口机制）"""
    B, H, W, C = x.shape
    if shift > 0:
        x = torch.roll(x, shifts=(-shift, -shift), dims=(1, 2))       # cyclic shift
        attn_mask = shift_window_attn_mask(H, W, ws, shift)
    else:
        attn_mask = None
    windows = window_partition(x, ws)                                # [nw, ws², C]
    scores = (windows @ windows.transpose(-2, -1)) / math.sqrt(C)    # 窗口内自注意力
    if attn_mask is not None:
        scores = scores + attn_mask.to(scores.device)                # 屏蔽跨窗口位置（同形状广播）
    out = torch.softmax(scores, dim=-1) @ windows
    out = window_reverse(out, ws, H, W)
    if shift > 0:
        out = torch.roll(out, shifts=(shift, shift), dims=(1, 2))    # 还原
    return out

torch.manual_seed(0)
x = torch.randn(1, 8, 8, 32)                     # 8×8 特征图，窗口 4×4
y = swin_window_attention(x, ws=4, shift=2)
print(y.shape)                                   # [1, 8, 8, 32]
# 对比：移位前后输出不同（信息在窗口间流动），但计算量完全相同
```

## 四、复杂度与显存分析

### 4.1 数值示例：n=8192 时各模式的花费（相对稠密）

| 模式 | 分数数量 | 相对稠密 | KV cache |
|------|---------|---------|----------|
| 稠密 | $8192^2 \approx 67$M | 100% | $O(n)$ |
| SWA（W=1024） | $8192 \times 1024 \approx 8.4$M | 12.5% | $O(W)$ 每层 |
| Longformer（W=512 + 全局） | $\approx 8192 \times 512$ | ~6% | $O(W + g)$ |
| Strided（s=32） | $8192 \times 256$ | ~3% | $O(n)$（不省） |

**重要误区**：稀疏注意力省的是**计算量**；**KV cache 不省**（窗口内历史照样要存，strided 甚至要存全部）。省 KV cache 的是 GQA/MQA/MLA。

### 4.2 Swin 的复杂度

$H \times W$ 特征图、窗口 $w \times w$：窗口数 $\frac{HW}{w^2}$，每个窗口内 $w^2$ 个 token 的 self-attention 是 $O(w^4)$：

$$O\left(\frac{HW}{w^2} \cdot w^4\right) = O(HW \cdot w^2)$$

- $w=7$（Swin 默认）：$49 \times$ 常数，**与 token 总数线性**，远小于全局的 $O(H^2W^2)$；
- shifted window 不增加复杂度（cyclic shift + 掩码是 $O(HW)$ 的轻量操作）。

### 4.3 Mistral-7B 的账

$W=4096$、32 层：单层计算量 $O(n \cdot 4096)$ 而非 $O(n^2)$；每层 KV cache $O(4096)$（配合 GQA 再省 head 维度）；等效感受野 $32 \times 4096 = 131072$（理论上限）。SWA 与 GQA 正交叠加，是"推理友好"与"计算友好"的典型组合。

## 五、优缺点

| 优点                                | 缺点                              |
| --------------------------------- | ------------------------------- |
| 复杂度 $O(n^2) \to O(nw)$，长文本/高分辨率可行 | 固定启发式模式，窗口外的长程依赖完全丢失            |
| 局部先验贴合语言/视觉的局部性                   | 不规则访问模式，Tensor Core 利用率低，实际加速打折 |
| 窗口机制天然适合 2D 图像（Swin 分层）           | 每层模式固定，无法按内容自适应                 |
| 配合层间滚动（Mistral）可扩大等效感受野           | 与 FlashAttention 分块优化冲突，工程复杂    |
| 训练时精度无损（只是剪边，非近似）                 | 质量普遍低于 dense（困惑度更高）             |

| 维度 | 稀疏/窗口 | FlashAttention | 线性注意力 |
|------|----------|---------------|-----------|
| 解决的问题 | $O(n^2)$ 计算量 | $O(n^2)$ 显存与访存 | $O(n^2)$ 计算量 |

| 组合关系 | 与 FlashAttention 冲突 | — | 与二者正交 |

## 七、高频面试问答

**Q1：Sliding Window Attention 的原理？**
每个 query 只 attend 到前面 $W$ 个 key（causal + 窗口），复杂度从 $O(n^2)$ 降到 $O(nW)$。单层只能看 $W$ 步，但多层堆叠后等效感受野达 $O(L \cdot W)$，配合层间窗口滚动（rolling），信息逐层传播，Mistral-7B 用 $W=4096$ 的 32 层 SWA。

**Q2：Longformer 怎么弥补窗口盲区？**
sliding + global：普通 token 用滑动窗口看局部，[CLS] 等少数 global token 保留全序列视野，且所有 token 都能被 global token 看到——局部与全局互补，复杂度仍是 $O(nw)$。

**Q3：Swin 的 shifted window 解决什么问题？**
窗口注意力让 patch 只能与同窗口内交互，**窗口之间无信息流动**（等效感受野被锁死在窗口大小）。shifted window 把窗口移位 $\lfloor w/2 \rfloor$，下一层里原窗口边界的 patch 得以与相邻窗口交互；用 cyclic shift + 掩码实现，计算量不变。两层窗口交替堆叠即可覆盖全图。

**Q4：为什么大模型主流不用稀疏注意力？**
① 不规则访问不匹配 Tensor Core 稠密 GEMM，理论提速实现不了；② 启发式固定模式漏长程依赖，质量下降；③ FlashAttention 已解决 dense 的显存/访存瓶颈；④ 稀疏**不省 KV cache**，而推理真正的瓶颈正是 KV cache（要靠 GQA/MLA）。

**Q5：稀疏注意力和 GQA 的关系？**
正交但分工不同：稀疏（SWA）省的是**训练/前向的计算量**（砍 $QK^\top$ 的边数）；GQA 省的是**推理的 KV cache 显存与带宽**。Mistral 同时使用两者，互不影响。

**Q6：SWA 的 KV cache 是 O(W) 还是 O(n)？**
每层是 $O(W)$（窗口外历史无需缓存），但多层仍是 $O(L \cdot W)$；相比稠密 causal 的 $O(L \cdot n)$ 有节省。但注意 strided/random 模式**不省** KV cache——省 cache 一定要靠共享/压缩 KV。

**Q7：Swin 和 ViT 的复杂度差异？**
ViT 全局 attention 是 $O((HW)^2)$；Swin 窗口内是 $O(\frac{HW}{w^2} \cdot w^4) = O(HW \cdot w^2)$，与 token 数线性（$w=7$ 时常数 49）。代价是跨窗口交互需要 shifted window 交替，且没有真正的全局视野。
