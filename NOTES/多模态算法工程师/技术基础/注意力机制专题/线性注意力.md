# 线性注意力：Performer 与核方法近似

> 本模块索引见 [注意力机制专题详解](注意力机制专题详解.md)

## 一、定义与公式

### 1.1 问题：softmax 的点积核无法换序

标准注意力：

$$\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

逐行写出（先忽略缩放，注意力权重矩阵为 $A$）：

$$O_i = \frac{\sum_j e^{q_i^\top k_j} \cdot v_j}{\sum_j e^{q_i^\top k_j}}$$

若把分子记为 $A_{ij} = e^{q_i^\top k_j}$（softmax 的未归一化核），矩阵形式为：

$$O = D^{-1} (A V), \qquad D = \text{diag}(A \mathbf{1}_n)$$

问题在于：**必须先构造 $n \times n$ 的 $A$ 才能做 $AV$**，复杂度 $O(n^2 d)$。如果能把核拆成两个特征向量的内积 $A_{ij} = \phi(q_i)^\top \phi(k_j)$，就可以交换结合顺序，先算 $K^\top V$：

$$O = D^{-1} \left(\phi(Q) \left(\phi(K)^\top V\right)\right)$$

复杂度从 $O(n^2 d)$ 降为 $O(n m d)$（$m$ 为特征维度）——这就是**线性注意力**的通用思想（Katharopoulos et al., 2020 首创，Performer 给出严格近似的版本）。

### 1.2 Performer：FAVOR+ 随机特征（含推导）

目标：找到 $\phi$ 使得 $e^{q^\top k} \approx \phi(q)^\top \phi(k)$。

**关键恒等式（高斯分布的矩生成函数/特征函数）**：

$$\mathbb{E}_{\omega \sim \mathcal{N}(0, I_d)}\left[\cos\left(\omega^\top (q - k)\right)\right] = e^{-\frac{\|q-k\|^2}{2}}$$

**推导**：$\omega^\top(q-k) \sim \mathcal{N}(0, \|q-k\|^2)$，而零均值高斯 $X$ 的矩生成函数 $\mathbb{E}[e^{itX}] = e^{-\text{Var}(X)/2}$（这里取实部）：

$$\mathbb{E}[\cos(\omega^\top(q-k))] = \mathbb{E}[e^{i\omega^\top(q-k)}] = e^{-\frac{\|q-k\|^2}{2}}$$

**第二步**：把 $e^{q^\top k}$ 写成三项积：

$$e^{q^\top k} = e^{\frac{\|q\|^2 + \|k\|^2 - \|q-k\|^2}{2}} = e^{\frac{\|q\|^2}{2}} \cdot e^{-\frac{\|q-k\|^2}{2}} \cdot e^{\frac{\|k\|^2}{2}}$$

**第三步**：用期望的无偏估计替换中间项，并展开余弦：

$$e^{q^\top k} \approx e^{\frac{\|q\|^2}{2}} \cdot \frac{1}{m} \sum_{t=1}^{m} \cos\left(\omega_t^\top (q-k)\right) \cdot e^{\frac{\|k\|^2}{2}}$$

$$= \frac{1}{m} e^{\frac{\|q\|^2}{2}} e^{\frac{\|k\|^2}{2}} \sum_{t=1}^{m} \left[\cos(\omega_t^\top q)\cos(\omega_t^\top k) + \sin(\omega_t^\top q)\sin(\omega_t^\top k)\right]$$

**第四步**：定义正随机特征（保证 $\phi(q)^\top \phi(k) \ge 0$，所以叫 FAVOR+ 的 positive）：

$$\phi(x) = \frac{1}{\sqrt{m}} \cdot e^{\frac{\|x\|^2}{2}} \cdot \left[\sin(\omega_1^\top x),\; \cos(\omega_1^\top x),\; \dots,\; \sin(\omega_m^\top x),\; \cos(\omega_m^\top x)\right] \in \mathbb{R}^{2m}$$

于是得到核近似：

$$e^{q^\top k} \approx \mathbb{E}_\omega\left[\phi(q)^\top \phi(k)\right]$$

$\omega_t \sim \mathcal{N}(0, I_d)$ 是随机投影，$m$ 是特征维度（蒙特卡洛估计，误差 $\sim O(1/\sqrt{m})$）。为提高精度可用**正交化**的 $\omega$（把随机高斯矩阵 QR 分解取 Q）降低方差。

### 1.3 线性化后的完整公式

$$O = D^{-1} \left[\phi(Q) \left(\phi(K)^\top V\right)\right], \qquad D = \text{diag}\left(\phi(Q) \left(\phi(K)^\top \mathbf{1}_n\right)\right)$$

计算顺序（关键）：先算 $\phi(K)^\top V \in \mathbb{R}^{2m \times d}$，再左乘 $\phi(Q) \in \mathbb{R}^{n \times 2m}$：

$$\underbrace{\phi(K)^\top V}_{O(n m d)} \quad \to \quad \underbrace{\phi(Q) \cdot (\cdots)}_{O(n m d)}$$

总复杂度 $O(n m d)$。取 $m = O(d)$ 时即 $O(n d^2)$，**与 $n$ 线性**。

## 二、核心原理

### 2.1 结合顺序的交换（为什么能线性）

标准做法 $QK^\top$（先算 $n \times n$）→ softmax → $\times V$；线性做法把核函数换成内积后，利用矩阵乘法的结合律把 $K$ 和 $V$ 先乘起来：

$$\phi(Q) \left(\phi(K)^\top V\right) = \left(\phi(Q)\phi(K)^\top\right) V$$

左边只产生 $2m \times d$ 的中间量，右边产生 $n \times n$——**"先 $K^\top V$"是省算力的全部秘密**。代价是**不再有逐行的 softmax 归一化**，改为全局分母 $D$（这改变了分布的性质，见优缺点）。

### 2.2 核视角下的注意力家族

| 方法 | 核 $A_{ij}$ | 近似/精确 |
|------|------------|----------|
| 标准 softmax | $e^{q^\top k}$（softmax 归一化） | 精确 |
| Performer | $\phi(q)^\top \phi(k)$（随机特征） | 蒙特卡洛近似 |
| Linear Transformer | $1 + \text{elu}(q^\top k)$ 或 $\text{relu}$ 特征 | 启发式 |
| cosFormer | 余弦重加权特征 | 启发式 |

### 2.3 为什么效果有损失（三个原因）

1. **核近似误差**：蒙特卡洛估计误差 $\sim O(1/\sqrt{m})$，$m$ 越大越贵，精度有天然上限；
2. **注意力分布失去尖锐性**：线性化把"先点积再归一化"变成"线性平均再整体归一化"，难以表达 one-hot 式尖锐注意力，对**精确拷贝/检索/翻译**类任务明显退化；
3. **数值不稳定**：$e^{q^\top k}$ 的指数增长难以被有限维随机特征稳定捕捉，长序列训练时方差大。

## 三、源码实现

### 3.1 手写 FAVOR+ 特征映射与线性注意力

```python
import math
import torch

def feature_map(x, omega):
    """FAVOR+ 正随机特征 φ(x) ∈ R^{2m}（m = omega 的行数）"""
    m = omega.shape[0]
    proj = x @ omega.T                                   # [n, m]：随机投影
    feat = torch.cat([torch.sin(proj), torch.cos(proj)], dim=-1)          # [n, 2m]
    feat = feat * torch.exp(0.5 * (x ** 2).sum(-1, keepdim=True))         # e^{||x||²/2}
    return feat / math.sqrt(m)                            # 1/√m 归一化

def linear_attention(Q, K, V, omega):
    """Performer 线性注意力：先 φ(K)ᵀV 再左乘 φ(Q)，全程不出现 n×n 矩阵"""
    phi_q = feature_map(Q, omega)                         # [n, 2m]
    phi_k = feature_map(K, omega)                         # [n, 2m]
    KV = phi_k.transpose(-2, -1) @ V                      # [2m, d] ← 关键一步
    O = phi_q @ KV                                        # [n, d]
    D = phi_q @ phi_k.sum(dim=-2, keepdim=True).transpose(-2, -1)   # [n, 1]
    return O / D
```

### 3.2 与标准 attention 对比（近似误差 vs m）

```python
def standard_attention(Q, K, V):
    S = Q @ K.transpose(-2, -1) / math.sqrt(K.shape[-1])
    P = torch.softmax(S, dim=-1)
    return P @ V

torch.manual_seed(0)
n, d = 256, 16
# 注意：Q/K 做 L2 归一化（Performer 实验的常见做法）。否则 ||q-k||² 很大，
# 核信号 e^{-||q-k||²/2} 接近 0，会被随机特征的 O(1/√m) 噪声完全淹没，
# 蒙特卡洛估计退化为纯噪声——这也是线性注意力数值不稳定的根源之一。
Q = torch.nn.functional.normalize(torch.randn(n, d), dim=-1)
K = torch.nn.functional.normalize(torch.randn(n, d), dim=-1)
V = torch.randn(n, d)
O_ref = standard_attention(Q, K, V)

print(f"{'m':>5} {'输出相对误差':>12} {'核相关系数':>12}")
for m in (8, 32, 128, 512, 2048):
    omega = torch.randn(m, d)                        # 随机高斯投影
    O_lin = linear_attention(Q, K, V, omega)
    rel_err = (O_lin - O_ref).norm() / O_ref.norm()
    # 核近似质量：φ(q)·φ(k) 与 e^{q·k} 的相关系数
    kern = feature_map(Q, omega) @ feature_map(K, omega).T
    corr = torch.corrcoef(torch.stack(
        [kern.flatten(), torch.exp(Q @ K.T).flatten()]))[0, 1].item()
    print(f"{m:>5} {rel_err:12.4f} {corr:12.4f}")
```

```python
#    32          0.2480        0.6970

#   512          0.1490        0.9620

# ② 但注意力输出误差在 ~0.15 处封顶——分母 D 的估计误差 + 归一化后

```

### 3.3 验证"先 KᵀV"与"先 QKᵀ"数学等价

```python
torch.manual_seed(1)
n, d, m = 64, 16, 32
Q = torch.nn.functional.normalize(torch.randn(n, d), dim=-1)
K = torch.nn.functional.normalize(torch.randn(n, d), dim=-1)
V = torch.randn(n, d)
omega = torch.randn(m, d)

phi_q = feature_map(Q, omega)          # [n, 2m]
phi_k = feature_map(K, omega)          # [n, 2m]

left  = phi_q @ (phi_k.transpose(-2, -1) @ V)   # 先 KᵀV：O(nmd)，显存 O(md)
right = (phi_q @ phi_k.transpose(-2, -1)) @ V   # 先 QKᵀ：O(n²m)，显存 O(n²)

print(torch.allclose(left, right, atol=1e-4))   # True：结合律保证（FP32 舍入误差 ~1e-5）
# 输出：True  left 中间量: torch.Size([64, 16])  right 中间量: n×n
print("left 中间量:", (phi_k.transpose(-2, -1) @ V).shape, "| right 中间量: n×n")
# left 中间量: torch.Size([64, 16]) | right 中间量: n×n
```

### 3.4 可运行的最简演示（n=512, 误差量级）

```python
torch.manual_seed(2)
n, d, m = 512, 32, 256
Q = torch.nn.functional.normalize(torch.randn(n, d), dim=-1)
K = torch.nn.functional.normalize(torch.randn(n, d), dim=-1)
V = torch.randn(n, d)
omega = torch.randn(m, d)

O_ref = standard_attention(Q, K, V)
O_lin = linear_attention(Q, K, V, omega)
print(f"相对误差: {(O_lin - O_ref).norm() / O_ref.norm():.4f}")   # m=256 时约 0.1~0.2
```

## 四、复杂度与显存分析

### 4.1 计算量对比

| 步骤 | 标准 attention | 线性注意力（m=d） |
|------|---------------|-------------------|
| $QK^\top$ | $O(n^2 d)$ | — |
| 特征映射 | — | $O(n d m) = O(n d^2)$ |
| $\phi(K)^\top V$ | — | $O(n m d) = O(n d^2)$ |
| $\phi(Q)(\cdots)$ | — | $O(n m d) = O(n d^2)$ |
| $PV$ | $O(n^2 d)$ | — |
| **合计** | $O(n^2 d)$ | $O(n d^2)$ |
| **中间显存** | $O(n^2)$（S、P 落盘） | $O(n m + m d)$ |

### 4.2 数值示例（d=128, m=256, n=8192, FP16）

- 标准：$QK^\top$ 与 $PV$ 共约 $2 \times 8192^2 \times 128 \times 2 \times 2 \approx 6.9$ TFLOPs；S 矩阵 $8192^2 \times 2$ B $= 134$ MB（每 batch 每头）；
- 线性：$2nmd$ MACs $= 2 \times 8192 \times 256 \times 128 \approx 0.54$ GFLOPs ×2（两处矩阵乘）≈ 1.1 GFLOPs 量级，**比标准低三个数量级**；中间量只有 $256 \times 128$；
- 但注意：线性注意力的实现是**两个小矩阵乘**，GPU 上无法用大 GEMM 吃满 Tensor Core；且 $m$ 常要取 $> d$ 才能保精度，实际墙钟加速远小于理论比值。

### 4.3 长序列下的定位

- $n \le 4096$：FlashAttention（精确 + 快）完胜，线性注意力无优势；
- $n \ge 32K$：线性注意力的 $O(n)$ 复杂度开始占优，但精度损失和数值稳定性是代价；
- 后续路线：状态空间模型（Mamba）、门控线性 RNN（RWKV）用更工程化的方式实现"线性建模序列"，基本取代了 Performer。

## 五、优缺点

| 优点 | 缺点 |
|------|------|
| 复杂度 $O(n^2) \to O(n)$，超长序列唯一可选 | 核近似误差 $\sim O(1/\sqrt{m})$，精度有上限 |
| 中间显存 $O(n^2) \to O(nm)$ | 注意力分布不尖锐，拷贝/检索/算术任务退化 |
| 理论 FLOPS 大幅下降 | 小矩阵乘无法利用 Tensor Core，实际加速打折 |
| 数学推导优雅（核方法 + 随机特征） | 长序列训练数值不稳；被 Mamba/RWKV 取代 |
| 天然支持流式/增量推理（KV 可累加） | 与 KV cache 优化（GQA/MLA）正交但配合复杂 |

## 六、与同类对比

| 维度 | 标准（FlashAttention） | Performer | 稀疏注意力 |
|------|----------------------|-----------|-----------|
| 复杂度 | $O(n^2 d)$ | $O(n d^2)$ | $O(n w)$ |
| 显存 | $O(n)$（Flash 优化后） | $O(nm)$ | $O(nw)$ |
| 近似性 | 精确 | **近似**（随机特征） | 精确但剪边 |
| 质量 | 基准 | 检索/拷贝退化明显 | 长程依赖丢失 |
| 硬件友好 | 极好（大 GEMM） | 差（小矩阵乘） | 差（不规则访问） |
| 适用 | 通用 | 理论上的超长序列 | 局部依赖强的任务（长文、图） |
| 现状 | 事实标准 | 基本退场 | 局部沿用（SWA 等） |

## 七、高频面试问答

**Q1：线性注意力为什么能到 O(n)？**
把 softmax 的指数核近似成特征内积 $e^{q^\top k} \approx \phi(q)^\top\phi(k)$，然后用矩阵乘法结合律**先算 $\phi(K)^\top V$（$2m \times d$）再左乘 $\phi(Q)$**，全程不构造 $n\times n$ 矩阵，复杂度 $O(n m d)$，取 $m=O(d)$ 即线性于 $n$。

**Q2：FAVOR+ 的 φ 为什么能近似 softmax 核？**
用高斯特征函数恒等式 $\mathbb{E}_\omega[\cos(\omega^\top(q-k))] = e^{-\|q-k\|^2/2}$，把 $e^{q^\top k} = e^{\|q\|^2/2}e^{-\|q-k\|^2/2}e^{\|k\|^2/2}$ 的中间项用蒙特卡洛估计替换，得到 $\phi(x) = \frac{1}{\sqrt m}e^{\|x\|^2/2}[\sin, \cos]$，使 $e^{q^\top k} \approx \mathbb{E}[\phi(q)^\top\phi(k)]$。

**Q3：为什么 Performer 效果不如标准 attention？**
① 随机特征误差 $O(1/\sqrt m)$；② 去掉逐行 softmax 后分布不尖锐，无法做精确检索/拷贝；③ 指数核动态范围大，有限维特征难以稳定捕捉。本质是"用近似换线性"。

**Q4：线性注意力为什么没有成为大模型标配？**
① 精度损失在检索类任务不可接受；② 小矩阵乘不匹配 Tensor Core，实际加速远小于理论；③ FlashAttention 把精确 attention 的 $n^2$ 显存问题解决后，dense 在可达长度内更优；④ Mamba/RWKV 以更成熟的方式解决了线性序列建模。

**Q5：标准 attention 和线性 attention 的归一化有什么本质区别？**
标准是**逐行** softmax（每行权重和为 1，分布尖锐）；线性化后分母 $D$ 是全局统一的 $\phi(Q)\phi(K)^\top \mathbf{1}$，相当于"非归一化核的线性平均"，丢失了行内竞争（每个 query 必须争抢有限的注意力预算），这是表达能力下降的数学根源。

**Q6：Performer 和 FlashAttention 谁更快？**
看序列长度。短序列 FlashAttention 完胜（精确且硬件友好）；超长序列（$n$ 极大）Performer 的 $O(n)$ 复杂度理论上占优，但受制于小矩阵乘与精度问题，实际部署很少。工程上"先 FlashAttention，不够再想线性"。

**Q7：正交随机特征（orthogonal features）是什么？**
普通随机特征方差大，精度差；把随机高斯矩阵 $\Omega \in \mathbb{R}^{m \times d}$ 做 QR 分解取 $Q$ 矩阵，各 $\omega$ 互相正交，降低了特征间的相关性/方差，同 $m$ 下近似更准（Performer 论文的核心贡献之一）。
