# 校准算法：激活量化前，先给数据"量一遍体温"

> 本模块索引见 [量化详解](量化详解.md)

激活量化不能像权重量化那样"扫一遍参数就完事"——激活的值依赖输入，必须先喂一批代表性数据，统计出激活分布，再据此定 scale/zero point。这一步就叫**校准（Calibration）**。本文讲清校准是什么、三种主流校准算法（MinMax / KL / Percentile）的原理与取舍，以及让激活也能 INT8 的 SmoothQuant。

## 一、什么是校准

**校准 = 用校准集（calibration set）统计激活的分布，从而确定量化参数 $s$（scale）与 $z$（zero point）。**

- 把模型在 FP32/FP16 下跑一遍校准集，在各层"钩子"处采集激活张量；
- 对每个要量化的张量，统计它的数值范围/分布 → 算出 $s$（和 $z$）；
- 之后模型正式部署时，就用这套固定的 $s$/$z$ 做静态量化（static quantization）。

### 1.1 为什么权重不用校准、激活要校准

| | 权重 | 激活 |
| --- | --- | --- |
| 值的来源 | 训练收敛后的固定参数 | 输入数据过模型产生的中间量 |
| 是否依赖输入 | 否，一次训练定终身 | 是，换输入就变 |
| 范围能否离线精确得知 | 能，扫一遍参数即可 | 不能，必须采样估计 |
| 量化参数怎么定 | 直接算 min/max | 校准集统计 + 校准算法 |
| 离群风险 | 低（分布平滑） | 高（个别通道/个别 token 会很大） |

一句话：**权重是"常量"，直接量；激活是"变量"，先统计再量**。这也是 LLM 部署常"只量化权重"的原因之一——省掉校准这一整步（详见 [量化详解](量化详解.md) 第三节）。

### 1.2 校准与动态量化的区别

- **动态量化**：运行时每个 batch 现场算 min/max 再量化，无校准，但每层都多一次归约开销；
- **静态量化**：校准期定好 $s$/$z$，推理时直接用（只做整数运算 + 少量反量化），快但依赖校准集代表性。

## 二、三种校准算法（核心）

校准的核心矛盾来自 [量化数学基础](量化数学基础.md) 第五节：**量化范围选大了，小值被粗步长伤到；选小了，离群点被截断**。三种算法代表三种解法。

### 2.1 MinMax：直接取观测最小/最大值

$$r_{peak} = \max_i |r_i|, \qquad s = \frac{r_{peak}}{q_{max}}$$

- 做法：统计激活张量的绝对最大值，作为量化范围；
- **优点**：零超参数、零假设、实现最简单、绝不截断任何观测值；
- **缺点**：对离群点极度敏感——**一个极端值就把整个量化范围撑大**，主体小值全部被粗步长稀释。

### 2.2 Entropy（KL 散度）：TensorRT 默认

思路：**找一个阈值 $t$，使"原始激活分布"与"量化后分布"的 KL 散度最小**——既想覆盖足够多主体，又不想被离群点撑大范围。

流程（TensorRT 熵校准）：

```
1. 对激活张量做直方图（如 1024 个 bin），得真实分布 P
2. 对每个候选阈值（第 i 个 bin 对应的值）：
   a. 参考分布 P_ref = 直方图[0:i]，把阈值外的尾部折叠进最后一个 bin
   b. 把 [0, i] 内的分布量化成 128 个 level，再展开回直方图，得 Q
   c. 计算 KL(P_ref || Q)
3. 选 KL 最小的阈值 t，s = t / qmax
```

$$t^* = \arg\min_{t} \ KL\big(P_{\text{ref}}(t) \,\|\, Q_{\text{quant}}(t)\big), \qquad KL(P\|Q) = \sum_i P_i \log \frac{P_i}{Q_i}$$

- **优点**：信息论最优——在"截断离群"与"保护主体"之间自动找平衡，多数情况精度最好，因此是 TensorRT 的默认算法；
- **缺点**：需要直方图与逐阈值搜索（计算稍重）；离群点极稀疏时可能退化为 MinMax（离群质量太小，对 KL 无影响）。

### 2.3 Percentile：取 99.99% 分位

$$t = \text{quantile}_{p}(|r|), \qquad p \approx 99.9\% \sim 99.99\%, \qquad s = \frac{t}{q_{max}}$$

- 做法：取激活绝对值的 $p$ 分位作为量化范围，直接**放弃最极端的 $1-p$ 数据**；
- **优点**：对离群点鲁棒、超参数直观（"容忍 0.01% 的截断"）、实现极简；
- **缺点**：$p$ 是拍脑袋定的，不保证信息最优；截断掉的极端值在推理中真出现时误差不可控（对部署场景的"罕见大激活"有风险）。

### 2.4 对比表

| 算法 | 复杂度 | 对离群鲁棒性 | 精度 | 适用场景 | 代表使用方 |
| --- | --- | --- | --- | --- | --- |
| MinMax | 极低（一次归约） | 差（一个极端值毁所有） | 有离群时差 | 分布干净的小模型、快速验证 | 简单 PTQ 工具 |
| Entropy(KL) | 中（直方图+搜索） | 好（自动权衡） | 通常最好 | 视觉/LLM 通用部署 | TensorRT（默认） |
| Percentile | 低（一次分位数） | 好（直接排除尾部） | 好但依赖 p 选择 | 重尾分布、离线鲁棒场景 | PyTorch、OpenVINO 等 |

**工程建议**：默认先试 MinMax；若精度不达标，换 KL（TensorRT 默认）或 Percentile(99.99%)，并结合校准集设计（第三节）改善。

## 三、校准集设计

校准算法的结果上限由校准集决定——**校准集不代表性，再好的算法也白搭**。

### 3.1 选择原则

1. **覆盖各类输入**：不同类别、不同难度、不同模态的样本都要有；不能只喂"简单样本"，否则激活范围被低估，部署时真实输入激活超出范围被截断；
2. **数量几百~几千即可**：激活分布统计到一定程度后边际收益递减，一般 256~2048 张图片 / 数千条文本足够；
3. **避免单一分布**：例如全用纯白背景图或全用短文本，会导致统计偏差；
4. **与部署场景一致**：校准数据的来源分布应尽量贴近真实部署输入分布。

### 3.2 多模态模型的校准集

- 要**同时覆盖图文分布**：纯文本、单图、多图、图文混合样本都要有；
- 视觉侧激活与文本侧激活尺度差异大（视觉 token 数量多、数值分布不同），校准要分别统计各子模块（视觉塔、投影层、LLM 主干）；
- 跨模态对齐层（如 Q-former、投影层）对激活范围敏感，校准样本里应包含难样本（模糊图、小物体、长文本）来覆盖极端激活。

### 3.3 校准的常见坑

- 校准集太小 → 低估范围 → 上线后截断错误；
- 校准集与部署分布漂移（domain shift）→ scale 失配；
- 用训练集校准而训练集分布 ≠ 真实分布；
- 批归一化/BatchNorm 层在 FP32 前向与量化推理时的行为差异（BN 折叠问题）。

## 四、SmoothQuant：让激活也能 INT8

### 4.1 问题：激活的离群点把范围撑爆

LLM/多模态模型的激活存在**系统性离群通道（outlier channels）**：少数通道的值整体远大于其它通道（可大到 100 倍）。后果：

- 校准出的 $s$ 被离群通道撑大 → 其余通道的激活被粗步长稀释；
- 激活只能 per-tensor（[量化数学基础](量化数学基础.md) 第三节）→ 无法像权重那样按通道单独救；
- 结果：激活 INT8 精度崩，只能退而求其次留 FP16。

### 4.2 核心思想：把激活的难度迁移到权重

直觉：离群难在激活（per-tensor 限制）而不难在权重（per-channel 可以）。那就**用一个数学恒等变换，把激活的离群"转移"到权重上**：

$$Y = XW = \big(X \cdot \text{diag}(s)\big)\big(\text{diag}(s)^{-1} W\big)$$

- $X$ 逐通道乘上缩放向量 $s$（离群通道被压小），得到平滑后的激活 $X' = X\,\text{diag}(s)$；
- $W$ 对应行乘上 $s$ 的倒数，得到补偿后的权重 $W' = \text{diag}(s)^{-1} W$；
- **乘积不变**：$Y = X'W'$ 与原来完全相等——数学上无任何损失；
- 但激活的离群被抹平 → 激活也能用一个小 scale 做 INT8；权重虽然被撑大，但权重是 per-channel 量化，扛得住。

一句话：**"把激活的刺拔掉，扎到权重上——因为权重有 per-channel 这把盾。"**

### 4.3 缩放向量怎么选

一个常用的启发式：按通道最大幅值开根号，越大通道缩得越多：

$$s_j = \sqrt{\frac{\max_j |X_{:,j}|}{\max |X|}}$$

（论文里是 $s_j = \frac{\max |X_{:,j}|^\alpha}{\max |X|}$，$\alpha$ 在 0~1 间控制"迁移多少难度"，0 不迁移、1 全迁到权重。）

### 4.4 SmoothQuant 的价值

- 让**激活也能走 INT8**，配合权重 INT8 → 全 INT8 推理，吞吐大幅提升；
- 只改权重（离线一次）+ 改激活 scale（校准期一次），**无需训练**（PTQ 友好）；
- 是多模态/LLM 高吞吐部署的关键技术之一，被 TensorRT、vLLM 等采纳。

### 4.5 SmoothQuant 的代价与局限

- **权重被撑大**：迁移过来的离群让部分权重范围变大，权重量化（即便 per-channel）的相对精度下降——$\alpha$ 越大、权重越吃亏，需要折中；
- **依赖校准**：缩放向量由校准集统计得到，校准集不代表性时迁移量会失配；
- **不改变激活分布的本质**：只是换了个地方承担误差，极端情况下仍可能精度不足 → 再上 QAT；
- **对卷积等非 per-channel 友好的结构**收益有限（激活迁移到权重需要权重侧 per-channel 支持）。

## 五、源码实现（可运行）

### 5.1 三种校准算法对比（模拟重尾激活）

```python
import torch

torch.manual_seed(0)


def quantize_sym(x, s, bits=8):
    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    q = torch.round(x / s).clamp(qmin, qmax)
    return q.to(torch.float32) * s


def mse_with(x, s):
    return ((x - quantize_sym(x, s)) ** 2).mean().item()


# ============ 模拟激活：主体 N(0,1)，带重尾离群 ============
N, C = 4096, 64
act = torch.randn(N, C)
act[:, 7] *= 3.0                                      # 通道 7：方差大
act[:, 50] = torch.distributions.StudentT(5.0).sample((N,)) * 2.0  # 通道 50：重尾离群
act = act.reshape(-1)

# ---- 1. MinMax：直接取观测最大/最小值 ----
s_mm = act.abs().max() / 127.0

# ---- 2. Percentile：99.99% 分位 ----
thr_pc = torch.quantile(act.abs(), torch.tensor(0.9999))
s_pc = thr_pc / 127.0

# ---- 3. KL 熵校准（TensorRT 风格）：直方图 -> 试探阈值 -> 最小 KL ----
def kl_scale(a, nbins=1024, n_levels=128):
    hist = torch.histc(a, bins=nbins, min=0, max=a.max().item())
    P = hist / hist.sum()
    edges = torch.linspace(0, a.max().item(), nbins + 1)
    best_kl, best_i = float("inf"), nbins
    for i in range(n_levels, nbins + 1):                 # 试探每个阈值（第 i 个 bin）
        Q = torch.zeros(nbins)
        bins_idx = torch.arange(i)
        levels = (bins_idx * n_levels) // i              # bin -> 量化层映射
        cnt = torch.bincount(levels, minlength=n_levels)
        s_lvl = torch.zeros(n_levels)
        s_lvl.index_add_(0, levels, P[:i])
        Q[:i] = s_lvl[levels] / cnt[levels].clamp_min(1)  # 量化后展开回直方图
        Q[i - 1] += P[i:].sum()                          # 阈值外尾部折叠到边界
        Q = Q / Q.sum()
        kl = (P * torch.log((P + 1e-12) / (Q + 1e-12))).sum().item()
        if kl < best_kl:
            best_kl, best_i = kl, i
    thr = edges[best_i].item()
    return thr / 127.0, thr, best_i


s_kl, thr_kl, bi = kl_scale(act)

def report(name, s):
    total = mse_with(act, s)
    bulk = mse_with(act[act.abs() < thr_pc], s)
    print(f"{name}: s={s:.4f}  total_MSE={total:.6f}  主体MSE={bulk:.6f}")

print(f"激活: max={act.abs().max().item():.2f}  q99.99={thr_pc.item():.3f}  q99={torch.quantile(act.abs(), torch.tensor(0.99)).item():.3f}")
report("MinMax   ", s_mm.item())
report("Percentile", s_pc.item())
report("KL       ", s_kl)
print(f"KL 选出阈值 thr={thr_kl:.3f} (bin {bi}/1024)")
# 输出：
# 激活: max=33.54  q99.99=9.679  q99=3.058
# MinMax   : s=0.2641  total_MSE=0.005819  主体MSE=0.005819
# Percentile: s=0.0762  total_MSE=0.005024  主体MSE=0.000485
# KL       : s=0.1174  total_MSE=0.003072  主体MSE=0.001146
# KL 选出阈值 thr=14.904 (bin 455/1024)
# 解读：
#   - MinMax 被 max=33.5 撑大到 s=0.264，主体（99.99% 数据在 9.68 以内）被粗步长伤到；
#   - Percentile 用 9.68 做阈值，主体 MSE 最低（0.0005），但 0.01% 尾部被截断；
#   - KL 自动选了 14.9，total_MSE 最低（0.003）——在截断与主体精度间取得最优平衡。
```

### 5.2 SmoothQuant 最小演示（平滑前后量化误差对比）

```python
import torch

torch.manual_seed(0)
x = torch.randn(1024, 16) * 0.5
x[:, 3] *= 50.0                     # 通道 3 是系统性激活离群通道
W = torch.randn(16, 16) * 0.5

def sym_quant_mat(M):
    s = M.abs().max() / 127.0
    return torch.round(M / s).clamp(-127, 127).float() * s

def matmul_err(x, W):
    y = x @ W
    yq = sym_quant_mat(x) @ sym_quant_mat(W)
    return ((y - yq).abs().mean() / y.abs().mean()).item()

print(f"SmoothQuant 平滑前 误差率: {matmul_err(x, W):.4f}")
s_ch = x.abs().amax(dim=0, keepdim=True)     # 每通道最大幅值
s_ch = torch.sqrt(s_ch / s_ch.max())         # 归一化后开根（越大通道缩得越多）
x_s = x / s_ch                               # 激活被压缩（离群通道变小）
W_s = W * s_ch.t()                           # 权重补偿（对应输出通道变大）
print(f"SmoothQuant 平滑后 误差率: {matmul_err(x_s, W_s):.4f}")
# 输出：
# SmoothQuant 平滑前 误差率: 0.0546
# SmoothQuant 平滑后 误差率: 0.0139
# 解读：平滑后 Y = (X·diag(s))·(diag(s)⁻¹·W) 数学上等价，但激活离群被抹平，
#       激活 INT8 量化误差率从 5.5% 降到 1.4%（约 4 倍改善）。
```

## 六、高频面试问答

**Q1：什么是校准？为什么权重不用校准、激活要？**
校准 = 用校准集统计激活分布，确定 scale/zero point。权重是训练完的常量，范围离线可精确得知，直接量化；激活依赖输入、逐层变化，必须先采样统计，否则范围定不准。

**Q2：MinMax、KL、Percentile 三种校准的区别？**
MinMax 取观测最大值做范围，简单但一个离群点就毁所有；KL 用直方图+试探阈值找"量化前后分布 KL 最小"的阈值，在截断与主体精度间自动平衡，TensorRT 默认；Percentile 取 99.99% 分位直接排除尾部，对离群鲁棒但 p 是拍脑袋的。对重尾数据，KL/Percentile 明显优于 MinMax。

**Q3：KL 校准的原理和流程？**
原理：选阈值 t，使"原始激活分布 P 与量化分布 Q 的 KL 散度最小"。流程：① 对激活做直方图；② 对每个候选阈值，把直方图截断+尾部折叠，量化成 128 层再展开；③ 算 KL；④ 取 KL 最小的阈值定 scale。

**Q4：校准集怎么选？数量多少？**
覆盖各类输入（类别/难度/模态）、数量几百~几千即可（256~2048 张图或数千条文本）、避免单一分布、与部署分布一致。多模态模型要同时覆盖图文、分别统计各子模块。

**Q5：SmoothQuant 的核心思想？**
激活有系统性离群通道，且激活只能 per-tensor 救不了；用恒等变换 $Y=(X\text{diag}(s))(\text{diag}(s)^{-1}W)$ 把激活的离群迁移到权重，权重 per-channel 扛得住。这样激活也能 INT8，全程无训练。

**Q6：激活离群点为什么难处理？**
激活只能 per-tensor（硬件限制），离群通道把整体 scale 撑大，主体被稀释；而且激活误差逐层传播。所以要么 SmoothQuant 迁移到权重，要么激活保持高精度。

**Q7：校准集不代表性会怎样？**
低估激活范围 → 部署时真实激活超范围被截断 → 精度崩；校准集与部署分布漂移也会导致 scale 失配。所以校准集要贴近真实分布并覆盖极端输入。

**Q8：动态量化和静态量化（校准）的区别？**
动态量化运行时每 batch 现场算范围，无校准但开销大；静态量化用校准期定好的 scale，推理只做整数运算，快但依赖校准集代表性。
