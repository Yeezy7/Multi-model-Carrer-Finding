# 量化数学基础：对称/非对称量化公式、scale 与 zero point、误差从哪来

> 本模块索引见 [量化详解](量化详解.md)

量化所有算法的地基，就是"浮点实数 → 整数"的两个映射公式和反映射。本文把它们逐符号推导清楚，并用手写代码实测每种量化的真实误差。公式全部基于 INT8（范围 $-128 \sim 127$）、UINT8（范围 $0 \sim 255$）。

## 一、量化映射公式（核心）

### 1.1 对称量化（Symmetric Quantization）

把浮点张量 $r$ 映射到以 0 为中心的整数区间 $[q_{min}, q_{max}]$：

$$q = \text{round}\left(\frac{r}{s}\right), \qquad r \approx q \cdot s$$

- $q$：量化后的整数（INT8 时 $q \in [-128, 127]$）；
- $s$：**scale（步长）**，一个整数代表多少浮点值，$s > 0$；
- 反量化（dequantization）：$r \approx q \cdot s$——即"整数 × 步长"还原近似值；
- 因为以 0 对称，**没有 zero point**，公式最简单。

### 1.2 非对称量化（Asymmetric Quantization / Affine）

浮点范围 $[r_{min}, r_{max}]$ 可以不在 0 附近（如 ReLU 后全为正），此时引入 **zero point $z$**（浮点 0 对应的整数）：

$$q = \text{round}\left(\frac{r}{s}\right) + z, \qquad r \approx (q - z) \cdot s$$

- $z$：zero point，一个整数，保证"浮点 0 精确映射到整数 z"（$r=0 \Rightarrow q = z$）；
- 反量化：先减去 $z$ 再乘 $s$。

### 1.3 scale 和 zero point 怎么定（推导）

量化把 $[r_{min}, r_{max}]$ 均匀切成 $q_{max} - q_{min}$ 份，一份就是步长 $s$：

$$s = \frac{r_{max} - r_{min}}{q_{max} - q_{min}}$$

推导：一个 scale 要把"浮点跨度 $r_{max}-r_{min}$"装进"整数跨度 $q_{max}-q_{min}$"，比例即步长。

zero point 取"浮点 $r_{min}$ 映射到整数 $q_{min}$"时所需的偏移：

$$z = \text{round}\left(q_{min} - \frac{r_{min}}{s}\right)$$

推导：由 $q = \text{round}(r/s) + z$，令 $r = r_{min}$ 时应得到 $q_{min}$，故 $z = q_{min} - r_{min}/s$。等价地也可用上边界 $z = \text{round}(q_{max} - r_{max}/s)$。

对称量化就是非对称的特例：$r_{min} = -r_{max} = -r_{peak}$，此时 $z = 0$，且

$$s_{sym} = \frac{r_{peak}}{q_{max}} = \frac{\max(|r_{min}|, |r_{max}|)}{2^{b-1} - 1}$$

### 1.4 逐符号数值示例：$r \in [-1, 2]$，INT8

给定张量 $r = [-1, 0, 1, 2]$，$q_{min}=-128,\ q_{max}=127$：

**对称量化**（$r_{peak} = \max(1, 2) = 2$）：

$$s = \frac{2}{127} \approx 0.01575$$

| $r$ | $r/s$ | $\text{round}(r/s)$ |
| --- | --- | --- |
| $-1$ | $-63.5$ | $-64$（银行家舍入取偶） |
| $0$ | $0$ | $0$ |
| $1$ | $63.5$ | $64$ |
| $2$ | $127$ | $127$ |

**非对称量化**：

$$s = \frac{2 - (-1)}{127 - (-128)} = \frac{3}{255} \approx 0.01176,\qquad z = \text{round}\left(-128 - \frac{-1}{0.01176}\right) = \text{round}(-128 + 85) = -43$$

| $r$ | $r/s$ | $r/s + z$ | $\text{round}(\cdot)$ |
| --- | --- | --- | --- |
| $-1$ | $-85$ | $-128$ | $-128$ |
| $0$ | $0$ | $-43$ | $-43$ |
| $1$ | $85$ | $42$ | $42$ |
| $2$ | $170$ | $127$ | $127$ |

反量化验证：$(q - z) \cdot s$，如 $q=-128 \Rightarrow (-128+43)\times 0.01176 = -1.0$ 精确还原。注意**非对称量化用同样的 4 个值，步长更细（0.0118 < 0.0158）**，因为整个 $[-1,2]$ 范围被利用得更充分——这正是范围不对称时非对称量化更准的原因。

### 1.5 为什么要用 $2^{b-1}-1$ 而不是 $2^{b-1}$

INT8 有符号范围是 $-128 \sim 127$，正侧最大值是 $127 = 2^{7}-1$ 而非 $128$。用 $127$ 作 $q_{max}$ 的原因是：

- 对称量化要求 $s \cdot q_{max} = r_{peak}$，若 $q_{max} = 128$ 则 $r_{peak}$ 需要超过 $s$ 能表示的范围，且 $r_{max}$ 一侧多一格；
- 保持"正负对称"（$q_{max} = -q_{min}$），让 scale 在正负方向一致，避免多余的非对称；
- 于是公式里统一写 $q_{max} = 2^{b-1} - 1$：INT8 用 127，INT4 用 7，UINT8 用 255。

### 1.6 为什么反量化是"整数 × scale"而不是加回来

从 $q = \text{round}(r/s) + z$ 反解：$r/s \approx q - z \Rightarrow r \approx (q-z)s$。映射 $r \mapsto q$ 是有损的（round 丢信息），反量化只能取"这一格的代表值"——步长中点是 $L_2$ 最优还原点（推导见第四节 4.3），所以反量化就是 $(q-z)\cdot s$ 这一行代码，不存在更复杂的还原。

## 二、对称 vs 非对称对比

| 维度 | 对称量化 | 非对称量化 |
| --- | --- | --- |
| 公式 | $q = \text{round}(r/s)$ | $q = \text{round}(r/s) + z$ |
| zero point | 无（恒为 0） | 有，需额外存储与计算 |
| 有效利用 | 只有 $[q_{min}, q_{max}]$ 的一半（负半轴）可能浪费 | 整个整数范围都用上 |
| 适合分布 | 权重（近似以 0 对称的高斯分布） | 激活（ReLU 后偏正，如 $[0, r_{max}]$） |
| 硬件 | 指令简单、快，Tensor Core 常见模式 | 需额外处理 $z$，部分硬件不支持激活的 $z$ |
| 何时用 | 分布对称时优先 | 分布明显不对称时更准 |

**实践经验**：
1. **权重**：分布近似对称 → 几乎都用对称量化（省一个 $z$，精度损失可忽略）；
2. **激活**：ReLU/SiLU 后全为正 → 理论上用非对称（配 UINT8 0~255）更好；但现代 GPU Tensor Core 对 INT8 符号量化支持更好，实践中常用对称或"zero point 化的有符号量化"；
3. **零值精确性**：非对称量化保证 $r=0 \Rightarrow q=z$ 精确映射，对**卷积 padding 为 0、激活里大量 0** 的场景（ReLU、稀疏）很重要——对称量化里 0 也会被舍入误差污染。

## 三、per-tensor vs per-channel

**per-tensor**：整个张量共用一个 $s$（和一个 $z$）。
**per-channel**：每个输出通道（对权重而言通常是每行/每输出维）各用一个 $s$。

### 3.1 为什么 per-channel 精度更高

以线性层权重 $W \in \mathbb{R}^{C_{out} \times C_{in}}$ 为例：

- **per-tensor**：一个 $s$ 必须覆盖全矩阵的最大幅值。只要某个输出通道权重特别大，其它通道的小权重就被"粗步长"严重稀释；
- **per-channel**：每个输出通道用自己的 $s$，大通道大步长、小通道小步长，**每个通道都利用满自己的整数范围**。

数学上：per-tensor 的相对误差由 $\max_c \|W_c\|_\infty$ 决定，per-channel 由 $\max_c \|W_c\|_\infty / \|W_c\|_\infty = 1$ 按通道归一化——本质是**去掉了通道间的幅值差异**。实测（见第六节代码）：同样的权重矩阵，per-tensor 对称量化的 MSE 是 per-channel 的约 30 倍。

### 3.2 为什么 GPU 上"权重 per-channel + 激活 per-tensor"是标配

- **权重离线可知、维度固定** → 天然可以做 per-channel，且反量化可以在加载时预计算或融合进 kernel，开销小；
- **激活逐 token 变化、且硬件限制**：多数 GPU 的 INT8 指令只支持整块张量共享一个 scale（有些支持 per-row/分组但寄存器开销大），做 per-channel 需要额外指令把每行结果乘不同 scale，性能收益不划算；
- 因此工业界惯例：**权重 per-channel（或 per-group），激活 per-tensor（或 per-token/per-channel 的折中方案如 per-token）**。LLM 里的 group quantization（如 GPTQ 的 g=128，每 128 个权重一组）就是 per-channel 的推广，在粒度与存储开销间取平衡（见 [LLM量化算法.md](LLM量化算法.md)）。

## 四、舍入与误差

### 4.1 round 到最近整数

量化必然 round，这一步引入**量化噪声** $e = r - q \cdot s$。若 $r$ 的分布相对步长足够平滑，$e$ 近似在 $[-s/2, s/2]$ 均匀分布。

### 4.2 均匀分布假设下的噪声方差：$s^2/12$

$e \sim U(-s/2, s/2)$ 时：

$$\text{Var}(e) = \frac{(s/2 - (-s/2))^2}{12} = \frac{s^2}{12}, \qquad \text{std}(e) = \frac{s}{\sqrt{12}} \approx 0.2887 s$$

这意味着：**步长减半，噪声标准差减半**——所以一切校准算法（MinMax/Percentile/KL）的核心目标都是"把 $s$ 压小"，而压小的唯一办法是**不要被离群点撑大量化范围**（见 [校准算法.md](校准算法.md)）。

### 4.3 相对误差分析

对单个数 $r$，绝对误差 $|e| \le s/2$，相对误差 $\approx s/(2|r|)$：

- $|r|$ 接近 $r_{max}$ 时相对误差最小（约 $1/(2q_{max})$，INT8 下约 0.4%）；
- $|r|$ 很小时相对误差巨大——**小值相对精度差是量化的固有属性**；
- 所以"给激活/权重乘一个大的常数再量化"（如 SmoothQuant 的 per-channel 缩放）能让整体相对误差更均匀（见 [校准算法.md](校准算法.md) 第四节）。

### 4.4 误差的量化度量：MSE、最大误差、余弦相似度

评估一个量化方案，常用的三个数字各有侧重：

| 指标 | 公式 | 侧重 |
| --- | --- | --- |
| MSE | $\frac{1}{n}\sum_i (r_i - q_i s)^2$ | 整体能量误差 |
| Max Abs Err | $\max_i \|r_i - q_i s\|$ | 最坏情况 |
| 余弦相似度 | $\frac{r^\top \hat r}{\|r\|\|\hat r\|}$ | 相对结构/方向是否保留 |

- 量化部署更关心**余弦相似度**（是否破坏方向）与**下游任务指标**（是否影响预测），MSE 只作辅助；
- 同一 MSE 下，误差分布是否均匀（集中在少数离群点 vs 均匀散布）对模型影响差别很大——这也是"per-channel 量化让误差按通道均匀化"的价值。

## 五、溢出的边界（clamp）

整数只能表示 $[q_{min}, q_{max}]$，超出范围的 $r$ 必须被截断：

$$q = \text{clamp}\big(\text{round}(r/s), \ q_{min}, \ q_{max}\big)$$

### 5.1 大值截断 vs 小值精度：此消彼长

设量化范围边界为 $r_{peak} = s \cdot q_{max}$：

- **把 $r_{peak}$ 调大**（$s$ 变大）→ 大值不截断，但小值的步长变粗、相对误差变大；
- **把 $r_{peak}$ 调小**（$s$ 变小）→ 小值更准，但超过 $r_{peak}$ 的离群值被截断（clamp），截断误差 $r - r_{peak}$ 会很大。

量化范围选择本质是**在"截断误差"与"舍入误差"之间做最优化**：

$$\min_{r_{peak}} \ \underbrace{\mathbb{E}\left[(r - q(r)\cdot s)^2\right]}_{\text{舍入噪声（正比 }s^2\text{）}} + \underbrace{\mathbb{E}\left[(r - r_{peak})^2 \cdot \mathbb{1}_{|r| > r_{peak}}\right]}_{\text{截断误差（离群点贡献）}}$$

- 数据集中无离群 → 应选 $r_{peak} = \max|r|$（MinMax 策略）；
- 数据有重尾离群 → 应牺牲离群点、保护主体（Percentile/KL 策略）；
- 这就是三种校准算法的数学动机（见 [校准算法.md](校准算法.md) 第二节）。

### 5.2 数值示例：$r = [-200, -5, 0, 5, 200]$

对称量化时 $r_{peak} = 200,\ s = 200/127 \approx 1.575$：

- $r=-200 \to \text{clamp}(-127) \to$ 反量化 $-200$（精确，恰好是边界）；
- $r=-5 \to \text{round}(-3.17) = -3 \to$ 反量化 $-4.72$（相对误差 $\sim 5.5\%$——小值被粗步长伤到）；
- $r=200 \to 127 \to 200$（精确）。

同样的 5 个数，若选 $r_{peak} = 5$（$s \approx 0.039$），$\pm 200$ 会被截断为 $\pm 5$（截断误差 195！），但 $\pm 5$ 的相对误差只有约 0.8%。**这就是"宁缺毋滥"与"宁滥勿缺"的权衡。**

## 六、源码实现（可运行）

手写对称/非对称量化的量化与反量化，并对真实权重矩阵实测误差，对比 per-tensor 与 per-channel：

```python
import torch
import torch.nn.functional as F

torch.manual_seed(0)


def quantize_sym(r, bits=8):
    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    s = r.abs().max() / qmax
    q = torch.round(r / s).clamp(qmin, qmax)
    return q.to(torch.int8), s


def dequantize_sym(q, s):
    return q.to(torch.float32) * s


def quantize_asym(r, bits=8):
    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    s = (r.max() - r.min()) / (qmax - qmin)
    z = torch.round(qmin - r.min() / s)
    q = torch.round(r / s + z).clamp(qmin, qmax)
    return q.to(torch.int8), s, z.to(torch.int32)


def dequantize_asym(q, s, z):
    return (q.to(torch.float32) - z) * s


# ---- 1. 数值示例：r in [-1, 2]，INT8 ----
r = torch.tensor([-1.0, 0.0, 1.0, 2.0])
q, s = quantize_sym(r)
q2, s2, z2 = quantize_asym(r)
print("sym  s =", s.item(), " q =", q.tolist())
print("asym s =", s2.item(), " z =", z2.item(), " q =", q2.tolist())
print("asym 反量化:", dequantize_asym(q2, s2, z2).tolist())
# 输出：
# sym  s = 0.015748031437397003  q = [-64, 0, 64, 127]
# asym s = 0.0117647061124444  z = -43  q = [-128, -43, 42, 127]
# asym 反量化: [-1.0, 0.0, 1.0, 2.0]

# ---- 2. 量化一个权重矩阵 -> 反量化 -> 对比误差 ----
W = torch.randn(64, 128) * 0.1
W[3, :] *= 5.0  # 制造一个"大权重"行，考验量化

def report(name, W, Wq):
    err = (W - Wq).abs().max().item()
    cos = F.cosine_similarity(W.reshape(1, -1), Wq.reshape(1, -1)).item()
    mse = ((W - Wq) ** 2).mean().item()
    print(f"{name}: max_abs_err={err:.6f}  cosine={cos:.6f}  mse={mse:.2e}")

# per-tensor
q, s = quantize_sym(W)
report("per-tensor 对称", W, dequantize_sym(q, s))
q, s, z = quantize_asym(W)
report("per-tensor 非对称", W, dequantize_asym(q, s, z))

# per-channel（每个输出通道一个 scale，即按行）
def quantize_per_channel_sym(r, bits=8):
    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    s = r.abs().amax(dim=1, keepdim=True) / qmax
    q = torch.round(r / s).clamp(qmin, qmax)
    return q.to(torch.int8), s

def dequantize_per_channel(q, s):
    return q.to(torch.float32) * s

q, s = quantize_per_channel_sym(W)
report("per-channel 对称", W, dequantize_per_channel(q, s))
# 输出：
# per-tensor 对称: max_abs_err=0.008074  cosine=0.999281  mse=2.19e-05
# per-tensor 非对称: max_abs_err=0.007112  cosine=0.999451  mse=1.67e-05
# per-channel 对称: max_abs_err=0.008025  cosine=0.999976  mse=7.39e-07
# 解读：per-channel 的 MSE 比 per-tensor 小约 30 倍（2.19e-05 -> 7.39e-07），
#      余弦相似度 0.999976 逼近 1 —— 因为"大权重"行不再拖累其它行。

# ---- 3. 舍入噪声：均匀分布假设下方差 s^2/12 ----
u = torch.rand(100000)  # ~ U(0,1)
s3 = 1.0 / 127.0
nu = (u / s3).round() * s3 - u
print(f"量化噪声 std = {nu.std().item():.5f}  理论 s/√12 = {s3 / (12 ** 0.5):.5f}")
# 输出：量化噪声 std = 0.00228  理论 s/√12 = 0.00227（实测与理论吻合）

# ---- 4. 溢出/clamp 边界 ----
x = torch.tensor([-200.0, -5.0, 0.0, 5.0, 200.0])
q, s = quantize_sym(x)
print("clamp:", q.tolist(), " 反量化:", dequantize_sym(q, s).tolist())
# 输出：clamp: [-127, -3, 0, 3, 127]  反量化: [-200.0, -4.724409103393555, 0.0, 4.724409103393555, 200.0]
# 解读：±200 被 clamp 到 ±127 后恰好还原；±5 被粗步长量化成 ±3，反量化 4.72（相对误差约 5%）。

# ---- 5. 权重误差 -> 输出误差传播直觉 ----
W2 = torch.randn(64, 128) * 0.1
q, s = quantize_sym(W2)
Wq2 = dequantize_sym(q, s)
x2 = torch.randn(128)
y, yq = W2 @ x2, Wq2 @ x2
print(f"原始输出 std={y.std().item():.4f}  量化输出 std={yq.std().item():.4f}  输出差异 std={(y - yq).std().item():.4f}")
# 输出：原始输出 std=1.1468  量化输出 std=1.1483  输出差异 std=0.0086
# 解读：输出差异 std 仅 0.0086，远小于输出本身 std 1.15 —— 权重量化误差被矩阵乘法"平均"掉了（下节）。
```

## 七、量化误差对推理的影响

### 7.1 权重误差如何传播到输出

线性层 $y = W x$ 量化后 $y_q = W_q x = (W + \Delta W)x$，输出误差：

$$y - y_q = \Delta W \, x \quad\Rightarrow\quad \|y - y_q\| \le \|\Delta W\| \cdot \|x\|$$

- 误差与激活幅值成正比：**激活越大，权重误差越被放大**；
- 但矩阵乘法是**求和**，各元素误差 $\Delta W_{ij} x_j$ 符号随机、相互抵消（中心极限定理），所以实际输出误差远小于最坏上界（实测代码第 5 段：输出差异 std 只有输出 std 的 0.7%）；
- 因此"一层权重量化"对输出的影响通常是温和的，**误差累积主要发生在多层串行 + 激活也量化**的场景。

### 7.2 激活量化误差的逐层累积

激活量化误差比权重误差更棘手，因为它会**逐层放大**：

- 第 $l$ 层的激活误差 $\delta_l$ 会作为下一层的输入误差参与计算：$\delta_{l+1} = \delta_l W_{l+1}$；
- 即使每层只引入 1% 相对误差，50 层 Transformer 串下来，误差上界按范数可能累积到可观水平（虽然随机符号会互相抵消一部分）；
- 因此**激活量化比权重量化对精度更敏感**（[量化详解](量化详解.md) 第三节），深度模型尤其如此；
- 缓解手段：减少量化的层数（只量化权重）、用 SmoothQuant 把激活误差迁移走、或用 QAT 让模型在训练中就适应激活噪声。

### 7.3 哪些层对量化最敏感

1. **第一层/最后一层**：输入是原始像素/token，范围特殊；输出直接决定预测，误差无缓冲；
2. **残差相加、归一化层**：量化这些"小范围"张量相对误差大（第四节 4.3）；
3. **注意力中的 Q/K**：语义敏感，且值范围受 softmax/温度影响大；
4. **多模态投影层**：跨模态对齐层对数值波动敏感（视觉 token 与文本 token 尺度差异大）。

实践上，量化评估常看"逐层误差"或"注意力层敏感度"来决定哪些层跳过量化、哪些层用更高精度（见 [LLM量化算法.md](LLM量化算法.md) 与 [量化评估与实践.md](量化评估与实践.md)）。

## 八、高频面试问答

**Q1：对称量化和非对称量化的区别？什么时候用哪个？**
对称量化 $q=\text{round}(r/s)$，无 zero point；非对称量化 $q=\text{round}(r/s)+z$，多一个 zero point 把浮点 0 精确映射到整数。权重分布近似对称 → 用对称；激活（ReLU 后偏正）范围不对称 → 用非对称能更好利用整数范围。现代硬件（Tensor Core INT8）通常要求对称，实践中权重对称、激活对称或非对称。

**Q2：zero point 是什么？为什么要它？**
zero point 是浮点 0 对应的整数值，让 $r=0$ 精确映射到整数 $z$，避免 0 值被舍入污染（对 padding 0、ReLU 稀疏激活重要），也让非对称量化能充分利用 $[q_{min},q_{max}]$ 全范围。公式 $z = \text{round}(q_{min} - r_{min}/s)$。

**Q3：为什么 per-channel 比 per-tensor 准？为什么 GPU 上激活只能 per-tensor？**
per-tensor 一个 scale 被全张量最大幅值撑大，小通道被粗步长稀释；per-channel 每个输出通道用自己的 scale，都利用满整数范围。权重离线可知、维度固定，可做 per-channel；激活逐 token 变化且多数 GPU INT8 指令只支持整张量共享 scale，per-channel 需要额外反量化指令，不划算，所以激活默认 per-tensor。

**Q4：量化误差怎么评估？**
指标上：最大绝对误差（max abs err）、MSE、余弦相似度（衡量方向/相对结构是否保留）。关系上：权重误差 → 输出误差经 $\Delta W x$ 传播但被求和平均；评估要放到模型层（困惑度、下游任务指标），单张量 MSE 小不代表模型精度无损失。

**Q5：舍入噪声为什么方差是 s²/12？**
round 后误差在 $[-s/2, s/2]$ 近似均匀分布，均匀分布方差 $= \frac{(b-a)^2}{12} = \frac{s^2}{12}$。所以步长减半 → 噪声标准差减半，这就是校准算法拼命压 scale 的原因。

**Q6：大值截断和小值精度怎么权衡？**
量化范围 $r_{peak}$ 大 → 不截断但小值步长粗；$r_{peak}$ 小 → 小值准但离群值被 clamp。最优 $r_{peak}$ 最小化"舍入噪声（∝s²）+ 截断误差（离群点贡献）"，这正是 MinMax/Percentile/KL 三种校准各自的取舍。

**Q7：对称量化反量化为什么是 r ≈ q·s？**
因为映射是"整数 × 步长"还原：$r$ 落在 $[q\cdot s - s/2, q\cdot s + s/2]$ 都被量化成 $q$，反量化取区间中点 $q\cdot s$，是 $L_2$ 意义下的最优还原点。

**Q8：为什么 LLM 部署几乎只量化权重、激活保持 FP16？**
激活量化难（依赖输入、有离群、逐层传播、硬件 per-tensor 限制），而权重离线可知、per-channel 容易、误差可控。只量化权重就能省 75% 显存（INT4），收益大、风险小。
