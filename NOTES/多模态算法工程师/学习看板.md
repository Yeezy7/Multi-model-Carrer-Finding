# 📖 多模态算法工程师 · 学习看板

> 本页用 **Dataview** 插件自动汇总学习进度。使用前提：安装并启用 Dataview 插件（见文末）。

## 使用说明

1. 打开任意一篇笔记，顶部属性面板（或代码块）找到 `learned` 字段，勾选 ✅ 即代表"学过了"；
2. 本看板会自动刷新：勾选后对应笔记出现在"已学"栏，未学的出现在"待学习"清单；
3. 想要彻底掌握，配合每篇笔记末尾的 **自我检验** checklist 一起打勾。

## 全局统计

```dataview
TABLE
  length(rows) AS 总笔记数,
  length(rows WHERE learned) AS 已学,
  round(100 * length(rows WHERE learned) / length(rows), 1) AS 完成率
FROM "NOTES/多模态算法工程师"
WHERE file.name != "学习看板"
GROUP BY "全部笔记"
```

## 各模块进度

```dataview
TABLE
  length(rows) AS 总数,
  length(rows WHERE learned) AS 已学,
  round(100 * length(rows WHERE learned) / length(rows), 1) AS 完成率
FROM "NOTES/多模态算法工程师"
WHERE file.name != "学习看板"
GROUP BY file.folder
SORT file.folder ASC
```

## 待学习清单（按模块）

```dataview
TABLE WITHOUT ID
  file.link AS 笔记,
  file.folder AS 模块
FROM "NOTES/多模态算法工程师"
WHERE file.name != "学习看板" AND !learned
SORT file.folder ASC, file.name ASC
```

## 已学笔记

```dataview
TABLE WITHOUT ID
  file.link AS 笔记,
  file.folder AS 模块
FROM "NOTES/多模态算法工程师"
WHERE file.name != "学习看板" AND learned
SORT file.folder ASC, file.name ASC
```

## 安装 Dataview 插件（只需一次）

1. Obsidian 左下角「设置」→「第三方插件」→「关闭安全模式」；
2. 「浏览」→ 搜索 **Dataview** → 安装；
3. 回到已安装插件列表，启用 **Dataview**；
4. 回到本页面，代码块会自动渲染成表格。

> 若不想装插件：也可直接用 Obsidian 搜索功能输入 `learned:false` 查看未学笔记，在每篇笔记顶部属性面板手动改 `learned` 即可。
