# 深度学习与机器学习基础

## 一、PyTorch 与训练基础

### 9.1 `[基础]` `model.eval()` 和 `torch.no_grad()` 有什么区别？

- **答案**：`model.eval()` 切换 Dropout、BatchNorm 等层的推理行为；`torch.no_grad()` 关闭梯度记录。
- **原因**：模型状态和自动求导是两套机制，测试时通常需要同时使用。
- **关键点**：忘记 `eval()` 会造成随机输出；忘记 `no_grad()` 会浪费显存。
- **追问**：MC Dropout 为什么要在测试时保留 Dropout？

### 9.2 `[基础]` BatchNorm 和 LayerNorm 的区别是什么？

- **答案**：BatchNorm 通常按 batch 统计特征，LayerNorm 通常对单个样本的特征维度归一化。
- **原因**：BatchNorm 依赖 batch 统计，LayerNorm 对 batch size 不敏感，更适合 Transformer。
- **关键点**：训练/推理统计量；batch size；归一化维度。
- **追问**：小 batch 训练为什么可能不适合 BatchNorm？

### 9.3 `[基础]` 梯度消失和梯度爆炸如何处理？

- **答案**：可通过合理初始化、归一化、残差结构、学习率调整、梯度裁剪和稳定激活函数缓解。
- **原因**：深层网络反复链式相乘会放大或缩小梯度，导致参数更新失控或停滞。
- **关键点**：监控梯度范数；定位层；裁剪阈值；学习率。
- **追问**：梯度裁剪为什么不能解决所有训练不稳定？

## 二、Transformer 与注意力

### 9.4 `[基础]` Self-Attention 的计算流程是什么？

- **答案**：输入映射得到 Q、K、V，计算 `QKᵀ/√d`，经 Softmax 得到权重，再对 V 加权求和。
- **原因**：Q-K 衡量 Token 之间的相关性，权重决定从其他 Token 聚合多少信息。
- **关键点**：缩放；Mask；多头；复杂度。
- **追问**：为什么要除以 `√d`？

### 9.5 `[基础]` MHA、MQA 和 GQA 有什么区别？

- **答案**：MHA 每个头都有独立 Q/K/V；MQA 多个 Query 头共享一组 K/V；GQA 在两者之间按组共享 K/V。
- **原因**：减少 K/V 头可以降低 KV Cache 和 Decode 开销，但可能损失部分表达能力。
- **关键点**：头数；KV Cache；质量-效率权衡。
- **追问**：为什么 GQA 常用于大模型推理？

### 9.6 `[基础]` RoPE 解决了什么问题？

- **答案**：RoPE 将位置信息通过旋转变换注入 Q、K，使注意力分数体现相对位置信息。
- **原因**：Transformer 本身没有顺序概念，需要位置编码区分 Token 的位置和距离。
- **关键点**：相对位置；外推；频率；长上下文。
- **追问**：RoPE 长度外推为什么会失效？

## 三、损失与正则化

### 9.7 `[基础]` Cross Entropy 和 MSE 分别适合什么任务？

- **答案**：Cross Entropy 主要用于分类或 Token 预测，MSE 常用于连续值回归。
- **原因**：分类目标是离散分布，交叉熵衡量预测分布与真实分布差异；回归目标是连续数值。
- **关键点**：Logits；Softmax；标签形式；异常值。
- **追问**：语言模型为什么常用 Cross Entropy？

### 9.8 `[基础]` 测试时 Dropout 层还参与计算吗？

- **答案**：`eval()` 模式下不再随机丢弃神经元，前向仍经过该层，但它近似恒等映射。
- **原因**：训练阶段已按保留概率对激活进行缩放，使训练期望和推理输出一致，所以推理时无需再次随机丢弃或缩放。
- **关键点**：`eval()` 控制层行为；`no_grad()` 只关闭梯度；忘记 `eval()` 会导致结果抖动。
- **追问**：MC Dropout 如何用于不确定性估计？

### 9.9 `[基础]` 卷积层参数量如何计算？

- **答案**：普通二维卷积参数量为 `C_out × C_in × K_h × K_w + C_out`，最后一项是 bias。
- **原因**：每个输出通道都有一组连接全部输入通道的卷积核，以及一个偏置。
- **关键点**：与输入高宽、Batch Size、Padding、Stride 无关；分组卷积还要除以组数。
- **追问**：深度可分离卷积为什么参数更少？
