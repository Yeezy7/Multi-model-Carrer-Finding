# 模型训练与对齐

## 一、微调与参数高效训练

### 6.1 `[基础]` SFT 在多模态模型中做什么？

- **答案**：用图像/视频/文本指令与目标回答构成监督样本，让模型学习多模态输入到任务输出的映射。
- **原因**：预训练获得通用能力，SFT 将能力对齐到问答、抽取、定位或业务格式。
- **关键点**：输入模板；标签屏蔽；任务混合；数据质量。
- **追问**：多模态 SFT 中哪些 Token 需要计算 Loss？

### 6.2 `[基础]` LoRA 的核心思想是什么？

- **答案**：冻结原模型权重，在目标线性层旁增加低秩矩阵，只训练这部分增量参数。
- **原因**：任务适配通常不需要改变全部参数，低秩更新能降低显存和训练成本。
- **关键点**：秩 `r`；缩放系数；注入层；合并权重。
- **追问**：LoRA 的秩太小或太大分别有什么影响？

### 6.3 `[简历]` QLoRA 和 LoRA 的主要区别是什么？

- **答案**：QLoRA 在量化后的基座模型上训练 LoRA 适配器，进一步降低显存；LoRA 通常以 FP16/BF16 等精度加载基座。
- **原因**：QLoRA 适合有限显存下的领域适配，但需要关注量化误差和训练稳定性。
- **关键点**：量化基座冻结；适配器训练；计算精度；合并和部署。
- **追问**：为什么量化权重还能反向训练 LoRA？

### 6.4 `[场景]` 多任务 SFT 如何设置 Task Sampling？

- **答案**：根据任务难度、数据量、业务重要性和验证集表现设置采样比例，并通过消融观察各任务之间的迁移和干扰。
- **原因**：数据量大的任务会主导梯度，导致小任务或关键业务能力被忽略。
- **关键点**：温度采样；任务权重；过拟合；负迁移。
- **追问**：某个任务提升但其他任务下降，如何处理？

## 二、数据构造与对齐

### 6.5 `[面经]` 多模态训练数据最容易出现哪些问题？

- **答案**：图文不匹配、答案幻觉、重复数据、格式错误、难度分布失衡和视觉信息未被回答使用。
- **原因**：多模态数据同时存在图像质量、文本质量和跨模态一致性问题。
- **关键点**：去重；一致性过滤；难例挖掘；答案验证；数据配比。
- **追问**：如何自动检测图文不匹配样本？

### 6.6 `[基础]` 如何判断模型是否发生灾难性遗忘？

- **答案**：在领域任务集和通用能力集上分别评估微调前后表现，并观察不同任务、语言和输入模态的变化。
- **原因**：领域数据可能让模型更擅长目标任务，但损伤通用问答、视觉识别或指令遵循。
- **关键点**：保留集；混合训练；学习率；LoRA 模块范围。
- **追问**：发现遗忘后有哪些缓解方法？

### 6.7 `[场景]` 多模态模型训练 Loss 下降但指标不升，如何排查？

- **答案**：检查标签掩码、数据泄漏、评测脚本、任务分布、生成格式和训练集与验证集的分布差异。
- **原因**：Loss 只反映训练目标，可能与最终结构化、定位或时间边界指标不一致。
- **关键点**：逐样本回放；基线复现；Loss 分项；生成结果分析。
- **追问**：如何设计与线上任务一致的训练目标？

## 三、消融与实验

### 6.8 `[简历]` 一个好的消融实验应该怎么做？

- **答案**：固定数据、模型和训练配置，只逐项增加或移除一个模块，同时报告效果、效率和失败案例。
- **原因**：控制变量可以判断单个技术点的真实贡献，避免多个改动共同发生导致无法归因。
- **关键点**：基线；单变量；重复实验；统计波动；成本指标。
- **追问**：如果两个模块存在协同作用，如何设计消融？

### 6.9 `[面经]` 什么时候应该继续调参，什么时候应该改数据？

- **答案**：先看错误是否集中在数据覆盖不足、标签错误或困难场景；若数据问题明显，优先补数据和样本策略，再调模型超参。
- **原因**：参数调优无法弥补训练分布中完全没有的场景，也无法修复系统性标签错误。
- **关键点**：错误分桶；数据覆盖；训练/验证差距；收益成本。
- **追问**：如何判断新增数据是否真正有效？
