# 题源与使用说明

## 一、题目标签

| 标签 | 含义 |
|---|---|
| `[简历]` | 面试官可以直接从简历追问，优先级最高 |
| `[面经]` | 多家公开面经中反复出现的考察方向 |
| `[基础]` | 深度学习、视觉、机器学习和大模型通用基础 |
| `[场景]` | 需要现场设计方案或分析问题的开放题 |
| `[手撕]` | 需要写代码、伪代码或说明复杂度 |

## 二、使用原则

- 题目答案只保留面试现场需要说清楚的内容，不代替完整技术文档。
- `[面经]` 只表示公开资料中的高频考点，不宣称题目来自某家公司的保密题库。
- `[简历]` 题必须能对应到简历中的项目、实习、论文、指标或技术栈。
- 对指标要能说明数据集、基线、改动、收益和代价，不能只背结果数字。
- 对开放题优先采用“目标 → 方案 → 取舍 → 指标 → 风险”的回答顺序。

## 三、推荐口述时长

- 基础概念题：30～60 秒；
- 技术方案题：1～2 分钟；
- 项目主问题：2～3 分钟；
- 系统设计题：3～5 分钟。
