# 多模态算法工程师面试题库

> 依据：范黎健多模态算法工程师简历 + 主流互联网大厂公开面经高频方向。
>
> 使用方式：先看每题的“答案”和“原因”，再用“追问”进行口述训练；详细原理回看 `技术基础`、`算法论文基础` 和 `任务专题`。

## 一、题库定位

- **目标岗位**：多模态算法工程师、视觉语言模型算法工程师、大模型视觉算法工程师、视频理解算法工程师、文档智能算法工程师。
- **题目来源**：公开面经高频题、岗位常见场景题、简历项目定制追问、基础算法题。
- **回答长度**：每道题采用“答案 + 原因 + 关键点 + 追问”，适合面试前快速复习。
- **题目标记**：`[面经]` 表示公开面经高频方向；`[简历]` 表示根据简历定制；`[场景]` 表示岗位设计题；`[基础]` 表示通用基础题。

## 四、建议刷题顺序

1. 简历与项目深挖：先保证项目能讲清楚；
2. 多模态基础 + Qwen-VL：建立模型链路；
3. 视频理解 + 文档理解：匹配两个核心项目；
4. 训练对齐 + 推理部署：回答“怎么优化、怎么落地”；
5. 检测异常 + 基础 + 手撕：补齐岗位通用能力。
