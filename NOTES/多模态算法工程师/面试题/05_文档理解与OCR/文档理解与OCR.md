# 文档理解与 OCR

## 一、文档视觉理解

### 5.1 `[面经]` 文档理解和普通图像问答有什么区别？

- **答案**：文档理解更关注文字、版面、表格、图表、阅读顺序和结构化关系，通常还要求精确抽取字段。
- **原因**：文档答案不仅由视觉对象决定，还依赖空间布局和文本内容之间的关系。
- **关键点**：OCR；版面分析；表格结构；坐标；结构化输出。
- **追问**：为什么纯 OCR 文本有时不如 VLM？

### 5.2 `[简历]` 如何处理小字体、密集表格和复杂版面？

- **答案**：保留全局页面获取布局，再对高信息密度区域做 Dynamic Resolution 局部裁剪，并加入低清和压缩等困难样本训练。
- **原因**：全局图解决结构关系，局部高分辨率解决细节识别，困难样本提升输入退化下的鲁棒性。
- **关键点**：区域选择；分辨率预算；全局-局部融合；困难样本。
- **追问**：局部裁剪过多会有什么问题？

### 5.3 `[简历]` KIE 的输出为什么要结构化？

- **答案**：结构化输出便于字段校验、下游数据库写入和业务规则处理，比自由文本更容易评估和消费。
- **原因**：合同和财报抽取通常要求字段名、类型和层级稳定，语言流畅但格式错误仍不可用。
- **关键点**：Schema；字段缺失；类型约束；JSON 校验；重试策略。
- **追问**：模型输出 JSON 不合法时如何处理？

## 二、数据与评测

### 5.4 `[简历]` 为什么要构造低清、JPEG、旋转和扫描噪声样本？

- **答案**：模拟真实文档采集中的输入退化，提升模型在 OCR-rich 场景下的鲁棒性。
- **原因**：公开高质量数据和线上真实图片存在分布差异，模型可能在标准集高分但在线上失效。
- **关键点**：增强强度；保持标签正确；真实噪声分布；困难子集评测。
- **追问**：数据增强过强会有什么副作用？

### 5.5 `[基础]` ANLS 和 F1 分别适合什么任务？

- **答案**：ANLS 适合存在编辑距离差异的文本答案，字段级 F1 适合结构化抽取的正确、漏抽和误抽统计。
- **原因**：文本答案可能只有少量字符差异，而结构化字段更关心精确匹配和覆盖率。
- **关键点**：大小写与空格归一化；字段级匹配；微平均和宏平均。
- **追问**：数字字段能否直接使用普通文本相似度？

### 5.6 `[场景]` 如何评估表格和图表理解？

- **答案**：分别评估文本读取、表格结构恢复、数值比较、趋势判断和多步计算，并保留图表类型和问题类型切片。
- **原因**：模型可能能读出文字，但不能正确理解坐标、单位、列关系或计算步骤。
- **关键点**：ChartQA；数值误差；单位归一化；结构化证据。
- **追问**：图表问答错误如何判断是识别错还是推理错？

## 三、系统设计

### 5.7 `[场景]` 如何设计合同信息抽取系统？

- **答案**：文档切分与版面解析 → 文本/图像/表格索引 → 字段级检索 → VLM 抽取 → Schema 校验 → 人工复核和结果入库。
- **原因**：长合同直接整篇输入成本高，分阶段处理便于控制上下文、权限和错误定位。
- **关键点**：页码坐标；跨页字段；证据回链；置信度；人工兜底。
- **追问**：如何处理表格跨页和字段重复？

### 5.8 `[场景]` 文档模型线上准确率下降，如何排查？

- **答案**：先按文档类型、分辨率、页面长度和字段分桶，检查输入分布、裁剪质量、OCR 错误、模型版本和输出解析。
- **原因**：线上指标下降可能来自数据漂移、预处理变化、服务故障或模型退化，不能只重训模型。
- **关键点**：版本对比；回放集；输入快照；错误归因；灰度回滚。
- **追问**：没有完整标注时如何做线上质量监控？
