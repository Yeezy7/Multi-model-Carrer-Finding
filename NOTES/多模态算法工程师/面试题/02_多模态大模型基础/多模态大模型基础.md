# 多模态大模型基础

## 一、架构与模态融合

### 2.1 `[面经]` 一个典型 VLM 由哪些模块组成？

- **答案**：通常包括视觉编码器、模态连接器或 Projector、语言模型和输入输出处理模块。
- **原因**：视觉编码器负责提取图像特征，Projector 将视觉特征映射到语言模型可接受的表示空间，LLM 负责理解和生成。
- **关键点**：视觉信息进入 LLM 的方式；各模块冻结策略；训练阶段划分。
- **追问**：Projector 为什么不能直接省略？

### 2.2 `[面经]` 图像特征如何与文本 Token 融合？

- **答案**：将图像编码成视觉 Token，经投影后与文本 Token 按约定格式拼接，再送入统一的语言模型进行自回归建模。
- **原因**：拼接后模型能在同一序列中建立视觉和文本之间的注意力关系。
- **关键点**：视觉 Token 位置；模态边界；位置编码；因果 Mask。
- **追问**：拼接式融合和 Cross-Attention 融合有什么区别？

### 2.3 `[面经]` 多模态对齐主要对齐什么？

- **答案**：需要对齐图像与文本的语义、局部区域与词语、视觉内容与指令任务之间的对应关系。
- **原因**：全局语义对齐只能让模型“看懂大意”，细粒度问答、定位和 OCR 还需要局部对齐。
- **关键点**：对比学习；图文匹配；生成式指令微调；区域级监督。
- **追问**：只用图文对比损失为什么不够？

### 2.4 `[面经]` 多模态模型相比纯文本模型的主要难点是什么？

- **答案**：难点包括模态表示空间不同、视觉 Token 成本高、细粒度感知不稳定、数据质量不一致和幻觉。
- **原因**：图像和文本的信息密度、噪声形式、序列长度和监督方式都不同。
- **关键点**：编码、对齐、数据、推理、评估五条链路同时优化。
- **追问**：如何判断问题来自视觉编码器还是语言模型？

### 2.5 `[面经]` 多模态模型为什么会产生视觉幻觉？

- **答案**：模型可能过度依赖语言先验，或者视觉证据不足、训练数据存在噪声、跨模态对齐不充分。
- **原因**：生成模型的语言流畅性不等于视觉事实正确，尤其在小目标、遮挡和复杂关系上更明显。
- **关键点**：增加视觉 grounding；困难负样本；拒答机制；细粒度幻觉评估。
- **追问**：如何构造视觉幻觉的评测集？

## 二、训练与评估

### 2.6 `[基础]` 多模态指令微调和纯文本 SFT 有什么区别？

- **答案**：多模态 SFT 的输入包含图像、视频或区域信息，监督目标仍可为文本，但需要保证视觉证据与回答对应。
- **原因**：如果只优化语言表达，模型可能学会模板而没有真正使用图像。
- **关键点**：多模态模板；视觉占位符；任务混合；图像质量与答案一致性。
- **追问**：怎样判断模型是否真的看了图？

### 2.7 `[面经]` 多模态模型应该如何评估？

- **答案**：按任务拆分评估视觉识别、OCR、图表推理、文档问答、视频时序、指令遵循和幻觉，同时记录 Token、显存和延迟。
- **原因**：单一平均分会掩盖模型在小字体、长视频或空间关系上的缺陷。
- **关键点**：公开基准 + 业务集；整体指标 + 困难子集；效果 + 成本。
- **追问**：为什么必须保留失败样本分析？

### 2.8 `[场景]` 如何设计多模态模型的线上监控？

- **答案**：监控输入分布、视觉 Token 数、请求延迟、输出格式、拒答率、幻觉抽检和业务任务指标。
- **原因**：线上问题可能来自输入分辨率、数据漂移、服务拥塞或模型输出异常，不一定是准确率下降。
- **关键点**：分桶统计；采样回放；告警阈值；灰度回滚。
- **追问**：没有人工标签时如何监控质量？

## 三、多模态 RAG 与应用

### 2.9 `[面经]` 多模态 RAG 和传统文本 RAG 有什么区别？

- **答案**：多模态 RAG 的知识单元不仅是文本，还包括图片、表格、页面区域和视频片段，需要统一索引、检索和生成上下文。
- **原因**：如果只抽成文本，可能损失版面、空间和视觉证据；如果直接塞原图，又会增加 Token 成本。
- **关键点**：多模态切片；跨模态 embedding；重排；证据引用。
- **追问**：表格图片应该转文本还是保留图像？

### 2.10 `[场景]` 如何设计企业文档多模态问答系统？

- **答案**：先做文档解析和区域切片，再分别建立文本、表格、图片和版面索引，检索后让 VLM 基于证据生成结构化答案。
- **原因**：企业文档的答案可能跨页、跨表格，单一 OCR 文本检索容易丢失布局和图表关系。
- **关键点**：页码和坐标保留；混合召回；重排；答案可追溯；权限过滤。
- **追问**：如何处理检索证据和模型答案不一致？
