## 一、一句话解释

> **Qwen 主系列（3.5 / 3.6 / 3.7 / 3.8）≠ 纯文本模型：开源中小尺寸（35B-A3B、27B）与 Plus 是原生多模态主力，Max 旗舰以文本推理 / Agent 立身、2026 年 6 月快照起补上视觉，Qwen3.8-Max-Preview（2.4T 参数）走向原生全模态——趋势是"旗舰也全模态"。**

拆开看三个事实：

1. **原生多模态进主系列**：从 Qwen3.5 起，开源版（397B-A17B / 122B-A10B / 35B-A3B / 27B）与 Plus 全部原生支持文本 / 图像 / 视频 / 文档输入，无需外接视觉编码器；
2. **Max 从纯文本起步**：Qwen3.7-Max 2026 年 5 月首发时是纯文本旗舰（不原生支持图像/音频输入），**2026-06-08 快照**才加入视觉模态理解；
3. **旗舰全模态收敛**：Qwen3.8-Max-Preview 是 2.4T 参数的**原生全模态** MoE（文本 + 视觉 + 音频 + 语音生成打通），正式版将开源。

> **面试记忆点**：2026 年 Qwen 的多模态分工 = **开源版与 Plus 承担多模态主力、Max 前期偏文本推理、6 月快照起补视觉、Qwen3.8 走向全模态旗舰**。回答"主系列是不是多模态"必须分型号、分时间，不能一刀切。

### 5.2 Qwen3.6-27B 架构详解

#### 5.2.1 混合注意力：Gated DeltaNet + Gated Attention

Qwen3.6-27B 的核心创新是**混合注意力（Hybrid Attention）**——在同一个模型中交替使用两类注意力层：

**① Gated DeltaNet（线性注意力层，省显存）**

DeltaNet 是线性注意力家族（GLA、Based、Mamba 等）的一员，其核心是"delta rule"更新隐状态：

$$\mathbf{h}_t = (1 - \alpha_t)\,\mathbf{h}_{t-1} + \alpha_t\,\mathbf{v}_t \otimes \mathbf{k}_t$$

其中 $\alpha_t = \sigma(\mathbf{x}_t^\top \mathbf{w}_\alpha)$ 是门控标量，$\otimes$ 为外积。加入门控（gated）版本后，每步用一个**常数大小的 KV 状态** $\mathbf{h}_t \in \mathbb{R}^{d}$ 递推更新，替代全注意力的 $O(L)$ 长度 KV 缓存：

$$\text{KV 显存：全注意力 } O(Ld) \ \longrightarrow \ \text{DeltaNet } O(d)$$

**收益**：长上下文推理时 KV 显存不随序列长度线性增长，256K 上下文可用显存装下。

**② Gated Attention（全注意力层，保表达）**

标准 softmax 注意力上加入门控：

$$\text{Attn}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d}}\right)\mathbf{V} \cdot \mathbf{g}$$

门控 $\mathbf{g}$ 让模型按 token 选择性缩放注意力输出。全注意力保留了对"细粒度信息检索"（翻原文、精确匹配）的强表达，这是纯线性注意力（如 Mamba）的短板。

**③ 为什么混合？**

| 维度 | 线性注意力（DeltaNet） | 全注意力 |
|------|----------------------|----------|
| KV 显存 | $O(d)$ 常数，长上下文友好 | $O(Ld)$，随长度线性涨 |
| 表达力 | 有限（隐状态压缩为单向量） | 强（逐 token 检索） |
| 适合任务 | 长文档、流式、指令跟随 | 精确检索、复杂推理 |
| 混合方案 | **主体层（约 3/4）** | **关键层（约 1/4，每 4 层插 1 层）** |

#### 5.2.2 混合布局（面试常考）

Qwen3.6-27B 的层布局：

$$16 \times \big[\, 3 \times (\text{Gated DeltaNet} \rightarrow \text{FFN}) \rightarrow 1 \times (\text{Gated Attention} \rightarrow \text{FFN}) \,\big]$$

即共 16 个大块，每块内先连 3 个"Gated DeltaNet → FFN"层，再放 1 个"Gated Attention → FFN"层。**比例 3:1**——大部分层用省显存的线性注意力承载长上下文，小部分层用全注意力兜住强表达。

> **面试记忆点**：27B 稠密 + 混合注意力 = 在"稠密、单卡可部署"的约束下，用线性注意力把上下文撑到 262K，用门控注意力保住推理精度。这是"性能密度"路线的架构基础。

#### 5.2.3 上下文：262144 原生 → 1,010,000 扩展

| 项 | 数值 |
|----|------|
| 原生训练上下文 | **262,144 token**（$2^{18}$，原生无需截断） |
| 扩展方式 | **YaRN**（Yet another RoPE extensioN） |
| 扩展后上限 | **1,010,000 token**（约 1M，$2^{20}$ 附近） |

YaRN 通过调整 RoPE 的频域缩放（NTK-aware + 线性插值结合）把位置编码外推到约 4 倍，无需重新训练即可复用长上下文。1M 级上下文让"整本书 / 整仓库代码 / 长会议记录"成为单次推理输入。

#### 5.2.4 原生多模态：单一 checkpoint，无需外部视觉编码器

Qwen3.6-27B 的多模态是**原生（native）**的，与"视觉编码器 + 投影层 + LLM"的经典 LLaVA 路线有本质区别：

| 维度 | 经典方案（视觉编码器接入） | **Qwen3.6-27B 原生方案** |
|------|---------------------------|--------------------------|
| 视觉理解 | 外接 ViT（如 SigLIP），需投影层对齐 | **无需额外视觉编码器接入**，模型本体直接吃视觉 token |
| 权重形态 | 视觉塔 + LLM 多套权重 | **单一 checkpoint**（一个权重文件） |
| 训练方式 | 视觉塔冻结 + LLM 微调（分阶段） | 从头统一训练，模态对齐内生于预训练 |
| 部署 | 需要多组件加载 | 单模型加载即用 |

支持的输入形态：**文本 / 图像 / 视频 / 文档**（文档即图文混合的长序列）。这一设计把"多模态模型"从"拼装车"变成"一体车"——部署简单、幻觉更少、模态间共享同一语义空间。

#### 5.2.5 思考 / 非思考双模式

延续 Qwen3 系列的双模式设计：

| 模式 | 适用场景 |
|------|----------|
| **思考模式（Thinking）** | 复杂推理、数学、编码难题（推理时生成思维链） |
| **非思考模式（Non-Thinking）** | 日常对话、快速回答（低延迟、省算力） |

### 5.3 性能密度：27B 全面超越 397B（本代最重要的事实）

| Benchmark | **Qwen3.6-27B** | Qwen3.5-397B-A17B | 差距 |
|-----------|-----------------|--------------------|------|
| SWE-bench Verified | **77.2** | 76.2 | +1.0 |
| Terminal-Bench 2.0 | **59.3** | 52.5 | +6.8 |
| SkillsBench | **48.2** | 30.0 | +18.2 |

397B-A17B 参数约为 27B 的 **15 倍**（397/27 ≈ 14.7），但 27B 在三个关键编码 / 技能 benchmark 上**全面超越**。意义：

1. **性能密度路线胜利**：混合注意力 + 高质量数据 + 可扩展 RL，小模型完全可能反超大模型；
2. **部署友好**：27B 稠密可单卡（或多卡少量）部署，不需要千卡级 MoE 集群；
3. **对面试**：这是 2026 年"小参数打大模型"叙事的最硬实证，与"参数迷信"形成对照。

### 5.4 Qwen3.6-35B-A3B 与 Plus：截图 → 前端代码链路

| 模型 | 链路 | 关键能力 |
|------|------|----------|
| **Qwen3.6-Plus**（API） | **界面截图 / 设计稿 → 前端代码** | 原生多模态数据训练；**编程最强国产**；视觉理解与代码生成在同一模型内闭环 |
| Qwen3.6-35B-A3B（开源） | 开源版同链路能力 | MoE 稀疏激活（35B 总参 / 3B 激活），本地可跑 |

**截图 → 前端代码**的本质：模型同时具备"看懂 UI 布局（视觉）"与"生成 HTML/CSS/JS（代码）"两种能力，且二者在同一语义空间内互相协作——这是单一模型原生多模态的优势，拼接式方案（视觉模型描述 → 代码模型生成）在两跳之间丢信息。

## 六、Qwen3.7（2026.05）：Agent 时代旗舰与多模态智能体基座（重点）

### 6.1 Qwen3.7-Max（05-20）：面向智能体时代的旗舰

#### 6.1.1 核心定位

> **Qwen3.7-Max = 面向智能体时代的文本推理旗舰：万亿参数 MoE + 正交解耦架构，主打长程自主任务与高并发工具调用。**

| 项 | 数值 / 内容 |
|----|-------------|
| 参数规模 | **万亿参数 MoE** |
| 上下文 | **100 万 tokens** |
| 并发 | **30K RPM**（高并发） |
| 长程任务 | **35 小时全自主任务**（自主编程 + **超 1000 次工具调用**） |
| 推理效率 | 芯片内核自我进化，推理速度提升 **10 倍** |
| 基准 | GPQA **92.4**、SWE-bench Pro **60.6** |
| 生态 | **MCP 集成**（Model Context Protocol） |
| 架构 | **正交解耦底层架构**：长链路推理不断片、工具调用稳定 |

#### 6.1.2 Arena 战绩

Arena 全球盲测总榜**国产第一**——超过 Kimi-K2.6、DeepSeek-v4-pro、GLM-5.1，接近 GPT / Claude / Gemini 最强档。这是"国产模型追平国际最强"的标志性数据点。

#### 6.1.3 架构关键词：正交解耦（Orthogonal Decoupling）

"正交"指把影响 Agent 稳定性的多个因素（长链路推理、工具调用、上下文管理）在架构上**互相独立**：

- 长链路推理不断片：100 万上下文内长时间多步推理不丢失状态；
- 工具调用稳定：1000+ 次连续工具调用不崩、不串、不重复；
- 自我进化：芯片内核（kernel）在任务中自我优化，推理提速 10 倍。

> **面试记忆点**：Agent 旗舰的卖点不再是"单题分数"，而是"长程稳定性 + 工具调用可靠性"——这是 2026 年模型评测范式的转向（从 benchmark 到长程 Agent 任务）。

#### 6.1.4 多模态边界（必须按时间分阶段）

| 阶段 | 时间 | 视觉 / 音频能力 |

## 十、高频面试问答

**Q1：Qwen3.6-27B 怎么用 27B 打 397B？**
三张牌：① 架构——Gated DeltaNet 线性注意力 + Gated Attention 混合，稠密 27B 在 262K 长上下文下 KV 显存可控；② 数据与训练——高质量多模态数据 + 可扩展 RL，性能密度来自训练质量而非堆参数；③ 事实——SWE-bench Verified 77.2 vs 76.2、Terminal-Bench 2.0 59.3 vs 52.5、SkillsBench 48.2 vs 30.0，三项全部超越 15 倍参数的 397B MoE。结论：参数规模不是实力的唯一标尺。

**Q2：Gated DeltaNet 是什么？**
线性注意力家族成员，基于 delta rule 更新隐状态：$\mathbf{h}_t = (1-\alpha_t)\mathbf{h}_{t-1} + \alpha_t \mathbf{v}_t \otimes \mathbf{k}_t$，门控 $\alpha_t$ 决定遗忘与写入。核心收益：KV 状态常数大小（$O(d)$），KV 显存不随序列长度线性增长，长上下文（262K）可单卡部署；代价是表达力弱于全注意力，所以要与 Gated Attention 混合使用。

**Q3：Max 是多模态模型吗？**
按时间分阶段：Qwen3.7-Max 2026 年 5 月首发时是**纯文本旗舰**（不原生支持图像 / 音频输入）；**2026-06-08 快照**（Qwen3.7-Max-2026-06-08）才加入视觉模态理解，可感知真实世界场景、做多模态交互混合智能体；Qwen3.8-Max-Preview 更进一步，2.4T 原生全模态。所以"Max 是多模态"只对 6 月快照之后成立，不能一刀切。

**Q4：Plus 和 Max 怎么选？**
看任务类型：Max = 万亿 MoE 文本推理 / 长程 Agent 旗舰（35 小时自主任务、1000+ 工具调用、GPQA 92.4），适合深度推理、复杂编码；Plus = 35B 稠密原生多模态智能体基座（五大输入形态、GUI + CLI 双环境、ScreenSpot Pro 79.0、AndroidWorld 81.0），适合看屏幕操作、截图 → 代码、多模态感知任务，且性价比高。一句话：想得深用 Max，看得全 + 做事用 Plus。

**Q5：Qwen3.7-Max 的视觉是什么时候加的？**
2026 年 6 月 8 日快照（Qwen3.7-Max-2026-06-08）。5 月 20 日首发时是纯文本旗舰；6 月 8 日快照增加视觉模态理解后，Max 才具备感知真实世界场景、作为多模态交互混合智能体的能力。

**Q6：原生多模态和"视觉编码器 + 投影 + LLM"有什么区别？**
经典方案（LLaVA 路线）外接 ViT 视觉塔 + 投影层，视觉理解依赖外部编码器，需分阶段训练、多组件部署；Qwen3.6-27B 的原生方案**无需额外视觉编码器接入**，单一 checkpoint 直接吃文本 / 图像 / 视频 / 文档，模态对齐内生于预训练。收益：部署简单、模态共享同一语义空间、截图 → 代码这类跨模态协作任务更稳。

**Q7：混合布局 16×(3×DeltaNet→FFN)→1×(Attention→FFN) 怎么理解？**
共 16 个大块，每块内 3 个 Gated DeltaNet（线性注意力）层后接 1 个 Gated Attention（全注意力）层，比例 3:1。线性注意力层负责长上下文（KV 显存 $O(d)$，262K 上下文装得下），全注意力层负责精确检索与强表达，两全其美。面试可说：这是"性能密度"路线的架构基石。

**Q8：Qwen3.8-Max-Preview 相对 Qwen3.7-Max 强在哪？**
三点：① 复杂多轮智能体任务准确率 +35%；② 长文本幻觉率 -62%；③ 全栈代码开发完整性 +40%。再加上 2.4T 参数、百万级上下文、双推理模式、原生全模态、多智能体协同，且正式版将开源。意义是"旗舰也全模态"的落地。

**Q9：主系列、VL、Omni 是什么关系？**
时间线关系：VL（2003-2025，视觉语言，终结于 Qwen3-VL）→ Omni（2025-2026，全模态统一，Thinker-Talker）→ 主系列（2026，收容器）。VL 的视觉能力与 Omni 的全模态能力被主系列完整吸收：开源版与 Plus 原生多模态，Max 从纯文本到 6 月快照补视觉再到 2.4T 原生全模态。命名上后缀消失，能力全部继承。

**Q10：262144 原生上下文为什么还要扩到 1,010,000？**
262144（$2^{18}$）是原生训练长度；用 YaRN 位置编码扩展把 RoPE 频域按 NTK-aware 方式缩放，可外推到 1,010,000（约 $2^{20}$），约 4 倍扩展且无需重新训练。收益是整本书 / 整仓库代码 / 长会议记录单次输入。面试点：线性注意力省下 KV 显存，才让"1M 上下文真的推得动"。

## 十一、常见误区

**误区 1：Max 一直支持图像输入。**
错。Qwen3.7-Max 2026 年 5 月首发是纯文本旗舰（不原生支持图像 / 音频输入），2026-06-08 快照才加入视觉模态理解；原生全模态要到 Qwen3.8-Max-Preview（2.4T）。"Max = 多模态"必须限定在 6 月快照之后。

**误区 2：Qwen3.6-27B 是 MoE。**
错。27B 是**稠密模型**——参数全量激活。它的特殊之处不在稀疏化，而在混合注意力（Gated DeltaNet 线性注意力 + Gated Attention 全注意力按 3:1 布局）与原生多模态。MoE 档是 35B-A3B 和 397B-A17B。

**误区 3：主系列没有多模态，多模态只在 VL / Omni。**
错。2026 年起主系列就是多模态主线：开源版（397B-A17B、27B、35B-A3B、3.8-27B）与 Plus 全部原生多模态，VL / Omni 后缀已让位于主系列。主系列不是"纯文本升级版"，而是"Omni 能力的收容器"。

**误区 4：原生多模态 = 模型里塞了个视觉编码器。**
错。Qwen3.6-27B 的原生多模态**不需要额外视觉编码器接入**，单一 checkpoint 直接理解文本 / 图像 / 视频 / 文档，与"视觉塔 + 投影 + LLM"的拼接方案是两种路线。

**误区 5：Qwen3.8-Max-Preview 只是 Max 的小升级。**
错。它是主系列多模态的终点形态：2.4T 原生全模态 + 多智能体协同 + 相对 Qwen3.7-Max 复杂 Agent 任务 +35%、幻觉 -62%、代码完整性 +40%，且正式版将开源——"旗舰也全模态"由它落地。
