# 算法笔试与面试高频机器学习题

## 一、概念判断题

### 1. 训练误差越低，测试误差一定越低吗？

不一定。训练误差下降可能伴随过拟合，测试误差通常先降后升；还要排除数据泄漏和训练/测试分布差异。

### 2. L1 正则一定比 L2 正则产生更多 0 权重吗？

通常更容易产生稀疏解，但结果取决于数据、正则强度和特征相关性。“一定”过强。

### 3. AUC 越高，Accuracy 一定越高吗？

不一定。AUC 衡量全阈值排序能力，Accuracy 是某个阈值和类别分布下的结果。

### 4. 决策树需要标准化吗？

通常不需要，因为阈值切分对单调缩放不敏感；但缺失值、异常值和编码仍需处理。

### 5. PCA 是监督降维吗？

标准 PCA 不使用标签，是无监督降维；它最大化输入方差，不保证最有利于分类。

### 6. 相关系数为 0 是否说明两个变量独立？

不说明。独立能推出不相关，但不相关一般不能推出独立；联合高斯是常见特殊情况。

## 二、计算与手推题

### 1. 二分类指标

给定 $TP=80, FP=20, FN=40, TN=860$：

$$Precision=80/(80+20)=0.8$$

$$Recall=80/(80+40)=2/3$$

$$F1=2\times0.8\times(2/3)/(0.8+2/3)\approx0.727$$

Accuracy 为 $940/1000=0.94$，但不能据此忽略 Recall；这正是类别不均衡场景的常见陷阱。

### 2. 逻辑回归梯度

若 $p=\sigma(w^Tx)$，单样本 BCE 的 logit 梯度为 $p-y$，参数梯度为：

$$\nabla_wL=(p-y)x$$

### 3. K-Means 更新

给定簇分配后，令目标 $\sum_{x_i\in C_k}\|x_i-\mu_k\|^2$ 最小，对 $\mu_k$ 求导得：

$$\mu_k=\frac{1}{|C_k|}\sum_{x_i\in C_k}x_i$$

### 4. 贝叶斯计算

若 $P(A)=0.1,P(B|A)=0.8,P(B|\bar A)=0.2$，则：

$$P(B)=0.1\times0.8+0.9\times0.2=0.26$$

$$P(A|B)=\frac{0.1\times0.8}{0.26}\approx0.308$$

注意不要把 $P(A|B)$ 和 $P(B|A)$ 混淆。

### 5. 熵计算

二分类节点类别比例为 $(0.5,0.5)$ 时，熵最大；比例为 $(1,0)$ 时，熵为 0。对数底数只改变单位和常数比例，不改变最优划分排序。

## 三、算法比较题

| 问题 | 推荐答题要点 |
|---|---|
| L1 vs L2 | L1 稀疏，L2 平滑；几何尖角 vs 圆形；相关特征下 L2 通常更稳定 |
| Bagging vs Boosting | 前者并行降方差，后者串行修正负梯度、主要降偏差 |
| GBDT vs 随机森林 | Boosting 顺序纠错，RF 独立平均；前者更强但对噪声更敏感 |
| PCA vs 特征选择 | PCA 生成新正交特征，特征选择保留原始列；前者压缩强、可解释性弱 |
| 逻辑回归 vs SVM | 都可做线性分类；逻辑回归有概率解释，SVM 关注 margin 和支持向量 |
| One-Class SVM vs Isolation Forest | 前者边界/核方法，小样本可用；后者随机隔离、速度快、适合大规模 |
| Triplet vs InfoNCE | 前者显式 anchor-positive-negative + margin，后者在候选集合上做对比分类 |

## 四、现象—原因—方案题

### 1. 训练集和验证集都很差

可能是特征/标签错、任务难、模型容量不足、训练未收敛或预处理不一致。先做小样本过拟合测试、检查标签和输入，再调模型与训练。

### 2. 训练集很好，验证集很差

优先排查数据泄漏、近重复划分、分布差异、标签噪声和过拟合；随后考虑数据增强、正则化、降低容量、增加代表性难例。

### 3. Accuracy 很高但少数类 Recall 很低

类别不均衡或阈值偏向多数类。看混淆矩阵、PR-AUC 和分层指标，使用类别权重/采样/阈值优化，并保留真实分布验证集。

### 4. ROC-AUC 高但线上报警很多

排序可能没问题，但阈值、类别比例、概率校准或线上分布发生变化。使用线上代表性验证集重新选阈值，监控 PR、误报成本和分数漂移。

### 5. 图文检索 Recall@K 下降

依次检查：文本/图片预处理、向量是否归一化、度量是否一致、数据和 hard negative、模型 embedding 质量、ANN 索引参数和过滤条件。先用暴力检索区分模型问题与索引问题。

### 6. VLM 输出流畅但视觉事实错误

语言先验压过视觉证据、视觉 token 压缩损失细节、数据中存在共现偏差或评测只看语言相似度。可增加细粒度/反事实数据、OCR/检测工具复核、引用区域证据，并用事实一致性评测。

## 五、多模态场景开放题

### Q1：如何设计商品图文一致性模型？

先定义颜色、数量、品牌、款式等错误类型并构造分层数据；用 CLIP/SigLIP 做图文相似度初筛，再用属性抽取或 VLM 进行细粒度复核，最后用分类器/规则融合。评估报告整体 F1、各错误类型 Recall/Precision、阈值、延迟和 badcase。

### Q2：如何做零样本工业异常检测？

用正常图像建立 patch/global 表示或使用视觉-文本对齐模型，把异常类别/缺陷描述转成文本原型，得到 patch 异常图和 image-level score。用正常验证集及少量代表性缺陷校准阈值，分别评估图级识别和像素级定位，VLM 只作为解释或复核层。

### Q3：如何判断模型是否真正学到了图文关系？

设计反事实测试：保持图片不变替换关键属性文本、保持文本不变替换图片属性、加入 hard negative 和同背景不同主体样本；按颜色/数量/品牌/场景分层评估，并检查模型是否只依赖 OCR、背景或高频词。

## 六、答题与排错口诀

```text
先定义任务，再确认数据；
先查泄漏和指标，再调模型；
先做 baseline，再加复杂度；
先看分层 badcase，再看平均分；
先区分模型、索引、服务，再谈优化。
```
