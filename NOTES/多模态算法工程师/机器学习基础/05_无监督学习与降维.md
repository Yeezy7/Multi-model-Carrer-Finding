# 无监督学习与降维

## 一、K-Means 聚类

K-Means 给定簇数 $K$，最小化样本到所属中心的平方距离：

$$J=\sum_{k=1}^{K}\sum_{x_i\in C_k}\|x_i-\mu_k\|_2^2$$

迭代过程：

1. 初始化 $K$ 个中心；
2. 将每个样本分配给最近中心；
3. 对每个簇取均值更新中心；
4. 直到中心变化或目标函数下降小于阈值。

K-Means 每轮分配复杂度约为 $O(nKd)$，其中 $n$ 为样本数、$K$ 为簇数、$d$ 为特征维度；结果依赖初始化，通常使用 K-Means++。

### 1.1 局限

- 需要预先指定 $K$；
- 偏好近似球形、尺度相近的簇；
- 对异常点敏感；
- 欧氏距离在高维空间可能退化；
- 不同特征尺度会直接改变距离，应在训练集上先做合适缩放。

## 二、GMM 与 EM

高斯混合模型假设数据来自 $K$ 个高斯分布的加权混合：

$$p(x)=\sum_{k=1}^{K}\pi_k\mathcal{N}(x|\mu_k,\Sigma_k)$$

EM 交替执行：

- **E 步**：计算样本属于每个成分的责任度 $\gamma_{ik}=P(z_i=k|x_i)$；
- **M 步**：用责任度加权更新 $\pi_k,\mu_k,\Sigma_k$。

EM 每轮不会降低似然，但只能保证收敛到局部最优，初始化和成分数仍很重要。K-Means 可看作方差相同且趋于 0 的 GMM 的特殊极限。

## 三、PCA 主成分分析

PCA 用一组正交方向把数据投影到低维空间，同时最大化投影方差或最小化重构误差。

### 3.1 计算流程

1. 在训练集上对每个特征中心化；
2. 计算协方差矩阵 $\Sigma=\frac{1}{n}X^TX$；
3. 求 $\Sigma$ 的特征值和特征向量；
4. 取最大 $k$ 个特征值对应的方向组成 $W_k$；
5. 得到低维表示 $Z=XW_k$。

最大方差方向满足：

$$\max_{\|w\|_2=1}w^T\Sigma w$$

由拉格朗日乘子可知，最优 $w$ 是协方差矩阵最大特征值对应的特征向量。

### 3.2 重构误差视角

保留前 $k$ 个主成分等价于在所有 $k$ 维线性子空间中最小化投影重构误差。解释方差比：

$$r_k=\frac{\sum_{j=1}^{k}\lambda_j}{\sum_{j=1}^{d}\lambda_j}$$

PCA 是线性降维，不等价于选择原始特征；主成分通常是原始特征的线性组合。

## 四、降维与多模态 Embedding

PCA、随机投影可以用于可视化、去噪和压缩，但不能默认“二维图上分得开”就代表任务性能好。t-SNE/UMAP 更适合可视化局部结构，不应直接作为分类或检索效果证据：

- 对距离和全局结构有变换；
- 对初始化、参数和随机种子敏感；
- 二维簇间距离不一定有语义意义。

多模态 embedding 可用 PCA 降维后做索引压缩，但需要在独立验证集上检查 Recall@K 是否下降，并注意 PCA 必须只在训练库拟合，不能用测试查询参与拟合。

## 五、聚类评估

无标签时不能直接使用 Accuracy。常用内部指标：

- **轮廓系数**：比较样本与本簇平均距离 $a$、与最近其他簇平均距离 $b$，$s=(b-a)/\max(a,b)$；
- **Calinski-Harabasz**：类间离散度与类内离散度之比；
- **Davies-Bouldin**：簇内散度与簇间距离的相对比值，越小越好。

有标签时可用 ARI、NMI 等衡量聚类与真实标签的一致性。选择 $K$ 可结合业务先验、肘部法、轮廓系数和稳定性，而不是只看单次最优分数。

## 六、高频面试题

### Q1：PCA 为什么要中心化？

协方差和方差描述的是相对均值的波动。若不中心化，均值位置会影响主方向，第一主成分可能只是指向数据均值，而不是表示样本变化。

### Q2：PCA 和特征选择有什么区别？

特征选择保留原始特征的子集，可解释性强；PCA 生成新的正交特征，通常压缩更有效但可解释性弱。

### Q3：K-Means 适合所有聚类任务吗？

不适合。它依赖欧氏距离和球形簇假设，对尺度、异常值、初始化和 $K$ 敏感。非球形或密度不均数据可以考虑 DBSCAN、谱聚类或 GMM，但仍需结合业务验证。
