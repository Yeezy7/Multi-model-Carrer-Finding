# 决策树与集成学习

## 一、决策树的基本思想

决策树通过一系列特征划分，把样本递归分到更“纯”的叶节点。内部节点是判断条件，叶节点输出类别或数值。

分类树常用不纯度：

### 1.1 熵与信息增益

$$H(S)=-\sum_{k=1}^{K}p_k\log p_k$$

以特征 $A$ 划分后的信息增益：

$$IG(S,A)=H(S)-\sum_v\frac{|S_v|}{|S|}H(S_v)$$

ID3 倾向选择取值多的特征，因此 C4.5 使用信息增益率：

$$GainRatio=\frac{IG(S,A)}{H(A)}$$

### 1.2 Gini 指数

$$Gini(S)=1-\sum_{k=1}^{K}p_k^2$$

CART 选择使加权 Gini 最小的划分。二分类中，纯节点 Gini 为 0，类别各半时最大。

| 指标 | 常见算法 | 直觉 |
|---|---|---|
| 信息增益 | ID3 | 划分后不确定性下降最多 |
| 信息增益率 | C4.5 | 对多取值特征做惩罚 |
| Gini | CART | 随机抽两个样本，类别不同的概率 |

回归树通常以节点内平方误差或方差下降为划分标准，叶节点输出该区域目标均值。

## 二、树的生长与剪枝

基本流程：

1. 从根节点开始枚举候选特征和切分点；
2. 选择使加权不纯度下降最多的切分；
3. 对左右子节点递归执行；
4. 达到停止条件后，把节点变为叶子。

停止条件包括最大深度、最小叶子样本数、最小不纯度下降和最大叶节点数。树太深会记忆噪声，需要预剪枝或后剪枝。

CART 的代价复杂度与样本数、特征数、候选切分数有关；工程中排序特征、直方图分桶和近似切分用于加速。

## 三、随机森林：Bagging 的代表

随机森林训练许多决策树，每棵树使用：

- Bootstrap 对样本有放回采样；
- 每个节点只随机选择部分特征；
- 分类多数投票，回归取平均。

通过平均多个高方差、低相关的树，随机森林主要降低方差。树之间越相关，集成收益越小。

未被某棵树采到的样本叫 OOB（out-of-bag）样本，可以近似作为该树的验证样本，减少额外验证集需求。

## 四、Boosting：从弱学习器到强学习器

Boosting 顺序训练弱学习器，让后一个模型重点修正前面模型的错误。一般形式：

$$F_m(x)=F_{m-1}(x)+\eta h_m(x)$$

$\eta$ 是学习率，$h_m$ 是第 $m$ 个弱学习器。学习率越小通常需要更多树，但泛化可能更好。

### 4.1 GBDT

GBDT 在每轮拟合当前模型损失对预测值的负梯度（伪残差）：

$$r_{im}=-\left[\frac{\partial \ell(y_i,F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$$

回归平方损失时，伪残差就是 $y_i-F_{m-1}(x_i)$；分类时则是概率意义下的残差。

### 4.2 XGBoost 与 LightGBM

| 模型 | 关键特点 | 常见优势 |
|---|---|---|
| GBDT | 梯度提升树的基本范式 | 解释清晰、效果强 |
| XGBoost | 二阶泰勒展开、正则化、列采样、并行优化 | 稳定、功能完整、小中型数据强 |
| LightGBM | Histogram、Leaf-wise 生长、GOSS/EFB | 大规模数据训练快、内存低 |

XGBoost 的二阶近似目标可写为：

$$\mathcal{L}^{(t)}\approx\sum_i[g_i f_t(x_i)+\frac{1}{2}h_i f_t^2(x_i)]+\Omega(f_t)$$

其中 $g_i$、$h_i$ 是一阶和二阶梯度。LightGBM 的 leaf-wise 生长每次分裂收益最大的叶子，效果可能更强但更容易过拟合，需要限制叶子数、深度或最小叶样本数。

## 五、Bagging 与 Boosting 对比

| 维度 | Bagging | Boosting |
|---|---|---|
| 训练关系 | 并行、相互独立 | 串行、后者修正前者 |
| 主要降低 | 方差 | 偏差，也可能降低方差 |
| 代表 | 随机森林 | GBDT/XGBoost/LightGBM |
| 对噪声 | 相对稳健 | 对异常值和错误标签更敏感 |
| 调参重点 | 树数量、特征采样、深度 | 学习率、树数、深度、正则化 |

## 六、特征重要性与工程陷阱

- Gini/增益重要性偏爱取值多或连续特征；
- Permutation importance 更接近“打乱该特征后性能下降多少”，但特征相关时解释会不稳定；
- SHAP 可解释单样本贡献，但计算和解释成本更高；
- 树模型通常不要求特征标准化；
- 缺失值处理和类别编码仍需按模型实现确认，不能把“树不怕尺度”误解为“不需要数据清洗”。

多模态场景中，树模型常作为融合器：输入 CLIP 相似度、OCR 置信度、检测数量、VLM 属性分数，输出审核或匹配结果。它不替代视觉编码器，而是学习多路信号的非线性组合。

## 七、高频面试题

### Q1：随机森林为什么不容易过拟合？

单棵树可能高方差，但 Bootstrap 和随机特征子集让树之间具有差异；平均低相关模型能降低方差。它不是绝对不会过拟合，树太多通常趋于稳定，但树深、噪声特征和分布漂移仍会影响泛化。

### Q2：GBDT 为什么要拟合残差？

平方损失下残差就是对预测值的负梯度；一般损失下拟合的是负梯度方向的伪残差。因此每一棵新树都在当前模型最需要改进的方向上更新。

### Q3：LightGBM 为什么训练快？

主要利用直方图把连续特征离散化、减少候选切分；采用 leaf-wise 生长提高单轮收益；并使用 GOSS、EFB 等方法减少样本或特征开销。代价是 leaf-wise 更容易过拟合，需要限制叶子规模。
