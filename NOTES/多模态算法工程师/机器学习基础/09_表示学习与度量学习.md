# 表示学习与度量学习

## 一、从特征到表示

特征是输入的可用描述，表示学习则让模型自动学习一个空间，使任务相关的样本结构变得明显：

$$z=f_\theta(x)$$

好的表示通常满足：同类/匹配样本更近，不同类/不匹配样本更远，同时保留任务需要的细粒度信息。图像、文本和音频可以分别编码，再通过投影层映射到共享空间。

## 二、距离与相似度

### 2.1 欧氏距离

$$d(x,y)=\|x-y\|_2$$

对高维 embedding，欧氏距离容易受到向量范数影响。

### 2.2 余弦相似度

$$cos(x,y)=\frac{x^Ty}{\|x\|_2\|y\|_2}$$

只关注方向，不直接关注长度。若向量已经 L2 归一化，余弦相似度等于内积，便于使用 FAISS 等向量索引。

距离选择必须与训练目标和索引度量一致；训练时用 cosine、线上用未归一化 inner product，可能导致排序变化。

## 三、Triplet Loss

给定 anchor $a$、正样本 $p$、负样本 $n$：

$$L=\max(0,d(a,p)-d(a,n)+m)$$

目标是让正样本距离至少比负样本小 margin $m$。负样本太容易时 loss 为 0、没有学习信号；困难负样本过多又可能引入假负样本和训练不稳定，因此需要 hard/semi-hard mining。

## 四、InfoNCE 与对比学习

给定一个正样本和一组候选：

$$L_i=-\log\frac{\exp(sim(z_i,z_i^+)/\tau)}{\sum_j\exp(sim(z_i,z_j)/\tau)}$$

它本质上把“从候选中找出匹配样本”转成分类问题。温度 $\tau$ 控制分布尖锐程度；batch 内其他样本常作为负样本。

对比学习的关键不是只换一个 loss，而是同时设计：

- 正样本定义是否可靠；
- 负样本是否为真负样本；
- batch 是否覆盖足够多样性；
- 相似度与归一化是否一致；
- 评估是否与线上检索目标一致。

详细公式与 CLIP 双向训练见 [对比学习与 CLIP](../算法论文基础/04_对比学习与CLIP.md)，SigLIP 的 sigmoid loss 见 [SigLIP 图文对齐](../算法论文基础/05_SigLIP图文对齐.md)。

## 五、CLIP 与传统度量学习的关系

CLIP 用图像编码器和文本编码器生成共享空间表示，对 batch 内图文相似度矩阵做双向对比学习：

```text
图像 → image encoder → image embedding ┐
                                       ├→ 相似度矩阵 → 对比损失
文本 → text encoder  → text embedding  ┘
```

和 Triplet 的区别：CLIP 通常一次使用 batch 中大量候选，InfoNCE 提供归一化分类目标；Triplet 明确指定一个负样本和 margin。两者都依赖高质量正负关系。

## 六、检索评估与 embedding 诊断

- Recall@K：正确目标是否出现在前 K；
- MRR：第一个正确结果排名的倒数；
- mAP：多个相关结果下的平均精度；
- embedding 可视化只用于诊断，不能替代检索指标。

常见 badcase：

1. 只匹配背景和风格，没有识别主体属性；
2. 文本标题包含高频词，模型忽略数量、材质、颜色；
3. hard negative 其实是语义近邻正例；
4. 向量库近似搜索误差被误认为模型表示误差；
5. 训练评估随机切分造成同商品近重复。

## 七、多模态项目中的选型

| 需求 | 合适表示/目标 |
|---|---|
| 文本搜图/图搜图 | 双塔 embedding + 对比学习 |
| 图文是否一致 | embedding 初筛 + 匹配分类器或 VLM 复核 |
| 细粒度属性识别 | 局部/区域表示 + 监督分类或生成式问答 |
| 多模态 RAG | 共享向量空间 + 元数据过滤 + rerank |
| 零样本异常检测 | 正常/异常文本原型与图像 patch 表示对齐 |

## 八、高频面试题

### Q1：为什么要做 L2 归一化？

它把向量长度影响从相似度中分离，使内积等于余弦相似度，并让不同样本的尺度更可比。是否归一化取决于训练目标；不能把所有 embedding 都无条件归一化。

### Q2：对比学习为什么需要 hard negative？

容易负样本很快被区分，梯度接近 0；语义相近但不匹配的 hard negative 能迫使模型学习细粒度差异。但假负样本会把真正相关样本推远，需要清洗、分层采样或软标签。

### Q3：Recall@K 下降，怎么判断是模型还是向量库问题？

先用精确暴力搜索评估同一批 embedding，再与 ANN 索引比较；若暴力也差，查模型/数据/负样本；若暴力好而 ANN 差，查索引参数、向量归一化、度量类型和过滤条件。
