# 线性模型与逻辑回归

## 一、线性回归

线性回归假设目标与特征的条件期望可以由线性函数表示：

$$\hat y=w^Tx+b$$

最小二乘目标：

$$L(w,b)=\frac{1}{n}\sum_{i=1}^{n}(w^Tx_i+b-y_i)^2$$

矩阵形式在满秩且无正则时的正规方程为：

$$\hat w=(X^TX)^{-1}X^Ty$$

实际工程中更常用梯度下降或带正则的数值求解，因为 $X^TX$ 可能不可逆、计算复杂度高且数值不稳定。

### 1.1 梯度

令 $\hat y=Xw$，$L=\frac{1}{n}\|Xw-y\|_2^2$，则：

$$\nabla_wL=\frac{2}{n}X^T(Xw-y)$$

梯度下降：

$$w\leftarrow w-\eta\nabla_wL$$

## 二、L1、L2 与 Elastic Net

$$L_{ridge}=L+\lambda\|w\|_2^2$$

$$L_{lasso}=L+\lambda\|w\|_1$$

| 方法 | 约束效果 | 特点 |
|---|---|---|
| Ridge/L2 | 平滑压小全部权重 | 共线特征下更稳定，不产生严格 0 |
| Lasso/L1 | 产生稀疏权重 | 可做特征选择，但相关特征可能随机选一个 |
| Elastic Net | L1 + L2 | 兼顾稀疏和相关特征稳定性 |

正则化强度越大，模型方差通常下降、偏差上升。正则项一般不作用于偏置 $b$；特征尺度差异很大时，L1/L2 的惩罚会失去公平性，因此训练集拟合标准化后再应用。

## 三、逻辑回归

逻辑回归用于二分类，但它不是回归类别数，而是建模条件概率：

$$z=w^Tx+b, \qquad p(y=1|x)=\sigma(z)=\frac{1}{1+e^{-z}}$$

预测规则常取 $p\ge 0.5$，但 0.5 不是永远正确的业务阈值。决策边界 $p=0.5$ 等价于 $z=0$，所以仍是线性边界。

### 3.1 对数几率

$$\log\frac{p}{1-p}=w^Tx+b$$

每个权重表示对应特征增加一个单位时，对数几率的变化；$e^{w_j}$ 是在其他特征不变时的 odds ratio。

### 3.2 二元交叉熵

$$L=-\frac{1}{n}\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)]$$

对 logit 的单样本梯度是：

$$\frac{\partial L_i}{\partial z_i}=p_i-y_i$$

这个形式是逻辑回归易考的手推结论。它说明预测偏大时梯度为正，会把 logit 往下推；预测偏小时反之。

## 四、多分类逻辑回归与 Softmax

对 $K$ 类 logits $z$：

$$p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}$$

交叉熵：

$$L=-\sum_{k=1}^{K}y_k\log p_k$$

若标签是 one-hot，等于正确类别的 $-\log p_y$。Softmax 对所有 logit 同时归一化；多标签分类不能用 Softmax，因为多个标签可以同时为真，应使用独立 Sigmoid。

## 五、线性模型的优缺点

优点：训练快、可解释、适合高维稀疏特征、容易校准和做 baseline。局限：表达能力受线性边界限制，对复杂交互和非线性关系不足。

提升非线性能力的方式：

1. 加入多项式或交叉特征；
2. 使用核方法；
3. 使用树模型或神经网络；
4. 先用非线性编码器提取 embedding，再接线性分类头。

多模态中常见“冻结 CLIP/VLM 编码器 + 线性 probe”：它是在测试表示质量，而不是重新训练整个模型。

## 七、高频面试题

### Q1：逻辑回归为什么叫回归？

它回归的是 log-odds 或线性 score，再通过 Sigmoid 映射为概率；最终用于分类，所以名字中的“回归”指函数形式，不是任务输出必须是连续值。

### Q2：逻辑回归的损失为什么不用 MSE？

交叉熵来自 Bernoulli 最大似然，概率解释直接；在 Sigmoid 与交叉熵组合下，logit 梯度是 $p-y$，优化通常更稳定。MSE 并非不能用，但梯度可能受 Sigmoid 饱和影响。

### Q3：L1 为什么能产生稀疏解？

L1 在 0 点不可导，其等值线有尖角，最优点更容易落在坐标轴上；从几何上看，L1 约束区域与损失等高线相切于坐标轴的概率更高。

### Q4：多分类和多标签分类如何选激活函数？

互斥多分类用 Softmax，使各类别概率和为 1；多标签分类用每类独立 Sigmoid，因为多个标签可以同时为真。
