# 特征工程与数据预处理

## 一、特征工程的目标

特征工程把原始数据转换为更适合模型学习的表示。好的特征应当：

- 与目标相关但不包含目标泄漏；
- 在训练和线上推理时定义一致；
- 对噪声、尺度和缺失有明确处理；
- 能被模型有效使用，而不是只在训练集上有相关性。

传统机器学习依赖人工特征较多；深度学习和多模态模型会学习表示，但数据清洗、尺度、采样、去重和特征拼接仍然决定上限。

## 二、数值特征处理

### 2.1 标准化与归一化

Z-score 标准化：

$$x'_{j}=\frac{x_j-\mu_j}{\sigma_j}$$

Min-Max 归一化：

$$x'_j=\frac{x_j-\min(x_j)}{\max(x_j)-\min(x_j)}$$

标准化适合依赖距离、内积或梯度尺度的模型，如逻辑回归、K-Means、PCA、神经网络；树模型通常不敏感。归一化还可能专指向量 L2 归一化：

$$\tilde z=\frac{z}{\|z\|_2}$$

它与特征逐列缩放不是一回事。CLIP 图文检索通常对 embedding 做 L2 归一化后计算余弦相似度。

### 2.2 缺失值

常见策略：均值/中位数/众数填充、模型填充、增加 missing indicator、使用能处理缺失的树模型。填充值和缺失指示器必须只在训练集拟合，线上缺失机制变化时要监控。

“缺失完全随机”与“缺失本身携带业务信号”处理不同，不能一律删行；删行还可能加剧类别不均衡。

### 2.3 异常值

先确认异常值是测量错误、脏数据还是有价值的极端样本。可用分位数截断、IQR、RobustScaler、对数变换或业务规则处理。异常检测任务中的异常样本不能未经分析就当作脏数据删除。

## 三、类别与文本特征

| 特征类型 | 常见编码 | 注意点 |
|---|---|---|
| 无序类别 | One-hot、目标编码、Embedding | 目标编码必须在训练折内计算 |
| 有序类别 | 序数编码 | 编码数字间距不一定有真实意义 |
| 高基数 ID | Hash、频次、Embedding | 直接 one-hot 维度爆炸且易记忆身份 |
| 文本 | TF-IDF、BM25、预训练 embedding | 词表/IDF 只用训练集拟合 |
| 图像 | 统计特征、CNN/ViT embedding | 预处理与模型训练设定必须一致 |

TF-IDF 的直觉是提高稀有但有区分度的词权重：

$$TFIDF(t,d)=TF(t,d)\times\log\frac{N}{DF(t)+1}$$

在当前多模态项目中，文本通常由 tokenizer 或 text encoder 处理，但商品标题清洗、OCR 文本拼接和截断策略仍属于特征工程。

## 四、特征选择

- **过滤式**：相关系数、互信息、卡方、方差过滤；速度快，但不考虑最终模型；
- **包裹式**：递归特征消除、逐步选择，效果可能好但成本高；
- **嵌入式**：L1、树模型重要性、注意力或门控，训练过程中完成选择。

选择特征的评估必须在训练折内完成。若先在全数据按标签相关性筛选，再做交叉验证，验证折信息已经泄漏。

相关系数低不等于特征无用：非线性关系可能相关系数接近 0；相关系数高也不等于因果关系。

## 五、Pipeline 与线上一致性

推荐把预处理与模型封装为同一条 pipeline：

```text
原始输入
  → 清洗与校验
  → 训练集 fit 的变换
  → 模型推理
  → 阈值/后处理
  → 结构化输出
```

需要记录：训练数据版本、词表/类别映射、均值方差、embedding 模型版本、阈值和后处理规则。模型升级时这些工件必须一起版本化。

## 六、多模态特征融合

常见融合方式：

- **早期融合**：拼接图像、文本、OCR 的特征后统一建模；表达交互强，但维度和缺失处理复杂；
- **中期融合**：通过 cross-attention、projector 或 gated fusion 交互；适合学习跨模态关系；
- **晚期融合**：分别预测再加权、投票或用树模型/MLP 融合；可解释、便于灰度和降级。

融合前要确认各路分数的尺度、方向和校准。不能直接把 cosine similarity、OCR 置信度和概率相加，除非先在验证集上做缩放或学习权重。

## 七、高频面试题

### Q1：为什么标准化必须在切分之后做？

均值和方差是从数据估计的统计量。若用全量数据计算，就把验证/测试分布信息带入训练流程；正确做法是在训练集 fit，再固定参数变换其他集合。

### Q2：树模型为什么通常不需要标准化？

树通过特征阈值切分，单调缩放不会改变样本排序和可选切分顺序；距离和梯度尺度不是其核心机制。但缺失、异常和类别编码仍需处理。

### Q3：多路分数如何融合？

先统一分数含义和尺度，再在验证集学习加权、逻辑回归或树模型融合器，并按场景分层评估。上线后监控各路分数漂移，避免某个模型版本变化破坏固定权重。
