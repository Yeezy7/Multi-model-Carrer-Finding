# 机器学习基础学习地图：笔试与面试高频考点

## 一、这套笔记解决什么问题

机器学习基础不是多模态岗位的旁支。图文匹配、跨模态检索、异常检测、VLM 评测，本质上都在反复使用以下能力：

> **定义任务 → 构造数据 → 学习表示或决策函数 → 选择损失与指标 → 分析泛化和错误 → 调整阈值或系统。**

本目录只保留三类知识：笔试能计算、面试能解释、项目能落地。已有的深度学习和大模型专题不重复讲，而是在对应位置建立连接。

## 四、面试回答模板

遇到“某算法是什么”时，按下面五句话组织：

1. **任务**：它解决分类、回归、排序、聚类还是异常检测？
2. **目标**：优化什么损失或距离？
3. **机制**：参数/树/中心/表示如何更新？
4. **取舍**：复杂度、数据要求、优点和失败模式是什么？
5. **场景**：在图像、文本或多模态项目中为什么选它？

不要只背公式。至少能用一个小例子解释公式中每个量的含义，并能说出一个错误分析和一个改进方案。

## 五、阶段性自测

- [ ] 能区分训练误差、泛化误差、验证集误差和测试集误差。
- [ ] 能从混淆矩阵推导 Precision、Recall、F1，并解释 ROC-AUC 与 PR-AUC 的差异。
- [ ] 能手推一次线性回归梯度、逻辑回归梯度和 K-Means 更新。
- [ ] 能比较 Bagging、Boosting、随机森林、GBDT 和 XGBoost。
- [ ] 能解释 L1 为什么产生稀疏、PCA 为什么保留最大方差。
- [ ] 能说明 CLIP 的 InfoNCE 与传统度量学习的关系。
- [ ] 能针对类别不平衡、数据泄漏、过拟合和阈值不合适提出排查路径。
- [ ] 能把一个多模态任务拆成数据、表示、决策、评测和部署五层。
