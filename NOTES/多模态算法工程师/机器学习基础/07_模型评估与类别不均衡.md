# 模型评估与类别不均衡

## 一、混淆矩阵

二分类的四种结果：

| | 真实正类 | 真实负类 |
|---|---:|---:|
| 预测正类 | TP | FP |
| 预测负类 | FN | TN |

基础指标：

$$Precision=\frac{TP}{TP+FP}$$

$$Recall=\frac{TP}{TP+FN}$$

$$F1=\frac{2PR}{P+R}$$

$$Accuracy=\frac{TP+TN}{TP+TN+FP+FN}$$

Precision 回答“预测为正的样本有多少是真的”，Recall 回答“真实正样本有多少被找回”。F1 是调和平均，只有 P、R 都高时才高。

## 二、ROC-AUC 与 PR-AUC

改变分类阈值，得到：

$$TPR=Recall, \qquad FPR=\frac{FP}{FP+TN}$$

ROC 曲线画 TPR-FPR，AUC 表示随机抽一个正样本和一个负样本时，正样本得分更高的概率。它衡量排序能力，不代表某个固定阈值下的 Precision/Recall。

PR 曲线画 Precision-Recall，在正类稀少时更能反映正类识别质量。异常检测、内容审核、缺陷召回通常应重点看 PR-AUC、Recall 和业务误报成本，不能只报 Accuracy 或 ROC-AUC。

## 三、阈值选择

默认 0.5 只是概率输出的一个切分点，不是最优业务阈值。阈值应在独立验证集上依据目标选择：

- 最大化 F1 或 F$\beta$；
- 固定 Recall 后最大化 Precision；
- 固定误报率后最大化召回；
- 最小化期望代价：$Risk(t)=C_{FP}P(FP|t)+C_{FN}P(FN|t)$。

确定阈值后要锁定，再到测试集只报告一次。生产中还要监控分数分布漂移和阈值后的真实反馈。

## 四、多分类与多标签指标

- **Macro average**：每个类别先算指标，再等权平均，关注小类；
- **Micro average**：先汇总所有 TP/FP/FN，再计算，受大类影响；
- **Weighted average**：按各类样本数加权。

互斥多分类常用 Softmax 和 top-1/top-k accuracy；多标签任务每个标签独立判断，应分别统计每类和整体指标。不要把多分类平均策略混用后再比较模型。

## 五、概率校准

一个模型若在所有预测概率约为 0.8 的样本中只有约 80% 正确，则称为校准良好。常用指标 ECE 把置信度分桶，比较每桶平均置信度与准确率：

$$ECE=\sum_{m=1}^{M}\frac{|B_m|}{n}|acc(B_m)-conf(B_m)|$$

温度缩放只调一个温度参数，通常在验证集上改善校准而不改变排序。VLM 的“置信度”常不是严格概率，结构化输出与人工审核系统不要直接把生成概率当业务置信度。

## 六、类别不均衡

类别比例悬殊时，模型可能通过全判多数类取得高 Accuracy，却完全找不到少数类。

### 6.1 数据层方法

- 随机过采样少数类；
- 随机欠采样多数类；
- SMOTE 等合成样本方法（高维 embedding 上需谨慎）；
- 分层采样、按实体去重、难例挖掘。

### 6.2 算法层方法

- 类别权重：$L=\sum_i w_{y_i}\ell_i$；
- Focal Loss：降低容易样本权重；
- 调整决策阈值；
- 使用代价敏感学习或两阶段级联。

采样只应发生在训练集；验证和测试集要保留真实分布，否则指标会偏离线上。

## 七、选择指标的原则

| 场景 | 优先指标 | 原因 |
|---|---|---|
| 商品图文一致性 | F1、分类型 Recall/Precision | 误判和漏判都重要，且错误类型不同 |
| 工业缺陷检测 | image AUROC、pixel AUROC、PRO、Recall | 既看图级异常，也看定位质量 |
| 图文/视频检索 | Recall@K、mAP、MRR | 关注正确结果是否出现在前 K |
| 内容审核 | 关键违规类 Recall、误伤率、PR-AUC | 漏审成本和误伤成本不对称 |
| 生成式 VLM | 任务准确率、事实一致性、人工/模型评审 | BLEU/ROUGE 不能覆盖视觉事实错误 |

异常检测的专项指标可参考 [多模态评测与幻觉](../算法论文基础/13_多模态评测与幻觉.md)。

## 八、高频面试题

### Q1：Accuracy 很高但模型没用，为什么？

可能是类别极不平衡，模型只预测多数类。应查看混淆矩阵，报告少数类 Precision/Recall/F1、PR-AUC，并根据业务代价调阈值或使用重采样/类别权重。

### Q2：ROC-AUC 很高，线上效果仍差，可能是什么？

AUC 只衡量全阈值范围的排序，不保证业务阈值处的 Precision/Recall；也可能存在分布漂移、类别比例变化、数据泄漏或线上标签延迟。应看 PR 曲线、固定阈值指标和分层数据。

### Q3：Precision 和 Recall 如何取舍？

取决于错误代价。漏掉高风险违规或安全缺陷时优先 Recall；人工审核成本高或误伤用户代价大时提高 Precision。最终应在验证集用成本函数或约束条件选阈值。

## 九、自测 checklist

- [ ] 能从混淆矩阵计算 Precision、Recall、F1 和 Specificity。
- [ ] 能解释 ROC-AUC、PR-AUC 和固定阈值指标的区别。
- [ ] 能给出类别不平衡的至少三种处理方式及数据泄漏风险。
- [ ] 能为内容审核和工业质检分别选择合理指标。
- [ ] 能解释为什么模型排序能力好不等于概率校准好。
