# 对比学习与 CLIP：图文对齐的范式奠基

## 一、对比学习（Contrastive Learning）总览

### 1.1 核心思想

对比学习是自监督/多模态预训练的基石。一句话：

> **让"语义相近的样本"在特征空间中靠近，让"语义不同的样本"远离。**

对比学习不预测标签（判别式），也不重建内容（生成式），而是学习一个**度量空间**：样本在空间中的距离 = 语义距离。

### 1.2 三种范式对比

| 范式 | 目标 | 代表 | 优缺点 |
|------|------|------|--------|
| 生成式 | 重建输入（像素/文本） | MAE、GPT | 学到细粒度结构，但目标与语义不完全一致 |
| 判别式 | 预测标签 | ResNet | 需要标注，难扩展 |
| **对比式** | 拉近正样本、推远负样本 | SimCLR、MoCo、**CLIP/SigLIP** | 无需标注、学语义特征，是跨模态对齐的最佳范式 |

### 1.3 对比学习的核心要素

| 要素 | 说明 |
|------|------|
| 正样本对（Positive） | 语义相同的一对样本（同一张图的两个增强视图 / 图文对） |
| 负样本对（Negative） | 语义不同的样本对（batch 内其他样本） |
| 编码器 | 把样本映射到特征空间（可共享或独立） |
| 相似度函数 | 通常是余弦相似度 / L2 归一化内积 |
| 损失函数 | InfoNCE、NCE、Triplet、**Sigmoid Loss** |

### 1.4 负样本的数量决定质量

对比学习的性能**几乎完全取决于负样本的数量和质量**：
- batch 内负样本（in-batch negatives）：最常用，但受 batch size 限制；
- memory bank（MoCo）：维护一个特征队列，提供大量负样本；
- hard negatives：难分负样本（如同类别不同个体），质量更高。

## 二、InfoNCE 损失：对比学习的标准形式

### 2.1 定义

给定一个 batch 的 N 个样本（含正样本对和 N-1 个负样本），InfoNCE 把问题转化为 **N 分类问题**：

$$\mathcal{L}_i = -\log \frac{\exp(s_{i,i}/\tau)}{\sum_{j=1}^{N} \exp(s_{i,j}/\tau)}$$

- $s_{i,j}$：样本 i 和 j 的相似度（余弦相似度）；
- $\tau$：温度参数；
- 分子：正样本对的相似度；
- 分母：正样本 + 所有负样本的相似度之和。

### 2.2 数学直觉

InfoNCE 等价于：**在 N 个候选中找出唯一正确样本的分类任务**。

$$\mathcal{L}_i = -\log p_i, \quad p_i = \text{softmax}_j(s_{i,j}/\tau)$$

最小化 loss = 最大化正样本被正确选出的概率 = 正样本相似度尽量大、负样本相似度尽量小。

### 2.3 与交叉熵的关系

$$\mathcal{L}_{InfoNCE} = \text{CrossEntropyLoss}(s/\tau,\ y=正样本索引)$$

即：把相似度矩阵按行做 softmax（除以温度），用正样本索引作为标签，就是标准的交叉熵。**CLIP 用的就是这一形式**（只是图像→文本和文本→图像两个方向各算一次取平均）。

### 2.4 梯度分析（为什么负样本重要）

对相似度 $s_{i,j}$ 的梯度：

$$\frac{\partial \mathcal{L}_i}{\partial s_{i,j}} = \begin{cases} p_{i,j} - 1 & j = i \text{（正样本）} \\ p_{i,j} & j \neq i \text{（负样本）} \end{cases}$$

- 正样本：梯度为负 → 相似度增大方向更新；
- 负样本：梯度为正 → 相似度减小方向更新；
- **负样本越多，分母越大，正样本被"孤立"得越彻底，特征区分度越高**。

> 这就是 CLIP 必须用超大 batch（32K+）的原因：batch 越大，负样本越多，学到的东西越细。

## 三、温度参数 τ（Temperature）

### 3.1 作用

$$\text{softmax}(s_{ij}/\tau)$$

| τ 取值 | softmax 分布 | 效果 |
|--------|-------------|------|
| τ 小（如 0.01） | 尖锐（接近 one-hot） | 梯度集中在最相似的负样本上，对困难负样本敏感 |
| τ 大（如 1.0） | 平滑 | 所有负样本梯度接近均匀，区分度弱 |

### 3.2 物理含义

- 温度决定"对比的力度"：τ 小 = 必须把正样本推到极强地高于所有负样本；
- τ 过大：梯度均匀分散，正负样本区分不充分；
- τ 过小：梯度只集中在 top-1 最相似的负样本（hard negative），可能导致不稳定。

### 3.3 可学习温度

很多实现把温度作为**可学习参数**：

```python
logit_scale = nn.Parameter(torch.ones([]) * 2.6592)   # 初始值 ln(1/0.07)
logits = similarities * logit_scale.exp()             # 训练中自动调整缩放
```

CLIP 论文用固定 τ=0.07（即 scale ≈ 14.28）；SigLIP 等项目用可学习温度 + 可学习偏置（见 05_SigLIP）。

## 四、CLIP：对比学习在多模态的里程碑

### 4.1 论文信息

> Learning Transferable Visual Models From Natural Language Supervision — OpenAI, ICML 2021（WIT-400M 图文对）

### 4.2 核心思想

> **用 4 亿个"图像-文本对"作为监督信号，学一个图文共享的特征空间。**

CLIP 不要求人工标注（不需要 label），互联网上天然的图片+alt text 就是训练数据。训练好后：
- 图像和文本被编码到**同一语义空间**；
- 余弦相似度反映图文匹配程度；
- 因此可以做 **zero-shot 分类**（见 4.6）。

### 4.3 架构

```text
图像 ──→ Image Encoder（ViT）──→ 图像特征 I_i (D 维)
                                        │   L2 归一化
                                        ▼
                                  s_ij = I_i · T_j
                                        │
文本 ──→ Text Encoder（Transformer）──→ 文本特征 T_j (D 维)
```

两个编码器：
- **Image Encoder**：ViT（或 ResNet）；
- **Text Encoder**：Transformer（双向注意力，类似 BERT，但只有 12 层，63M 参数，比图像塔小得多）。

### 4.4 训练目标：对称 InfoNCE

对 batch 内 N 对图文，计算相似度矩阵 $S \in \mathbb{R}^{N \times N}$，两个方向分别做对比损失再平均：

$$\mathcal{L} = \frac{1}{2N} \left[ \sum_{i=1}^{N} -\log \frac{e^{s_{ii}/\tau}}{\sum_j e^{s_{ij}/\tau}} + \sum_{j=1}^{N} -\log \frac{e^{s_{jj}/\tau}}{\sum_j e^{s_{ji}/\tau}} \right]$$

- 第一项：图像 i 要从 N 个文本中找出自己的文本（text→image direction 的反向）；
- 第二项：文本 j 要从 N 张图中找出自己的图；
- 对称性让图像和文本的地位平等。

### 4.5 训练细节

| 配置 | 值 |
|------|-----|
| 数据 | WIT-400M 图文对 |
| Batch size | 32768（超大，关键！） |
| 优化器 | AdamW，warmup 1 epoch |
| 学习率 | 余弦衰减 |
| 混合精度 | FP16 |
| 温度 | 固定 0.07 或可学习（论文固定） |
| 文本长度 | 最多 76 token（截断） |

### 4.6 Zero-shot 分类（核心能力）

分类任务不需要任何训练样本：

```text
输入图像
  ↓
候选类别文本: "a photo of a dog" / "a photo of a cat" / ...
  ↓
计算图像与每个文本的相似度
  ↓
取相似度最高的类别 = 预测结果
```

**为什么能 zero-shot？** 因为训练时学到的语义空间是"语言驱动的"——模型见过"a photo of a {任何词}"这类通用描述，类别词只是该空间的点。遇到新类别时，把类别名填进模板，相似度即任务解决。

**prompt 模板的作用**：直接裸用类别名（"dog"）效果差，用模板（"a photo of a {class}"）效果好。原因是训练数据几乎都是完整句子，模型更适应句子形态的文本；模板还给了模型上下文（photo 场景）。

### 4.7 prompt ensemble（多模板集成）

用多个模板（"a photo of a ..."、"a picture of ..."）分别计算特征后取平均/融合，可以提升 zero-shot 准确率。这是 CLIP 零样本性能的重要工程技巧。

## 五、CLIP 的应用与扩展

### 5.1 典型下游任务

| 任务 | 做法 |
|------|------|
| Zero-shot 分类 | 候选文本 prompt + 相似度 argmax |
| 图文检索 | 图像特征 vs 文本特征，余弦相似度 Top-K |
| 图文匹配/一致性 | 相似度打分 + 阈值（项目一的核心） |
| 视觉特征提取 | 直接取图像 embedding 用于下游任务 |
| 检测/分割的开放词汇 | RegionCLIP、Grounding DINO 等用 CLIP 做开放词汇 |
| VLM 视觉塔 | LLaVA 早期、许多 VLM 直接用它做视觉编码器 |

### 5.2 CLIP 家族

| 模型 | 改进 |
|------|------|
| **SigLIP** | sigmoid loss，弱化 batch 依赖（见 05） |
| OpenCLIP | 开源复现，数据规模更大 |
| EVA-CLIP | 用图像预训练特征蒸馏 CLIP，更强 |
| CoCa | 对比 + 生成联合训练（caption + contrastive） |
| BLIP/BLIP-2 | 对比 + 匹配 + 生成多目标（见 06/07） |

### 5.3 CLIP 的局限（面试必讲）

| 局限 | 说明 | 缓解 |
|------|------|------|
| 细粒度能力差 | 对"数量、位置、颜色组合"等细节不敏感 | 加 VLM 复核、region 级对比 |
| 计数/空间关系弱 | "三个苹果"、"左边还是右边"经常失败 | 更高分辨率、多尺度过 |
| 幻觉式匹配 | 相似度高不代表语义一致（如品牌相似） | 阈值 + 规则 + VLM 校验 |
| 对 prompt 敏感 | 模板好坏影响巨大 | prompt ensemble、微调 |
| 视觉编码分辨率受限 | 224 输入丢细节 | 更高分辨率（384/448）、动态分辨率 |
| 易被对抗样本欺骗 | 相似度打分对扰动敏感 | 输入校验、多模型融合 |

> 正是这些局限催生了"CLIP 相似度 + VLM 图文理解 + 规则/模型融合"的混合方案（项目一）以及 SigLIP 等改进。

## 六、CLIP 代码实现（训练级理解）

### 6.1 核心前向与损失（伪代码）

```python
import torch
import torch.nn.functional as F

def clip_loss(image_features, text_features, logit_scale):
    # 1. L2 归一化（保证余弦相似度 ∈ [-1, 1]）
    image_features = F.normalize(image_features, dim=-1)
    text_features = F.normalize(text_features, dim=-1)

    # 2. 相似度矩阵（温度缩放）
    logits = logit_scale * image_features @ text_features.t()   # [N, N]

    # 3. 标签 = 对角线（第 i 张图配第 i 个文本）
    labels = torch.arange(logits.shape[0], device=logits.device)

    # 4. 双向交叉熵（对称 InfoNCE）
    loss_i2t = F.cross_entropy(logits, labels)       # 图像找文本
    loss_t2i = F.cross_entropy(logits.t(), labels)   # 文本找图像
    return (loss_i2t + loss_t2i) / 2
```

### 6.2 为什么必须先 L2 归一化

1. 归一化后内积 = 余弦相似度，范围 [-1,1]，与温度缩放配合稳定；
2. 消除特征模长影响：只关心"方向"（语义），不关心"尺度"；
3. 让特征落在单位球面上，方便统一距离度量。

### 6.3 对比：SigLIP 的损失差异（预告）

| | CLIP | SigLIP |
|--|------|--------|
| 损失 | softmax 交叉熵（行内归一化） | 逐对 sigmoid 二分类（无归一化） |
| 标签 | 每行 1 个正样本（argmax 任务） | 每个 pair 独立 0/1 |
| batch 依赖 | 强（32K+） | 弱（4K 即可） |
| 数学形式 | N 选 1 | N² 个独立判断 |

## 七、对比学习与其他概念的联系

### 7.1 对比学习 vs 度量学习（Triplet）

| | Triplet Loss | InfoNCE |
|--|--------------|---------|
| 形式 | 锚点-正-负 三元组 | batch 内 N 选 1 |
| 负样本数 | 固定 1 个 | N-1 个 |
| 相对优势 | 简单直观 | 负样本多、效果好、易实现 |

### 7.2 对比学习 vs 生成式（MAE/GPT）

- 生成式：目标 = 重建，学到"结构"（像素/词的分布）；
- 对比式：目标 = 区分，学到"语义"（哪些样本相似）；
- 语义任务是下游任务（分类/检索/对齐）直接需要的，所以对比学习在多模态里是主力。

### 7.3 对比学习在微调中的用法

1. **图文对齐微调**（项目一）：用商品图文对数据，继续训练 CLIP/SigLIP，让特征对齐电商域语义；
2. **hard negative 构造**：把"同商品不同图"或"相似描述不同商品"作为难负样本，显著提升判别力；
3. **蒸馏**：用大 CLIP 指导小 CLIP，压缩部署。

## 八、高频面试问答

**Q1：CLIP 为什么能 zero-shot 分类？**
训练学到的共享空间是"语言语义空间"，类别词通过模板变成文本特征，图像特征与哪个文本特征最接近就属于哪类。分类任务被转化为"检索"任务，不需要任何训练样本。

**Q2：CLIP 为什么需要大 batch？**
InfoNCE 的负样本全部来自 batch 内部，batch 越大负样本越多，对比越充分，学到特征越有区分度。CLIP 论文显示 batch 32768 明显优于 256。这也是 SigLIP 出现的原因之一。

**Q3：温度参数 τ 的作用？**
控制 softmax 的尖锐程度。τ 小 → 集中在最相似的负样本上（hard negative 意识强），τ 大 → 均匀分布（区分度弱）。τ 通常设为 0.07 或可学习。

**Q4：对比学习和度量学习的关系？**
对比学习是度量学习的进阶：Triplet 只有 1 个负样本，InfoNCE 有 N-1 个负样本，负样本数量和质量决定了特征区分度。两者核心都是"正近负远"。

**Q5：CLIP 的局限？怎么缓解？**
细粒度（数量、空间、颜色组合）差、prompt 敏感、分辨率受限。缓解：更高分辨率、VLM 复核、规则融合、区域级对比、多 prompt 集成。

**Q6：图像特征和文本特征为什么要归一化？**
让内积等价于余弦相似度、消除模长干扰、限定范围保证与温度缩放配合稳定、统一距离度量。

**Q7：CLIP 的文本编码器为什么比图像编码器小？**
文本信息密度高（token 少、语义明确），小模型足够；图像信息冗余大，需要更大模型提取。同时省显存、省算力。

**Q8：对称 InfoNCE 为什么要算两个方向？**
图像找文本 + 文本找图像，保证两个模态地位对等、特征空间对称。只用单向会导致另一个模态特征退化。

**Q9：对比学习正负样本怎么构造？**
图文对：batch 内对角线为正、其余为负；单模态自监督：同一图像的两个增强视图为正。难负样本（hard negative）可以通过语义相似检索构造，显著提升效果。

**Q10：CLIP 做图文一致性判断有什么坑？**
相似度高≠语义一致：品牌相似、颜色相近、物体同类别都会高分。需要阈值校准 + 错误样本分析 + VLM 复核 + 多模态规则融合（项目一的核心思路）。
