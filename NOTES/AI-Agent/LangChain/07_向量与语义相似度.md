# 向量与语义相似度

## 一、余弦相似度

### 1.1 核心概念

余弦相似度衡量两个向量在方向上的相似程度，值域为 [-1, 1]：

| 值 | 含义 |
|----|------|
| 1 | 方向完全一致（夹角 0°） |
| 0 | 方向正交无关（夹角 90°） |
| -1 | 方向完全相反（夹角 180°） |

**核心思想：** 只关注方向是否一致，不受向量长度影响。

### 1.2 数学公式

```
cos_sim = (A · B) / (||A|| × ||B||)
```

拆解为三步：
1. **点积：** 对应位置元素相乘后求和
2. **模长：** 各元素平方和开平方根
3. **归一化：** 点积除以模长乘积

### 1.3 直观理解

向量 A = [0.5, 0.5]，向量 B = [0.7, 0.7]：
- B 的每个维度都是 A 的 1.4 倍（长度不同）
- 但方向完全一致（比值相同）
- 余弦相似度 = 1.0

这就是余弦相似度"剔除长度影响"的含义——它关注的是维度间的比例关系，而非绝对值。

## 二、嵌入向量与语义

### 2.1 嵌入模型的作用

嵌入模型将文本映射到高维向量空间：
- **相似的文本** → 向量方向接近（余弦相似度高）
- **不相关的文本** → 向量方向差异大（余弦相似度低）
- 这种"语义 → 向量"的映射是通过大量语料训练得到的

### 2.2 嵌入模型的两个核心方法

| 方法 | 输入 | 输出 | 用途 |
|------|------|------|------|
| `embed_query(text)` | 单条短文本（查询） | 单个向量 | 将用户查询转为向量 |
| `embed_documents(texts)` | 多条文本（文档库） | 向量列表 | 将文档批量转为向量 |

### 2.3 在 RAG 中的应用

RAG（检索增强生成）利用向量相似度实现语义检索：

```
用户查询 → embed_query → 查询向量
                                ↓
文档库 → embed_documents → 文档向量 → 余弦相似度排序 → Top-K 文档
```

核心流程：
1. 所有文档预先通过嵌入模型转为向量并存储
2. 用户查询到来时，将查询转为向量
3. 计算查询向量与所有文档向量的余弦相似度
4. 返回相似度最高的 Top-K 文档作为上下文
5. 将检索到的文档 + 用户问题一起送入 LLM 生成回答

### 2.4 补充：其他距离度量

| 度量方式 | 公式 | 特点 |
|----------|------|------|
| 余弦相似度 | cos(A, B) | 关注方向，忽略长度 |
| 欧氏距离 | \|A - B\|² | 关注绝对距离 |
| 点积 | A · B | 未归一化，受长度影响 |

在文本嵌入中，余弦相似度是最常用的度量方式。
